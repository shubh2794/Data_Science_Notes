Agent Skills

A skill is a reusable, packaged capability an agent can pull off the shelf — a tool, a procedure, or a bundle of instructions and resources — and compose with others to get work done.

Agentic AI Composition Tools

01 What a skill is

  • A skill packages a capability the agent can invoke by name — from a single tool (e.g. search) to a multi-step procedure with its own instructions and helper files.
  • It's the unit of reuse and extension: add a skill and the agent can do something new, without retraining.
  • Think "give the agent a new ability" rather than "write a longer prompt."
One sentence: a skill is a named, reusable capability the agent selects and composes on demand.

02 Anatomy of a skill

PartRole
NameHow the agent refers to it
DescriptionWhat it does & when to use it — the key to selection
Inputs / schemaArguments the agent must supply
Procedure / bodyThe tool call(s), code, or instructions it runs
ResourcesFiles, templates, or sub-tools it bundles

A plain tool is the simplest skill (one function). Richer skills wrap multiple steps and their own guidance.

03 Selecting the right skill

  • The agent matches the task to a skill mainly via its description — so good descriptions are as important as the code.
  • With a handful of skills, list them all in context. With hundreds, retrieve the relevant few first (skill selection becomes a retrieval problem — see RAG).
  • Progressive disclosure: show the agent a short skill index, and load a skill's full details only when it's chosen — saving context budget.

05 Authoring skills

  • Write for selection: a crisp description of what and when beats a clever implementation the agent never picks.
  • Keep them focused: one clear capability per skill composes better than a do-everything mega-skill.
  • Add a skill when a capability is reused, error-prone to improvise, or needs bundled resources — otherwise a plain tool or prompt suffices.

06 Scaling to many skills

  • More skills = more power, but also a harder selection problem and more context to manage.
  • Mitigations: retrieval over a skill index, categorization, and progressive disclosure of details.
  • Shared skill libraries let many agents reuse the same vetted capabilities.

07 Takeaways

  • A skill is a named, reusable capability — from a single tool to a multi-step procedure with resources.
  • Description drives selection; write it for when-to-use, not just how-it-works.
  • Compose skills into sequences to solve real tasks.
  • At scale, selection becomes retrieval; use progressive disclosure to save context.
  • Extends agents; selection builds on retrieval and context engineering.
