Agentic RL

Preference optimization aligns a single response. Agentic RL trains the model over whole multi-step trajectories — sequences of reasoning and tool calls — rewarding it for outcomes it actually achieves, not just answers humans prefer.

Agentic AI Reinforcement Learning Tool use

01 From single answers to trajectories

  • RLHF/DPO optimize one response against a preference. But an agent takes many steps — search, compute, act — before it succeeds or fails.
  • Agentic RL optimizes the policy over the full trajectory: which actions, in which order, lead to success.
  • The reward often comes at the end (task solved or not), so the model must learn which steps mattered — a credit-assignment problem.
One sentence: reinforce the agent's behaviour over multi-step rollouts, rewarding trajectories that achieve the goal.

02 The RL framing

state s_t = context so far action a_t = next token / tool call trajectory τ = (s₀,a₀, s₁,a₁, …) return R(τ) = Σ_t γ^t r_t
  • The LLM is the policy π_θ(a|s) — at each step it samples the next action (a token or a tool invocation).
  • A rollout runs the policy in the environment (tools, code, web) to produce a trajectory and a return.
  • Training nudges π_θ to make high-return trajectories more likely. See Reinforcement Learning for the foundations.

03 Where the reward comes from

  • Verifiable outcomes (RLVR): for math, code, and games you can check correctness automatically — a clean, un-hackable reward. This powers modern reasoning models.
  • Outcome vs process rewards: reward only the final result, or score intermediate steps (process reward models) to give denser signal.
  • Sparsity: a single end-of-trajectory reward is informative but sparse — long tasks make credit assignment hard.

04 Learning from rollouts

Sample many trajectories, keep what works, push the policy toward it. "Train" and watch the success rate climb.

Reinforce successful rollouts Each training step makes successful trajectories more likely

Algorithms like PPO and GRPO do exactly this: estimate how much better than average each trajectory was (advantage) and increase the probability of the better ones — GRPO uses the group of sampled rollouts as its own baseline, skipping a separate value model.

05 Credit assignment

  • With reward only at the end, which of 20 steps deserves credit? Advantage estimation and discounting spread the signal back over the trajectory.
  • Process reward models score steps individually, giving denser feedback and better long-horizon learning.
  • The longer the horizon, the harder this gets — a core difficulty of agentic training.

06 Challenges

  • Reward hacking: the agent games an imperfect reward (e.g. passes a weak test without solving the task) — verifiable rewards help.
  • Exploration: it must try diverse strategies, not collapse onto one mediocre routine.
  • Cost: rollouts mean running the full agent (and its tools) thousands of times.
  • Stability: long trajectories + sparse rewards make training noisy.

07 Takeaways

  • Agentic RL trains over trajectories, not single responses — rewarding goal achievement across many steps.
  • The LLM is the policy; rollouts in an environment produce returns that shape it.
  • Verifiable rewards (RLVR) give clean signal; process rewards densify it.
  • PPO / GRPO raise the probability of higher-advantage trajectories.
  • Credit assignment, exploration, cost, and reward hacking are the hard parts.
  • Combines RL, agents, and preference optimization.
