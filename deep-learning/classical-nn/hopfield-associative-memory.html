Classical Neural Networks · part 2 of 10

Hopfield Networks & Associative Memory

A computer's memory is looked up by address: give it a location and it hands back what is stored there. A brain seems to work the other way round. A smell, a half-heard phrase or three notes of a song bring back the whole memory; the content is the key. A Hopfield network is the simplest machine that does this. It is one layer of binary units, all connected to each other with symmetric weights, and it stores patterns with a one-line Hebbian rule, W = ∑ ξξᵀ. It recalls a pattern by letting the units flip one at a time until nothing changes. The central fact is that this flipping always goes downhill on an energy function. Each stored pattern becomes a valley, a corrupted cue is a point on the valley's slope, and recall is the state rolling to the bottom. The same picture explains how the network fails. It forms valleys nobody asked for (spurious states), and once more than about 0.138·N patterns are stored, the valleys merge into mush. The page then covers the pseudo-inverse rule, the bidirectional associative memory, the continuous network behind the Hopfield–Tank optimization work, and the modern Hopfield network, whose one-step update turns out to be exactly the softmax attention of a transformer.

01 Content-addressable memory

An associative (content-addressable) memory stores a set of patterns and, given any input, returns the stored pattern that best matches it. The input may be a noisy copy, a fragment, or a pattern with some bits unknown. The memory does not search a list. Its dynamics are built so that the stored patterns are the only places the state can come to rest, and the nearest one is where it usually ends up.

There are two flavours. An auto-associative memory maps a pattern to itself: a corrupted "A" comes back as a clean "A". This is pattern completion and error correction. A hetero-associative memory maps one pattern to a different one: a face to a name, an English word to a French word. The Hopfield network is the classic auto-associator. The linear associator (§02) and the BAM (§11) are the classic hetero-associators.

The historical line runs from correlation-matrix memories (Steinbuch's Lernmatrix, 1961; Willshaw, 1969; Anderson and Kohonen, independently, 1972) to Hopfield's 1982 paper. That paper added feedback and symmetric weights, and with them an energy function borrowed from the physics of spin glasses, magnetic materials whose atoms each point up or down. That link is why the ±1 units on this page are often called spins, and why the capacity result in §09 came from statistical physics.

Why this belongs in a deep-learning library. Hopfield networks are not used to store images today. The ideas are everywhere, though. Energy and attractor dynamics lead straight to Boltzmann machines (part 3) and from there to modern energy-based and score-based models. The recurrent, settle-to-a-fixed-point view of computation reappears in recurrent networks. And §13 shows that a transformer's attention layer performs one update step of a modern Hopfield network.

02 The linear associator: memory as an outer product

Start without feedback or non-linearity. We want a matrix W that maps each input key xᵏ ∈ ℝⁿ to its output yᵏ ∈ ℝᵐ. The simplest candidate adds up one outer product per pair. That rule is Hebbian: the weight from input j to output i grows when the two are active together.

storage — one outer product per pairW = ∑ₖ yᵏ xᵏᵀ (an m × n matrix; Wᵢⱼ = ∑ₖ yᵢᵏ xⱼᵏ) recall of the l-th keyW xˡ = yˡ (xˡᵀxˡ) + ∑ₖ≠ₗ yᵏ (xᵏᵀxˡ) └── signal ──┘ └──────── crosstalk ────────┘ perfect recallif the keys are orthonormal (xᵏᵀxˡ = δₖₗ), the crosstalk vanishes and W xˡ = yˡ exactly the least-squares fix for non-orthogonal keys (optimal linear associative memory)W = Y X⁺ X = [x¹ … xᴾ], Y = [y¹ … yᴾ], X⁺ = (XᵀX)⁻¹Xᵀ the pseudo-inverse

Worked numbers. Take two orthonormal keys in ℝ⁴, x¹ = ½(1, 1, −1, −1) and x² = ½(1, −1, 1, −1), with targets y¹ = (1, 0) and y² = (0, 1). Then W = y¹x¹ᵀ + y²x²ᵀ has rows ½(1, 1, −1, −1) and ½(1, −1, 1, −1). W x¹ = (x¹·x¹, x²·x¹) = (1, 0) = y¹, and the recall is exact. Now add a third key x³ = ½(1, 1, 1, 1). It is orthogonal to both, so it stores cleanly too. A fourth orthonormal key is still possible, but a fifth is not, because ℝ⁴ holds at most four orthogonal directions. Any further key overlaps the others, and every overlap xᵏᵀxˡ leaks a scaled copy of yᵏ into the answer. That leakage is crosstalk. The whole capacity story of this page is the study of that one term.

  • Why it is only a memory in a weak sense. The linear associator is a single matrix multiply, so a noisy key gives a noisy answer. Noise in x passes straight through to Wx. It interpolates, and nothing pulls the output towards a stored y.
  • What fixes that. A non-linearity that snaps each output to ±1, plus feedback so the snapped output can be fed back and cleaned up again. For auto-association (y = x), that combination is the Hopfield network.
  • The modern echo. A key–value attention lookup is also "weights from keys, read out values". The difference is that attention replaces the raw inner product with a softmax over inner products. §13 shows that this one change is what turns crosstalk from a hard limit into an exponentially small nuisance.

03 The discrete Hopfield network

N binary units, every unit connected to every other, symmetric weights, no self-connections. Each unit repeatedly sets itself to the sign of its input. There are no separate input and output layers. The cue is written into the units as the initial state, and the answer is read from the same units once they stop changing.

states = (s₁, …, s_N), sᵢ ∈ {−1, +1} (the "bipolar" or spin coding; §04 says why not 0/1) local field of unit ihᵢ = ∑ⱼ wᵢⱼ sⱼ − θᵢ update rulesᵢ ← sgn(hᵢ) with the convention: if hᵢ = 0, leave sᵢ unchanged the two structural conditions the energy argument needswᵢⱼ = wⱼᵢ (symmetric) wᵢᵢ = 0 (no self-coupling) a stored pattern must be a fixed pointsgn(hᵢ(ξ)) = ξᵢ for every i, i.e. ξᵢ hᵢ(ξ) > 0

Geometrically the state is a corner of the N-dimensional hypercube {−1, +1}ᴺ. Each update moves the state along one edge or leaves it where it is. A pattern is "stored" if its corner is a fixed point, a corner where every unit already agrees with its field. It is stored usefully if the corners around it lead back to it. That neighbourhood is its basin of attraction.

The thresholds θᵢ are usually zero for memories. They do matter for optimisation problems (§12), where they carry the linear terms of a cost function. Setting θ = 0 and using ±1 units makes the network symmetric under s → −s. That symmetry is why the reversed patterns in §08 are stored for free.

04 Hebbian storage: W = ∑ ξξᵀ with a zero diagonal

To store P patterns ξ¹ … ξᴾ, set each weight to the correlation between its two units across the patterns. Units that usually agree get a positive weight and pull each other the same way. Units that usually disagree get a negative weight and push each other apart. This is Hebb's postulate, "cells that fire together wire together", applied once to the whole training set instead of learned incrementally.

Why a stored pattern is (usually) a fixed point. Put the network in state ξ¹ and compute a field. The sum splits into the pattern itself plus everything else:

signal + crosstalkhᵢ(ξ¹) = ∑ⱼ≠ᵢ wᵢⱼ ξⱼ¹ = ((N−1)/N) ξᵢ¹ + (1/N) ∑ᵤ≠₁ ξᵢᵘ ∑ⱼ≠ᵢ ξⱼᵘ ξⱼ¹ └─ signal ─┘ └──────────── crosstalk ────────────┘ bit i of ξ¹ is stable when the crosstalk does not overturn the signalξᵢ¹ hᵢ(ξ¹) > 0

The inner sum ∑ⱼ ξⱼᵘξⱼ¹ is N times the overlap between patterns u and 1. For random patterns each overlap is about ±√N, so the crosstalk is a sum of P−1 random terms of size about 1/√N. That noise grows like √(P/N), and §09 turns the sentence "the signal must beat it" into the capacity limit.

Worked numbers, N = 4. Store the single pattern ξ = (1, −1, 1, −1), unnormalised for readability, so wᵢⱼ = ξᵢξⱼ for i ≠ j. That gives w₁₂ = −1, w₁₃ = +1, w₁₄ = −1, w₂₃ = −1, w₂₄ = +1, w₃₄ = −1. Corrupt bit 2 to get s = (1, 1, 1, −1). Its field is h₂ = w₂₁s₁ + w₂₃s₃ + w₂₄s₄ = (−1)(1) + (−1)(1) + (1)(−1) = −3, so s₂ ← −1 and the pattern is repaired in one flip. §06 follows the energy through the same flip.

05 Asynchronous versus synchronous updating

The update rule says what one unit does. It does not say when. The choice matters. Asynchronous updating, one unit at a time in random or fixed order, always converges to a fixed point. Synchronous updating, every unit at once from the old state, can instead fall into a two-state oscillation and never settle.

asynchronous (Hopfield's choice)pick i; sᵢ ← sgn(∑ⱼ wᵢⱼ sⱼ − θᵢ); repeat. Every other unit keeps its value during the step. synchronous (Little's model, 1974)s(t+1) = sgn(W s(t) − θ) all N units computed from the same old state the smallest counterexample: two units, w₁₂ = w₂₁ = +1, start at s = (+1, −1)sync: h = (−1, +1) → s = (−1, +1) → h = (+1, −1) → s = (+1, −1) → … a 2-cycle, forever async: update unit 1: h₁ = s₂ = −1 → s = (−1, −1); now h = (−1, −1) agrees with s → fixed point what can be proved for the synchronous case (symmetric W)the state always ends in a fixed point or a cycle of length 2, never a longer one

The two units above each "want" to copy the other. Updated together, they swap values forever. Updated in turn, the second one simply agrees with the first. Synchronous dynamics are not useless: they parallelise perfectly, and on hardware they are the natural choice. But the Lyapunov argument of §06 is built on single flips. The synchronous case needs a different function of two consecutive states, and that function allows the period-2 orbit.

06 The energy function, and why asynchronous updates never increase it

Every state of a symmetric, zero-diagonal network has an energy E(s). No asynchronous update ever raises it, and every update that flips a unit strictly lowers it. Because the states are finite and the energy is bounded below, the network must reach a fixed point in a finite number of flips. This is Hopfield's 1982 insight. It turns "does the dynamics converge?" into "a ball rolling downhill must stop".

the energy (a Lyapunov function for the dynamics)E(s) = −½ ∑ᵢ ∑ⱼ wᵢⱼ sᵢ sⱼ + ∑ᵢ θᵢ sᵢ = −½ sᵀWs + θᵀs single out unit k (use wₖₖ = 0 and wᵢₖ = wₖᵢ to gather both halves of the double sum)E(s) = −sₖ (∑ⱼ≠ₖ wₖⱼ sⱼ − θₖ) + (terms not involving sₖ) = −sₖ hₖ + const flip sₖ → sₖ′; only the first term changesΔE = −(sₖ′ − sₖ) hₖ = −Δsₖ · hₖ the update sets sₖ′ = sgn(hₖ), so Δsₖ is 0 or has the sign of hₖΔsₖ = 0 ⇒ ΔE = 0 Δsₖ = ±2 = 2 sgn(hₖ) ⇒ ΔE = −2 |hₖ| < 0 (a flip only happens when hₖ ≠ 0, by the tie convention) bounded belowE(s) ≥ −½ ∑ᵢⱼ |wᵢⱼ| − ∑ᵢ |θᵢ|, and there are only 2ᴺ states conclusiona strictly decreasing sequence on a finite set must stop: every asynchronous run ends at a fixed point

Where each assumption was used. Symmetry was used to combine wₖⱼsₖsⱼ and wⱼₖsⱼsₖ into the single field hₖ. With asymmetric weights, no energy function exists in general, and the dynamics can cycle or wander. Zero diagonal kept sₖ out of its own field. A negative self-weight can make a flip raise the energy and lets a single unit oscillate. A positive self-weight keeps the descent but makes flips harder, which adds stable states. One unit at a time is what let us hold every other sⱼ fixed while computing ΔE. That is why §05's synchronous 2-cycle does not contradict the theorem.

Worked numbers. Go back to §04's four-unit example. In the corrupted state s = (1, 1, 1, −1), the six pair terms wᵢⱼsᵢsⱼ are (−1, +1, +1, −1, −1, +1). Their sum is 0, so E = −0 = 0. After the flip, s = ξ and every pair term equals (ξᵢξⱼ)² = 1, so E = −6. The formula agrees: ΔE = −Δs₂·h₂ = −(−2)(−3) = −6.

Stored patterns and their energies. For one pattern with the 1/N scaling, E(ξ) = −(N−1)/2 ≈ −N/2. With P random patterns, E(ξᵘ) ≈ −N/2 plus crosstalk corrections. In general, E(s) ≈ −(N/2) ∑ᵤ mᵤ², where mᵤ = (1/N) ξᵘ·s is the overlap with pattern u. The energy is literally minus the sum of squared overlaps. The state is pulled towards whichever patterns it already resembles, which is exactly the content-addressable behaviour we wanted.

07 Attractors and basins of attraction

Each fixed point is an attractor. Its basin is the set of start states that end there. The ideal memory has exactly 2P attractors, the patterns and their negatives, with basins that split the hypercube evenly. A real Hebbian network has many more attractors, and part of the hypercube drains into states that were never stored.

For a network small enough, we can simply count. The figure below takes N = 16 units, so there are 2¹⁶ = 65 536 states. It stores P random 4 × 4 patterns, runs asynchronous sweeps (in a fixed unit order, so the answer is deterministic) from every state, and tallies where each one ends. Basin sizes depend on the update order. Which states are fixed points does not.

Attractor census: where all 65 536 states of a 16-unit network come to rest P = 1 gives two perfect halves; watch mixtures and other spurious attractors appear by P = 3–4
  • P = 1: exactly two attractors, ξ and −ξ, each draining half the hypercube. Every state lands on whichever of the two it overlaps more. This is the ideal case.
  • P = 2–3: the stored patterns and their negatives still take most of the volume, but mixture states appear, with smaller basins and higher energy.
  • P ≥ 4 at N = 16: this is already α = 0.25, well past the 0.138 limit of §09. Mixtures often drain a third to a half of the hypercube, and for some draws "other" spurious attractors take most of it, while the stored patterns keep a shrinking share. Tiny networks are noisy versions of the large-N theory, and results vary a lot between draws (press new patterns), but the trend is the one the theory predicts.
  • The energy path between two stored patterns rises and then falls. That barrier is what keeps a cue near ξ¹ from sliding to ξ². Flip bits in a different order and the barrier height changes, but a barrier is always there when both endpoints are minima.

08 Spurious states: reversed patterns, mixtures, spin-glass states

A Hebbian network stores more than it was asked to. Three families of extra attractors are always present, and each one follows directly from the form of W.

1 · reversed patterns — a symmetry, not a bugE(−s) = E(s) when θ = 0, and sgn(W(−ξ)) = −sgn(Wξ); so if ξ is a fixed point, so is −ξ 2 · odd mixturesξᵐⁱˣ = sgn(±ξᵃ ± ξᵇ ± ξᶜ) is a fixed point for large N and small P each component overlaps it by m = ½; energy ≈ −(N/2)·3·(½)² = −3N/8, above the −N/2 of a stored pattern why only odd mixturesan even number of ±1 terms can sum to zero, which leaves sgn undefined on those bits 3 · spin-glass statesminima uncorrelated with every stored pattern; they appear at high load and dominate beyond α ≈ 0.138

Why a 3-mixture is stable. Take s = sgn(ξᵃ + ξᵇ + ξᶜ). On each bit, at least two of the three patterns agree with s. So s overlaps each of them by ½ on average: on the ¾ of bits where a given pattern agrees with the majority it contributes +1, and on the other ¼ it contributes −1. The field is hᵢ ≈ ½(ξᵢᵃ + ξᵢᵇ + ξᵢᶜ). On a bit where all three agree, that is ±3/2, and on a 2-to-1 bit it is ±½. In both cases it has the same sign as sᵢ. So the mixture is a fixed point, but a shallower one. Its energy −3N/8 lies above the stored patterns' −N/2, and its basin is smaller.

Mixtures are not always harmful. They are the network "generalising" to something that shares features with several memories, which is why they reappear as metastable states in modern Hopfield networks (§13). Three remedies make them less of a problem in a classical network. Noise: stochastic units at a small temperature can climb out of the shallow mixture minima but not out of the deep pattern minima. That idea becomes the Boltzmann machine in part 3. Unlearning (Hopfield, Feinstein and Palmer, 1983): relax from random states and apply a small anti-Hebbian step at whatever spurious state is reached. This is a precursor of the Boltzmann machine's negative phase. Better storage rules such as the pseudo-inverse (§10).

A phase diagram in one paragraph. The replica analysis of Amit, Gutfreund and Sompolinsky (1985) found the following at zero temperature and large N. For α = P/N below about 0.05, the stored patterns are the global energy minima. Between 0.05 and 0.138 they are still minima but only local ones: spin-glass states sit lower, although retrieval from a reasonable cue still works. Above α꜀ ≈ 0.138 the retrieval states vanish altogether. Mixture states are the first casualties of noise, and at finite temperature they lose stability before the pure patterns do.

09 Capacity: crosstalk, the error function and 0.138·N

How many random patterns can N units hold? Treat the crosstalk of §04 as Gaussian noise and ask how often it overturns the signal. That gives a closed-form bit-error rate. The famous limit P ≈ 0.138·N is the load at which that small initial error rate snowballs into a total loss of the memory.

Why the limit is 0.138 and not "where P_err gets large". The one-step formula only checks bits at the exact stored pattern. But the first few unstable bits flip. Each flip changes every field, so the crosstalk grows and more bits become unstable. Below α꜀ this cascade stops at a state close to ξ, a few percent of bits wrong. Above α꜀ it becomes an avalanche and the state wanders far from ξ. The transition is sharp, a genuine phase transition in the large-N limit. That is why the lower panel below falls off a cliff instead of declining gently.

Capacity sweep: bit errors and retrieval quality as patterns are added Hebbian collapses near α ≈ 0.14; the pseudo-inverse survives far longer; correlated (biased) patterns wreck Hebbian storage early
  • Correlated patterns are the practical killer. The Gaussian argument assumes random, unbiased patterns. Real data such as letters, images or sparse codes are correlated, and their overlaps are O(N) instead of O(√N). The crosstalk then no longer averages away, and all patterns get dragged towards their common mean. The bias slider shows the Hebbian limit collapsing well below 0.138. For sparse patterns with a fraction a of active units, the right fix is a covariance rule, wᵢⱼ ∝ ∑(ξᵢ − a)(ξⱼ − a), whose capacity grows to order N/(a|ln a|), far more than 0.138·N when a is small.
  • The capacity is linear in N, but the weights are N². A Hopfield net uses N(N−1)/2 real weights to store about 0.14·N² bits. That is roughly 0.28 bits per weight, which is poor compared with the 2 bits per weight that the best possible (Gardner) storage of random patterns allows. The modern networks of §13 escape this by changing the energy, not the weights.

10 The pseudo-inverse (projection) rule

The Hebbian rule ignores how the patterns overlap one another. The pseudo-inverse rule takes the overlaps into account. It chooses W as the orthogonal projection onto the span of the patterns. Every pattern is then an exact fixed point, with zero crosstalk, as long as the patterns are linearly independent. It is the auto-associative version of the optimal linear associator from §02.

the rule (Personnaz, Guyon and Dreyfus, 1985; Kanter and Sompolinsky, 1987)W = Ξ (ΞᵀΞ)⁻¹ Ξᵀ Ξ = [ξ¹ … ξᴾ] (N × P); Q = ΞᵀΞ/N is the P × P overlap matrix why every pattern is exactly storedW ξᵘ = Ξ (ΞᵀΞ)⁻¹ Ξᵀ Ξ eᵤ = Ξ eᵤ = ξᵘ (a projection leaves its own subspace unchanged) zeroing the diagonal keeps that, as long as wᵢᵢ < 1hᵢ(ξᵘ) = ξᵢᵘ − wᵢᵢ ξᵢᵘ = (1 − wᵢᵢ) ξᵢᵘ, and 0 ≤ wᵢᵢ ≤ 1 with mean wᵢᵢ = P/N Hebbian is the special casefor exactly orthogonal patterns, ΞᵀΞ = N·I and W = (1/N) ∑ ξᵘξᵘᵀ capacityevery pattern stable for any P < N linearly independent patterns — but the basins shrink to nothing as P/N → 1; useful error correction up to roughly α ≈ 0.5
  • Cost. The rule is not local. Every weight depends on every pattern through (ΞᵀΞ)⁻¹, so it cannot be computed by a synapse that only sees its two units. It can be learned iteratively, though: ΔW = η (ξ − Wξ) ξᵀ is the delta rule of part 1 applied to auto-association, and it converges to the projection.
  • A middle ground. Storkey's rule (1997) is incremental and local, and it corrects part of the crosstalk. Its capacity is about N/√(2 ln N) under the "all bits stable" criterion, compared with Hebbian's N/(2 ln N).
  • A different road. Treat each unit as a perceptron that must output ξᵢᵘ given the other bits, and train it with a margin. This is Gardner's approach, and it reaches the theoretical maximum of 2N random patterns.

11 Bidirectional associative memory (BAM)

Kosko's BAM (1988) is the hetero-associative Hopfield network. It has two layers, X with n units and Y with m units, joined by one matrix used in both directions. A cue on either side bounces back and forth, X → Y → X → Y, until the pair stops changing. Kosko called this state resonance. The stored pairs are the resonant states.

storage — Hebbian over the pairsW = ∑ₖ yᵏ xᵏᵀ (m × n; bipolar x ∈ {±1}ⁿ, y ∈ {±1}ᵐ) recall — alternate the two directions, all units of a layer at oncey ← sgn(W x) x ← sgn(Wᵀ y) (ties keep the previous value) energyE(x, y) = −yᵀ W x (plus threshold terms if used) why it convergeswith x held fixed, y ← sgn(Wx) minimises −yᵀ(Wx) over y; with y held fixed, x ← sgn(Wᵀy) minimises −(Wᵀy)ᵀx each half-step is a block coordinate descent on a bounded function over a finite set ⇒ resonance in finitely many steps

There is no 2-cycle problem here, even though each layer updates synchronously. The units within a layer are not connected to each other, so updating them together is exactly the same as updating them one at a time. The layers alternate, and the energy argument of §06 goes through for each block. The same trick (bipartite graph, update a whole side at once) reappears in the RBM's block Gibbs sampler. Capacity is again limited by crosstalk. The practical number of reliably stored pairs is well below min(n, m) for Hebbian storage, and encoding tricks (augmenting with a constant unit, multiple training) raise it.

12 The continuous Hopfield network and optimisation (TSP)

Hopfield (1984) replaced the sign units with graded, sigmoid units driven by leaky-integrator dynamics, which is a model of an analogue electronic circuit. The state now moves through the inside of the hypercube, and an energy function still decreases along every trajectory. Hopfield and Tank (1985) then turned the argument around. Given a combinatorial problem, write its cost as a Hopfield energy, build the net, and let it roll downhill to a good solution.

Expanding that energy and matching it term by term against −½vᵀWv − Iᵀv gives the weights and biases directly. The constraint terms become inhibition between units in the same row and in the same column, and the distance term becomes inhibition between cities that are far apart and would be neighbours in the tour. The 1985 paper reported good tours for 10 and 30 cities, and it sparked a decade of work on "neural optimisation".

The sober verdict. Wilson and Pawley (1988) could not reproduce the results reliably. With the published constants, most runs even on 10 cities gave invalid tours, and the valid ones were mediocre. The penalty weights A–D trade feasibility against tour length, and they have to be tuned per instance. Gradient descent on a non-convex energy finds a local minimum, not the best one. The method survives in two useful forms. One is gain annealing: start at low λ, where the landscape has a single smooth minimum, and raise λ slowly so the state commits gradually. This is the deterministic cousin of simulated annealing. The other is mean-field relaxations in general. Dedicated solvers and, today, learned heuristics on graph networks beat it by a wide margin.

13 Modern (dense) Hopfield networks, and why their update is attention

The classical energy −½∑ᵤ(ξᵘ·s)² is quadratic in the overlaps. That quadratic form is why the crosstalk from P patterns adds up linearly and limits capacity to O(N). Make the energy sharper, so that each pattern's contribution grows much faster than quadratically with its overlap, and the best-matching pattern dominates everything else. The capacity then grows polynomially, and then exponentially, in N. Take the sharpest smooth version, a log-sum-exp, allow continuous states, and the update rule that falls out is precisely softmax attention.

What the update does. It scores every stored pattern by its dot product with the current state. The softmax turns the scores into weights that sum to one, and the new state is the weighted average of the stored patterns. When one pattern is clearly the best match, its weight is ≈ 1 and the average is that pattern. Ramsauer et al. show that when the patterns are well separated, a single update retrieves the pattern with an exponentially small error. Exponentially many patterns (in d) can be stored this way. The inverse temperature β sets the regime.

  • Large β: one pattern wins. The fixed point is a single stored pattern, and that is retrieval.
  • Small β: the weights are nearly uniform, and the fixed point is close to the mean of all patterns, a global average.
  • In between: patterns that are similar to each other share a metastable state, the average of a cluster. These are the modern descendants of §08's mixture states. Ramsauer et al. report that many heads of a trained BERT operate in the averaging or metastable regimes rather than retrieving single tokens, particularly in the lower layers.

That is the bridge to the rest of this library. A self-attention layer (Attention, Transformers) stores the current sequence's keys and values as its "patterns" and runs one retrieval step per query. Hopfield layers make the idea explicit and use it for pooling, for set lookups, and for memories of whole training sets, as in immune-repertoire classification. Seen from this side, the long-standing observation that attention can "copy" a token and can "average" a context is the retrieval and metastable regimes of an associative memory.

14 Practice, pitfalls and a cheat-sheet

  • Centre the data. Use ±1 coding. For biased patterns, store deviations from the mean (the covariance rule). Otherwise the common component turns into a giant attractor that swallows everything.
  • Stay well under the limit. For reliable error correction with Hebbian storage, keep P ≲ 0.1·N with random-like patterns, and far less with correlated ones. Use the pseudo-inverse rule when N is small and the patterns are fixed.
  • Use asynchronous updates if you want the convergence guarantee. With synchronous updates, check for a 2-cycle and break it.
  • Check the answer. The network always stops somewhere. Measure the overlap of the final state with every stored pattern and reject it if none is close. Spurious states look confident.
  • Reversed patterns. With θ = 0 the net cannot tell ξ from −ξ. Add a fixed bias unit, or read the answer up to sign.
  • Asymmetric weights (from biology, pruning or quantisation) remove the energy guarantee. Small asymmetry usually still converges. Large asymmetry gives cycles and chaos.

Takeaways. (1) Symmetric weights with a zero diagonal give an energy function, and asynchronous updates descend it, so recall is a ball rolling to the bottom of a valley. (2) Hebbian storage creates valleys at the patterns, at their negatives, and at odd mixtures, and past α ≈ 0.138 crosstalk sets off an avalanche that erases the memories. (3) Better storage (pseudo-inverse) buys capacity at the cost of locality. A sharper energy (log-sum-exp) buys exponential capacity, and its update rule is the attention mechanism. (4) Adding noise to the units, so that they sample instead of descend, turns this network into the Boltzmann machine in part 3.
