Radial Basis Function Networks

A multilayer perceptron builds its function out of global pieces: every hidden unit is a ridge that divides the whole input space in two, and the output is a delicate sum of many such cuts. A radial basis function (RBF) network builds it out of local pieces: every hidden unit is a bump centred somewhere in input space that responds only to inputs nearby, and the output is a weighted sum of bumps. That single change of hidden unit — distance to a centre instead of a dot product with a weight — reorganises how the network is trained. Once the centres and widths are fixed, the output is linear in the remaining weights, so the hardest part of training is an ordinary least-squares solve with a closed-form answer. This page builds the network from Cover's theorem (why a nonlinear lift helps at all), through exact interpolation and why it is numerically fragile, to regularization networks, the practical recipe (choose centres by clustering or forward selection, set widths by a heuristic, solve for the output weights), fully supervised gradient training, the contrast with the MLP, the GRNN and PNN, and finally the bridge to kernel machines, SVMs and Gaussian processes — which are, in a precise sense, RBF networks with a principled way of choosing everything.

01 The architecture: Gaussian hidden units, linear output

An RBF network has one hidden layer of M radial units — each computes a decreasing function of the distance between the input and its own centre — and a linear output layer that sums their responses. The hidden layer is a fixed-shape nonlinear feature map; the output layer is linear regression on those features. Introduced as a neural network by Broomhead & Lowe (1988) and Moody & Darken (1989), building on radial-basis interpolation from numerical analysis (Powell 1987).

  • A hidden unit is a template detector. φⱼ is 1 when the input equals the centre and decays with distance at a rate set by σⱼ; it answers "how much does x look like cⱼ?". An MLP unit answers "which side of this hyperplane is x on, and how far?" — a question about the whole space.
  • The network is a smooth, soft version of the competitive layer. Replace the hard winner of the previous part with graded responses and hang a linear readout off them and you have an RBF net; normalise the responses to sum to one and you have the GRNN of §11.
  • Two kinds of parameters, two kinds of problem. Centres and widths enter nonlinearly; output weights enter linearly. Every classical training recipe exploits this split (§07).
  • Universal approximation. With enough Gaussian units, RBF networks approximate any continuous function on a compact set arbitrarily well, even with a single shared width (Park & Sandberg 1991) — the same existence guarantee as the MLP, and just as silent about how many units you need.

02 Cover's theorem: why a nonlinear lift makes problems linear

Cover's theorem (1965): a pattern-classification problem cast nonlinearly into a high-dimensional space is more likely to be linearly separable than in a low-dimensional space. This is the justification for the RBF architecture — map the inputs through M nonlinear features, then solve a linear problem — and for every kernel method since.

The XOR example is remarkable because it needs no increase in dimension: two inputs become two features, yet the problem becomes separable, because the lift is nonlinear. Cover's theorem is the statistical statement (more dimensions, more separable dichotomies); the XOR lift is the geometric one (the right nonlinear features can fold the space so the classes come apart). The figure lets you break it: put a single centre at (0.5, 0.5) and all four points are the same distance from it, so they collapse to one feature value and no line can separate anything.

Shrink σ toward 0.15 and the class-B points slide toward the origin while the class-A points go to the axes' ends: the margin grows at first, then the class-A points' "other" coordinate also vanishes and everything piles up near the axes — still separable, but with every feature near zero for inputs not exactly on a centre, which is the over-local regime of §06. With the "mixed" centres one class-A point and one class-B point sit on centres and the lift is lopsided but still separable; with one centre, the four points map to a single number and separation is impossible.

03 Exact interpolation, and why it is ill-conditioned

The oldest use of radial basis functions is exact interpolation: put one centre on every training input, M = N, and solve Φw = t so the function passes through every target. For the Gaussian, Φ is always invertible when the inputs are distinct (Micchelli 1986) — but "invertible" and "safely invertible" are very different things, and the gap between them is set by the width.

  • Why wide bumps are ill-conditioned. When σ is large compared with the spacing, neighbouring columns of Φ are nearly identical — two bumps that overlap almost completely are almost the same feature — so Φ is nearly singular. The solver then builds the target out of huge positive and negative bumps that nearly cancel, which amplifies any noise in t.
  • Why narrow bumps overfit. When σ is small the matrix is near the identity and perfectly conditioned, but the interpolant is a row of spikes that returns to zero between data points: it fits the training set exactly and generalises terribly.
  • Why exact interpolation is the wrong goal anyway. With noisy targets, passing through every point means fitting the noise. The two fixes are the next two sections: add a penalty (regularization network), or use fewer centres than data points (the practical RBF net).
Conditioning versus width: exact interpolation of ten noisy points drag σ; the left curve is log₁₀ of the condition number, the right panel is the interpolant — then add λ and watch both calm down

At σ = 0.1 (about the spacing) the interpolant threads the points with κ ≈ 21 and modest weights. Push σ past 0.3 and κ passes 10⁷: the curve still goes through the points — the solver is exact in principle — but the faint bumps show weights in the hundreds or thousands with alternating signs, and between points the curve swings. By σ = 0.5 κ ≈ 6·10¹¹: the solve is still exact in principle, but a perturbation of one part in a million in the targets would already move the weights by a factor of order one — the fit is exact and meaningless. Now raise λ to 10⁻³: the condition number is capped at roughly (μ_max + λ)/λ, with μ_max the largest eigenvalue of Φ, the weights shrink by orders of magnitude, and the curve becomes smooth — no longer passing through each noisy point, which is the point.

04 Regularization networks

Poggio & Girosi (1990) showed that the RBF network is not an ad hoc architecture but the exact solution of a regularised function-fitting problem: minimise squared error plus a smoothness penalty, and the minimiser is a sum of Green's functions of the penalty, one centred on each data point. For a particular smoothness penalty that Green's function is the Gaussian.

Tikhonov functionalminimise over f: ∑ₙ (tₙ − f(xₙ))² + λ ‖P f‖² P = a differential operator measuring roughness representer form of the minimiserf(x) = ∑ₙ₌₁ᴺ wₙ G(x, xₙ) G = Green's function of P*P; a Gaussian for one specific infinite-order P the weights solve a shifted interpolation system(G + λ I) w = t G ∈ ℝᴺˣᴺ, Gₙₘ = G(xₙ, xₘ) what λ does to the fitted valuesGw = t − λw ⇒ residual at each training point is exactly λ wₙ worked (the three points of §03, 2σ² = 1)λ = 0: w = (−0.492, 1.362, −0.492), fit at x = 1 equals 1.000 λ = 0.1: w = (−0.383, 1.166, −0.383), fit at x = 1 = 1 − 0.1·1.166 = 0.883 λ = 1: w = (−0.098, 0.536, −0.098), fit at x = 1 = 1 − 0.536 = 0.464 conditioningκ(G + λI) = (μ_max + λ)/(μ_min + λ) ≤ (μ_max + λ)/λ — λ puts a floor under the smallest eigenvalue generalised RBF (fewer centres, M < N)f(x) = ∑ⱼ₌₁ᴹ wⱼ G(x, cⱼ), w = (ΦᵀΦ + λ G₀)⁻¹ Φᵀ t, G₀ = [G(cᵢ, cⱼ)] (or λI as a simple ridge)

This is the moment the RBF network stops being a heuristic. The number of centres (N), their positions (the data), the basis function (fixed by the smoothness prior) and the weights (a linear solve) all follow from one optimisation problem. What remains free is λ and σ, and those are exactly the hyperparameters of a kernel ridge regression or a Gaussian-process posterior mean (§12). The practical networks of the next sections are approximations to this solution that use M ≪ N centres to cut the O(N³) cost.

05 Choosing the centres: random, k-means, orthogonal least squares

With M < N centres, where they go matters more than anything else. Three standard answers, in increasing order of effort: pick M training inputs at random; run k-means on the inputs and use the centroids; or select centres greedily, one at a time, by how much each reduces the output error (orthogonal least squares). The first two look only at the inputs; the third also looks at the targets.

random subsetcⱼ = x_{π(j)}, π a random permutation; one shared width (e.g. §06) — cheap, fine when data are dense and M is generous k-means / competitive learning (Moody & Darken 1989)cⱼ = centroid of cluster j, σⱼ from the cluster's spread or its nearest centres — puts centres where the INPUT density is; the same prototype placement as the competitive layer of the previous part orthogonal least squares forward selection (Chen, Cowan & Grant 1991)candidates: pᵢ = column of φ(·; xᵢ, σ) evaluated on all N inputs, one candidate per training point step k: orthogonalise every remaining candidate against the chosen q₁ … q_{k−1}: vᵢ = pᵢ − ∑ⱼ (qⱼᵀpᵢ / qⱼᵀqⱼ) qⱼ error-reduction ratio: errᵢ = (vᵢᵀt)² / ( (vᵢᵀvᵢ)(tᵀt) ) — the fraction of tᵀt that candidate i explains choose i* = argmax errᵢ, set q_k = v_{i*}; stop when 1 − ∑ₖ err_k < ρ (the tolerance)
  • k-means is unsupervised, and that is both its virtue and its flaw. It is fast and stable and covers the input distribution, but it spends centres on regions where the target is flat as generously as on regions where it wiggles. For regression with a varying target, OLS typically needs noticeably fewer centres for the same error.
  • OLS is forward stepwise regression done efficiently: Gram–Schmidt makes the contribution of each new column independent of those already chosen, so the error reduction of a candidate can be computed without re-solving the whole least-squares problem. Cost is O(N²M) for N candidates and M selected.
  • Supervised clustering for classification — k-means within each class — puts centres near the class structure and tends to beat unsupervised k-means over all inputs when classes overlap in input density.

06 Width heuristics

The width decides how many centres "see" each input: too narrow and the network is a set of isolated spikes with gaps between them; too wide and the bumps are nearly identical, the design matrix is ill-conditioned, and the network can only represent smooth, low-frequency functions. Aim for each input to excite a few centres substantially.

global width from the spread of the centres (a common textbook rule)σ = d_max / √(2M) d_max = largest distance between any two centres equivalently φⱼ(x) = exp(−M ‖x − cⱼ‖² / d_max²) worked: M = 10 centres spread over [0, 1], d_max ≈ 1 ⇒ σ = 1/√20 = 0.224 p-nearest-neighbour rule (Moody & Darken), per centreσⱼ = √( (1/p) ∑_{i ∈ p nearest centres} ‖cⱼ − cᵢ‖² ), p ≈ 2 cluster-spread rule, per centreσⱼ = α · RMS distance of cluster j's members to cⱼ, α ≈ 1 … 2 "spread" as a half-response distanceφ = ½ at ‖x − c‖ = σ √(2 ln 2) = 1.177 σ — some toolkits parameterise the width by this distance rule of thumbthe width should exceed the typical distance between neighbouring inputs, but stay well below the extent of the whole input range

All of these are starting points; in practice σ (and λ) are tuned by validation error, or learned by gradient descent (§08). Per-centre widths help when the data density varies — a centre in a sparse region needs a wider bump to cover its territory — at the cost of more freedom to overfit.

07 Two-stage training and the closed-form output weights

The classical recipe trains an RBF network in two stages: stage 1 fixes the hidden layer (centres by §05, widths by §06) without looking at the output error; stage 2 solves for the output weights, which is linear least squares with a closed-form answer. Stage 2 is not an approximation or an iteration — it is the global optimum of the output weights given the hidden layer, found in one matrix solve.

Fitting a 1-D function: number of centres, width, placement and ridge the output weights are solved in closed form on every change; the faint curves are the individual wⱼφⱼ(x)

The defaults — ten grid centres, σ ≈ 0.08, almost no ridge — give a fit close to the true curve. Drop M to 3 and the network cannot bend enough (under-fitting: both errors high). Raise M to 40 with λ ≈ 0: the train error falls toward the noise floor and below it, the test error climbs, and the faint bumps grow large and alternate in sign. Now raise λ to about 10⁻² and the same 40 centres give a smooth fit again — the ridge is doing what the small M did, which is the whole argument of §04 in one slider. Compare centre placements at M = 6: OLS puts its centres where the target has structure and usually wins on test error; k-means spreads them by input density; random can leave a gap. The gradient button then moves centres and widths as well (§08): at M = 6 it pulls every placement down to roughly the same, lower test error — the centres migrate to where the target needs them — while at M = 10 there is little left to gain and it can even over-fit slightly, the usual price of a non-convex, unregularised optimisation.

08 Fully supervised gradient training

Nothing forbids treating centres and widths as ordinary parameters and training everything by gradient descent on the output error, exactly like an MLP. It usually lowers the error for a given M, because centres move to where the target needs them — but it gives up the convexity of the two-stage recipe, and widths can collapse or explode without care.

error and residualE = ½ ∑ₙ eₙ², eₙ = tₙ − y(xₙ), y(x) = ∑ⱼ wⱼ φⱼ(x) + w₀ gradients (Gaussian units)∂E/∂wⱼ = −∑ₙ eₙ φⱼ(xₙ) ∂E/∂cⱼ = −∑ₙ eₙ wⱼ φⱼ(xₙ) (xₙ − cⱼ) / σⱼ² ∂E/∂σⱼ = −∑ₙ eₙ wⱼ φⱼ(xₙ) ‖xₙ − cⱼ‖² / σⱼ³ practical choicesparameterise σⱼ = exp(sⱼ) so widths stay positive; initialise from the two-stage solution; use a smaller step for cⱼ, sⱼ than for wⱼ hybrid (a common compromise)each iteration: gradient step on (c, σ), then re-solve w in closed form — "variable projection"
  • The gradients are local. A centre only receives gradient from inputs within a few σ of it, because φⱼ(xₙ) vanishes elsewhere. That makes each update cheap but means a centre stranded far from the data never moves — the RBF version of the dead unit of the previous part.
  • Widths are the dangerous parameters. Shrinking σⱼ onto a single training point drives that point's error to zero, so unconstrained gradient descent on training error can collapse widths into spikes. Weight decay on w, a floor on σ, or early stopping on validation error prevent it.
  • Modern echo. A fully trained RBF layer is a differentiable layer like any other; RBF units appear as distance-based output layers for uncertainty-aware classifiers (e.g. DUQ, van Amersfoort et al. 2020) and as the radial expansion of interatomic distances in graph networks for molecules.

09 RBF networks for classification

For classification, give the network one output per class, train it by least squares on one-hot (or ±1) targets, and predict the class with the largest output. With enough data the outputs approximate the class posteriors, and the decision boundary is a level set of a sum of Gaussians — curved, closed around groups of centres, and naturally able to wrap one class inside another.

On "core vs ring" six k-means centres give a closed boundary around the core — something no single hyperplane, and no one-hidden-layer MLP with only two units, could draw. Drag the centre nearest the core out into the ring and watch the core's region shrink and the weights rebalance. Make σ tiny (0.03) and the output collapses to the bias everywhere except in small islands around each centre — accuracy drops because most points sit in the gaps. Make σ large (0.5) and all six bumps look alike; the weights balloon (see the bars) and the boundary becomes a smooth, almost quadratic curve — and with λ tiny it can begin to misbehave for the conditioning reasons of §03.

10 RBF versus MLP: local versus global

An MLP hidden unit responds over a half-space and an RBF unit over a ball; this one difference predicts most of the practical contrast between the two networks — in training speed, extrapolation, interference, and how they scale with input dimension.

Neither is "right" (the true function keeps oscillating), but only one of them tells you it is guessing. This locality is why distance-aware output layers resurface in modern uncertainty estimation.

11 GRNN and PNN: RBF networks with no training at all

Specht's general regression neural network (GRNN, 1991) and probabilistic neural network (PNN, 1990) put one Gaussian unit on every training example and replace the least-squares output layer with a normalised average — so "training" is storing the data, and the only parameter is σ. They are the Nadaraya–Watson kernel regressor and the Parzen-window Bayes classifier, drawn as networks.

Small σ makes the GRNN a staircase through every noisy point and the PNN a 1-nearest-neighbour classifier with many tiny decision islands; large σ flattens the GRNN to the mean and hands the PNN's decision to the majority class. The LOO curve on the right is U-shaped, and its minimum is a sensible σ found with no training loop. The price is paid at prediction time: every query touches every stored example, O(N) per prediction — the opposite trade to a trained RBF network with M ≪ N centres.

12 The bridge to kernel methods, SVMs and Gaussian processes

The Gaussian φ(x; c) = exp(−‖x − c‖²/2σ²) is also the Gaussian (RBF) kernel k(x, c). A function of the form ∑ⱼ wⱼ k(x, cⱼ) is therefore simultaneously an RBF network and a kernel expansion — and the kernel methods that followed are best understood as principled answers to the RBF network's open questions: which centres, how many, and how to regularise.

  • What each view contributes. The RBF network gives a compact model (M ≪ N) and fast prediction. Kernel ridge / GP give the exact regularised solution with all N centres and, for the GP, calibrated uncertainty, at O(N³) cost. The SVM gives sparsity chosen by the loss function. Sparse GPs with M "inducing points" close the circle: they are RBF networks whose centres are optimised as variational parameters.
  • The kernel trick is the regularization network's representer theorem, generalised: for any positive-definite kernel and any loss plus an RKHS-norm penalty, the minimiser is a finite sum of kernels at the data points. See Support Vector Machines — kernels for the Gaussian kernel's role there, and why its bandwidth plays exactly the part σ plays here.
  • And attention. Softmax attention with a query–key similarity is a normalised kernel smoother — the same form as the GRNN of §11, with learned keys in place of stored inputs. See Attention.

13 Practice, pitfalls and takeaways

  • Standardise inputs — one Euclidean distance mixes every feature, so unscaled features silently set the metric. For strongly anisotropic data use per-dimension widths (a diagonal Mahalanobis distance).
  • Always regularise the output solve. A small ridge λ costs almost nothing in fit and removes the conditioning cliff of §03; tune λ and σ jointly on validation data (or by GCV / LOO, which are cheap for linear smoothers).
  • Solve, don't invert: Cholesky on ΦᵀΦ + λI, or QR/SVD on Φ when λ is tiny.
  • Centres: k-means for a quick, robust start; OLS when the target varies unevenly and you want fewer units; per-class k-means for classification.
  • Mind the dimension. Above a dozen or so input dimensions pure RBF nets need prohibitively many units unless the data lie near a low-dimensional manifold; reduce dimension first or prefer an MLP / kernel machine.
  • Use the locality: the distance to the nearest centre (or ∑ⱼ φⱼ(x)) is a free out-of-distribution score — flag inputs where every unit is silent.
Takeaways. An RBF network is a layer of Gaussian bumps plus linear regression. Cover's theorem says a nonlinear lift makes classes separable; exact interpolation shows the lift must be regularised because wide bumps make the system ill-conditioned; Poggio & Girosi show the regularised solution is an RBF network. In practice: choose M ≪ N centres by k-means or OLS, set σ so a few bumps overlap each input, and solve the output weights in closed form with a ridge. RBF nets train fast, interfere little and extrapolate to their bias; they suffer in high dimensions. Their descendants — kernel ridge regression, GPs, Gaussian-kernel SVMs, random features — keep the same function class and choose the centres and regularisation in a principled way.
