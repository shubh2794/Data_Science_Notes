Self-Organizing Maps & Competitive Learning

Every network earlier in this series learns by being told something — a target, an error, a pattern to store. The networks on this page learn by competing. A layer of units looks at the same input, the unit whose weight vector is closest wins, and only the winner (or the winner and its neighbours) moves toward the input. Nothing else is needed: repeated over a data set, this one rule places the weight vectors where the data are, so the layer becomes a set of prototypes — a vector quantizer, and in the simplest case exactly online k-means. Kohonen's self-organizing map adds a single twist, a fixed lattice on which the units sit and a neighbourhood that drags the winner's lattice-neighbours along with it, and that twist makes the prototypes arrange themselves into a smooth, topology-preserving sheet laid over the data: a two-dimensional map of a high-dimensional space. From there the page covers how the map is scheduled (ordering, then convergence), how it is read (U-matrix, component planes, quantization and topographic error), the batch algorithm, the supervised cousin LVQ, the stability–plasticity problem that adaptive resonance theory was built to solve, and counter-propagation, which bolts a lookup table onto a competitive layer.

01 Competitive learning and winner-take-all

A competitive layer is a set of K units, each holding a weight vector wₖ in the input space; for each input x exactly one unit — the one whose weight is nearest — wins, and only the winner learns, by stepping a fraction of the way toward x. There is no target and no error signal. What the layer learns is where the inputs are: after enough steps each weight vector sits near the centre of mass of the inputs it wins, and the layer partitions the input space into K Voronoi cells, one per unit.

competition — find the winner (best-matching unit)c(x) = argminₖ ‖x − wₖ‖ the same competition with normalised vectors, as a dot productif ‖x‖ = ‖wₖ‖ = 1: ‖x − wₖ‖² = 2 − 2 wₖᵀx, so argminₖ ‖x − wₖ‖ = argmaxₖ wₖᵀx winner-take-all outputyₖ = 1 if k = c(x), yₖ = 0 otherwise standard competitive learning rule (only the winner moves)w_c ← w_c + η (x − w_c) wₖ unchanged for k ≠ c, 0 < η < 1 the same rule written for every unit at once (instar form)Δwₖ = η yₖ (x − wₖ) worked stepw_c = (0.2, 0.8), x = (0.6, 0.4), η = 0.5 ⇒ w_c ← (0.2, 0.8) + 0.5·(0.4, −0.4) = (0.4, 0.6) distance to x before: √(0.16 + 0.16) = 0.566; after: 0.283 — exactly (1 − η) of the old gap

Why the rule finds cluster centres

Fix the partition for a moment: unit k wins the set Sₖ of inputs. Averaged over that set the update is η(E[x | x ∈ Sₖ] − wₖ), which is zero only when wₖ is the centroid of its cell. So a converged competitive layer has every weight at the mean of the inputs it wins — the fixed-point condition of k-means (§03). Equivalently, the rule is stochastic gradient descent on the quantization error

the objective competitive learning descendsE(w₁ … w_K) = ½ E ‖x − w_c(x)‖² ∂/∂w_c of one sample's term = −(x − w_c) so w_c ← w_c + η (x − w_c) is one SGD step with step size η; the non-winners have zero gradient for that sample

The dot-product form is how the idea first appeared (von der Malsburg 1973; Grossberg 1976; Rumelhart & Zipser 1985): with inputs and weights kept on the unit sphere, "nearest" and "most strongly activated" coincide, and the winner can be found by lateral inhibition — every unit inhibits every other, so after a few iterations only the most active remains on. The Euclidean form is simpler to compute and needs no normalisation, and it is what every modern implementation uses. Hardware and early biological models used the inhibitory network; software uses argmin.

The step size is a memory length

With a constant η the weight is an exponential moving average of the inputs it has won: after the update w ← (1 − η)w + ηx, an input seen m wins ago carries weight η(1 − η)ᵐ. With η = 0.1 the effective memory is about 1/η = 10 wins — the unit keeps tracking recent data and never settles. With η = 1/n, where n counts that unit's wins, the weight is exactly the running mean of everything it has won and converges. Real schedules sit between: large η early so units can travel, small η late so they settle. That trade-off returns, sharpened, as the stability–plasticity dilemma in §11.

02 Dead units, and the conscience fixes

A unit that starts far from every input never wins, so it never moves, so it never wins: it is dead, and the layer effectively has fewer prototypes than you paid for. Winner-take-all has no mechanism that helps a loser. The fixes all do the same thing — make winning cost something — so frequent winners are handicapped and starved units get a chance.

conscience learning (DeSieno 1988) — track win frequency, bias the competitionpₖ ← pₖ + B (yₖ − pₖ) running win frequency, B ≈ 10⁻⁴ … 10⁻² bₖ = C (1/K − pₖ) positive for units that win less than their fair share 1/K c(x) = argminₖ ( ‖x − wₖ‖² − bₖ ) competition uses the biased distance; the update itself is unchanged frequency-sensitive competitive learning (Ahalt et al. 1990)c(x) = argminₖ nₖ · ‖x − wₖ‖² nₖ = number of wins so far — a busy unit looks further away leaky learning — losers move too, just much lessw_c ← w_c + η_w (x − w_c), wₖ ← wₖ + η_l (x − wₖ) for k ≠ c, η_l ≪ η_w worked numbers (conscience, K = 4, C = 1)unit A has won 70% of the time: b_A = 0.25 − 0.70 = −0.45 (its squared distance is inflated by 0.45) dead unit D has p_D = 0: b_D = 0.25 − 0 = +0.25 (its squared distance is reduced by 0.25) x at squared distance 0.30 from A and 0.50 from D: A scores 0.30 + 0.45 = 0.75, D scores 0.50 − 0.25 = 0.25 ⇒ D wins

Once the revived unit has moved into a region of data and starts winning its share, pₖ climbs toward 1/K and the bias falls back to zero — so the handicap switches itself off. The learning rate for the frequency estimate should be an order of magnitude or more below the weight learning rate, so pₖ is a stable average rather than a noisy one. A side effect worth knowing: conscience pushes every unit toward winning equally often, so dense regions of input space end up with more, smaller cells. That is equiprobable quantization, which is a different objective from minimum squared error; it is often what you want for coding, less so for finding cluster centres.

Competitive learning with dead units — and the conscience that revives them units start bunched in a corner; press run and compare the three rules

With the plain rule and the default six units, the unit nearest the data wins everything at first, walks into the nearest cluster, and the rest follow only if the boundary of their cell happens to reach some data. Typically two or three units end with a win share of zero (red bars) and the quantization error stalls well above what six prototypes could achieve. Switch to conscience and press reset/run: every unit is eventually pulled into the data, the win shares level out near 1/K, and the error drops. FSCL does the same through a different mechanism; leaky learning gets there by dragging every unit slowly toward the data mean, which also drags live units off their centroids.

03 Competitive learning is online k-means

With a per-unit step size η = 1/nₖ, the competitive learning rule is MacQueen's (1967) online k-means: each prototype is exactly the running mean of the inputs it has won. Batch k-means (Lloyd's algorithm) alternates the same two moves — assign every point to its nearest centre, move every centre to its cell's mean — over the whole data set at once. Both descend the same within-cluster squared error; see Clustering (k-Means) for the batch algorithm, k-means++ seeding and the choice of K.

running mean as a competitive updatenₖ ← nₖ + 1, wₖ ← wₖ + (1/nₖ)(x − wₖ) ⇒ wₖ = (x₁ + ⋯ + x_nₖ) / nₖ exactly worked, one dimensionunit wins x = 1, then 2, then 6: w = 1 → 1 + ½(2 − 1) = 1.5 → 1.5 + ⅓(6 − 1.5) = 3.0 = (1 + 2 + 6)/3 ✓ the shared objectiveJ = ∑ₙ ‖xₙ − w_c(xₙ)‖² (batch k-means: exact coordinate descent on J; online: stochastic gradient on J) convergence of the online version (Robbins–Monro conditions per unit)∑ₜ ηₖ(t) = ∞, ∑ₜ ηₖ(t)² < ∞ — satisfied by 1/nₖ, violated by any constant η
  • Same local minima. Both are greedy descents on a non-convex J; both can park two prototypes in one cluster and leave another cluster uncovered. The dead-unit problem of §02 is the online face of a bad k-means initialisation, and k-means++ seeding is its batch fix.
  • What the neural framing added. Streaming operation (no data set in memory), the conscience/frequency ideas, and — the big one — a neighbourhood, which turns k-means into the self-organizing map. Set the SOM's neighbourhood width to zero and it becomes online k-means again (§09).
  • Where it lives today. The codebook of a VQ-VAE (van den Oord et al. 2017) is a competitive layer: the encoder's output snaps to its nearest code vector, and the popular exponential-moving-average codebook update is precisely the constant-η competitive rule, with dead codes revived by re-seeding them at recent encoder outputs — a direct descendant of the conscience fix. See Autoencoders & VAEs.

04 The Kohonen self-organizing map

A self-organizing map (Kohonen 1982) places its units at fixed positions rᵢ on a low-dimensional lattice — usually a 2-D rectangular or hexagonal grid — and, when a unit wins, updates not just the winner but every unit, by an amount that falls off with lattice distance from the winner. Units that are neighbours on the grid are therefore always pulled toward the same inputs, so they end up with similar weight vectors: the grid is draped over the data like an elastic sheet, and nearby grid cells map to nearby regions of input space.

the ingredientsunits i = 1 … M, each with a lattice position rᵢ ∈ ℤ² (fixed) and a weight wᵢ ∈ ℝᵈ (learned) 1. best-matching unit (BMU)c(x) = argminᵢ ‖x − wᵢ‖ — a competition in INPUT space 2. neighbourhood function — a kernel on the LATTICEh_ci(t) = exp( −‖r_c − rᵢ‖² / 2σ(t)² ) (Gaussian; a "bubble" h = 1 inside radius σ, 0 outside, is the cheap variant) 3. update every unitwᵢ ← wᵢ + η(t) · h_ci(t) · (x − wᵢ) for all i worked neighbourhood weightsσ = 1: lattice distance 0 → 1, 1 → e^(−1/2) = 0.607, 2 → e^(−2) = 0.135, 3 → e^(−4.5) = 0.011 σ = 2: lattice distance 1 → e^(−1/8) = 0.882, 2 → e^(−1/2) = 0.607, 4 → e^(−2) = 0.135 the limitsσ → 0: h_ci = [i = c] ⇒ plain competitive learning / online k-means (§03) σ → ∞: h_ci = 1 for all i ⇒ every unit moves toward every input; the whole map collapses onto the data mean

Two distances are in play and it is essential not to confuse them. The competition uses distance in input space ‖x − wᵢ‖ — the data decide who wins. The cooperation uses distance on the lattice ‖r_c − rᵢ‖ — the fixed grid decides who learns with the winner. Everything the SOM does that k-means does not comes from this second, data-independent distance.

A SOM unfolding over 2-D data the grid starts as a tangle near the centre; play it and watch the ordering phase untangle it, then the convergence phase settle it

On the uniform square with the defaults, the first few hundred steps are chaos: σ ≈ 4 on a 10 × 10 grid means half the map moves with every winner, so the net contracts to a crumpled blob that then swings out as a whole. By about a quarter of the run the net has an orientation and no fold; after that σ keeps shrinking, the net spreads into the corners and the grid squares become nearly equal. Now set σ₀ = 0.5 and reset: the neighbourhood is too narrow to coordinate distant units, and the map typically freezes with a twist — a fold along a diagonal that the small late neighbourhood can never undo, which the topographic error reports as a large fraction. The 1-D chain on the square traces a space-filling, Peano-like curve; on the ring it wraps all the way round with its two ends meeting and a topographic error of a percent or two — a 1-D lattice matching 1-D data — whereas the 10 × 10 sheet on the same ring must fold, and its TE stays above 30%. Switch to batch to see the per-epoch algorithm of §09, which unfolds in far fewer (but costlier) updates.

05 Decaying σ(t) and η(t): the ordering and convergence phases

A SOM is trained in two phases that do different jobs: an ordering phase with a wide neighbourhood and a large step, which sets the global topology of the map, and a much longer convergence phase with a small neighbourhood and a small step, which fine-tunes each unit onto its local data. Both σ and η must shrink over time; the shape of the decay matters less than the two endpoints and the length of each phase.

exponential schedules (a common textbook choice)σ(t) = σ₀ · exp(−t/τ_σ), η(t) = η₀ · exp(−t/τ_η) pick the time constant so the neighbourhood reaches 1 at the end of orderingσ(T₁) = 1 ⇒ τ_σ = T₁ / ln σ₀ worked: a 10 × 10 map, ordering phase of T₁ = 1000 stepsσ₀ = 5 (half the map's width) ⇒ τ_σ = 1000 / ln 5 = 621 steps; σ(500) = 5·e^(−0.805) = 2.24, σ(1000) = 1.00 η₀ = 0.1, τ_η = 1000 ⇒ η(1000) = 0.1·e^(−1) = 0.037 linear / inverse-time alternativesσ(t) = σ₀ + (σ_end − σ₀)·t/T, η(t) = η₀ / (1 + t/τ) (inverse time satisfies the Robbins–Monro conditions) rules of thumb for the phases (Kohonen)ordering: about 1000 steps, η from ≈ 0.1 … 0.9 down to ≈ 0.02, σ from about half the map width down to 1 convergence: at least ≈ 500 × (number of units) steps, η ≈ 0.01 or less, σ held at about 1 (touching only nearest neighbours)
  • Why the neighbourhood must start wide. Ordering is a global decision — which corner of the lattice goes to which part of the data. Only a neighbourhood comparable to the map size couples the far ends of the lattice strongly enough to make that decision consistently. Start with σ₀ ≈ 1 and different parts of the map order themselves independently, and where two differently-oriented patches meet you get a fold or a twist that later, narrower neighbourhoods cannot undo.
  • Why it must end narrow. A wide neighbourhood pulls every unit toward the mean of a large region; the prototypes are smoothed together and the map under-covers the edges of the data (the "border effect" — the map shrinks inward). Shrinking σ lets each unit settle onto its own cell's data. Ending at σ → 0 recovers k-means exactly; most practice stops at σ ≈ 0.5–1 so the map stays smooth.
  • η is the ordinary stochastic-approximation step. It must decay for the weights to converge rather than jitter; the neighbourhood already weights the step, so the effective step size for unit i is η(t)·h_ci(t).
  • Initialisation changes how much ordering is needed. Random initialisation needs a genuine ordering phase. Linear initialisation — spread the grid over the plane of the first two principal components, scaled by their standard deviations — starts the map already ordered, so a short phase with modest σ suffices and results become reproducible. See PCA.
The neighbourhood kernel, and how σ and η shrink across the two phases drag the time slider; left shows who learns with the winner, right shows where you are in the schedule

At t = 0 with σ₀ = 5 nearly the whole 11 × 11 lattice is lit: every unit moves with the winner. At t = T₁ = 1000 the lit patch has shrunk to the winner, its four lattice neighbours at h = e^(−1/2) ≈ 0.61 and the four diagonal units at e^(−1) ≈ 0.37, and it stays that size through convergence while η keeps falling to its floor of 0.01. The Mexican hat (a difference of Gaussians) is the lateral-interaction profile of the original biological motivation — nearby units excite, a ring further out inhibits — and it shows why the Gaussian became standard: negative h pushes those units away from the input, which sharpens the map in theory and destabilises it in practice.

06 Topology preservation — what the map keeps and what it distorts

A well-trained SOM is (approximately) a topology-preserving map: units adjacent on the lattice have nearby weight vectors, and inputs close in data space have BMUs close on the lattice. It is a nonlinear, discrete projection of the data onto a 2-D grid — closer in spirit to PCA bent along the data than to clustering — but the preservation is approximate, one-directional in practice, and bought at a price in density.

the two directions of "neighbourhood-preserving"lattice → data: ‖rᵢ − rⱼ‖ small ⇒ ‖wᵢ − wⱼ‖ small (the neighbourhood update enforces this directly) data → lattice: ‖x − x′‖ small ⇒ ‖r_c(x) − r_c(x′)‖ small (fails where the data's intrinsic dimension exceeds the lattice's) magnification — unit density versus data density p(x), 1-D, continuum limitminimum-MSE quantizer / k-means: unit density ∝ p(x)^(1/3) 1-D SOM chain (Ritter & Schulten 1986): unit density ∝ p(x)^(2/3) equiprobable (conscience) quantizer: unit density ∝ p(x)^1 the energy-function caveatfor continuous data the online SOM rule is NOT the gradient of any energy (Erwin, Obermayer & Schulten 1992) a small change to the BMU rule — c(x) = argminᵢ ∑ⱼ h_ij ‖x − wⱼ‖² (Heskes 1999) — makes it the gradient of E = ½∑ₙ ∑ᵢ h_{c(xₙ)i} ‖xₙ − wᵢ‖²
  • Dimension mismatch produces folds. A 2-D sheet fitted to 3-D data that fill a volume cannot be a homeomorphism; the sheet folds back and forth to fill the volume, and two inputs close in space can land on distant units across a fold. The lattice → data direction still holds (the sheet is continuous); the data → lattice direction breaks. The topographic error of §08 measures exactly this.
  • Distances are not preserved, only neighbourhoods. Every lattice cell is the same size, but the data regions they cover are not; a SOM plot says nothing about how far apart two clusters are unless you colour it by the distances themselves — which is the U-matrix (§07).
  • Density: over-represents sparse regions relative to k-means, under-represents relative to data. The 2/3 exponent means a region ten times denser gets 10^(2/3) ≈ 4.6 times more units per unit volume, where k-means would give 10^(1/3) ≈ 2.2 and an equiprobable quantizer 10.
  • Compared with modern embeddings. t-SNE and UMAP also preserve neighbourhoods and not distances, but they place each point freely in 2-D; a SOM places prototypes on a fixed grid and then maps points to prototypes. The SOM gives you a reusable, parametric, out-of-sample mapping (a new point just finds its BMU) and a fixed display; the embeddings give much finer local structure.

07 Reading a map: the U-matrix and component planes

Because a SOM grid shows neighbourhoods but not distances, it is read through two derived images: the U-matrix, which colours each unit by how far its weight vector is from its lattice neighbours' (Ultsch & Siemon 1990), and component planes, which colour each unit by one coordinate of its weight vector. Cluster boundaries appear as ridges in the U-matrix; correlated input features appear as similar-looking component planes.

U-matrix value of unit iU(i) = (1 / |N(i)|) · ∑_{j ∈ N(i)} ‖wᵢ − wⱼ‖ N(i) = lattice neighbours of i (4 on a square grid, 6 on a hexagonal one) reading itlow U (dark valley) — the unit sits inside a dense region; its neighbours are close in data space high U (bright ridge) — neighbours on the grid are far apart in data space: the map is stretched across a gap between clusters component plane for input feature kP_k(i) = w_{ik} — one heatmap per input dimension, all on the same grid hit mapH(i) = number of training inputs whose BMU is i (hit count zero on a ridge is typical: interpolating units)
A SOM trained on colours: the map, its U-matrix, and the three component planes inputs are RGB triples drawn around a few base colours; hover a unit to read its weight vector

With five base colours the left panel lays the colours out as territories — each base colour owns a region of the grid, with blended units along the borders — and the U-matrix makes the borders explicit: bright ridges run exactly where the colour on the left changes most abruptly, separating darker basins where neighbouring units are nearly identical. Switch the left panel to the hit map and the ridge units turn out to be rarely or never BMUs (about a tenth of the units have zero hits): they are interpolating prototypes stretched across empty space between clusters, and a sample that lands on one is ambiguous. Raise the spread and the ridges soften because the clusters now touch; lower it and they sharpen. Component planes answer "which features drive the structure": a territory that is bright in the R plane and dark in G and B is the red one, and two features whose planes look alike are correlated across the data.

08 Measuring a map: quantization error and topographic error

A SOM has two jobs that pull against each other — fit the data (small quantization error) and keep the lattice ordered (small topographic error) — so it is judged by both numbers together, never one alone. A narrower final neighbourhood lowers the first and raises the second.

quantization error — how well the prototypes fit the dataQE = (1/N) ∑ₙ ‖xₙ − w_c(xₙ)‖ topographic error — how often the map tears (Kiviluoto 1996)TE = (1/N) ∑ₙ u(xₙ), u(x) = 1 if the best and second-best matching units of x are NOT lattice neighbours, else 0 worked, 5 samplesdistances to BMU: 0.10, 0.20, 0.10, 0.40, 0.20 ⇒ QE = 1.00 / 5 = 0.20 BMU / second-BMU pairs: (3,4) (3,8) (12,13) (5,40) (7,8) on a 10-wide grid — (5,40) is not adjacent ⇒ TE = 1/5 = 0.20 the trade-off in the limitsσ_end → 0: QE → the k-means optimum, TE rises (no force keeps neighbours together) σ_end large: TE → 0 (a smooth, contracted sheet), QE rises (prototypes pulled toward the mean)

Both numbers are live in the unfolding figure of §04: during ordering TE drops as the tangle comes undone, then QE falls steadily as σ shrinks. A twisted map (σ₀ too small) shows the tell-tale combination — reasonable QE, stubbornly high TE. Other measures exist (the topographic product, trustworthiness and continuity from the embedding literature), but QE and TE are the pair every toolbox reports.

09 The batch SOM

The batch SOM replaces per-sample updates with a per-epoch fixed-point step: assign every input to its BMU, then set every unit's weight to a neighbourhood-weighted mean of all the inputs. It has no learning rate, is deterministic given the initialisation, parallelises trivially, and is the default in most modern SOM libraries (Kohonen 1993).

one batch epoch(1) for every n: cₙ = argminᵢ ‖xₙ − wᵢ‖ (2) for every i: wᵢ ← ∑ₙ h_{cₙ i} xₙ / ∑ₙ h_{cₙ i} fast form via the Voronoi sets — compute the per-unit sums onceSⱼ = ∑_{n: cₙ = j} xₙ, nⱼ = |{n : cₙ = j}| ⇒ wᵢ ← ∑ⱼ h_ji Sⱼ / ∑ⱼ h_ji nⱼ why it is the fixed point of the online ruleonline update averaged over the data: E[ h_{c(x) i} (x − wᵢ) ] = 0 ⇔ wᵢ = E[h_{c(x) i} x] / E[h_{c(x) i}] the limit σ → 0h_ji = [i = j] ⇒ wᵢ ← Sᵢ / nᵢ, the cell mean — one epoch of Lloyd's batch k-means
  • σ still has to shrink, epoch by epoch; batch removes η, not the neighbourhood schedule. Ten to a few dozen epochs usually suffice.
  • A unit with no nearby hits takes a weighted mean dominated by its neighbours' Voronoi sets — so ridge units interpolate between clusters, which is what the U-matrix of §07 reveals.
  • Cost. Each epoch is N BMU searches (O(NMd)) plus an M × M neighbourhood smoothing of the Voronoi sums (O(M²d)), independent of N — cheap for large N, and each piece is a dense matrix product that GPUs are good at.

10 Learning vector quantization: supervised prototypes

Learning vector quantization (Kohonen 1986–1990) gives each prototype a class label and turns the competitive rule into a classifier: the winner moves toward an input of its own class and away from an input of another class. The result is a nearest-prototype classifier whose decision boundary is the set of Voronoi faces between prototypes of different classes — a compressed, trainable alternative to k-nearest neighbours.

classificationŷ(x) = class( w_c(x) ), c(x) = argminᵢ ‖x − wᵢ‖ LVQ1 — move the winner toward (right class) or away (wrong class)w_c ← w_c + η(t)(x − w_c) if class(w_c) = y w_c ← w_c − η(t)(x − w_c) if class(w_c) ≠ y LVQ2.1 — update the two nearest prototypes, only near the boundarylet wᵢ, wⱼ be the two nearest, dᵢ = ‖x − wᵢ‖, dⱼ = ‖x − wⱼ‖; require class(wⱼ) = y ≠ class(wᵢ) and the window test min( dᵢ/dⱼ , dⱼ/dᵢ ) > s, s = (1 − ω)/(1 + ω), ω ≈ 0.2 … 0.3 then wⱼ ← wⱼ + η(x − wⱼ) (correct one toward), wᵢ ← wᵢ − η(x − wᵢ) (wrong one away) worked window test, ω = 0.25s = 0.75 / 1.25 = 0.6. dᵢ = 1.0, dⱼ = 1.4: min(0.714, 1.4) = 0.714 > 0.6 ⇒ update dᵢ = 1.0, dⱼ = 2.0: min(0.5, 2.0) = 0.5 < 0.6 ⇒ x is not near the midplane — skip worked LVQ1 step, η = 0.1w_c = (1, 1) labelled A, x = (2, 1) labelled B: w_c ← (1, 1) − 0.1·(1, 0) = (0.9, 1) — pushed away from the B sample
  • Why the window. Moving the wrong prototype away is unstable if done everywhere: prototypes can be pushed off to infinity by distant samples. LVQ2.1 only acts inside a slab around the midplane between the two prototypes, which is where the Bayes boundary is decided; it therefore sharpens the boundary without dragging prototypes away from their class. Standard practice: LVQ1 (or OLVQ1, with an adaptive per-prototype η) first, LVQ2.1 as a short fine-tune with a small η.
  • Initialise prototypes inside their class — e.g. k-means per class — or LVQ1 wastes its early steps and can strand prototypes on the wrong side.
  • Modern descendants. Generalized LVQ (Sato & Yamada 1996) minimises a smooth cost μ = (d⁺ − d⁻)/(d⁺ + d⁻) by gradient descent, which fixes LVQ2.1's divergence; GMLVQ also learns the metric. Prototype networks for few-shot learning (Snell et al. 2017) classify by nearest class-mean in a learned embedding — LVQ with one prototype per class and a deep feature extractor.
LVQ: labelled prototypes and the nearest-prototype boundary background = the class of the nearest prototype; run LVQ1, then switch to LVQ2.1 and watch the boundary sharpen

Prototypes start at random training points of their own class. On two moons with three prototypes per class, LVQ1 lifts accuracy from the initial nearest-prototype value into the mid-to-high 90s within a few epochs, and the boundary becomes a polyline following the gap between the moons. With a single prototype per class the boundary is one straight line — the perpendicular bisector of the two prototypes — and no rule can do better than a linear classifier; add prototypes and the boundary gains a segment per extra Voronoi face. LVQ2.1 reports how many samples fall inside its window — about 20 of 300 per epoch here — and only those move anything, which is why it is a fine-tuner, not a trainer: after LVQ1 it nudges two moons from about 98% to over 99%. Now try LVQ2.1 on two moons with one prototype per class: most samples fall in the wide window between two distant prototypes, the "push the wrong one away" step dominates, and the prototypes are driven apart until accuracy collapses to 50% — the divergence the window and the LVQ1-first rule exist to prevent.

11 Adaptive resonance theory: ART-1 and the stability–plasticity dilemma

Every competitive learner above has the same weakness: a new input always moves some existing prototype, so learning new patterns erodes old ones unless the step size is frozen — and a frozen learner can no longer learn. Adaptive resonance theory (Grossberg 1976; Carpenter & Grossberg 1987) resolves this stability–plasticity dilemma by letting a category learn only when the input matches it well enough, and creating a new category otherwise. The threshold for "well enough" is a single parameter, the vigilance ρ.

  • Why this is stable. Templates only ever lose bits (w ← I ∧ w), so a template cannot oscillate; with fast learning, any finite set of binary inputs is learned in a bounded number of passes and then every input directly accesses its category without search (Carpenter & Grossberg 1987). Plasticity is preserved because a sufficiently novel input simply gets a new category rather than overwriting an old one.
  • The L − 1 + |wⱼ| denominator makes the choice prefer the smaller of two templates that match equally — the subset — so a specific category is tried before a general one that contains it. Without it, a broad template would capture everything.
  • Vigilance is a resolution knob. ρ near 1 demands near-identical matches: many narrow categories. ρ small: few broad ones. It is the only thing deciding the number of clusters, which is both the appeal (no K to pick) and the weakness (the result depends on presentation order and on ρ, with no objective being optimised).
  • Family. ART-2 handles analogue inputs; Fuzzy ART (Carpenter, Grossberg & Rosen 1991) replaces AND with the fuzzy min and adds complement coding; ARTMAP pairs two ART modules for supervised learning. The stability–plasticity dilemma itself is now called catastrophic forgetting, and continual-learning methods for deep networks — replay, parameter-importance penalties, dynamically growing architectures — are its modern answers; ART's "grow a new unit when nothing matches" is the ancestor of the last.

In the listed order each "short" glyph arrives right after its full version and is a subset of it, so its match is |I ∧ w|/|I| = 1 and it resonates at any vigilance, shrinking the template to the intersection; at ρ = 0.7 the result is five categories — the Ls, the pluses, the boxes, T and X. Press reversed and the asymmetry of the match ratio shows: now the fuller glyph comes second, its match is |w|/|I| < 1, and vigilance decides. The box scores 12/16 = 0.75 against the broken-box template, so it merges at ρ = 0.7 and splits at 0.8; worse, the short L then scores 5/7 = 0.714 against that template, resonates, and erodes it to 5 pixels, after which the full L (5/9 = 0.56) has to found its own category. At ρ = 0.95 reversed there are seven categories; at 0.4 either order collapses to three or four broad ones. Same patterns, same ρ, different categories — ART-1 is order-dependent, which is the honest cost of learning in one pass with no global objective.

12 Counter-propagation: a competitive layer plus a lookup table

Counter-propagation (Hecht-Nielsen 1987) stacks a Kohonen competitive layer and a Grossberg "outstar" layer: the competitive layer quantizes the input to one of K prototypes, and the outstar layer learns, for each prototype, the average target of the inputs it wins. It is a learned lookup table — a piecewise-constant function approximator — trained without backpropagation, and was popular because it trained orders of magnitude faster than the backprop networks of its day.

forward passc = argminₖ ‖x − wₖ‖, zₖ = [k = c], ŷ = ∑ₖ vₖ zₖ = v_c training (usually two stages)stage 1, Kohonen layer: w_c ← w_c + α (x − w_c) (competitive learning, §01) stage 2, outstar layer: v_c ← v_c + β (y − v_c) (running average of the targets that unit c sees) at convergencev_c = E[ y | x ∈ cell c ] — the conditional mean of the target over each Voronoi cell full (bidirectional) counter-propagationtrain the competitive layer on the concatenation [x ; y]; then either half can be presented and the other recalled interpolation modelet the top few units share the output with weights ∝ their closeness ⇒ a smoother, piecewise-blended ŷ

Seen from today, counter-propagation is the simplest member of a family: replace the hard winner with a soft, distance-weighted one and you get the normalised radial basis function network and the general regression neural network of the next part (Radial Basis Function Networks); let the competitive layer be learned jointly with the outputs and you are at a mixture of experts with a hard gate. Its weakness is the same as any lookup table — resolution costs units exponentially in the input dimension, and the output is a staircase unless interpolation is added.

14 Practice, pitfalls and takeaways

  • Standardise the features. Everything rests on Euclidean distance; a feature measured in thousands will decide every competition by itself. Z-score each input dimension before training, and read component planes in standardised units.
  • Map size. A common heuristic is M ≈ 5√N units for N samples, with the grid's side ratio set to the ratio of the top two principal standard deviations, so the sheet's shape matches the data's.
  • Prefer linear (PCA) initialisation and the batch algorithm for reproducible maps; use random initialisation and online updates when demonstrating self-organization or streaming.
  • Check both QE and TE, and look at the U-matrix before trusting any visual cluster; a SOM will draw clusters on uniform data if you only look at the weight colours.
  • A SOM is not a clustering algorithm by itself — it produces M prototypes (often hundreds) for display. To get K clusters, cluster the prototypes (k-means or hierarchical on the weight vectors, guided by the U-matrix).
  • LVQ: initialise per class, LVQ1 then a short LVQ2.1 or switch to GLVQ; count parameters honestly — P prototypes per class in d dimensions is P·C·d numbers.
  • ART: tune ρ on held-out data and fix a presentation order (or shuffle and average); expect category proliferation on noisy inputs at high vigilance.
Takeaways. Competitive learning is stochastic gradient descent on quantization error — online k-means — and its failure mode, dead units, is fixed by making winning costly. The SOM adds a lattice and a shrinking neighbourhood, which turns a set of prototypes into an ordered 2-D map; order is set early with a wide σ, accuracy late with a narrow one, and the map is read through its U-matrix and judged by QE and TE together. LVQ makes the prototypes supervised; ART refuses to overwrite a category that does not match and grows a new one instead; counter-propagation hangs a lookup table off the winners. The same ideas survive in VQ codebooks, prototype classifiers and load-balanced routing.
