Encoder vs Decoder Models

The same Transformer block wires up three ways — encoder-only, decoder-only, and encoder-decoder — and the difference comes down to one thing: which tokens each position is allowed to attend to.

Deep Learning Transformers Architectures

01 Three configurations

  • Encoder-only (BERT) — bidirectional; built for understanding a whole input.
  • Decoder-only (GPT) — causal; built for generating text left-to-right.
  • Encoder-decoder (T5) — bidirectional encoder feeds a causal decoder via cross-attention; built for transduction (input → output).
One sentence: encoder = read everything, decoder = generate without peeking ahead, encoder-decoder = read one thing to write another.

03 Encoder-only (BERT)

  • Bidirectional self-attention: every token sees the whole input, left and right.
  • Pretrained by masked language modeling (predict blanked-out tokens).
  • Best for understanding tasks: classification, NER, entailment, extractive QA. Can't generate freely.

04 Decoder-only (GPT)

  • Causal self-attention: position i attends only to ≤ i, so it can't see the future.
  • Pretrained by next-token prediction — and scaled up, this is the modern LLM.
  • Best for generation and few-shot / in-context learning. The dominant design today.

05 Encoder-decoder (T5)

  • A bidirectional encoder reads the source; a causal decoder generates the target, attending to the encoder via cross-attention.
  • Natural fit for translation, summarization, and other input→output transductions.
  • See Transformers → encoder-decoder for the full block diagram.

06 Which to use

GoalPick
Understand / classify / tag inputEncoder-only (BERT)
Generate / chat / few-shotDecoder-only (GPT)
Map input → output sequenceEncoder-decoder (T5)

07 Takeaways

  • One block, three wirings, distinguished mainly by the attention mask.
  • Encoder bidirectional (understanding); decoder causal (generation); encoder-decoder bridges them with cross-attention (transduction).
  • Decoder-only dominates modern LLMs; encoder-only still strong for understanding tasks.
  • Builds on Transformers and Attention masking.
