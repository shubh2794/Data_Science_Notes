Residual / Skip Connections

The one-line idea that made very deep networks trainable: instead of a layer computing F(x), have it compute F(x) + x — a shortcut that lets gradients flow straight through. ResNets, and the residual streams inside every Transformer, rely on it.

Deep Learning Architectures Training

01 The depth problem

  • Stacking many layers should help, but plain deep nets get worse — gradients vanish on the way back, and accuracy degrades even on training data.
  • The signal has to survive a long chain of multiplications; tiny factors compound to near-zero.
  • Skip connections fix this with a shortcut path.

02 The residual idea

y = F(x) + x (learn the residual F(x), not the whole mapping)

Add the input back to the output. Toggle skip connections and watch the gradient survive (or vanish) on its way to the early layers.

Gradient strength reaching each layer (backward pass) Without skips, early layers get almost no gradient — they can't learn

03 Why it works

  • Gradient highway: the + x term gives the gradient a direct path back — its derivative is 1, so it doesn't shrink.
  • Identity is easy: if a layer isn't useful, it can learn F(x) ≈ 0 and just pass the input through — extra depth never hurts.
  • The model learns the change to the representation, which is often small and easier to fit.

05 Everywhere now

  • Every Transformer block is residual: x + Attention(x) and x + FFN(x) (the "Add" in Add & Norm) — the residual stream.
  • Combined with normalization, residuals are what make 12–96+ layer models trainable.
  • A near-universal default in modern deep learning.

06 Takeaways

  • y = F(x) + x — learn the residual; add a shortcut around each block.
  • Gradient highway (derivative 1) defeats vanishing gradients; identity is trivial to learn.
  • ResNets and the Transformer residual stream both depend on it.
  • Pairs with Neural Network Training and normalization.
