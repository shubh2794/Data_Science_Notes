RNNs & LSTMs

Before attention, sequences were processed one step at a time — a network that reads a token, updates a memory, and carries it forward. Simple and elegant, until the gradient has to travel back through hundreds of steps. Gates were the fix that made recurrence work.

Deep Learning Sequence modeling Gated memory

01 Why recurrence?

A feedforward net (MLP) maps a fixed-size input to an output. But language, audio, and time series are variable-length sequences where order matters and earlier elements inform later ones. A recurrent neural network (RNN) handles this by reading one element at a time and maintaining a hidden state — a running summary of everything seen so far.

  • Shared weights through time. The same cell is applied at every step, so the model generalizes across positions and to sequences of any length.
  • Memory is the hidden state. Everything the model "remembers" must be squeezed into one fixed-size vector hₜ.
  • Sequential by construction. Step t needs step t−1, so RNNs can't parallelize across time the way Transformers can.

02 The recurrent cell & unrolling

At each step the cell combines the new input xₜ with the previous hidden state hₜ₋₁, squashes through a nonlinearity, and emits the new state:

vanilla (Elman) RNN — one recurrent stephₜ = tanh( Wₓ xₜ + Wₕ hₜ₋₁ + b )
optional output (per step)yₜ = W_y hₜ + c
  • Wₓ — input-to-hidden weights; Wₕ — the recurrent hidden-to-hidden weights (the same matrix reused every step).
  • h₀ is usually the zero vector; it's the memory before any input arrives.

To reason about training, we unroll the loop into a deep feedforward graph — one layer per timestep, all sharing Wₓ, Wₕ, b. A sequence of length T becomes a network of effective depth T.

03 Backpropagation through time

Because the unrolled net is just a deep network with tied weights, we train it with ordinary backprop — here called backpropagation through time (BPTT). The gradient for the shared recurrent weights is summed over every step:

accumulate the shared-weight gradient across time∂L/∂Wₕ = Σₜ (∂Lₜ / ∂Wₕ)

The catch is how a loss at step t reaches a state far back at step k: the gradient must pass through every cell in between, multiplying one Jacobian per step.

the gradient chain through time (t → k)∂hₜ / ∂hₖ = ∏ⱼ₌ₖ₊₁ᵗ ∂hⱼ / ∂hⱼ₋₁ = ∏ⱼ diag(tanh′(·)) · Wₕᵀ

In practice we cap the unroll length with truncated BPTT — backprop only over the last k steps — to bound memory and compute.

04 Vanishing & exploding gradients

That product of (t − k) Jacobians is the whole problem. Taking norms, the long-range gradient is bounded by a quantity that is exponential in the distance:

λ = ‖Wₕ‖ · (max tanh′) controls the fate of the gradient‖ ∂hₜ / ∂hₖ ‖ ≤ λ^(t − k)
  • λ < 1 → vanishing. The gradient shrinks geometrically; the network can't learn dependencies more than a few steps back. This is the common case (tanh′ ≤ 1).
  • λ > 1 → exploding. The gradient blows up, producing NaNs. The cheap fix is gradient clipping — rescale the gradient when its norm exceeds a threshold.
  • λ ≈ 1 → stable — the knife-edge the gates below are designed to sit on.

06 The LSTM: a gated memory cell

The Long Short-Term Memory cell (Hochreiter & Schmidhuber, 1997) adds a second, protected memory track — the cell state cₜ — that information can ride along almost untouched. Three gates (sigmoid units that output values in [0,1]) decide what to erase, what to write, and what to expose.

forget gate — what to erase from the cellfₜ = σ( W_f · [hₜ₋₁, xₜ] + b_f )
input gate + candidate — what new info to writeiₜ = σ( W_i · [hₜ₋₁, xₜ] + b_i ) c̃ₜ = tanh( W_c · [hₜ₋₁, xₜ] + b_c )
cell update — keep the old, add the new (⊙ = elementwise)cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ
output gate — what to expose as the hidden stateoₜ = σ( W_o · [hₜ₋₁, xₜ] + b_o ) hₜ = oₜ ⊙ tanh( cₜ )
The constant error carousel. Look at the cell update: when the forget gate fₜ ≈ 1, then ∂cₜ/∂cₜ₋₁ ≈ 1. The gradient flows back along the cell state with a multiplier near 1 instead of λ^(t−k) — so it neither vanishes nor explodes. That additive, gated path is exactly what lets LSTMs learn dependencies hundreds of steps long.

07 The GRU: a leaner gate set

The Gated Recurrent Unit (Cho et al., 2014) folds the LSTM's ideas into two gates and drops the separate cell state — fewer parameters, often comparable accuracy.

update gate (z) & reset gate (r)zₜ = σ( W_z · [hₜ₋₁, xₜ] ) rₜ = σ( W_r · [hₜ₋₁, xₜ] )
candidate state — reset gate controls how much past to useh̃ₜ = tanh( W · [ rₜ ⊙ hₜ₋₁, xₜ ] )
interpolate old ↔ new with the update gatehₜ = (1 − zₜ) ⊙ hₜ₋₁ + zₜ ⊙ h̃ₜ

Like the LSTM's forget gate, the update gate zₜ gives the GRU an additive carry path — when zₜ ≈ 0 the previous state passes through unchanged, preserving the gradient.

08 Wiring them up

  • Stacked (deep) RNNs. Feed one layer's hidden sequence as the next layer's input to build hierarchy.
  • Bidirectional RNNs. Run one pass forward and one backward, then concatenate — each step sees both left and right context. Great for tagging/encoding, not for autoregressive generation.
  • Sequence-to-sequence (encoder–decoder). An encoder RNN compresses the input into a context vector; a decoder RNN generates the output. This powered early neural machine translation — and its single-vector bottleneck is precisely what attention was invented to relieve.

10 Takeaways & where RNNs stand now

  • An RNN is a shared cell looped over time, carrying a fixed-size hidden state as its only memory.
  • BPTT unrolls the loop; the gradient through (t−k) steps scales like λ^(t−k) → vanishing or exploding.
  • Gates fix it with an additive carry path. The LSTM's cell state (forget gate ≈ 1) and the GRU's update gate keep the long-range gradient near 1.
  • Transformers largely replaced RNNs for NLP — they parallelize across time and read any position directly via attention. See the full map in Architectures Compared.
  • The recurrent idea is back. State-space models (S4, Mamba) revive linear recurrence for O(n) long-sequence modeling — RNNs, reborn with better math.
