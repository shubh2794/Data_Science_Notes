State Space Models

Attention is powerful but quadratic in sequence length. State space models (S4, Mamba) revive a linear recurrence that scales linearly with length — a serious contender for very long sequences.

Deep Learning Sequences Sub-quadratic

01 The motivation

  • Self-attention connects every token to every other — great, but O(n²) compute and memory in sequence length.
  • RNNs are O(n) but slow (sequential) and forget long-range info.
  • SSMs aim for the best of both: a linear recurrence that's cheap, parallelizable to train, and keeps long-range memory.
One sentence: a learned linear state that carries information along the sequence in linear time — sub-quadratic long-context modeling.

02 The state space recurrence

hₜ = A·hₜ₋₁ + B·xₜ yₜ = C·hₜ (+ D·xₜ)
  • A hidden state h is updated by a learned linear map A as it sweeps the sequence; the output reads it out via C.
  • Because it's linear, the recurrence can be unrolled as a convolution and computed in parallel for training, then run as a fast recurrence at inference.
  • Careful structure of A (e.g. HiPPO initialization in S4) is what lets the state remember the distant past.

03 Why it scales

Linear vs quadratic is the whole pitch. Stretch the sequence length and watch the gap open up.

Compute cost vs sequence length Attention grows with n²; an SSM grows with n

04 Selective SSMs (Mamba)

  • Plain SSMs use the same dynamics for every token; Mamba makes A,B,C depend on the input (selective), so the model can choose what to remember or forget.
  • That input-dependence breaks the simple convolution, so Mamba uses a hardware-aware parallel scan to stay fast on GPUs.
  • Result: Transformer-level quality on long sequences with linear scaling.

06 Takeaways

  • SSMs use a linear recurrence (hₜ = A hₜ₋₁ + B xₜ) to model sequences in linear time.
  • Trainable as a convolution (parallel), runnable as a recurrence (fast inference).
  • Mamba adds input-selective dynamics + a hardware-aware scan for Transformer-level quality.
  • Trade-off: cheaper long context, but weaker direct recall than attention — hence hybrids.
  • Alternative to Transformers; compared in DL Architectures Compared.
