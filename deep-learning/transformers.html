Transformers & Self-Attention

Replace recurrence with attention: every token looks at every other token in parallel, weighted by learned relevance. The architecture behind BERT, GPT, T5, and modern LLMs.

Deep Learning Sequence modeling Attention

01 Why attention beats recurrence

The Transformer threw out recurrence and convolution entirely, keeping only attention — and won on speed and quality.

The problem with RNNs

  • No parallelism. An RNN reads token t only after token t−1. Training is inherently sequential, so it can't exploit modern GPUs the way a fully-parallel model can.
  • Long-range decay. Information from early tokens must survive a long chain of multiplications to reach later ones. Even LSTMs/GRUs blur distant dependencies — the path length between two tokens is O(n).

The problem with CNNs

  • Convolutions only see a local window per layer. Connecting two far-apart tokens needs a deep stack of layers (O(log n) path length with dilation), building global context bottom-up.

The transformer idea

Build each token's representation directly from all other tokens via self-attention: figure out how relevant every other word is to this one, and form a weighted blend of their representations. Any two positions are now one operation apart, and the whole sequence is processed in parallel.

One sentence: attention is a content-based, differentiable lookup — a soft "which of these other tokens should I read from, and how much?"

02 Query, key, value

Attention is a soft dictionary lookup. Queries ask, keys advertise, values are what you retrieve.

  • Query (Q) — what the current token is looking for.
  • Key (K) — what each token offers, used to match against queries.
  • Value (V) — the actual content that gets blended into the output once relevance is decided.

Each is a learned linear projection of the input embedding: Q = XWᵠ, K = XWᴷ, V = XWⱽ. The similarity between a query and a key is a dot product — large when the two vectors point the same way:

a · b = Σᵢ aᵢbᵢ = ‖a‖ ‖b‖ cos(θ)

So QKᵀ is an n × n grid of all query-vs-key similarities: row i, column j is "how much should token i attend to token j?". Softmax turns each row into a probability distribution, and we use it to average the value vectors.

Self-attention's lineage: it generalizes a "second-order Markov model with skips," where a learnable mask picks which earlier tokens vote for the next one. Attention just makes that mask soft, content-dependent, and differentiable.

03 Scaled dot-product attention

The single equation at the heart of the Transformer.

Attention(Q, K, V) = softmax( QKᵀ / √dₖ ) V

Step by step:

  • Scores QKᵀ — raw compatibility, shape n × n.
  • Scale by 1/√dₖ — see below.
  • Softmax per row — convert scores to attention weights that sum to 1.
  • Weight the values — multiply by V to get each token's new representation as a weighted sum of all values.

Why divide by √dₖ?

If query and key components are roughly independent with unit variance, their dot product over dₖ dimensions has variance dₖ — so it grows with dimension. Large scores push softmax into a near one-hot spike, where gradients vanish. Dividing by √dₖ rescales variance back to ~1, keeping softmax in a responsive regime. Crank the temperature below to feel this: sharper weights = more confident, but brittle.

04 Multi-head attention

One attention map sees one kind of relationship. Run several in parallel and you cover many at once.

MultiHead(Q,K,V) = Concat(head₁, …, headₕ) Wᴼ headᵢ = Attention(QWᵢᵠ, KWᵢᴷ, VWᵢⱽ)
  • Project Q/K/V into h lower-dimensional subspaces (each of size d_model / h), run scaled dot-product attention independently in each, concatenate, and mix with output projection Wᴼ.
  • Because each head works in a d_model/h subspace, total compute and parameters stay roughly the same as one full-size head.
  • Different heads specialize — some track syntax (subject↔verb), some coreference, some local adjacency. You get an ensemble of relationship detectors for free.

05 Positional encoding

Attention is permutation-invariant — it has no built-in sense of order. We inject position explicitly.

Sinusoidal (original Transformer)

PE(pos, 2i) = sin( pos / 10000^(2i/d_model) ) PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )

Each dimension is a sinusoid of a different wavelength — fast-changing dimensions encode fine position, slow ones encode coarse position. Added directly to the token embeddings. Cheap and parameter-free, but doesn't naturally extrapolate past the longest training length.

Relative position

Encode the distance between tokens rather than absolute index (needs 2n−1 offset vectors for relative positions −(n−1) … +(n−1)). Generalizes to longer sequences; costlier to fold into attention.

Rotary (RoPE)

Rotate each query/key vector by an angle proportional to its position: RoPE(x, pos) = R(pos)·x. The dot product of two rotated vectors then depends on their relative offset — so RoPE captures absolute position via the rotation yet behaves relatively, adds no parameters, and extrapolates well. It powers most modern long-context LLMs.

06 The transformer block

A block = attention sublayer + feed-forward sublayer, each wrapped in a residual connection and normalization.

Residual + LayerNorm

Every sublayer is wrapped as output = x + Sublayer(x). The residual lets gradients flow straight through, making 12–96 layer stacks trainable. LayerNorm normalizes across the feature dimension per token:

LayerNorm(x) = (x − μ) / √(σ² + ε) · γ + β

Mean/variance are computed over d_model for each token independently — no batch dependence, so it behaves identically at training and during single-token autoregressive decoding (a key reason it's preferred over BatchNorm here).

Pre-norm vs post-norm

  • Post-norm (original): LayerNorm(x + Sublayer(x)). Strong but finicky to train deep; needs warmup.
  • Pre-norm (modern, GPT-2 onward): x + Sublayer(LayerNorm(x)). Cleaner gradient flow, far more stable when scaling to many layers.

Position-wise feed-forward network

FFN(x) = max(0, xW₁ + b₁) W₂ + b₂ (ReLU; GELU in modern variants)

Two linear layers with a non-linearity, applied to each position independently. It expands to d_ff ≈ 4·d_model then projects back — a per-token "thinking" step that adds most of the model's parameters (≈⅔ of GPT-3's weights live here).

07 Encoder–decoder & masking

The original Transformer is a seq2seq model: an encoder reads the source, a decoder generates the target, cross-attention bridges them.

Self-attention vs cross-attention

  • Self-attention: Q, K, V all come from the same sequence — each token attends to its own neighbors.
  • Cross-attention: Q comes from the decoder, K and V from the encoder output — the decoder reads relevant source content while generating.

Masking

  • Causal (look-ahead) mask in the decoder sets future positions to −∞ before softmax, so position t can only attend to ≤ t. This enforces autoregressive generation and prevents the model from cheating by reading the answer.
  • Padding mask zeroes out attention to padding tokens so they don't pollute the weighted sum.

Decoder layer = three sublayers

  1. Masked multi-head self-attention (over generated tokens so far).
  2. Multi-head cross-attention (queries from decoder, keys/values from encoder).
  3. Position-wise feed-forward network.
The encoder is bidirectional (no causal mask) so each source token sees the whole input; the decoder is causal so generation stays left-to-right.

08 Output & decoding

A linear projection to vocabulary size, a softmax, then a choice of how to pick the next token.

logits = h Wₒ (Wₒ : d_model × vocab) P(token) = softmax(logits)
  • Greedy: take the argmax each step — fast, deterministic, often bland.
  • Beam search: keep the top-k partial sequences — better for translation.
  • Temperature / top-k / nucleus (top-p) sampling: trade determinism for diversity in open-ended generation.

KV cache

During autoregressive generation, the keys and values of all earlier tokens don't change. Caching them means each new step only computes K/V for the one new token and reuses the rest — turning per-step cost from O(n²) down to O(n). This is the single biggest inference optimization in deployed LLMs.

09 Complexity: attention vs RNN vs CNN

Why parallelism and short paths matter — with n = sequence length, d = representation dim, k = kernel size.

Layer typeComplexity per layerSequential opsMax path length
Self-attentionO(n²·d)O(1)O(1)
Recurrent (RNN)O(n·d²)O(n)O(n)
ConvolutionalO(k·n·d²)O(1)O(log_k n)
  • Max path length is how many steps information travels between the two most distant tokens — O(1) for attention means any pair is directly connected, the root of its long-range strength.
  • Sequential ops O(1) means attention parallelizes fully across positions; the RNN's O(n) is its training bottleneck.
  • The catch: attention is quadratic in sequence length (n²). For very long contexts this dominates, motivating sparse/linear-attention and FlashAttention-style work.

Modern LLMs (GPT, Llama, Mistral) are overwhelmingly decoder-only: a single causal stack, trained on next-token prediction, scaled up — simplicity that scales.

11 Training details that matter

The small choices that make a Transformer actually converge.

  • Teacher forcing & shift-right: the decoder input is the target shifted by one ([START, y₁ … yₙ₋₁]) predicting [y₁ … yₙ, EOS]. With the causal mask, every position is trained in parallel.
  • Cross-entropy loss with a loss mask that ignores padding positions.
  • Label smoothing (ε≈0.1): replace one-hot targets with soft ones so the model doesn't become overconfident — slightly hurts perplexity but improves accuracy/BLEU and calibration.
  • Adam with warmup: learning rate ramps up linearly then decays (the original lr ∝ d_model^-0.5 · min(step^-0.5, step·warmup^-1.5)). Warmup keeps early, high-variance updates from destabilizing training — especially with post-norm.
  • Residuals + normalization are what make 12–96 layers trainable at all; without them gradients vanish.

12 Takeaways

  • Attention = differentiable, content-based lookup. softmax(QKᵀ/√dₖ)V blends value vectors by query-key relevance.
  • Parallel + short paths. Every token reaches every other in one step, and the sequence is processed at once — the twin wins over RNNs.
  • Multi-head gives many relationship detectors; FFN adds per-token capacity; residual + LayerNorm make depth trainable.
  • Position must be injected (sinusoidal → relative → RoPE) because attention itself is order-blind.
  • Three families — encoder-only for understanding, decoder-only for generation, encoder–decoder for transduction.
  • The cost is O(n²) in sequence length; KV caching, FlashAttention, and sparse/linear attention chip away at it.
