World Models & JEPA

A world model learns how the environment evolves, so an agent can plan by "imagining" futures. JEPA pushes a key idea: predict an abstract representation of what comes next, not every pixel — focus on what's predictable and useful.

Deep Learning Self-supervised Representation

01 What a world model is

  • A model of the environment's dynamics: given the current state and an action, predict the next state (and reward).
  • With one, an agent can plan in imagination — roll out futures internally instead of acting in the real world — which is far cheaper and safer.
  • Model-based RL agents like Dreamer learn a latent world model and train a policy entirely inside it.
One sentence: learn how the world changes so you can predict, plan, and learn without acting every time.

02 What should you predict?

The central design choice — and where JEPA differs from generative models. Toggle the two approaches.

Predict pixels vs predict a latent representation Generative reconstructs every detail; JEPA predicts an abstract embedding

03 Why predict in latent space

  • The future is full of unpredictable detail (exact pixels, leaf positions). Forcing a model to reconstruct all of it wastes capacity on noise.
  • Predicting an abstract representation lets the model ignore irrelevant detail and capture the structure that matters for prediction and planning.
  • This is the core argument behind JEPA (Joint-Embedding Predictive Architecture).

04 How JEPA works

encode(context) → predict → target_embedding ≈ encode(target)
  • Encode a context and a target separately; a predictor maps the context embedding toward the target's embedding (not its raw pixels).
  • Trained to match in representation space, with care (e.g. stop-gradient / EMA target encoder) to avoid collapse to a trivial constant.
  • Variants: I-JEPA (images), V-JEPA (video) — strong self-supervised representations without pixel reconstruction.

05 Prediction as self-supervision

  • Predicting masked or future parts of the input is a powerful self-supervised signal — the same idea behind language modeling.
  • JEPA argues the prediction should happen in representation space for perception, where pixel-level detail is a distraction.
  • It's part of a broader bet that good world models + representations are a path toward more capable, grounded AI.

06 Takeaways

  • World models learn environment dynamics so agents can plan in imagination.
  • The key choice is the prediction target: raw pixels (generative) vs an abstract embedding (JEPA).
  • JEPA predicts in latent space, ignoring unpredictable detail — efficient, robust representations.
  • Watch for representation collapse; fixed with asymmetric / EMA targets.
  • Connects to RL (model-based planning) and self-supervised representation learning.
