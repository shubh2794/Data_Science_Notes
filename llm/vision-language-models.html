Vision-Language Models

Bolt a visual encoder onto an LLM and you get a model that can see: caption images, answer questions about them, read documents, and reason over pictures and text together.

LLMs & Generative AI Multimodal Vision

01 Why multimodal

  • Most real tasks mix modalities — a screenshot plus a question, a chart plus a caption, a photo plus an instruction.
  • A VLM brings images into the same token stream an LLM already reasons over, so all the LLM's language and reasoning ability transfers to visual inputs.
  • The recipe is mostly reuse: a pretrained vision encoder + a pretrained LLM, glued by a small trained connector.
One sentence: turn an image into tokens the LLM can read, and language understanding extends to vision for free.

02 The standard architecture

image → vision encoder → projector → visual tokens → ‖ text tokens → LLM → text out
  • Vision encoder (often a CLIP-pretrained ViT) turns the image into a set of patch embeddings.
  • Projector / connector (an MLP or cross-attention "resampler") maps those into the LLM's embedding space and, often, fewer tokens.
  • LLM consumes the visual tokens alongside the text tokens and generates the answer.

03 Images become tokens

A ViT splits the image into a grid of fixed-size patches; each patch is embedded into one visual token. Smaller patches → more tokens → more detail but more compute.

Patchify: image → visual tokens Each patch becomes one token fed to the LLM

This is why high-resolution images are expensive: token count grows with the square of resolution. Resamplers compress the patch grid down to a fixed budget of visual tokens.

05 Training

  • Contrastive pretraining (CLIP): align image and text embeddings so matching pairs are close — gives a strong, language-aligned vision encoder.
  • Connector alignment: train the projector on image-caption pairs while keeping encoder and LLM mostly frozen.
  • Instruction tuning: fine-tune on visual-instruction data (VQA, OCR, grounding) so the model follows multimodal instructions.

07 Takeaways

  • VLM = vision encoder + projector + LLM — images become tokens the LLM reasons over.
  • Patchify turns an image into a grid of visual tokens; resolution drives token count quadratically.
  • Fusion via projection/prefix, cross-attention, or a resampler.
  • CLIP-style contrastive pretraining gives a language-aligned encoder; instruction tuning teaches multimodal following.
  • Builds on LLMs and Vision Transformers.
