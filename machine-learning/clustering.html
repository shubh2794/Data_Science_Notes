Clustering — k-Means

UnsupervisedPartitioning Group data by similarity with no labels — the canonical example being k-Means, which alternates assigning points to the nearest centroid and moving each centroid to its members' mean.

Overview

Clustering is an unsupervised technique that groups data points by similarity (or dissimilarity) without predefined labels. The goal is to discover structure the data already contains.

  • Common uses: market & customer segmentation, image segmentation, document categorization, anomaly detection, and exploratory data analysis.
  • Every distance-based method below is sensitive to scale, so feature scaling is essential (see the limitations section).

Types of clustering

  • Partitioning — split data into k non-overlapping clusters by optimizing an objective (k-Means, k-Medoids, Fuzzy C-Means).
  • Hierarchical — build a tree of nested clusters, bottom-up (agglomerative) or top-down (divisive).
  • Density-based — grow clusters in dense regions and label sparse points as noise (DBSCAN, OPTICS).
  • Grid-based — partition the space into cells and cluster by cell density (STING, CLIQUE).
  • Model-based — assume the data is generated by a mixture of distributions (Gaussian Mixture Models).

The k-Means algorithm

k-Means partitions n points into k clusters, assigning each point to the cluster with the nearest mean and minimizing the within-cluster sum of squares (WCSS, a.k.a. inertia).

  1. Initialize — choose k and place k centroids (randomly, or via k-means++).
  2. Assign — attach each point to its nearest centroid.
  3. Update — move each centroid to the mean of its assigned points.
  4. Repeat assign/update until centroids stop moving (or max iterations).
assignment · centroid updateC(xᵢ) = argminⱼ ‖xᵢ − μⱼ‖² μⱼ = (1/|Cⱼ|) Σ_(x ∈ Cⱼ) x
objective — within-cluster sum of squares (inertia)J = Σⱼ₌₁ᵏ Σ_(x ∈ Cⱼ) ‖x − cⱼ‖²

This iterative scheme is Lloyd's algorithm. Each step can only lower J, so it always converges — but only to a local minimum. Cost is O(n·k·t) for t iterations.

Worked example (k=2). Points (1,1),(1.5,2),(3,4),(5,7),(3.5,5),(4.5,5),(3.5,4.5) with initial centroids c₁=(1,1), c₂=(5,7). After assignment: C₁={(1,1),(1.5,2),(3,4)}, C₂={the rest}. Update: c₁≈(1.83, 2.33), c₂≈(4.13, 5.38). Repeat until stable. Try it live below.

Choosing k & smarter initialization

How many clusters?

  • Elbow method — plot inertia (J) against k; pick the "elbow" where adding clusters stops paying off.
  • Silhouette score — pick the k that maximizes the average silhouette (see evaluation metrics).

Initialization & local minima

  • Plain random init can land in a poor local minimum. k-means++ spreads initial centroids out (choosing each new seed with probability proportional to squared distance from existing seeds), giving much better, more consistent results.
  • Also run k-Means several times with different seeds and keep the lowest-inertia solution.
  • Convergence is declared when centroids move less than a threshold, the objective barely changes, or max iterations is hit.

Partitioning variants: k-Medoids & Fuzzy C-Means

  • k-Medoids (PAM) — uses an actual data point (a medoid) as each cluster's representative instead of a mean. Far more robust to outliers, but costly at O(k(n−k)²).
  • Fuzzy C-Means — soft assignment: each point gets a membership degree across clusters rather than belonging to exactly one, capturing overlap.

Hierarchical clustering

Builds a tree (dendrogram) of nested clusters — no need to fix k up front; you cut the tree at a chosen height afterwards.

  • Agglomerative (bottom-up) — start with every point as its own cluster, repeatedly merge the two closest clusters. Cost ≈ O(n³).
  • Divisive (top-down) — start with one cluster and recursively split (e.g. via k-Means/PCA).

Linkage — how to measure "closest" between clusters

single · complete · average · centroidsingle: d(Cᵢ,Cⱼ) = min_(x∈Cᵢ, y∈Cⱼ) d(x,y) complete: d(Cᵢ,Cⱼ) = max_(x∈Cᵢ, y∈Cⱼ) d(x,y) average: d(Cᵢ,Cⱼ) = (1/|Cᵢ||Cⱼ|) Σ Σ d(x,y) centroid: d(Cᵢ,Cⱼ) = d( μ(Cᵢ), μ(Cⱼ) )
  • Single linkage can "chain" and find elongated clusters; complete favors compact ones; average/centroid sit in between.
  • No predefined k and an interpretable tree are the big wins; the cost and noise-sensitivity are the price.

Density- & model-based (no predefined k)

DBSCAN

Density-Based Spatial Clustering grows clusters from dense regions using two parameters:

  • ε (epsilon) — neighborhood radius; minPts — minimum points to call a region dense.
  • Points are classified as core (≥ minPts neighbors within ε), border (near a core but not itself dense), or noise (neither).
  • Finds arbitrarily-shaped clusters and handles outliers natively — but struggles when clusters have very different densities, and is sensitive to ε/minPts. OPTICS extends it to varying densities.

Gaussian Mixture Models (GMM)

  • Assumes data is a mixture of Gaussians; fit with Expectation–Maximization (EM) — soft, probabilistic assignments that can model elliptical (not just spherical) clusters.
  • Choose the number of components with BIC/AIC. (k-Means is essentially a hard-assignment special case of GMM.)

Others that auto-discover k

Mean-shift (climbs to density peaks, bandwidth parameter), Affinity Propagation (message-passing exemplars), Spectral clustering (eigen-gap of a similarity graph, great for non-convex shapes), and BIRCH (scalable CF-tree).

Evaluating clusters

Without labels, evaluation is intrinsic — based on cohesion and separation.

silhouette of point i · a=mean intra-cluster dist, b=mean nearest-other-cluster dists(i) = ( b(i) − a(i) ) / max( a(i), b(i) ) s ∈ [−1, 1]
  • Inertia / WCSS — total within-cluster squared distance (lower = tighter); always drops as k grows, hence the elbow method.
  • Silhouette — near +1 means well-matched to its own cluster and far from others; near 0 means on a boundary; negative means likely misassigned.
  • Davies–Bouldin index — average ratio of within-cluster scatter to between-cluster separation; lower is better.

k-Means assumptions & limitations

  • Requires k up front.
  • Assumes spherical, roughly equal-sized clusters — struggles with elongated, nested, or varying-density shapes (use DBSCAN/GMM/spectral instead).
  • Sensitive to outliers (they drag centroids) and to initialization (local minima → use k-means++).
  • Feature scaling is mandatory — standardize or normalize so no feature dominates the distance.
