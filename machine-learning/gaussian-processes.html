Gaussian Processes

NonparametricBayesianRegressionClassification A distribution over functions that provides predictions with calibrated uncertainty — inference happens directly in function space.

01 Overview

A Gaussian process (GP) is a nonparametric Bayesian model that defines a prior directly over functions. Instead of choosing a fixed parametric form (linear, polynomial, neural network) and fitting its weights, a GP lets the data speak by placing a probability distribution over all smooth functions consistent with the observations.

  • Nonparametric — the model's complexity grows with the data. There is no fixed finite parameter vector; the training data themselves become part of the model.
  • Bayesian — predictions come with principled uncertainty estimates: the model knows what it doesn't know, outputting wide error bars far from observed data and tight ones near it.
  • Kernel-based — a kernel function encodes prior assumptions about function smoothness, periodicity, or length scale. The same kernel trick that powers SVMs lets GPs work in infinite-dimensional feature spaces.
  • Exact inference — for regression with Gaussian noise, the posterior distribution is available in closed form. No sampling, no variational tricks.
When to reach for a GP. GPs excel when you need calibrated uncertainty (Bayesian optimization, active learning), when data is small-to-moderate (n < a few thousand), or when the function is smooth and low-dimensional. They scale as O(n³) in the basic formulation, so for large datasets sparse approximations or other models may be preferred.

02 Definition & intuition

A Gaussian process is a collection of random variables, any finite subset of which has a joint Gaussian distribution.

GP definition f(x) ~ GP(m(x), k(x, x'))

The GP is fully specified by two functions:

  • Mean function m(x) = E[f(x)] — the expected value of the function at input x. Often set to zero; any prior mean belief can be absorbed into the kernel design or subtracted from the data.
  • Covariance (kernel) function k(x, x') = Cov(f(x), f(x')) — encodes how similar function values at two inputs are expected to be. This is where all the structural prior knowledge lives.

The finite-dimensional view

Pick any finite set of inputs x₁, x₂, …, xₙ. The corresponding function values form a multivariate Gaussian:

any finite collection is jointly Gaussian [f(x₁), f(x₂), …, f(xₙ)]ᵀ ~ N(μ, K) where μᵢ = m(xᵢ), Kᵢⱼ = k(xᵢ, xⱼ)

Intuitively, a GP is an infinite-dimensional Gaussian — a Gaussian distribution not over vectors but over functions. Drawing a sample from the GP means drawing an entire function; the kernel determines how "wiggly" or "smooth" these sampled functions look.

Consistency (Kolmogorov). The definition requires that marginalization is consistent: if we draw (f(x₁), f(x₂), f(x₃)) jointly, the marginal over (f(x₁), f(x₂)) must agree with what we would get by querying only those two points. The Gaussian family satisfies this automatically — marginals of a Gaussian are Gaussian.

03 Mean & kernel functions

The mean function

The mean function m(x) can in principle be any function, but in practice it is almost always set to zero. This is not restrictive: the GP posterior mean will adapt to the data regardless. A non-zero prior mean is useful when strong domain knowledge suggests a baseline trend.

Kernel properties

A valid kernel must produce a positive semi-definite covariance matrix for any finite set of inputs — the same Mercer condition underlying SVMs. Kernels can be combined: the sum, product, or composition of valid kernels is again valid, enabling compositional kernel design.

Common kernels

All formulas below use r = ‖x − x'‖ for the Euclidean distance.

  • Length scale ℓ — controls how far apart inputs can be and still be correlated. Small ℓ → wiggly functions; large ℓ → smooth, slowly-varying functions.
  • Signal variance σ² — the overall amplitude. Controls how far from the mean function values typically stray.
  • The Matérn family generalizes RBF by adding a smoothness parameter ν. As ν → ∞ it recovers the RBF. ν = 3/2 and ν = 5/2 are the most common practical choices.
Kernel composition. Because sums and products of kernels are kernels, you can build expressive models compositionally: k = k_RBF + k_periodic captures a smooth trend plus a seasonal pattern; k = k_linear × k_periodic captures growing oscillations. This compositionality is a key advantage of the GP framework.

04 GP regression

Given training inputs X = {x₁, …, xₙ} with noisy observations y = f(X) + ε where ε ~ N(0, σ²ₙI), the GP posterior at a new test point x* is obtained by conditioning the joint Gaussian. This is a standard result from multivariate normal conditioning.

The joint prior

Stack the training outputs y and test prediction f* into one vector. Their joint distribution is Gaussian with block covariance:

block covariance of the joint Gaussian Σ₁₁ = K(X,X) + σ²ₙI (n × n) training-training + noise Σ₁₂ = K(X,x*) (n × 1) training-test Σ₂₁ = K(x*,X) (1 × n) test-training Σ₂₂ = K(x*,x*) (1 × 1) test-test = prior variance

The posterior (predictive distribution)

Conditioning the joint Gaussian on the observed y gives the posterior in closed form:

GP posterior — closed-form predictive distribution f* | X, y, x* ~ N(μ*, σ²*) μ* = k*ᵀ (K + σ²ₙI)⁻¹ y σ²* = k** − k*ᵀ (K + σ²ₙI)⁻¹ k*

where k* = K(X, x*) is the vector of covariances between training points and x*, and k** = k(x*, x*) is the prior variance at x*.

Equation decoder: μ* = k*ᵀ (K + σ²ₙI)⁻¹ y
Say it
The posterior mean is a kernel-weighted average of the observations
Shapes
k* = (n×1), K = (n×n), y = (n×1) → μ* = scalar
Scope
Prediction at a single test point x*; vectorizes to multiple test points
Plain words
Measure how similar x* is to each training point (via the kernel), then blend the training outputs using those similarities as weights — nearby points dominate the prediction
Tiny example
Two training points, one at distance 0.5 (high kernel value) and one at distance 3.0 (near-zero kernel value) — the prediction is almost entirely the nearby observation
Why it’s here
This is the GP’s prediction — the entire purpose of fitting the model
  • Posterior mean μ* is a linear combination of the observations, weighted by how correlated x* is with each training point. Far from all data → weights vanish → μ* → 0 (prior mean).
  • Posterior variance σ²* is the prior variance minus an information gain. Near data → large information gain → low uncertainty. Far from data → uncertainty returns to the prior level.
  • The variance does not depend on the observed y values — only on input locations X. Where you observe determines how certain you are, regardless of what you observe.
  • In practice the inverse is never formed explicitly; solve (K + σ²ₙI) α = y using the Cholesky factorization K + σ²ₙI = LLᵀ, giving O(n³/3) rather than the O(n³) of a full inverse.

Worked example (2 observations)

Kernel: k(x,x') = exp(−(x−x')²/2) (RBF, ℓ = 1, σ² = 1). Noise: σ²ₙ = 0.1. Observations: x₁ = 0, y₁ = 1 and x₂ = 2, y₂ = −1.

build the kernel matrix and solve K + σ²ₙI = [[1.1, 0.135], [0.135, 1.1]] α = (K + σ²ₙI)⁻¹ y ≈ [1.04, −1.04]

Predict at x* = 1 (midpoint): k* = [e⁻&sup0;·&sup5;, e⁻&sup0;·&sup5;] = [0.607, 0.607].

prediction at the midpoint μ* = 0.607 · 1.04 + 0.607 · (−1.04) = 0.0 σ²* = 1.0 − [0.607, 0.607] · [0.491, 0.491]ᵀ ≈ 0.40

By symmetry, the posterior mean is zero at the midpoint between observations of +1 and −1. The posterior standard deviation σ* ≈ 0.63 is much smaller than the prior σ = 1, reflecting information from both nearby observations.

06 Weight-space vs function-space view

GPs can be derived from two equivalent perspectives, and understanding both deepens intuition.

Weight-space view

Start with a Bayesian linear model using explicit feature vectors φ(x):

Bayesian linear model f(x) = φ(x)ᵀ w, w ~ N(0, Σ_p)

The prior on weights induces a prior on functions. The covariance between function values at two inputs is:

induced kernel from the weight prior k(x, x') = φ(x)ᵀ Σ_p φ(x')

The posterior over w given data translates directly to predictions at new points. This is the standard Bayesian linear regression view, and the kernel is determined by the choice of features φ and weight prior Σ_p.

Function-space view

Instead of reasoning about weights, work directly with the GP defined by the kernel k(x, x'). The function-space view is more general because:

  • It avoids constructing φ(x) explicitly — critical when φ is infinite-dimensional (e.g., the RBF kernel corresponds to an infinite set of Gaussian basis functions).
  • The computational cost depends on n (data points), not on the dimensionality of the feature space.
  • The representer theorem guarantees that the GP posterior mean lies in the span of kernel evaluations at training points: f*(x) = Σᵢ αᵢ k(xᵢ, x).
Duality with kernel methods. The GP posterior mean is identical to the solution of kernel ridge regression (or kriging) with regularization parameter σ²ₙ. SVMs, kernel PCA, and GPs all share the same kernel trick; the GP additionally provides the full posterior distribution with uncertainty, not just a point estimate.

07 Hyperparameters & marginal likelihood

The kernel function typically has hyperparameters θ = {ℓ, σ², σ²ₙ, …} that must be set. In the GP framework, there is a principled Bayesian way to do this: maximize the marginal likelihood (also called the evidence or type-II maximum likelihood).

log marginal likelihood log p(y | X, θ) = −½ yᵀ K⁻¹_y y − ½ log |K_y| − (n/2) log(2π) where K_y = K(X,X) + σ²ₙI

The three terms have distinct roles:

  • Data fit: −½ yᵀ K⁻¹_y y — penalizes hyperparameters that make the observed data unlikely under the model. Favors flexible models that can fit the data.
  • Complexity penalty: −½ log |K_y| — penalizes overly flexible models. A larger length scale ℓ means a simpler (smoother) model, reducing this term.
  • Normalization: −(n/2) log(2π) — constant; does not affect optimization.

The balance between data fit and complexity penalty implements an automatic Occam's razor. Gradients of the log marginal likelihood with respect to θ can be computed analytically, enabling gradient-based optimization.

gradient of log marginal likelihood ∂ log p(y|X,θ) / ∂θ_j = ½ yᵀ K⁻¹_y (∂K_y/∂θ_j) K⁻¹_y y − ½ tr(K⁻¹_y ∂K_y/∂θ_j)
Automatic Occam’s razor. Unlike cross-validation-based hyperparameter tuning, the marginal likelihood optimizes all hyperparameters jointly in a single objective. It naturally penalizes model complexity: a model that is too flexible wastes probability mass on functions that don’t match the data, reducing the marginal likelihood. This is the same principle behind Bayesian model selection.

08 GP classification

For classification with binary labels y ∈ {0, 1}, the Gaussian likelihood is replaced by a Bernoulli likelihood through a squashing function:

GP classification model f(x) ~ GP(0, k(x, x')) p(y = 1 | f(x)) = σ(f(x)) where σ is the logistic function

The non-Gaussian likelihood means the posterior p(f | X, y) is no longer Gaussian, and exact inference is intractable. Two main approximation strategies exist:

Laplace approximation

  • Find the mode f̂ of the posterior p(f | X, y) by iteratively reweighted least squares (Newton's method).
  • Approximate the posterior as a Gaussian centered at the mode: q(f) = N(f̂, (K⁻¹ + W)⁻¹), where W = diag(−∇² log p(y|f)) is the Hessian of the log-likelihood.
  • Simple to implement, but can be inaccurate when the true posterior is skewed.

Expectation propagation (EP)

  • Approximates each likelihood factor p(yᵢ | fᵢ) by an un-normalized Gaussian tᵢ(fᵢ).
  • Iteratively refines these local approximations by moment matching — ensuring the approximate posterior shares the first two moments with the true posterior locally.
  • Generally more accurate than Laplace, especially for the marginal likelihood, but slightly more complex and can fail to converge.
Why not just threshold? A naive approach would apply GP regression then threshold at 0.5. But the GP classification framework properly accounts for the nonlinear relationship between the latent function and class probabilities, producing better-calibrated uncertainties. The predictive probability integrates over the posterior uncertainty in f, not just the point estimate.

09 Computational cost & scalable approximations

The main bottleneck of exact GP inference is the Cholesky factorization of the n × n kernel matrix.

OperationTimeSpace
Cholesky of K + σ²ₙIO(n³/3)O(n²)
Solve for αO(n²)O(n)
Predict mean at one x*O(n)O(n)
Predict variance at one x*O(n²)O(n)
Log marginal likelihoodO(n³/3)O(n²)

For n beyond a few thousand, the cubic cost and quadratic storage become prohibitive. Several approximation strategies exist:

Sparse GPs (inducing points)

  • Select m « n inducing points Z = {z₁, …, z_m} and approximate the full kernel matrix using the Nyström factorization: K(X,X) ≈ K(X,Z) K(Z,Z)⁻¹ K(Z,X).
  • Reduces cost to O(nm²) time and O(nm) space — linear in n when m is fixed.
  • The inducing points can be optimized jointly with kernel hyperparameters via the marginal likelihood.
  • Variational formulations provide a lower bound on the marginal likelihood, ensuring a principled approximation.

Random Fourier features

  • For shift-invariant kernels (like RBF), Bochner's theorem guarantees k(x − x') = E[φ(x)ᵀ φ(x')] where φ(x) is a random feature map drawn from the kernel's spectral density.
  • Approximate the kernel using D random features, then apply standard linear regression in the D-dimensional feature space. Cost: O(nD²).

Other approaches

  • Structured kernel interpolation (SKI / KISS-GP): exploits grid structure for near-linear scaling via Kronecker and Toeplitz algebra.
  • Stochastic variational inference: combines inducing points with minibatch training for truly large-scale GPs.
  • Local GPs: partition the input space and fit independent GPs to each region.
The cubic bottleneck in context. For n < 2000, exact GPs are fast enough for interactive use. For n up to ~10&sup4;, sparse methods with m ≈ 500–1000 inducing points work well. Beyond n ≈ 10&sup5;, stochastic variational methods or alternative models (deep ensembles, neural processes) may be more practical.

10 Connections & applications

Connections to other methods

  • Kernel ridge regression — the GP posterior mean is exactly the kernel ridge regression solution with regularization parameter λ = σ²ₙ. The GP adds the full posterior variance, turning a point estimate into a distribution.
  • SVMs — both use the kernel trick, but SVMs produce a point classification boundary (maximum margin), while GPs produce a full predictive distribution. SVMs use the hinge loss; GPs use the negative log marginal likelihood.
  • Neural tangent kernel — infinitely wide neural networks with random initialization converge to GPs. The kernel of this GP is the neural tangent kernel (NTK), connecting deep learning to the GP framework.
  • Kriging — GP regression is known as kriging in geostatistics, where it was independently developed for spatial interpolation of mineral deposits and weather data.
  • PCA & kernel PCA — the same kernel that defines a GP can be used for nonlinear dimensionality reduction.

Key applications

  • Bayesian optimization — use a GP as a surrogate model of an expensive black-box function (e.g., hyperparameter tuning of a neural network). An acquisition function (expected improvement, upper confidence bound) uses the GP’s mean and variance to decide where to query next. The uncertainty is essential: it balances exploitation (query where the mean is good) and exploration (query where uncertainty is high).
  • Active learning — select the next data point to label where the GP uncertainty is largest, minimizing the total number of labels needed.
  • Spatial statistics — model temperature, pollution, soil properties as smooth functions of location, with the GP providing interpolated maps with uncertainty bands.
  • Probabilistic numerics — model the solution of differential equations, integrals, or optimization steps as GPs, turning numerical approximation errors into posterior uncertainty.
  • Multi-fidelity modeling — combine cheap approximate evaluations with expensive high-fidelity evaluations using correlated GPs.
