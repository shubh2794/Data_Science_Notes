Learning Paradigms

How a model learns depends on what signal it gets. The big families — supervised, unsupervised, self-supervised, and reinforcement — differ mainly in what kind of feedback the data provides.

Machine Learning Foundations Taxonomy

01 It's about the signal

Pick a paradigm to see what the model actually sees.

What feedback does the model get? The available signal defines the paradigm

02 Supervised

  • Learn a mapping X → Y from labeled examples; minimize prediction error.
  • Classification (discrete labels) and regression (continuous) — most of classical ML lives here.
  • Bottleneck: labels are expensive to collect.

03 Unsupervised

  • No labels — find structure in the data itself.
  • Clustering groups similar points; dimensionality reduction compresses; density estimation models the distribution.
  • Used for exploration, compression, and anomaly detection.

04 Self-supervised

  • Create labels from the data itself — hide part of the input and predict it (next token, masked word, image patch).
  • Gets the scale of unsupervised data with the signal of supervised learning — the engine behind LLMs and modern representation learning.
  • Often a pretraining step, followed by supervised fine-tuning.

05 Reinforcement learning

  • An agent takes actions and learns from a reward signal — no labeled "correct answer," just feedback on outcomes.
  • Optimizes long-term return through trial and error — see Reinforcement Learning and preference optimization.
  • The third paradigm beyond supervised/unsupervised.
Also: semi-supervised (a little labeled + lots unlabeled) and transfer learning (reuse a pretrained model) sit between these.

06 Takeaways

  • The signal defines the paradigm: labels (supervised), structure (unsupervised), self-generated labels (self-supervised), reward (RL).
  • Self-supervised pretraining + supervised fine-tuning is the modern recipe.
  • RL learns from outcomes, not answers.
  • Frames everything in Machine Learning and Deep Learning.
