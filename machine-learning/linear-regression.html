Linear Regression

Fit a line to continuous targets by least squares: the assumptions behind it, why squared error is the right loss, the closed-form and iterative ways to solve it, and how to judge the result honestly. The geometry (projection onto the column space) lives in Linear Algebra.

Linear regression & its assumptions

Model the target as a weighted sum of the features plus an irreducible noise term ε:

population model · fitted predictiony = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ + ε ŷ = β̂₀ + β̂₁x₁ + β̂₂x₂ + … + β̂ₚxₚ
  • β₀ — intercept (value of y when all features are 0).
  • βⱼ — coefficient: expected change in y per one-unit increase in xⱼ, holding others fixed.
  • ε — error term capturing everything the features don't explain.

In matrix form, with X the n × (p+1) design matrix (a leading column of 1s carries the intercept):

matrix formŷ = X β̂ X is n × (p+1) β̂ is (p+1) × 1

The assumptions (why they matter)

OLS inference is only trustworthy when these roughly hold:

  • Linearity — the expected target is a linear function of the predictors.
  • Independence of errors — residuals are uncorrelated (matters most in time series).
  • Homoscedasticity — residual variance is constant across all predictor levels.
  • Normality of errors — residuals are approximately normal (needed for valid confidence intervals / p-values).
  • No multicollinearity — predictors aren't highly correlated with each other.
  • No endogeneity — predictors are uncorrelated with the error term.
Prediction vs. inference. Only the first two assumptions matter much if you just want good predictions on new data. The rest matter when you want to read the coefficients — standard errors, p-values and confidence intervals all assume homoscedastic, roughly normal, independent errors. Violate them and the point estimates can still be fine while the uncertainty around them is nonsense.

Reading the coefficients honestly

  • Coefficients carry units. βⱼ is measured in units of y per unit of xⱼ. A coefficient of 0.003 on "square feet" and 12 000 on "number of bathrooms" say nothing about relative importance — they're in different currencies. Magnitudes are only comparable after the features are put on a common scale.
  • Standardized coefficients. Z-score every feature first ((xⱼ − mean)/sd) and βⱼ becomes "change in y per one standard deviation of xⱼ" — now the magnitudes are comparable. See feature scaling.
  • "Holding others fixed" is an assumption, not a fact. If x₁ and x₂ move together in your data, no observation ever varies one while freezing the other, so the model is extrapolating into a region it never saw. This is exactly why multicollinearity makes coefficients unstable.
  • Association is not causation. A coefficient summarizes a conditional association in the sample you fit on. Reading it as "if we intervene and raise xⱼ by 1, y rises by βⱼ" requires causal assumptions the regression itself cannot supply.
  • The intercept is often meaningless when x = 0 is outside the data (a house with zero square feet). Centering the features makes β₀ the prediction at the average input, which is usually interpretable.
Linear ≠ straight line. "Linear" refers to linearity in the parameters, not the raw features. y = β₀ + β₁x + β₂x² + ε is still linear regression — it's linear in β₀, β₁, β₂ — and so are interaction terms like β₃(x₁·x₂). Push the polynomial degree too far and you buy variance instead of signal: see the bias-variance tradeoff.

Why squared error?

Squared error is not an arbitrary choice of "distance". It is the maximum-likelihood loss under a specific, very common noise assumption — and it happens to be extremely convenient to optimize.

1 · It is the MLE under Gaussian noise

Assume the noise is independent and identically distributed Gaussian, ε ~ N(0, σ²). Then each observation's likelihood, and the log-likelihood of the whole sample, are:

Gaussian noise ⟹ least squaresp(yᵢ | xᵢ, β) = (1 / √(2πσ²)) · e^( −(yᵢ − ŷᵢ)² / 2σ² ) ln L(β) = −(n/2)·ln(2πσ²) − (1 / 2σ²) · Σᵢ (yᵢ − ŷᵢ)² argmax_β ln L(β) = argmin_β Σᵢ (yᵢ − ŷᵢ)²

Everything except the sum is constant in β, so maximizing the likelihood is literally minimizing the sum of squared errors. Squared error isn't a heuristic — it is the correct loss if you believe the errors are Gaussian.

2 · It is convex and smooth

  • MSE is a quadratic in β, so it is convex: there is a single global minimum and no local traps. Gradient descent from anywhere converges to the same answer (see convexity).
  • It is differentiable everywhere, including at zero error — so the gradient is always defined and the closed-form solution exists.
  • The quadratic penalty means large errors dominate: doubling an error quadruples its cost. That is a feature when big misses are genuinely worse, and a bug when the big misses are just outliers.

3 · The alternatives, and what they buy you

LossFormBehaviour
MSE (L2)(1/n) Σ (yᵢ − ŷᵢ)²Estimates the conditional mean. Smooth, convex, closed form. Very sensitive to outliers — one bad point can drag the whole line.
MAE (L1)(1/n) Σ |yᵢ − ŷᵢ|Estimates the conditional median. Robust: an outlier contributes a bounded gradient of ±1 no matter how far away it is. But it is non-differentiable at 0 and has no closed form (it's a linear program / iterative solve).
Huberquadratic near 0, linear in the tailsThe compromise: smooth and mean-like for small residuals, robust and median-like for large ones. Costs you one hyperparameter, δ.
Huber loss on a residual r = y − ŷLδ(r) = ½ r² if |r| ≤ δ Lδ(r) = δ (|r| − ½δ) if |r| > δ

The two pieces agree in value and in slope at |r| = δ, which is what keeps Huber differentiable everywhere. Note the parallel to the likelihood story: MAE is the MLE under Laplace noise, whose heavier tails make a distant point far less surprising than a Gaussian would.

Try it. In the least-squares playground below, hit "Add an outlier" and watch a single point yank the OLS line — that is the quadratic penalty doing its worst, and the reason MAE and Huber exist.

Fitting: estimating the coefficients

"Fitting" means choosing the β̂ that minimize the sum of squared errors. Setting the gradient of the MSE to zero gives a linear system you can solve exactly; or you can walk downhill. Both routes reach the same optimum, because the problem is convex.

The gradient

gradient of the MSE · vector and per-coefficient forms∇_β MSE = (2/n) · Xᵀ (X β̂ − y) ∂MSE/∂βⱼ = (2/n) · Σᵢ (ŷᵢ − yᵢ) · xᵢⱼ

Read the per-coefficient form as a correlation between the residuals and the feature. If the errors still line up with xⱼ, that coefficient is wrong and the gradient says which way to move it. At the optimum every such correlation is zero — the residuals are orthogonal to every column of X, which is the same "error ⟂ column space" condition the projection derivation arrives at geometrically.

Normal equation (closed form)

Set the gradient to zero and rearrange:

setting the gradient to zero gives the normal equationsXᵀ(X β̂ − y) = 0 ⟹ Xᵀ X β̂ = Xᵀ y ⟹ β̂ = (Xᵀ X)⁻¹ Xᵀ y
  • Solves for the optimum in one shot — no learning rate, no iterations, no convergence to babysit.
  • Costs roughly O(n p²) to build XᵀX plus O(p³) to solve it, so the feature count is what hurts, not the sample count.
  • Requires XᵀX to be invertible. It is singular under exact multicollinearity (one feature is a linear combination of others, e.g. a full set of dummy variables with no reference level) or whenever p ≥ n. Near-singularity is just as bad in practice: coefficients blow up and flip sign on tiny data changes.
  • Real solvers never form the inverse. They factor X with QR or SVD and solve directly. That is numerically far more stable, and the SVD route yields the Moore–Penrose pseudoinverse, which returns the minimum-norm solution even when XᵀX is singular instead of erroring out.

Gradient descent (iterative)

repeat until convergenceβ := β − α · ∇_β MSE = β − α · (2/n) · Xᵀ(Xβ − y)
  • α is the learning rate (step size). Too large → oscillates or diverges; too small → crawls. Mechanics, schedules and convergence live on the optimization page.
  • Each full-batch step costs O(np) — linear in both dimensions, and it never needs a p × p matrix in memory.
  • SGD / mini-batch replaces the full sum with a sample, so the data never has to fit in memory at once — the only option for streaming or out-of-core data.
  • Gradient descent on OLS is scale-sensitive: unscaled features produce elongated elliptical contours and a zig-zagging path. See feature scaling.
Which one? A rule of thumb. Up to a few thousand features the normal equation (via QR/SVD) is fine and is usually faster than tuning a learning rate — that is what LinearRegression in a typical library does. Go iterative when p reaches tens of thousands (the O(p³) factor bites), when n is too large to hold in memory, when data arrives as a stream, or when you want a loss the closed form can't express (MAE, Huber, L1 penalties, logistic).

A worked example

Three points: (1, 2), (2, 3), (3, 5). With one feature the normal equation collapses to the familiar covariance-over-variance form:

simple linear regressionβ̂₁ = Σᵢ (xᵢ − x̄)(yᵢ − ȳ) / Σᵢ (xᵢ − x̄)² β̂₀ = ȳ − β̂₁ x̄
plugging in · x̄ = 2, ȳ = 10/3β̂₁ = ( (−1)(−4/3) + (0)(−1/3) + (1)(5/3) ) / ( 1 + 0 + 1 ) = 3 / 2 = 1.5 β̂₀ = 10/3 − 1.5 · 2 = 1/3 ≈ 0.333 ŷ = 0.333 + 1.5x → residuals = ( +1/6, −1/3, +1/6 )

The residuals sum to zero (that's the intercept's job) and are uncorrelated with x (that's the slope's job). Squared: SSres = 1/6 ≈ 0.1667, and against the mean SStot = 14/3 ≈ 4.667, so MSE = 1/18 ≈ 0.056 and R² = 1 − (1/6)/(14/3) = 27/28 ≈ 0.964. Those are exactly the numbers the playground below reports.

Evaluating a linear model

mean squared error · lower is betterMSE = (1/n) Σᵢ (yᵢ − ŷᵢ)² RMSE = √MSE MAE = (1/n) Σᵢ |yᵢ − ŷᵢ|
coefficient of determination · share of variance explainedR² = 1 − [ Σᵢ (yᵢ − ŷᵢ)² / Σᵢ (yᵢ − ȳ)² ]
  • MSE is in squared target units; RMSE puts it back in the target's own units, which is what you report to a human. MAE is the same idea without the outlier amplification.
  • R² compares your model against the dumbest possible baseline — always predicting ȳ. R² = 0.8 means the model explains 80% of the variance in y. It goes negative for a model worse than the mean, which is entirely possible on a test set.

Adjusted R², and why it exists

R² can never decrease when you add a feature. Even pure noise gets a small nonzero coefficient that shaves a little off SSres, so "maximize R²" always says "add more columns". Adjusted R² pays a price for each predictor:

adjusted R² · n observations, p predictorsR²_adj = 1 − (1 − R²) · (n − 1) / (n − p − 1)
  • It can decrease when a new feature doesn't earn its keep — that's the whole point. Use it to compare models with different numbers of predictors.
  • It is unbounded below and is not a proportion, so don't read it as "percent of variance".
  • On the worked example above (n = 3, p = 1, R² = 27/28): R²_adj = 1 − (1/28)(2/1) = 13/14 ≈ 0.929.

R² is not a validity check

A high R² can hide a badly wrong model. Fit a straight line to data that is genuinely a parabola and you can still land at R² = 0.95 while the residuals trace a clean smile. Classic constructed datasets make this vivid: several samples with identical means, variances, correlations, regression lines and R² look completely different when plotted — one linear, one curved, one dominated by a single outlier. The summary statistic cannot see the difference; the scatter plot can.

Residual diagnostics — the real check

Plot the residuals (yᵢ − ŷᵢ) against the fitted values ŷᵢ. Under a correctly specified model this is a structureless horizontal band around zero. Any pattern is a message:

  • Curvature (a U or an arch) → the linearity assumption is broken. Add a polynomial term, an interaction, or transform the feature.
  • A funnel / megaphone that widens with ŷ → heteroscedasticity. Point estimates survive; standard errors and intervals do not. Fix with a log transform of the target, weighted least squares, or robust standard errors.
  • A few points miles from the band → outliers. Check leverage before deleting anything: a high-leverage point at an extreme x can pivot the entire line.
  • Waves over time / index order → autocorrelated errors, the independence assumption failing. Standard errors are understated.
  • A Q-Q plot of the residuals checks the normality assumption; a heavy-tailed plot argues for Huber or robust inference.
