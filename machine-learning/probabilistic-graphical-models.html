Probabilistic Graphical Models

ProbabilisticGraphsInference Represent a joint distribution over many random variables as a graph — nodes are variables, edges encode who depends on whom — and read off factorizations, independencies, and efficient inference algorithms directly from the structure.

01 Overview

A joint distribution over K variables has exponentially many entries. Graphical models tame that explosion by exploiting conditional independence.

The core insight: most real-world variables interact only locally. If you encode "who talks to whom" in a graph, the joint distribution factorizes into a product of small, local functions — one per node or one per clique — and you can do inference, learning, and sampling without ever writing down the full table.

  • Directed models (Bayesian networks / belief networks): edges have arrows; each node stores p(xᵢ | parents(xᵢ)).
  • Undirected models (Markov random fields): edges have no arrows; each maximal clique stores a potential function ψ_c(x_c).
  • Factor graphs: a bipartite graph unifying both views — variable nodes and factor nodes.
Why it matters. Every classical generative model — naive Bayes, hidden Markov models, mixture models, topic models — is a graphical model. Modern deep generative models (VAEs, diffusion, normalizing flows) are too. The language of PGMs gives you the tools to reason about all of them: factorization, independence, message passing, and variational inference.

02 Directed graphical models (Bayesian networks)

A Bayesian network is a directed acyclic graph (DAG) where:

  • Each node is a random variable.
  • Each directed edge from parent to child means the child's distribution depends on the parent.
  • No directed cycles are allowed — "acyclic" is essential.

The graph encodes a factorization of the joint distribution:

Bayesian network factorizationp(x₁, x₂, …, xₖ) = ∏ᵢ p(xᵢ | pa(xᵢ))

where pa(xᵢ) denotes the parent set of node xᵢ in the DAG. Each factor is a conditional probability table (CPT) for discrete variables or a conditional density for continuous ones.

Worked example — a 5-node network

Consider: D → G ← I, I → S, G → L (Difficulty, Intelligence, Grade, SAT, Letter). The joint factorizes as:

p(D, I, G, S, L) = p(D) · p(I) · p(G | D, I) · p(S | I) · p(L | G)

Instead of storing one giant table with |D|·|I|·|G|·|S|·|L| entries, we store five small CPTs. If each variable is binary, the full table has 2⁵ = 32 entries; the factored form uses only 1 + 1 + 4 + 2 + 2 = 10 parameters.

Classic Bayesian-network examples

  • Naive Bayes: a single class node C pointing to every feature x₁, …, xₙ. All features are conditionally independent given the class — the "naive" assumption is the graph structure. → Naive Bayes page
  • Hidden Markov models: a chain of hidden states z₁ → z₂ → … → zₜ with observations x₁, …, xₜ dangling below. → HMMs & CRFs page
  • Mixture models: a latent cluster variable z pointing to the observed data x, with parameters shared across components. → Clustering page
  • Latent Dirichlet allocation: a topic model — per-document topic proportions → per-word topic assignments → observed words, with plate notation for the repeated structure.

03 D-separation — reading independence from the graph

The killer feature of a DAG is that you can read off conditional independence statements without doing any computation. The rule is called d-separation (directed separation).

Three building blocks

Every path between two nodes is a chain of triples. Each triple is one of three types, and each can be blocked or active depending on a conditioning set Z:

Triple typeStructureBlocked whenActive when
ChainA → B → CB ∈ Z (observed)B ∉ Z
ForkA ← B → CB ∈ Z (observed)B ∉ Z
Collider (v-structure)A → B ← CB ∉ Z and no descendant of B in ZB ∈ Z or any descendant of B ∈ Z

Chains and forks behave intuitively: observing the middle node blocks the flow of information. The collider is the surprise — it is blocked by default and opened when you condition on it (or on any of its descendants). This is the "explaining away" effect: learning about one cause of an observed effect tells you about the other cause.

The d-separation rule

Definition. Two nodes A and B are d-separated given a set Z if every undirected path from A to B is blocked — i.e., contains at least one blocked triple. D-separation implies conditional independence: A ⊥ B | Z.

The criterion is both sound (every d-separation implies a true independence for all distributions faithful to the graph) and complete (if two nodes are d-connected, there exists a distribution faithful to the graph where they are dependent).

Worked example

In the student network D → G ← I → S, G → L:

  • D ⊥ I | ∅? Path D → G ← I — G is a collider, unobserved, so the path is blocked. Yes, d-separated.
  • D ⊥ I | G? Same path — G is a collider, now observed, so the path is active. No, d-connected (explaining away).
  • D ⊥ S | I? Path D → G ← I → S — I is in the chain I → S and is observed, blocking that sub-path. The collider G is unobserved, blocking D → G ← I. Yes, d-separated.

05 Undirected graphical models (Markov random fields)

An undirected graphical model (also called a Markov random field, MRF) uses an undirected graph. Conditional independence is simpler here: A ⊥ B | Z if removing the nodes in Z disconnects A from B (the global Markov property).

The joint is specified by potential functions (also called factors or compatibility functions) over the maximal cliques of the graph:

Gibbs distributionp(x) = (1/Z) · ∏_c ψ_c(x_c)
partition function (normalizer)Z = ∑_x ∏_c ψ_c(x_c)
  • Each ψ_c(x_c) ≥ 0 is a clique potential — it assigns a non-negative "compatibility score" to each assignment of the variables in clique c. It is not a probability.
  • The partition function Z sums (or integrates) over all configurations to normalize the product into a valid distribution. Computing Z is generally intractable — it is a sum over exponentially many states.
  • Potentials are often written in log form: ψ_c(x_c) = exp(−E_c(x_c)), where E_c is an energy function. Then p(x) = (1/Z) exp(−∑_c E_c(x_c)) — a Boltzmann distribution.

Directed vs. undirected — when to use which

Directed (Bayesian network)Undirected (MRF)
FactorizationProduct of conditional probabilitiesProduct of potentials / Z
NormalizationAutomatic (each CPT sums to 1)Requires computing Z
Independence testD-separation (non-trivial, colliders)Graph separation (intuitive)
Causal semanticsNatural (edges = direct causes)No causal direction
Typical useGenerative modelling, causal reasoningSpatial/relational data, image labelling, physics
Hammersley–Clifford theorem. A strictly positive distribution satisfies the Markov properties of a graph if and only if it can be written as a Gibbs distribution with potentials on the cliques of that graph. This is the foundational result linking graph structure to factorization for undirected models.

06 Factor graphs

A factor graph is a bipartite graph with two types of nodes:

  • Variable nodes (circles): one per random variable.
  • Factor nodes (squares): one per factor in the distribution.
  • An edge connects a variable node to a factor node if and only if the variable appears in that factor's argument.
factor-graph jointp(x) ∝ ∏_a f_a(x_a)

Factor graphs are more explicit than either DAGs or undirected graphs: they remove ambiguity about which variables participate in which factor. Two different Bayesian networks can have the same undirected "moral graph" but different factor graphs. The sum-product algorithm (belief propagation) is naturally stated on factor graphs.

Converting to a factor graph

  • From a Bayesian network: each CPT p(xᵢ | pa(xᵢ)) becomes a factor node connected to xᵢ and all its parents.
  • From an MRF: each clique potential ψ_c becomes a factor node connected to all variables in clique c.

07 Exact inference

The central task: given evidence (some variables observed), compute the posterior marginals or the MAP assignment of the remaining variables. This requires summing (or maximizing) over all unobserved configurations.

Variable elimination

The simplest exact algorithm. To marginalize out a variable xⱼ:

  • Collect all factors that mention xⱼ and multiply them into a single intermediate factor.
  • Sum out xⱼ from that product to produce a new, smaller factor.
  • Repeat for each variable to eliminate, in some chosen order.
variable elimination step (summing out xⱼ)τ(x_rest) = ∑_{xⱼ} ∏_{a : xⱼ ∈ scope(f_a)} f_a(x_a)

The cost depends critically on the elimination ordering: a bad order creates huge intermediate factors. The optimal ordering is NP-hard to find, but greedy heuristics (min-degree, min-fill) work well in practice. The maximum size of any intermediate factor is determined by the graph's treewidth.

Belief propagation on trees (sum-product algorithm)

On a tree-structured factor graph, variable elimination can be organized as message passing. Each node sends a message to each neighbor exactly once (leaves first, root last, then back down). Two passes (up and down) compute all marginals simultaneously — much more efficient than running VE separately for each query.

variable → factor messageμ_{x→f}(x) = ∏_{g ∈ nb(x) \ f} μ_{g→x}(x)
factor → variable messageμ_{f→x}(x) = ∑_{x_f \ x} f(x_f) · ∏_{y ∈ nb(f) \ x} μ_{y→f}(y)
marginal at variable xp(x) ∝ ∏_{f ∈ nb(x)} μ_{f→x}(x)

On trees, belief propagation gives exact marginals. This is the engine behind the forward-backward algorithm for HMMs and the Viterbi algorithm (max-product variant). → HMMs & CRFs page

Junction tree algorithm

For graphs with cycles, the junction tree (clique tree) algorithm converts the graph into a tree of clusters (cliques), then runs exact belief propagation on that tree. It is exact but its cost is exponential in the treewidth — making it feasible only for graphs with moderate treewidth.

08 Approximate inference

When exact inference is intractable (high treewidth, continuous variables, enormous state spaces), we turn to approximations. Two major families:

Deterministic: variational methods

Approximate the true posterior p(z | x) with a simpler distribution q(z) by minimizing the KL divergence KL(q ‖ p), which is equivalent to maximizing a lower bound on the log-evidence (the ELBO):

evidence lower boundlog p(x) ≥ 𝔼_q[ log p(x, z) ] − 𝔼_q[ log q(z) ] = ELBO(q)
  • Mean-field approximation: assume q(z) = ∏ᵢ qᵢ(zᵢ) (fully factored). Each factor is updated in turn while holding the others fixed. Simple but ignores all posterior correlations.
  • Loopy belief propagation: run the sum-product messages on a graph with cycles as if it were a tree. Not guaranteed to converge, and the "marginals" are approximate, but often surprisingly accurate. It can be derived as a fixed-point condition of the Bethe free energy, a variational objective.
  • Expectation propagation: approximates each factor with an exponential-family term, iteratively refining a global approximation. More accurate than mean-field for correlated posteriors.

Stochastic: sampling / MCMC

Draw samples from the posterior and use them to estimate expectations. With enough samples, these methods are asymptotically exact.

  • Gibbs sampling: sample each variable in turn from its conditional given the current values of all others. The conditionals are easy to derive from the graphical model — they depend only on the variable's Markov blanket (parents, children, and children's other parents in a Bayesian net).
  • Metropolis–Hastings: propose a new state from a proposal distribution, accept or reject based on the acceptance ratio. Does not need normalized probabilities (the partition function cancels).
  • Particle methods (sequential Monte Carlo): weighted samples propagated forward in time — natural for temporal models like HMMs and state-space models.
Variational vs. MCMC trade-off. Variational methods are fast and deterministic but give a biased approximation (the gap between the ELBO and the true evidence). MCMC is unbiased in the limit but slow to mix and hard to diagnose convergence. Modern practice often combines both: use variational inference for a quick approximate posterior, then refine with MCMC if needed.

09 Learning in graphical models

Given data, we want to learn either the parameters of a known graph structure, or the structure itself.

Parameter learning

  • Fully observed data, directed model: MLE decomposes — each CPT is estimated independently by counting. For discrete variables: p̂(xᵢ = k | pa(xᵢ) = j) = count(xᵢ=k, pa=j) / count(pa=j). Add Dirichlet priors for Bayesian smoothing. → Probability page
  • Fully observed data, undirected model: MLE requires computing Z and its gradient, which is generally intractable. Practical workarounds: contrastive divergence, pseudo-likelihood, score matching.
  • Partially observed (latent variables): the log-likelihood is no longer concave. Use the EM algorithm: E-step computes expected sufficient statistics using inference, M-step updates parameters. EM is the workhorse behind mixture models, HMMs, and LDA.

Structure learning

  • Score-based: search over DAG structures using a score (BIC, Bayesian marginal likelihood). The search space is super-exponential in the number of nodes; greedy hill-climbing with edge additions/deletions/reversals is the standard approach.
  • Constraint-based: use statistical independence tests (e.g. conditional independence tests) to build the skeleton, then orient edges. The PC algorithm and its variants follow this approach.
  • Hybrid: combine scores and constraints. The GES (Greedy Equivalence Search) algorithm searches over equivalence classes of DAGs.
Observational equivalence. Multiple DAGs can encode exactly the same set of conditional independencies — they form a Markov equivalence class. From observational data alone, you can only identify the equivalence class (a CPDAG), not a unique DAG. Identifying the true causal direction requires interventional data or additional assumptions.

10 Connections & modern applications

PGMs are not an isolated subject — they connect to and underpin many areas:

  • Conditional random fields (CRFs): undirected models that condition on the entire input — they are discriminative MRFs. By conditioning, they avoid modelling the input distribution and the partition function depends only on the output structure. → HMMs & CRFs page
  • Causal inference: Bayesian networks with a causal interpretation. Interventions (do(X=x)) are modelled by graph surgery — deleting incoming edges to the intervened variable. D-separation then gives causal, not just statistical, independence.
  • Deep generative models: VAEs define a directed latent-variable model p(z)p(x|z) and use variational inference for the intractable posterior p(z|x). The ELBO objective from Section 08 is exactly the VAE training loss.
  • Knowledge graphs: can be seen as large-scale relational graphical models where entities and relations define the structure and link prediction is a form of inference. → Knowledge Graphs page
  • Message-passing neural networks: GNNs generalize belief propagation — each node aggregates messages from neighbors and updates its representation, echoing the sum-product algorithm on a factor graph.

Big picture. The PGM framework gives you a language for modelling (graphs and factorizations), a calculus for reasoning (d-separation, Markov properties), and an algorithmic toolkit for computation (message passing, variational inference, MCMC). Every probabilistic model you encounter — from a two-variable Bayes' rule problem to a billion-parameter diffusion model — can be understood through this lens.
