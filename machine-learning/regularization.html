Regularization

Model Generalization Methods designed to prevent overfitting by penalizing complexity, forcing parameters to be small, or introducing stochastic noise.

Overview

To improve generalization and prevent overfitting on the training set, it is essential to manage the complexity of your model. Regularization accomplishes this by constraining the magnitude of the model's weights during optimization, pushing the model toward simpler, more generalizable hypotheses. This aligns with Occam's razor: simpler hypotheses are more likely to generalize well.

Weight Decay & Why It Matters

Weight decay promotes generalization by penalizing the magnitude of a model’s weights during optimization. It encourages the model to prefer simpler solutions by favoring smaller weights.

Key Benefits of Weight Decay:

  • Minimizing Irrelevant Components: Weight decay modifies the loss function by adding a penalty proportional to the squared norm of the weight vector (L2 norm). This restricts the search space of optimal weights. If the original loss function is J_(original), weight decay transforms it into:
    J_(regularized) = J_(original) + λ / 2 ‖w‖₂²
    where λ (regularization strength) controls the penalty's importance. This drives the optimizer to favor smaller weight vectors.
  • Attenuating Outliers: By constraining the magnitude of weights, the model becomes less sensitive to noisy data points or outliers that could otherwise skew training parameters.
  • Stability: Smaller weights lead to a smoother loss landscape, preventing large oscillations in model predictions given small changes in input.
  • Geometric Interpretation: Geometrically, this restricts optimization to a small hypersphere (L₂-ball) around the origin, keeping weight values bounded.

Weight Sparsity & Feature Selection

Weight sparsity is an extreme case of weight decay where certain weights are driven all the way to exactly zero. This is particularly crucial in high-dimensional feature spaces, such as those with high-cardinality categorical variables and feature crosses.

The Challenge of High Cardinality: Consider a housing dataset spanning the globe. Crossing bucketted latitude (10,000 bins) and longitude (20,000 bins) creates 200,000,000 dimensions. Most of these represent areas with no meaningful data (e.g., oceans). Storing and computing these is highly inefficient.
  • L0 Regularization: Directly penalizes the count of non-zero weights: ‖w‖₀ = Σ I(wᵢ ≠ 0). This perfectly targets sparsity. However, L0 is non-convex and NP-hard to optimize for large-scale datasets.
  • L1 Regularization (Lasso): Penalizes the sum of absolute values of weights: ‖w‖₁ = Σ |wᵢ|. It serves as a convex surrogate for L0 and successfully drives uninformative features' weights to exactly zero, performing automatic feature selection.
  • L2 Regularization (Ridge): Penalizes the squared magnitudes. While it drives weights to small values, it does not set them to exactly zero. Thus, the model remains dense.

How Sparsity Helps Generalization:

  • Noise Reduction: Zeroing out weights removes noisy, irrelevant dimensions entirely from predictions.
  • Reduced Hypothesis Space: Restricts the model to operate inside a smaller, simpler feature space, preventing the learning of spurious correlation.
  • Efficiency & Interpretability: Sparse models require less RAM and computation at inference and make it clear which features drive predictions.

Effect on Gradient Update Rules

Adding L1 or L2 regularization terms directly alters the cost landscape and weight updates.

Regularized cost function J_(regularized) = J_(original) + λ J_(penalty)

Depending on the norm chosen, the penalties and derivatives differ significantly:

  • L1 Regularization Norm & Update:
    J_(L₁) = Σₖ |wₖ| ⟹ w := w - α (∂ J_(orig)) / (∂ w) - α λ sign(w)
    Here, L1 subtracts a constant force (αλ) in the opposite direction of the weight's sign, regardless of its magnitude. When the weight crosses zero, the discontinuity at 0 traps the weight, setting it to exactly zero.
  • L2 Regularization Norm & Update:
    J_(L₂) = Σₖ wₖ² ⟹ w := w - α (∂ J_(orig)) / (∂ w) - 2αλ w
    L2 subtracts a force proportional to the current magnitude of the weight. You can think of this as removing a fixed percentage (e.g., 5%) of the weight at each step. As the weight gets smaller, the penalty shrinks to near-zero, meaning the weight is diminished but never quite reaches exactly zero.

Regularization Strength (λ) Effects

The choice of the regularization constant λ dictates the balance between fitting accuracy and weight constraints:

Setting L1 Regularization (Lasso) L2 Regularization (Ridge)
"Too Small" λ No apparent effect; model fits noise, coefficients remain unconstrained. No apparent effect; coefficients remain unconstrained, leading to potential overfitting.
"Appropriate" λ Sparsity is achieved. Irrelevant or redundant weights drop to exactly 0, leaving only useful features. Weight magnitudes decrease following a centered distribution that becomes peaked around 0, reducing variance.
"Too Large" λ Weights uniformly plateau near zero. The constant penalty -αλsign(w) overpowers the loss gradient, leading to underfitting. All weights rapidly collapse toward zero, severely restricting model capacity and causing underfitting.

Choosing L1 vs. L2 Norm

While both norms reduce overfitting, their mathematical behaviors make them suited for different situations:

  • Error Minimization: L2-norm is mathematically smoother and generally better at minimizing prediction error because it penalizes larger errors more strongly, avoiding extreme outliers in prediction residuals.
  • Geometric Views:
    • L2 views all features similarly. Geometrically, it is represented as a circle, meaning it assumes features are "equidistant". If you are unsure of feature importance, L2 is the safer default.
    • L1 treats distance between features differently (represented as a square). If you expect only a small subset of features to carry real predictive power, L1 is optimal.
  • Rules of Thumb:
    • Broadly, L1 is more about "What?" (identifying which features matter) while L2 is about "How much?" (controlling the magnitude of all features).
    • L1 produces sparse vectors (great for memory limits or real-time feature extraction constraints).
    • L2 is smooth, captures energy, and is computationally easier to solve analytically but remains dense.

Geometric Interpretation

The different behavior of L1 and L2 can be visualized geometrically as a constraint boundary in the weight space intersecting the contours of the original loss function J.

Constraint Spaces:
  • L1 Constraint Region: Forms a diamond (polytope) defined by |w₁| + |w₂| ≤ C. The corners of the diamond lie exactly on the coordinate axes (w₁=0 or w₂=0).
  • L2 Constraint Region: Forms a circle (hypersphere) defined by w₁² + w₂² ≤ C.
Because the L1 diamond has sharp corners on the axes, the elliptical contours of the original loss function are highly likely to first intersect the constraint boundary at one of these corners. This forces one of the weights to be exactly zero. In contrast, the circular L2 boundary has no corners, so the intersection almost always occurs at a point where both weights are non-zero.

Deep Learning Regularization

While weight decay and sparsity apply generally, deep neural networks utilize specialized stochastic and target-level regularization methods.

1. Dropout Regularization (Srivastava et al., 2014)

During training, dropout randomly zeroes out a fraction p (e.g., 50%) of the activations in a layer at each step.

  • Co-adaptation Prevention: Neurons cannot rely on the presence of specific other neurons, forcing them to learn robust features that are useful in conjunction with many different random subsets of other neurons.
  • Ensemble Approximation: Dropout can be interpreted as training an ensemble of 2^M sub-networks with shared weights.
  • Inverted Dropout: To avoid changing the network behavior at test time, activations are scaled by 1 / (1-p) during training:
    hₜᵣₐᵢₙ := (mask ⊙ h) / (1-p)
    This ensures that at test time, we can run the network without masking and without scaling the weights.

2. Label Smoothing

Instead of training a model to predict hard binary targets (where the correct class is 1 and all others are 0), label smoothing softens the target labels by distributing a small probability mass ε across all classes.

Smoothed target probability for class i y'ᵢ = yᵢ (1 - ε) + ε / K

Where K is the number of classes, and ε is a hyperparameter (typically 0.1).

Why Use Label Smoothing?

  • Overconfidence & Infinite Logits: Softmax cross-entropy loss approaches zero only as the logit of the correct class approaches infinity relative to the others. This forces weights to grow indefinitely to maximize this difference, causing the model to overfit and yield overconfident, poorly-calibrated predictions.
  • Logit Bounding: By forcing the target to be 1-ε instead of 1.0, the model's logits are bounded to a finite difference, preventing the weights from exploding.
  • When to Use: Highly effective in classification models with many classes (e.g., translation, large-scale image labels) or where label noise is present.
  • When to Avoid: Avoid label smoothing if the model is used directly as a teacher in Knowledge Distillation, as it washes out the useful "dark knowledge" (relative probabilities of incorrect classes) that the student needs to learn.
