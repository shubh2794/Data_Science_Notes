Semi-Supervised Learning

Machine LearningLearning ParadigmsUnlabeled Data A few labeled examples are expensive; abundant unlabeled data is cheap. Semi-supervised learning (SSL) uses both to learn better than either alone.

01 The SSL setting

When labeling is expensive but raw data is plentiful.

  • Given: a small labeled set D_l = {(x₁, y₁), ..., (x_l, y_l)} and a large unlabeled set D_u = {x_{l+1}, ..., x_{l+u}} with u >> l.
  • Goal: learn a predictor f(x) that is better than training on D_l alone by exploiting structure in D_u.
  • Inductive SSL learns a general function that can predict on new, unseen points. Transductive SSL only labels the specific unlabeled points in D_u.
  • SSL is particularly useful in domains like medical imaging, speech recognition, and NLP where annotation is costly but raw data is abundant.
Key insight. Unlabeled data tells you about p(x) — the marginal distribution. If the structure of p(x) is informative about p(y|x), SSL can help. If it is not, SSL may actually hurt performance.

02 Core assumptions

SSL only works when the data obeys certain structural assumptions.

  • Smoothness assumption — If two points x₁ and x₂ are close in input space, their labels y₁ and y₂ should also be close. This is shared with supervised learning but SSL enforces it on unlabeled data too.
  • Cluster assumption — Data form distinct clusters, and points in the same cluster likely share a label. The decision boundary should pass through low-density regions, not through clusters.
  • Low-density separation — The flip side of the cluster assumption: the decision boundary should lie where few data points (labeled or unlabeled) reside.
  • Manifold assumption — High-dimensional data lies on a lower-dimensional manifold. Points on the same manifold (connected by dense data) should share a label.
cluster assumption — decision boundary avoids dense regions p(y = 1 | x) should change slowly within high-density regions of p(x) p(y = 1 | x) may change sharply only where p(x) is small
When assumptions hold. Two moons dataset: a supervised classifier with 2 labeled points per class draws a poor linear boundary. But the unlabeled points reveal the moon shapes, so label propagation along the manifold recovers the correct boundary. See the interactive demo below.

04 Self-training (pseudo-labeling)

The simplest SSL method: use the model's own predictions as labels.

  1. Train a base model on the labeled set D_l.
  2. Predict labels for unlabeled data D_u.
  3. Select the most confident predictions (above a threshold τ).
  4. Add those pseudo-labeled examples to the training set.
  5. Retrain. Repeat until convergence or no confident predictions remain.
pseudo-label selection D_pseudo = { (xⱼ, ŷⱼ) : max_c p(y = c | xⱼ; θ) ≥ τ } D_l ← D_l ∪ D_pseudo
  • Pros: Works with any base classifier. Simple to implement. No assumptions about data structure.
  • Cons: Confirmation bias — early mistakes become training signal. The model reinforces its own errors, especially when τ is too low.
  • Mitigation: use a high threshold τ, add pseudo-labels gradually, and periodically retrain from scratch.
Worked example. Spam filter with 50 labeled emails and 10,000 unlabeled. Train on 50 → predict on 10,000 → pick the 200 most confident predictions (τ = 0.95) → retrain on 250 → repeat. Each round the model sees more of the data distribution.

05 Co-training

Two views, two classifiers, each teaching the other.

  • Requires two conditionally independent views (feature sets) of each data point — e.g., for a web page, the page text and the anchor text of incoming links.
  • Train classifier f₁ on view 1 and f₂ on view 2 using the labeled data.
  • Each classifier labels the unlabeled data from its own view, and the most confident predictions are added to the other classifier's training set.
  • Repeat: f₁ teaches f₂ and vice versa.
co-training update rule f₁ labels x using features V₁ → confident pseudo-labels added to training set of f₂ f₂ labels x using features V₂ → confident pseudo-labels added to training set of f₁
  • Why it works: If the views are truly independent given the label, one view's confident prediction provides genuinely new information to the other.
  • Limitation: The conditional independence assumption rarely holds perfectly. In practice, any two diverse classifiers (different algorithms, different feature subsets) can be used as a weaker variant called multi-view learning.

06 Graph-based methods

Build a similarity graph over all data; propagate labels along edges.

Constructing the graph

  • Nodes = all data points (labeled + unlabeled). Edges connect similar points.
  • kNN graph: connect each node to its k nearest neighbors.
  • Gaussian (RBF) weights: w_{ij} = exp(-‖xᵢ − xⱼ‖² / 2σ²) — nearby points get strong edges.

Label propagation

  • Initialize: labeled nodes get their true label; unlabeled nodes get zero (or uniform).
  • Iterate: each unlabeled node updates its label to the weighted average of its neighbors' labels.
  • Clamp labeled nodes after each step (they never change).
  • Converges to a smooth labeling that respects the graph structure.
label propagation update — f is the label vector, W is the weight matrix, D is the degree matrix f(t+1) = D⁻¹ W f(t) then clamp: fᵢ(t+1) = yᵢ for all labeled i

Label spreading (normalized variant)

  • Uses the normalized graph Laplacian L = I − D⁻½ W D⁻½ for better-behaved propagation.
  • Adds a clamping parameter α ∈ (0, 1) that controls how strongly labels are pulled toward the initial assignment vs. the graph consensus.
label spreading — normalized propagation with soft clamping f(t+1) = α · D⁻½ W D⁻½ f(t) + (1 − α) · y

Graph Laplacian regularization

  • The graph Laplacian L = D − W measures smoothness: f⊃T L f = ½ Σ_{ij} w_{ij} (fᵢ − fⱼ)².
  • Minimizing f⊃T L f encourages neighboring nodes to have similar labels — the mathematical formalization of the smoothness assumption.
  • The full objective balances fitting labeled data with graph smoothness:
graph-regularized objective minimize Σ_{i=1}^{l} (fᵢ − yᵢ)² + λ f⊃T L f
Connection to clustering. Spectral clustering also uses the graph Laplacian — its eigenvectors define cluster structure. Label propagation can be viewed as a soft version of spectral clustering with seed labels.

07 Transductive SVMs (S3VM)

Push the SVM decision boundary into low-density regions.

  • Standard SVM maximizes margin using only labeled data. A transductive SVM (TSVM or S3VM) also considers unlabeled data: find the labeling of D_u and the hyperplane that jointly maximize the margin.
  • Directly implements the low-density separation assumption: the decision boundary should avoid regions where p(x) is high.
transductive SVM objective minimize (1/2) ‖w‖² + C_l Σ_{i=1}^{l} max(0, 1 − yᵢ(w·xᵢ + b)) + C_u Σ_{j=l+1}^{l+u} max(0, 1 − |w·xⱼ + b|)
  • The first penalty is the standard hinge loss on labeled data. The second pushes unlabeled points away from the boundary (penalizes small |w·x + b|).
  • Optimization is NP-hard in general (the unlabeled labels are discrete). Practical solvers use iterative heuristics, branch-and-bound, or continuous relaxations.
  • C_l and C_u control the influence of labeled vs. unlabeled data.

08 Generative models for SSL

Model the joint distribution; unlabeled data sharpens the generative model.

  • Assume each class generates data from a known family — e.g., a Gaussian mixture model (GMM) with one component per class.
  • Labeled data ties components to class labels. Unlabeled data helps estimate the mixture parameters (μ_c, Σ_c, π_c) more accurately via EM:
EM for semi-supervised GMM E-step: γ_{jc} = p(y = c | xⱼ; θ) for each unlabeled xⱼ M-step: update μ_c, Σ_c, π_c using labeled data (hard) + unlabeled data (soft, weighted by γ)
  • Works well when the generative model is a good fit. If the true data distribution does not match the assumed model, adding unlabeled data can degrade performance.
  • Related to Naive Bayes with EM — one of the earliest practical SSL methods.

09 Modern deep SSL

Consistency regularization and pseudo-labeling, scaled up with deep networks.

Consistency regularization

  • Core idea: a good model should give similar predictions for similar inputs. Apply random augmentations (flip, crop, noise) to an unlabeled input and penalize prediction disagreement.
consistency loss L_cons = Σ_{j} ‖p(y | Aug₁(xⱼ); θ) − p(y | Aug₂(xⱼ); θ)‖²

  • MixMatch averages predictions across multiple augmentations, sharpens the distribution (lower temperature), then applies MixUp between labeled and unlabeled batches.
FixMatch total loss L = L_supervised + λ_u · (1/|B_u|) Σ_{j ∈ B_u} 𝟙[max(q_j) ≥ τ] · H(ŷ_j, p(y | StrongAug(xⱼ))) where q_j = p(y | WeakAug(xⱼ)), ŷ_j = argmax(q_j), H = cross-entropy

Contrastive pre-training as implicit SSL

  • Contrastive learning learns representations from unlabeled data by pulling augmentations of the same image together and pushing different images apart.
  • Fine-tuning these representations with a small labeled set is a form of two-stage SSL: unsupervised pre-training + supervised fine-tuning.
  • The boundary between self-supervised pre-training and SSL is fuzzy — both leverage unlabeled data, but SSL methods typically use labeled and unlabeled data jointly.

10 When SSL fails

More data is not always better.

  • Assumption violation: If the cluster assumption does not hold (e.g., classes overlap heavily or the boundary runs through a dense region), unlabeled data provides misleading structure.
  • Model mismatch (generative): If the assumed generative model (e.g., Gaussian) is wrong, more unlabeled data makes the model converge to the wrong thing faster.
  • Confirmation bias (self-training): Early wrong pseudo-labels get reinforced. The model becomes overconfident in its own mistakes.
  • Class imbalance: The majority class can dominate pseudo-labels, starving minority classes of correctly propagated labels.
  • Distribution mismatch: If D_u comes from a different distribution than D_l, the unlabeled structure is irrelevant or harmful.
Practical rule. Always compare SSL against a supervised-only baseline. If SSL does not improve validation performance, the assumptions likely do not hold for your data.

12 Takeaways

  • SSL exploits unlabeled data when the structure of p(x) is informative about p(y|x) — this requires the smoothness, cluster, or manifold assumption to hold.
  • Self-training is the simplest approach (pseudo-label → retrain), but risks confirmation bias. Use high confidence thresholds.
  • Graph-based methods (label propagation/spreading) formalize the smoothness assumption via the graph Laplacian and are mathematically principled.
  • Modern deep SSL (FixMatch, MixMatch) combines consistency regularization with pseudo-labeling and achieves strong results with very few labels.
  • Always validate: SSL can hurt when assumptions are violated. Compare against a supervised-only baseline.
  • The practical recipe: start with self-supervised pre-training + fine-tuning (contrastive learning or masked prediction); if you need joint training, try FixMatch.
