Support Vector Machines

SupervisedMax-margin Find the separating hyperplane with the widest margin; only the points sitting on the margin — the support vectors — define it.

Overview

SVMs (Vapnik & Chervonenkis, 1963) are supervised algorithms for classification and regression, prized for strong performance in high-dimensional spaces. The core idea: find the optimal hyperplane that separates the classes with the largest possible gap. For data that isn't linearly separable, kernel functions implicitly map it to a higher-dimensional space where it becomes separable.

Hyperplane, margin & support vectors

A hyperplane is the decision boundary — in n dimensions it's an (n−1)-dimensional surface defined by a normal vector w and bias b:

hyperplane · decision rulew · x + b = 0 f(x) = sign(w · x + b)
  • The margin is the distance from the hyperplane to the nearest points of either class. Wider margin → better generalization.
  • Support vectors are exactly those nearest points; they alone determine the hyperplane — move any other point and nothing changes.
functional margin (labels yᵢ ∈ {−1,+1}) · geometric margin = functional / ‖w‖yᵢ (w · xᵢ + b) ≥ 1 margin width = 2 / ‖w‖
Functional vs. geometric margin. The functional margin yᵢ(w·xᵢ+b) can be inflated just by scaling w; the geometric margin divides by ‖w‖ to give the true distance. Fixing the functional margin to 1 and minimizing ‖w‖ is what maximizes the real gap.

The optimization problem (hard margin)

Maximizing 2/‖w‖ is the same as minimizing ½‖w‖², giving a clean convex quadratic program:

hard-margin SVM · linearly separable data onlyminimize (1/2) ‖w‖² subject to yᵢ (w · xᵢ + b) ≥ 1 for all i
  • Being convex, it has a unique global optimum — no local minima, unlike neural nets.
  • Solved via Lagrange multipliers → a dual form in which the data appears only as inner products xᵢ·xⱼ (this is what makes kernels possible). Each training point gets a multiplier αᵢ; only support vectors have αᵢ > 0 — the solution is sparse.
dual decision function — depends only on support vectorsf(x) = sign( Σᵢ αᵢ yᵢ K(xᵢ, x) + b )

Soft margin & hinge loss

Real data overlaps, so the hard-margin constraint is too strict. The soft margin introduces slack variables ξᵢ ≥ 0 that allow some points to sit inside the margin or be misclassified, penalized by a parameter C:

soft-margin SVM with slackminimize (1/2) ‖w‖² + C Σᵢ ξᵢ subject to yᵢ (w · xᵢ + b) ≥ 1 − ξᵢ , ξᵢ ≥ 0

Folding the constraints in gives the equivalent hinge-loss form — a margin term plus a per-point penalty that is zero once a point is correctly outside the margin:

hinge loss · regularized objectiveL = Σᵢ max(0, 1 − yᵢ(w·xᵢ + b)) minimize (1/2)‖w‖² + C Σᵢ max(0, 1 − yᵢ(w·xᵢ + b))
The C knob. Large C → heavy penalty on violations → narrow margin, fits training data hard (risk of overfitting). Small C → tolerant, wider margin that ignores some points (more bias, often better generalization). ½‖w‖² is the L2 regularizer.

The kernel trick

When classes aren't linearly separable, map the input to a higher-dimensional feature space φ(x) where they are separable — "a linear model in a higher-dimensional space is a non-linear model in the original space." The trick: the optimization only ever needs inner products, so we can compute them directly with a kernel and never form φ(x) explicitly.

kernel = inner product in the (implicit) feature spaceK(xᵢ, xⱼ) = φ(xᵢ) · φ(xⱼ)

Common kernels

linear · polynomial · RBF (Gaussian) · sigmoidlinear: K(xᵢ,xⱼ) = xᵢᵀ xⱼ polynomial: K(xᵢ,xⱼ) = (xᵢᵀ xⱼ + c)^d RBF: K(xᵢ,xⱼ) = exp(−γ ‖xᵢ − xⱼ‖²) sigmoid: K(xᵢ,xⱼ) = tanh(α xᵢᵀ xⱼ + c)
  • RBF maps to an infinite-dimensional space and is the usual default; γ sets each point's reach (large γ → wiggly, overfit boundary; small γ → smooth).
  • Polynomial captures feature interactions up to degree d; sigmoid mimics a neural-net activation (use cautiously).

Choosing a kernel

KernelBest for
LinearLinearly separable or very high-dimensional data (e.g. text) — fast.
PolynomialKnown feature interactions up to a degree.
RBFGeneral non-linear data — the default starting choice.
SigmoidNiche; performance varies — use with care.

Tune C and (for RBF) γ together by cross-validated grid search — they jointly control the bias–variance trade-off.

SVR & multiclass SVM

Support Vector Regression (SVR)

The same margin idea, flipped for regression: fit a function so that points within an ε-wide tube around it incur no loss, and only points outside the tube (the support vectors) are penalized. Kernels apply just as in classification.

Multiclass

  • SVMs are binary at heart, so multiclass is built from many binary SVMs:
  • One-vs-Rest (OvR) — one classifier per class (class c vs. everything else); pick the highest-scoring. k classifiers.
  • One-vs-One (OvO) — one classifier per class pair, majority vote. k(k−1)/2 classifiers (the common default for SVMs).

Pros, cons & applications

Pros

  • Effective in high dimensions (even when features > samples).
  • Robust to overfitting when the margin is clear; the solution is sparse (only support vectors matter).
  • Versatile via kernels for non-linear boundaries.

Cons

  • Scales poorly to very large datasets (quadratic programming is expensive).
  • Performance hinges on kernel choice and on tuning C/γ.
  • Kernelized models are harder to interpret; storing support vectors is memory-heavy.

Where they shine

Handwriting recognition (MNIST), text categorization / spam, bioinformatics (cancer detection); regression (prices, forecasting); and outlier/novelty detection (one-class SVM).
