Survival Analysis

Time-to-event data with a twist: you often do not know when the event happened, only that it had not happened yet. Survival analysis is the statistical machinery for learning from incomplete observations — estimating how long things last, comparing treatments, and modelling how covariates shift the risk over time.

01 Overview

The core problem: we observe durations, not all of them complete, and want to draw valid conclusions anyway.

Many questions in science and industry are about how long until something happens. How long until a patient relapses? Until a customer churns? Until a machine breaks down? In each case the response variable is a non-negative duration T, sometimes called the survival time, failure time, or event time. What makes this different from ordinary regression is censoring: for some subjects the event has not yet occurred when the study ends, so the true duration is unknown — only a lower bound is observed.

The setup

  • T — the true (possibly unobserved) event time for a subject.
  • C — the censoring time: the time at which observation ends without an event.
  • Y = min(T, C) — what you actually record: the earlier of the two.
  • δ = I(T ≤ C) — the event indicator: 1 if the event was observed, 0 if censored.
  • Your data: n triples (Yᵢ, δᵢ, xᵢ), where xᵢ is a vector of covariates.
the observation equationYᵢ = min(Tᵢ, Cᵢ), δᵢ = I(Tᵢ ≤ Cᵢ) if δᵢ = 1 → you saw the event at Yᵢ if δᵢ = 0 → you only know Tᵢ > Yᵢ (censored — partial information, not no information)

Ignoring censored observations — dropping them or treating Y as if it were T — produces biased estimates. Censored subjects tend to have longer survival times (they ran out of follow-up), so dropping them underestimates survival, and treating their Y as actual event times overestimates the event rate. Survival analysis handles this correctly.

Where it appears

  • Clinical trials — time to death, relapse, or adverse event under treatment vs. control.
  • Customer churn — time from signup to cancellation; active users are right-censored.
  • Reliability engineering — time to component failure; units still running are censored.
  • Recidivism — time from release to reoffending.
  • Web analytics — time to conversion after first visit.
Takeaway: survival analysis is not a single algorithm — it is a family of tools (nonparametric, semiparametric, parametric) unified by the idea that censored observations carry information and must be used, not discarded.

02 Censoring

The event happened, but you missed it — or it has not happened yet. The type of missingness matters.

Types of censoring

TypeWhat you knowTypical cause
Right censoringT > Y (event after last observation)Study ends, patient drops out, subscription still active
Left censoringT < Y (event before first observation)Disease already present at screening; defect existed before inspection
Interval censoringL < T ≤ R (event between two visits)Periodic check-ups detect the event between visits, exact time unknown

Right censoring is by far the most common and is the default assumption in most methods below. It comes in three flavours:

  • Type I — fixed end-of-study time; every subject still alive is censored at the same calendar date.
  • Type II — the study continues until a fixed number of events have occurred; the rest are censored.
  • Random — each subject has its own censoring time (dropout, lost to follow-up), drawn from some distribution.

The independent censoring assumption

Almost every standard method assumes that censoring is independent of survival: knowing that a subject is about to be censored tells you nothing about how close the event is. Formally, conditional on covariates x:

independent (non-informative) censoringT ⊥ C | x The event process and the censoring process are conditionally independent.
  • If patients drop out of a drug trial because they feel sicker, censoring is informative — the standard methods break down and survival will be overestimated.
  • Administrative censoring (study ends on a fixed date) is usually safe. Dropout censoring needs careful thought.
  • There is no way to test this assumption from the observed data alone, because you never see both T and C for the same subject.
Takeaway: censoring is not missing data in the usual sense — it is a known lower bound. But the reason for censoring must be unrelated to the event, or the analysis is compromised.

03 Survival & hazard functions

Two complementary ways to describe the distribution of event times — one cumulative, one instantaneous — and each can be recovered from the other.

Survival function

The survival function S(t) is the probability of surviving past time t. It starts at 1 and decreases toward 0:

survival functionS(t) = P(T > t) = 1 − F(t) where F(t) = P(T ≤ t) is the CDF of T S(0) = 1, S(∞) = 0, S is non-increasing

Hazard function (instantaneous risk)

The hazard function h(t) gives the instantaneous rate of the event at time t, given survival up to t. It is not a probability (it can exceed 1) but a rate:

hazard functionh(t) = lim_{Δt→0} P(t ≤ T < t + Δt | T ≥ t) / Δt = f(t) / S(t) where f(t) = dF(t)/dt is the density of T

Intuitively: h(t) · Δt ≈ P(event in the next small window | alive at t). A constant hazard means the event is equally likely at any moment (memoryless). An increasing hazard means aging or wear-out.

Cumulative hazard and the bridge between them

cumulative hazardH(t) = ∫₀ᵗ h(u) du = −log S(t) recovering S from HS(t) = exp(−H(t)) = exp(−∫₀ᵗ h(u) du) recovering h from Sh(t) = −d/dt log S(t) = −S′(t) / S(t)

These three functions — S, h, H — are equivalent representations. Knowing any one pins down the other two. The choice of which to model depends on the method.

Parametric examples

DistributionHazard h(t)Survival S(t)Behaviour
Exponential(λ)λ (constant)exp(−λt)Memoryless; hazard never changes
Weibull(λ, k)λk(λt)^(k−1)exp(−(λt)^k)k < 1: decreasing hazard; k = 1: exponential; k > 1: increasing (wear-out)

Takeaway: S(t) answers "what fraction survives past t?". h(t) answers "how intense is the risk right now for those still alive?". The cumulative hazard H(t) links them: S(t) = exp(−H(t)).

04 Kaplan-Meier estimator

A nonparametric estimate of the survival curve from observed data, including censored observations — the workhorse of survival analysis.

Suppose you want to estimate S(t) from your data without assuming a distributional form. The Kaplan-Meier (KM) estimator does this by computing a running product of conditional survival probabilities at each observed event time.

The product-limit formula

Sort the distinct observed event times: t₁ < t₂ < ⋯ < tₘ. At each event time tᵢ:

  • nᵢ — number of subjects at risk just before tᵢ (still being observed and event-free).
  • dᵢ — number of events (deaths, failures) occurring at tᵢ.
Kaplan-Meier estimatorŜ(t) = ∏ᵢ: tᵢ ≤ t (1 − dᵢ / nᵢ) = ∏ᵢ: tᵢ ≤ t (nᵢ − dᵢ) / nᵢ Each factor is the conditional probability of surviving past tᵢ given survival to just before tᵢ. The product telescopes into an unconditional survival estimate.
  • The KM estimate is a step function: flat between event times, dropping at each event time.
  • Censored observations reduce the risk set nᵢ at subsequent event times without creating a step — they contribute information by staying in the risk set until their censoring time.
  • By convention, censored marks are drawn as small tick marks on the survival curve.
  • If the last observation is censored, the KM curve does not reach zero — the tail is undefined.

Greenwood's formula for variance

Greenwood's variance estimateVar̂(Ŝ(t)) = Ŝ(t)² · ∑ᵢ: tᵢ ≤ t dᵢ / (nᵢ · (nᵢ − dᵢ)) Pointwise 95% CI: Ŝ(t) ± 1.96 · √Var̂(Ŝ(t)) In practice, log-transformed CIs (via log(−log Ŝ(t))) respect the [0, 1] bounds better.

Takeaway: the KM estimator is the first thing to compute with survival data. It makes no distributional assumptions, correctly handles censoring, and the resulting step-function plot gives an immediate visual sense of survival patterns. Median survival is where the curve crosses 0.5.

05 Log-rank test

The standard test for whether two (or more) groups have the same survival distribution, using all the event times jointly.

Once you have KM curves for two groups, the natural question is: are they significantly different? A naive approach — comparing median survival times — ignores most of the data. The log-rank test uses information from every event time, comparing observed events in each group to what you would expect under the null hypothesis of identical survival functions.

Construction

At each distinct event time tᵢ across both groups combined:

quantities at event time tᵢn₁ᵢ, n₂ᵢ = subjects at risk in groups 1, 2 nᵢ = n₁ᵢ + n₂ᵢ d₁ᵢ, d₂ᵢ = events in groups 1, 2 dᵢ = d₁ᵢ + d₂ᵢ expected events in group 1 under H₀E₁ᵢ = dᵢ · n₁ᵢ / nᵢ variance (hypergeometric)Vᵢ = dᵢ · n₁ᵢ · n₂ᵢ · (nᵢ − dᵢ) / (nᵢ² · (nᵢ − 1))
log-rank test statisticχ² = ( ∑ᵢ (d₁ᵢ − E₁ᵢ) )² / ∑ᵢ Vᵢ Under H₀: χ² ~ χ²(1) for two groups For G groups: the statistic generalises to a quadratic form with G − 1 degrees of freedom.

A worked example

Limitations

  • The log-rank test has optimal power under proportional hazards — when the hazard ratio is constant over time. If the survival curves cross, the test can miss a real difference (the positive and negative deviations cancel).
  • Weighted variants (Gehan-Breslow, Peto-Peto, Tarone-Ware) give more weight to early or late events, trading power in one regime for another.
  • The test tells you whether groups differ, not how. For effect size and covariate adjustment, you need the Cox model.
Takeaway: the log-rank test is to survival curves what the two-sample t-test is to means — but it handles censored data and uses all event times, not a single summary. See Hypothesis Testing for the general framework.

06 Cox proportional hazards model

A semiparametric regression model: covariates shift the hazard multiplicatively, and the baseline hazard is left completely unspecified.

The KM estimator and log-rank test handle group comparisons, but what if you want to model the effect of continuous covariates — age, dosage, lab values — on survival? The Cox proportional hazards (PH) model is the standard answer. It is semiparametric: it makes a structural assumption about how covariates affect the hazard, but leaves the shape of the baseline hazard free.

the Cox proportional hazards modelh(t | x) = h₀(t) · exp(β₁x₁ + β₂x₂ + ⋯ + βₚxₚ) = h₀(t) · exp(βᵀx) h₀(t) = baseline hazard (arbitrary non-negative function of time) exp(βᵀx) = relative risk factor (does not depend on time)

The proportional hazards assumption

The model says that covariates multiply the hazard by a constant factor that does not change over time. For two subjects a and b:

the hazard ratio is constant over timeh(t | xₐ) / h(t | x_b) = exp(βᵀ(xₐ − x_b)) ← does not depend on t This is the "proportional" in proportional hazards.

Interpreting coefficients

  • exp(βⱼ) is the hazard ratio for a one-unit increase in xⱼ, holding other covariates fixed.
  • exp(βⱼ) = 1.5 means a 50% higher instantaneous risk of the event.
  • exp(βⱼ) = 0.7 means a 30% lower risk — a protective effect.
  • βⱼ > 0 → higher xⱼ accelerates the event; βⱼ < 0 → higher xⱼ is protective.
  • For a binary covariate (treatment vs. control), exp(β) directly gives the treatment-vs-control hazard ratio.

From hazard to survival

the implied survival functionS(t | x) = exp(−H₀(t) · exp(βᵀx)) = S₀(t)^exp(βᵀx) where H₀(t) = ∫₀ᵗ h₀(u) du and S₀(t) = exp(−H₀(t)) is the baseline survival.

Even without specifying h₀(t), you can rank subjects by risk, compare hazard ratios, and (after estimating H₀) predict individual survival curves.

Takeaway: the Cox model separates what influences risk (the β coefficients) from how risk evolves over time (h₀). You can estimate β without ever specifying h₀ — that is the magic of partial likelihood, explained next. Cross-reference: the coefficient interpretation is analogous to logistic regression, where exp(βⱼ) gives an odds ratio instead of a hazard ratio.

07 Partial likelihood & estimation

The key insight: by conditioning on the observed event times, the baseline hazard cancels out, leaving an estimable function of β alone.

The idea

At each event time tᵢ where subject i had the event, ask: given that someone in the current risk set R(tᵢ) was going to fail right now, what is the probability it was specifically subject i?

conditional probability at event time tᵢP(subject i fails | one failure from R(tᵢ)) = h(tᵢ | xᵢ) / ∑_{j ∈ R(tᵢ)} h(tᵢ | xⱼ) = h₀(tᵢ) · exp(βᵀxᵢ) / ∑_{j ∈ R(tᵢ)} h₀(tᵢ) · exp(βᵀxⱼ) = exp(βᵀxᵢ) / ∑_{j ∈ R(tᵢ)} exp(βᵀxⱼ) ← h₀(tᵢ) cancels!

Multiplying over all event times gives the partial likelihood:

partial likelihoodL(β) = ∏_{i: δᵢ = 1} exp(βᵀxᵢ) / ∑_{j ∈ R(tᵢ)} exp(βᵀxⱼ) log partial likelihoodℓ(β) = ∑_{i: δᵢ = 1} [ βᵀxᵢ − log( ∑_{j ∈ R(tᵢ)} exp(βᵀxⱼ) ) ]
  • It is called partial because it uses only the ordering information at event times, not the exact times or the gaps between them. The baseline hazard h₀(t) never appears.
  • The risk set R(tᵢ) = {j : Yⱼ ≥ tᵢ} is the set of subjects still at risk just before time tᵢ.
  • Censored subjects contribute by staying in the risk set — they appear in the denominator sums as long as they are still being observed.
  • The structure resembles the softmax denominator in logistic regression: at each event time, the failing subject's score is compared against all subjects still at risk.

Estimation

Maximise ℓ(β) numerically via Newton-Raphson. The score (gradient) and observed information (Hessian) have clean forms:

score function (gradient)U(β) = ∂ℓ/∂β = ∑_{i: δᵢ = 1} [ xᵢ − x̄_w(tᵢ) ] where x̄_w(tᵢ) = ∑_{j ∈ R(tᵢ)} xⱼ · exp(βᵀxⱼ) / ∑_{j ∈ R(tᵢ)} exp(βᵀxⱼ) = weighted average covariate in the risk set, with weights ∝ exp(βᵀx)

At the maximum, each event subject's covariate vector equals (on average) the risk-weighted mean of the risk set — the same kind of moment-matching condition as in maximum-likelihood regression.

Estimating the baseline hazard

Once β̂ is known, the baseline cumulative hazard H₀(t) can be estimated nonparametrically:

Breslow estimator of cumulative baseline hazardĤ₀(t) = ∑_{i: tᵢ ≤ t, δᵢ = 1} 1 / ∑_{j ∈ R(tᵢ)} exp(β̂ᵀxⱼ) Ŝ₀(t) = exp(−Ĥ₀(t)) ← baseline survival curve Ŝ(t | x) = Ŝ₀(t)^exp(β̂ᵀx) ← predicted survival for covariate vector x

Handling ties

  • When multiple events share the same time, the partial likelihood must account for the ambiguous ordering. The Breslow approximation treats each tied event as if the full risk set were still present — fast but slightly biased with heavy ties.
  • The Efron approximation adjusts the risk set for each tied event — a better trade-off in practice.
  • The exact method enumerates all orderings — combinatorially expensive but correct.
Takeaway: the partial likelihood factors out the nuisance function h₀(t) entirely. You estimate β without committing to a distributional form — the semiparametric sweet spot. The price: you lose the ability to model absolute baseline risk without the Breslow step.

08 Checking the proportional hazards assumption

The Cox model assumes the hazard ratio is constant over time. If it is not, the model is misspecified — and the coefficient loses its single-number interpretation.

Why it matters

If the treatment effect wears off over time, or a risk factor matters only early on, the true hazard ratio is a function of t. The Cox model forces a single β, which will be some average over time — potentially misleading.

Diagnostic methods

  • Log-log plot. Under proportional hazards, log(−log Ŝ(t)) for different groups should be parallel curves (separated by a constant). Non-parallel or crossing curves signal a violation.
  • Schoenfeld residuals. At each event time, the Schoenfeld residual for covariate j is xⱼ − x̄_w(tᵢ). Under the PH assumption, these should show no trend over time. A formal test correlates the scaled residuals with time.
  • Time-interaction test. Add an interaction term xⱼ · g(t) to the model (e.g., xⱼ · log(t)). If its coefficient is significantly nonzero, the PH assumption is violated for that covariate.

Other residuals

09 Extensions

Beyond the basic Cox model: regularization, time-varying effects, accelerated failure time models, and competing risks.

Regularized Cox models

With high-dimensional covariates (genomics, text features), the Cox partial likelihood can overfit. The same regularization ideas from linear and logistic regression apply:

penalised partial log-likelihoodℓ_pen(β) = ℓ(β) − λ · P(β) P(β) = ∑ⱼ |βⱼ| ← L1 / lasso (sparse: drives coefficients to zero) P(β) = ½ · ∑ⱼ βⱼ² ← L2 / ridge (shrinks all coefficients toward zero) P(β) = α·∑|βⱼ| + ½(1−α)·∑βⱼ² ← elastic net (both sparsity and grouping)
  • The lasso penalty is especially useful in genomics, where thousands of genes are measured but only a few are prognostic.
  • Tuning λ by cross-validation on the partial likelihood (or concordance index) works exactly as in penalized regression.

Time-varying covariates

Some covariates change during follow-up: a patient's blood pressure, a user's activity level. The Cox model extends naturally by splitting each subject's follow-up into intervals where the covariate is constant:

  • Subject i's record becomes multiple rows: (t_start, t_end, δ, x(t)) for each interval.
  • At each event time, the risk set uses the current covariate value xⱼ(tᵢ) rather than a fixed baseline value.
  • The partial likelihood formula is unchanged — only the data preparation differs.

Accelerated failure time (AFT) models

An alternative to proportional hazards. Instead of multiplying the hazard, covariates stretch or compress the time scale:

AFT modellog T = β₀ + β₁x₁ + ⋯ + βₚxₚ + σε where ε has a fixed distribution (standard normal → log-normal AFT, standard extreme-value → Weibull AFT) Interpretation: exp(βⱼ) is an acceleration factor — it scales the time to event. exp(βⱼ) = 2 means covariate doubles survival time (protective).
  • AFT models are fully parametric: you must choose the error distribution.
  • Coefficient interpretation is often more intuitive: "this treatment doubles the expected time to failure" vs. "this treatment halves the hazard rate."
  • Weibull is the only distribution that is simultaneously a PH and an AFT model.

Competing risks

  • When subjects can experience multiple types of events (e.g., death from cancer vs. death from heart disease), standard survival analysis conflates them.
  • Cause-specific hazards model each event type separately, treating other event types as censoring.
  • The cumulative incidence function (CIF) estimates the probability of a specific event type by a given time, accounting for the competing events.
Takeaway: the Cox model is a starting point, not the whole story. High-dimensional data needs regularization; changing covariates need the counting-process formulation; and when the PH assumption fails, AFT models offer a different and sometimes more interpretable framework.

10 Pitfalls & what to remember

Pitfalls

  • Dropping censored subjects. This is the single most common mistake. Censored observations are not useless — they contribute to the risk set and removing them biases every estimate.
  • Ignoring informative censoring. If patients drop out because they are sicker (or healthier), the independent-censoring assumption fails and KM/Cox results are unreliable. Sensitivity analyses (e.g., worst-case imputation) help.
  • Treating censoring time as event time. Replacing T with Y for censored subjects underestimates true survival times.
  • Not checking proportional hazards. A single hazard ratio is meaningless if the effect reverses over time. Always plot the log-log curves and test Schoenfeld residuals.
  • Ignoring ties in continuous-time data. With coarsely recorded times (e.g., survival in whole months), heavy ties make the Breslow approximation inaccurate — use Efron or exact methods.
  • Overfitting with many covariates. As in regression, too many covariates relative to the number of events (not subjects) leads to overfitting. A common rule of thumb: at least 10-15 events per covariate.
  • Reading too much into the KM tail. At late times, the risk set is small and the estimate is noisy. Confidence bands widen dramatically — do not over-interpret the last steps.

What to remember

  • Survival data = durations + censoring indicators. The pair (Yᵢ, δᵢ) is the fundamental observation.
  • S(t), h(t), H(t) are equivalent descriptions. S(t) = exp(−H(t)); h(t) = −S′(t)/S(t).
  • Kaplan-Meier: nonparametric, product-limit, makes no distributional assumptions. The first thing to compute.
  • Log-rank test: compares groups under the null of equal survival; most powerful under proportional hazards.
  • Cox PH model: h(t|x) = h₀(t) · exp(βᵀx). Semiparametric. Partial likelihood eliminates h₀. Coefficients are log hazard ratios.
  • Independent censoring is the assumption that makes everything work — and it is untestable from the data.
