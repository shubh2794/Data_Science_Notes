Calculus

The study of change and accumulation — and, for machine learning, the machinery that turns a loss function into a direction to move. We build it in two halves: the classical analysis (limits → derivatives → Taylor → series → integrals), then the part almost no one teaches properly, matrix differential calculus — the differential-first method that produces every gradient identity you have ever looked up, and that is backpropagation.

02 Limits, continuity, and the o/O notation

Before you can differentiate you need to say precisely what "approaches" means. The ε–δ definition is not pedantry — it is exactly the statement that lets you bound an error, which is what every convergence proof in ML ultimately does.

The limit of a function

Write lim_{x→a} f(x) = L to mean: for every tolerance ε > 0 you name, I can name a radius δ > 0 such that being within δ of a (but not equal to it) forces f(x) to be within ε of L. The quantifier order matters: δ is allowed to depend on ε.

ε–δ definition of a limit lim_{x→a} f(x) = L ⟺ ∀ ε > 0 ∃ δ > 0 : 0 < |x − a| < δ ⟹ |f(x) − L| < ε
  • The point a itself is excluded (0 < |x − a|). The limit describes the neighbourhood, not the value. This is exactly why a derivative — a limit of a quotient that is 0/0 at the point — can exist at all.
  • One-sided limits: lim_{x→a⁻} and lim_{x→a⁺}. The two-sided limit exists iff both exist and agree. This is where ReLU's derivative fails at 0 (§03).
  • Algebra of limits: limits respect +, −, ×, ÷ (denominator non-zero) and composition with continuous functions. Nearly every limit you compute is an application of these plus one hard case.
  • Sequential characterisation: lim_{x→a} f(x) = L iff f(xₙ) → L for every sequence xₙ → a, xₙ ≠ a. This is the practical way to prove a limit does not exist — exhibit two sequences with different limits.

Continuity, and the three theorems that pay for it

f is continuous at c if lim_{x→c} f(x) = f(c) — the limit exists and equals the value. On ℝⁿ → ℝᵐ the same definition reads: for every ε there is a δ with ‖f(c + u) − f(c)‖ < ε whenever ‖u‖ < δ. A vector function is continuous iff each of its m component functions is.

Lipschitz continuity is a strictly stronger, quantitative condition: there is a constant K with ‖f(x) − f(y)‖ ≤ K‖x − y‖ for all x, y. Lipschitz ⟹ uniformly continuous ⟹ continuous, and none of the arrows reverse (√x on [0,1] is uniformly continuous but not Lipschitz).

Lipschitz constants compose and control ‖f(x) − f(y)‖ ≤ K‖x − y‖ K(g ∘ f) ≤ K(g)·K(f) for a linear map: K(A) = ‖A‖₂ = σ_max(A) (largest singular value)
Why Lipschitz is everywhere in modern ML. A network is a composition of layers, so its Lipschitz constant is at most the product of the layers'. Bounding it bounds how much the output can move when the input is perturbed — that is adversarial robustness, spectral normalisation in GANs, and the 1-Lipschitz constraint in Wasserstein critics. It also bounds how much the gradient can move (an L-smooth loss), which is exactly what fixes a safe learning rate η ≤ 1/L (§04).

The o and O notation

An indispensable shorthand for "how fast does the error vanish". Both are statements about a limit, usually u → 0 in calculus (and n → ∞ in complexity analysis).

Little-o and big-O, as u → 0 g(u) = o(h(u)) ⟺ g(u) / h(u) → 0 "vanishes faster than" g(u) = O(h(u)) ⟺ |g(u) / h(u)| stays bounded "at most the same order as"
  • Differentiability at c is exactly f(c + u) = f(c) + A u + o(‖u‖). Twice differentiability upgrades the remainder to o(‖u‖²). That is the whole content of §03 and §09 in one line each.
  • A forward finite difference has truncation error O(h); a central one, O(h²). That single exponent is why central differences are the default for gradient checking (§13).
  • In statistics the same symbols get subscripts — o_p, O_p — for "in probability", which is how consistency and asymptotic normality are stated.

03 The derivative — and what differentiability really requires

Two definitions of the derivative look different and are equivalent in one dimension. The second one is the one that survives to ℝⁿ, to matrices, and to backprop — so learn to think in it.

Definition 1 — the limit of a difference quotient

Derivative at a point f′(c) = lim_{h→0} [ f(c + h) − f(c) ] / h (equivalently lim_{x→c} [f(x) − f(c)]/(x − c) )

Geometrically: the secant line through (c, f(c)) and (c+h, f(c+h)) has slope equal to that quotient. As h → 0 the secant pivots into the tangent. Physically: average rate of change becoming instantaneous rate of change.

Definition 2 — the best affine approximation

Rearrange the limit. Saying the quotient tends to f′(c) is the same as saying the remainder in the affine model dies faster than h:

First-order Taylor formula · the definition that generalises f(c + h) = f(c) + h·f′(c) + r(h), where r(h)/h → 0 as h → 0 the linear part df(c; h) = h·f′(c) is the DIFFERENTIAL of f at c with increment h

Why this is the better definition. Divide the display above by h and let h → 0 and you recover Definition 1, so nothing is lost. But Definition 2 never divides — and division by a vector, or by a matrix, is meaningless. Replace h·f′(c) by A(c)u and |r|/|h| by ‖r‖/‖u‖ and you have the definition of differentiability for ℝⁿ → ℝᵐ (§08) and, verbatim after a vec, for matrix functions (§10). One definition, four levels.

Note also that the differential df(c; h) is an honest number for any h you like — it has nothing to do with "infinitely small quantities". The two arguments play different roles: c must be a point where the derivative exists; h is a free increment. Writing dy = f′(x) dx is legitimate precisely because of this, and (as §08 shows) it stays legitimate under substitution.

Differentiable ⟹ continuous, never the converse

If f is differentiable at c then f(c+h) − f(c) = h f′(c) + r(h) → 0, so f is continuous there. The converse fails badly:

  • f(x) = |x| is continuous at 0, but the left derivative is −1 and the right derivative is +1. A corner.
  • f(x) = x^{1/3} is continuous at 0 with a vertical tangent — the quotient blows up. A cusp.
  • There exist functions continuous everywhere and differentiable nowhere (nowhere-smooth "sawtooth-sum" constructions). Continuity is a much weaker property than intuition suggests.
ReLU and friends. ReLU(x) = max(0, x) is exactly the corner case: differentiable everywhere except x = 0, where the one-sided derivatives are 0 and 1. Frameworks simply pick a value in [0,1] (usually 0) — a subgradient. It works because the non-differentiable set is measure zero and because convex-analysis theory (subgradient methods) covers it. The lesson is that "the gradient" a framework hands you can be a convention, not a theorem.

Rules, and where they come from

The differentiation rules — all provable directly from the affine form d(αu) = α du d(u + v) = du + dv product: d(uv) = (du)v + u dv quotient: d(u/v) = [ v du − u dv ] / v² (v ≠ 0) chain: (g ∘ f)′(c) = g′(f(c)) · f′(c) power / log / exp: d(uᵅ) = α uᵅ⁻¹ du d(log u) = u⁻¹ du d(eᵘ) = eᵘ du d(αᵘ) = αᵘ (log α) du

Writing the rules in differential form rather than derivative form is a deliberate choice. Every one of them survives to matrices essentially unchanged (§10) — the product rule becomes d(UV) = (dU)V + U dV, which is the same line with the factors kept in order because matrices do not commute.

Higher derivatives. f″ = (f′)′ measures how the slope itself changes: curvature. f″ > 0 means convex (curving up), f″ < 0 concave. Note that differentiability of f at a point says nothing about f″ existing there — f(x) = |x|·x is differentiable everywhere but not twice differentiable at 0.

See the secant become the tangent

Drag the evaluation point along the curve and shrink h. Watch two things: the green secant rotating onto the orange tangent, and the error readout — it should fall roughly in proportion to h, which is the statement secant slope = f′(x₀) + O(h).

04 Mean value theorems — turning local into global

The derivative is a local object. The mean value theorem is the bridge that converts local slope information into global statements about the function — and every step-size bound in optimization is downstream of it.

Rolle's theorem

If f is continuous on [a,b], differentiable on (a,b), and f(a) = f(b), then f′(c) = 0 for some c ∈ (a,b). Proof sketch: a continuous function on a compact interval attains its max and min (extreme value theorem). If both occur at the endpoints, f is constant and every interior point works. Otherwise an extremum occurs at an interior point, and at an interior extremum of a differentiable function the derivative must vanish (if it were positive the function would increase to the right; if negative, to the left).

The mean value theorem

Mean value theorem (Lagrange form) f(b) = f(a) + (b − a) f′(c) for some c strictly between a and b equivalently: [ f(b) − f(a) ] / (b − a) = f′(c)

Proof: apply Rolle to ψ(x) = f(x) − f(a) − A(x − a) with A = [f(b) − f(a)]/(b − a). Then ψ(a) = ψ(b) = 0, so ψ′(c) = f′(c) − A = 0 for some c. Geometrically: somewhere on the arc there is a tangent parallel to the chord.

What the MVT immediately buys you

  • Sign of f′ ⟹ monotonicity. If f′ ≥ 0 on an interval then f is non-decreasing there; f′ > 0 gives strict increase. (Careful the other way: f(x) = x³ is strictly increasing yet f′(0) = 0.)
  • f′ ≡ 0 ⟹ constant. The reason "the antiderivative is unique up to a constant" is a theorem and not a convention.
  • A global bound from a local one. |f(b) − f(a)| ≤ (sup |f′|)·|b − a|. This is exactly how a bound on gradients becomes a Lipschitz constant.
  • Cauchy's MVT generalises to two functions: [f(b) − f(a)] g′(c) = [g(b) − g(a)] f′(c), which is what proves l'Hôpital's rule for 0/0 and ∞/∞ indeterminates.
The MVT is false for vector-valued functions. Take f(t) = (cos t, sin t)ᵀ. Then f(2π) − f(0) = 0, but ‖Df(t)‖ = 1 for every t, so no θ makes f(2π) = f(0) + 2π·Df(θ). The fix is either to apply it componentwise with a different c per component, to project onto a fixed direction a (aᵀ[f(c+u) − f(c)] = aᵀ(Df(c+θu))u), or to state it as an inequality — which is the version that actually gets used.

The multivariable MVT and the descent lemma

For a real-valued φ: ℝⁿ → ℝ the theorem survives intact: if the segment from c to c + u lies in the domain, then φ(c + u) = φ(c) + dφ(c + θu; u) for some θ ∈ (0,1), i.e. φ(c+u) = φ(c) + ∇φ(c + θu)ᵀu. (Proof: restrict to the line, ψ(t) = φ(c + tu), and use the 1-D theorem.)

Derivation of the descent lemma. Suppose the gradient is L-Lipschitz: ‖∇φ(x) − ∇φ(y)‖ ≤ L‖x − y‖ ("φ is L-smooth"). Write the exact increment as an integral along the segment and subtract the linear model:

L-smoothness ⟹ a quadratic upper bound (the descent lemma) φ(y) − φ(x) − ∇φ(x)ᵀ(y − x) = ∫₀¹ [ ∇φ(x + t(y−x)) − ∇φ(x) ]ᵀ (y − x) dt ≤ ∫₀¹ L t ‖y − x‖² dt = (L/2)‖y − x‖² ⟹ φ(y) ≤ φ(x) + ∇φ(x)ᵀ(y − x) + (L/2)‖y − x‖²

Now put the gradient step y = x − η∇φ(x) into that bound: φ(y) ≤ φ(x) − η‖∇φ(x)‖² + (Lη²/2)‖∇φ(x)‖² = φ(x) − η(1 − Lη/2)‖∇φ(x)‖². The right-hand side strictly decreases whenever 0 < η < 2/L, and the decrease is largest at η = 1/L, where it equals −‖∇φ(x)‖²/(2L).

That is where "η < 2/L" comes from. The stability condition quoted on the Optimization page — gradient descent converges on a quadratic iff 0 < η < 2/λ_max — is this lemma with L = λ_max(H), because for a quadratic the Hessian's largest eigenvalue is the Lipschitz constant of the gradient. A calculus theorem, not an empirical rule of thumb.

05 Taylor's theorem and the remainder

The MVT approximates a function by a constant plus a slope. Taylor's theorem is the same idea pushed to degree n — and, crucially, it comes with an explicit error term, so it is a tool for bounding, not just for hand-waving.

Taylor's theorem with Lagrange remainder f(x) = f(a) + (x−a)f′(a) + (x−a)²/2! · f″(a) + … + (x−a)ⁿ⁻¹/(n−1)! · f⁽ⁿ⁻¹⁾(a) + Rₙ(x) Rₙ(x) = (x − a)ⁿ / n! · f⁽ⁿ⁾(ξ) for some ξ strictly between a and x

Hypotheses: f⁽ⁿ⁻¹⁾ continuous on the closed interval, f⁽ⁿ⁾ existing on the open one. With n = 1 this is the mean value theorem — Taylor is often called the generalised mean value theorem for exactly that reason. The proof is Rolle applied to a cleverly built auxiliary function that vanishes at both a and x.

Worked example — how many terms do you need?

Approximate e^{0.5} by its Maclaurin polynomial (a = 0). All derivatives of eˣ are eˣ, so |f⁽ⁿ⁾(ξ)| ≤ e^{0.5} < 1.65 for ξ ∈ (0, 0.5), and

Check: T₅(0.5) = 1 + .5 + .125 + .0208333 + .0026042 = 1.6484375 against e^{0.5} = 1.6487213…, an error of 2.8×10⁻⁴ — comfortably inside the n = 5 bound of 1.65·(0.5)⁵/120 ≈ 4.3×10⁻⁴. The factorial in the denominator is why Taylor series converge so violently fast for entire functions and so grudgingly for functions with nearby singularities.

Build the polynomial, watch the remainder

Add terms one at a time. Two behaviours to notice. For sin and exp the approximation improves everywhere as the order grows. For ln(1+x) and 1/(1−x) it improves only inside a radius of convergence (here |x − a| < 1 + a and |x − a| < 1 − a) and diverges spectacularly outside it, no matter how many terms you add — the singularity at x = −1 (resp. x = 1) is felt at every order.

Taylor is the reason second-order optimization exists. Truncate at degree 2 around the current iterate and you get a local quadratic model m(u) = φ(θ) + ∇φᵀu + ½uᵀHu. Minimising m exactly gives u = −H⁻¹∇φ — Newton's method. Replace H by (1/η)I and you get gradient descent. 06 Sequences, series, and why iterative training terminates

Training is a sequence θ₀, θ₁, θ₂, …. Asking "does it converge, and how fast" is asking a question about sequences — and the answers (linear vs quadratic rate, geometric series, spectral radius) are ordinary calculus.

Sequences

  • Convergence: aₙ → a iff for every ε > 0 there is N with |aₙ − a| < ε for all n ≥ N. Limits are unique; convergent sequences are bounded.
  • Monotone convergence: a bounded monotone sequence converges (to its supremum / infimum). The workhorse for proving convergence without knowing the limit — e.g. a loss that decreases every step and is bounded below must converge.
  • Bolzano–Weierstrass: every bounded sequence has a convergent subsequence. This is the standard route to "some accumulation point exists" arguments in non-convex optimization.
  • The Cauchy criterion: aₙ converges ⟺ |aₙ − aₘ| → 0 as n, m → ∞. Again: convergence certified without naming the limit — precisely the situation you are in when watching a training curve.
Rates of convergence (eₙ = ‖θₙ − θ*‖) linear (geometric): eₙ₊₁ ≤ ρ eₙ, 0 < ρ < 1 ⟹ eₙ ≤ ρⁿ e₀ digits grow linearly in n superlinear: eₙ₊₁ / eₙ → 0 quadratic: eₙ₊₁ ≤ M eₙ² digits DOUBLE each step sublinear: eₙ ≍ 1/n or 1/√n (plain SGD)

Worked example. Gradient descent on the quadratic φ(θ) = ½θᵀHθ gives θₙ₊₁ = (I − ηH)θₙ, so along the eigenvector for λᵢ the error multiplies by (1 − ηλᵢ) each step. The overall rate is ρ = max_i |1 − ηλᵢ| = max(|1 − ηλ_min|, |1 − ηλ_max|). Convergence needs ρ < 1, i.e. 0 < η < 2/λ_max; the best η equalises the two ends, η = 2/(λ_min + λ_max), giving ρ = (κ − 1)/(κ + 1) with κ = λ_max/λ_min. Ill-conditioning is a statement about the rate of a geometric sequence.

If Σaₙ converges but Σ|aₙ| does not (e.g. Σ(−1)ⁿ⁺¹/n = ln 2), the convergence is conditional — and then a rearrangement of the terms can be made to converge to any number you like. Order matters. Absolute convergence is what licenses reordering, term-by-term differentiation, and swapping sums with integrals.
  • Uniform convergence. Pointwise convergence fₙ → f is not enough to conclude that f is continuous, or that ∫fₙ → ∫f, or that fₙ′ → f′. Uniform convergence (one N for all x at once) rescues continuity and integration; term-by-term differentiation additionally needs the derivative series to converge uniformly. This is the subtle reason you cannot always differentiate a limit of models term by term.

Power series and the radius of convergence

Power series Σ_{n≥0} cₙ (x − a)ⁿ converges for |x − a| < R, diverges for |x − a| > R 1/R = limsup |cₙ|^{1/n} (or R = lim |cₙ / cₙ₊₁| when that limit exists)

Inside R a power series may be differentiated and integrated term by term, and the result has the same radius. A Taylor series is a power series whose coefficients are cₙ = f⁽ⁿ⁾(a)/n!; note that a function can be infinitely differentiable and still not equal its Taylor series (the classic e^{−1/x²}, all of whose derivatives vanish at 0). "Analytic" is strictly stronger than "smooth".

Series of matrices — where this pays off in ML

Neumann series and the matrix exponential (I − A)⁻¹ = I + A + A² + A³ + … converges ⟺ spectral radius ρ(A) < 1 exp(A) = Σ_{k≥0} Aᵏ / k! converges for every square A
  • Discounted return. Σ_{t≥0} γᵗ r = r/(1 − γ) is a geometric series; the Bellman fixed point v = (I − γP)⁻¹r is its matrix version, and ρ(γP) = γ < 1 is exactly why value iteration converges. See Reinforcement Learning.
  • Ridge regression as a series. (XᵀX + λI)⁻¹ = (1/λ)(I + XᵀX/λ)⁻¹ = (1/λ)Σ(−XᵀX/λ)ᵏ for large λ — an explicit expansion of shrinkage in powers of the Gram matrix, and a clean way to see ridge as a smooth interpolation between the OLS solution and zero. See Regularization.
  • Vanishing / exploding gradients. Backprop through T steps multiplies T Jacobians. Their product behaves like ρᵀ — geometric decay or geometric blow-up. It is the same series arithmetic, and it is why residual connections (which make each Jacobian I + something small) help.

07 The Riemann integral — and what it is actually for

Differentiation asks about local change; integration asks about total accumulation. In ML the integral is almost never something you evaluate by hand — it is the definition of an expectation, and everything interesting is about how to estimate or differentiate one.

Construction

Take a bounded f on [a,b] and a partition P: a = x₀ < x₁ < … < x_k = b. On each subinterval let Mᵢ and mᵢ be the sup and inf of f. Form the upper and lower (Darboux) sums:

Upper / lower sums and the integrability criterion U(P) = Σᵢ Mᵢ Δxᵢ L(P) = Σᵢ mᵢ Δxᵢ L(P) ≤ U(P′) for ALL partitions P, P′ f is Riemann integrable ⟺ ∀ε > 0 ∃P : U(P) − L(P) < ε and then ∫ₐᵇ f = sup_P L(P) = inf_P U(P)
  • Which functions are integrable? Continuous ones (via uniform continuity — squeeze Mᵢ − mᵢ uniformly). Monotone ones. Bounded functions with finitely many discontinuities. More generally, functions of bounded variation. The Dirichlet function (1 on rationals, 0 elsewhere) is not Riemann integrable — U = 1, L = 0 for every partition — which is exactly the gap Lebesgue integration fills.
  • Linearity, additivity, monotonicity all hold; |∫f| ≤ ∫|f|; and if f ≥ 0 is continuous with ∫f = 0 then f ≡ 0.
  • Improper integrals extend the definition to infinite intervals (∫ₐ^∞) and to unbounded integrands, each as a limit. Every density on ℝ is an improper integral that happens to equal 1.

The fundamental theorem

The two halves of the fundamental theorem of calculus (I) F(x) = ∫ₐˣ f(t) dt ⟹ F′(x) = f(x) at every point where f is continuous (II) if F′ = f and f is integrable: ∫ₐᵇ f(t) dt = F(b) − F(a) change of variables: ∫ f(g(t)) g′(t) dt = ∫ f(u) du, u = g(t)

Part (I) says differentiation and integration are inverse operations; part (II) turns an infinite limiting process into an evaluation at two endpoints. The change-of-variables rule is just the chain rule read backwards — and in n dimensions it grows a Jacobian determinant (§09), which is the entire mathematical content of normalizing flows.

The inequalities you will actually use

Four integral inequalities that reappear as ML facts Cauchy–Schwarz: |∫ f g| ≤ (∫f²)^{1/2} (∫g²)^{1/2} → |corr| ≤ 1 Hölder: ∫|f g| ≤ (∫|f|^p)^{1/p} (∫|g|^q)^{1/q}, 1/p + 1/q = 1 Minkowski: (∫|f+g|^p)^{1/p} ≤ (∫|f|^p)^{1/p} + (∫|g|^p)^{1/p} → Lᵖ is a normed space Jensen: g convex ⟹ g(E[X]) ≤ E[g(X)] → the ELBO, and E[X²] ≥ (E[X])²

Jensen's inequality deserves special mention: it is the reason the evidence lower bound in variational inference is a lower bound at all, and (with g = −log) the reason KL divergence is non-negative.

The integral as an expectation

The Riemann–Stieltjes integral ∫ g dF — where the increments are ΔF rather than Δx — unifies the discrete and continuous cases into one object: it reduces to Σ g(xᵢ) p(xᵢ) when F is a step function and to ∫ g(x) f(x) dx when F has a density. That is why E[g(X)] = ∫ g dF is the definition of expectation, with no case split.

Everything in ML that is secretly an integral risk: R(θ) = E_{(x,y)~D}[ ℓ(f(x;θ), y) ] = ∫ ℓ dF marginal: p(x) = ∫ p(x | z) p(z) dz KL divergence: KL(p‖q) = ∫ p(x) log[ p(x)/q(x) ] dx and the empirical risk (1/m)Σᵢ ℓᵢ is a Monte-Carlo estimate of the first one.

Differentiating under the integral sign

This is the single most useful integration theorem for ML, because gradients of expectations are what we need and the parameter usually sits inside the integral.

Leibniz rule d/dθ ∫_{a(θ)}^{b(θ)} f(x, θ) dx = ∫_{a(θ)}^{b(θ)} ∂f/∂θ dx + f(b(θ), θ) b′(θ) − f(a(θ), θ) a′(θ) fixed limits + dominated ∂f/∂θ ⟹ ∇_θ ∫ f(x,θ)dx = ∫ ∇_θ f(x,θ) dx

Derivation of the score-function (REINFORCE) estimator. We want ∇_θ E_{x~p_θ}[ f(x) ], where θ is in the distribution, not the integrand. Swap the derivative and the integral, then multiply and divide by p_θ:

The log-derivative trick, step by step ∇_θ ∫ f(x) p_θ(x) dx = ∫ f(x) ∇_θ p_θ(x) dx = ∫ f(x) p_θ(x) · [ ∇_θ p_θ(x) / p_θ(x) ] dx = ∫ f(x) p_θ(x) ∇_θ log p_θ(x) dx since ∇log p = ∇p / p = E_{x~p_θ}[ f(x) ∇_θ log p_θ(x) ] ← now estimable by sampling

The alternative is the reparameterization trick: write x = g(ε, θ) with ε drawn from a fixed distribution, so that θ moves back inside the integrand and the ordinary chain rule applies — ∇_θ E_ε[f(g(ε,θ))] = E_ε[∇_x f · ∂g/∂θ]. Same gradient, dramatically lower variance. This is the difference between policy-gradient RL and a VAE's training signal.

When you cannot evaluate the integral

  • Quadrature in low dimensions: trapezoid (error O(h²)), Simpson (O(h⁴)), Newton–Cotes, and Gaussian quadrature (exact for polynomials up to degree 2n−1 using only n nodes, placed at the roots of an orthogonal polynomial). Gauss–Hermite quadrature is the standard tool for Gaussian expectations in low dimension.
  • Laplace's method: approximate ∫ e^{Mh(x)}dx by expanding h to second order around its maximum — i.e. by a Gaussian. This is the Laplace approximation to a posterior, and the origin of the BIC.
  • Monte Carlo in high dimensions: ∫f ≈ (1/N)Σ f(xᵢ), error O(N^{−1/2}) regardless of dimension. Deterministic quadrature costs O(N^{−k/d}) and dies of the curse of dimensionality; Monte Carlo does not. That is why sampling, not integration, is how ML computes expectations.

08 Multivariable: partials, gradient, total differential, chain rule

Going from ℝ → ℝ to ℝⁿ → ℝ is the genuinely conceptual jump (going from there to ℝⁿ → ℝᵐ is mostly bookkeeping). The trap: partial derivatives are weaker than you think.

Partial derivatives

The j-th partial derivative Dⱼ f(c) = ∂f(c)/∂xⱼ = lim_{t→0} [ f(c + t eⱼ) − f(c) ] / t — an ordinary 1-D derivative along the j-th axis, all other variables frozen.

Because it is a one-variable derivative, everything from §03 applies to it directly. But that convenience is also its weakness: a partial derivative sees the function along one line only.

Existence of all partials does not imply continuity. Let φ(x,y) = x + y when x = 0 or y = 0, and φ(x,y) = 1 otherwise. Then D₁φ(0,0) = D₂φ(0,0) = 1 — both partials exist at the origin — yet φ is wildly discontinuous there (it jumps to 1 the instant you leave either axis). Partials probe only the axes; differentiability is a statement about every direction at once. Even continuity of the partials in a ball is not necessary for differentiability, and their mere existence in a ball is not sufficient.

What is sufficient: if all partials Dⱼfᵢ exist in some ball around c and are continuous at c, then f is differentiable at c. (Proof: telescope the increment one coordinate at a time and apply the 1-D mean value theorem to each piece.) A function whose partials exist and are continuous on an open set is called continuously differentiable, C¹ — the condition every practical theorem assumes.

Differentiability, the total differential, and the gradient

Differentiability in ℝⁿ — the same sentence as §03 f(c + u) = f(c) + A(c) u + r(u), ‖r(u)‖ / ‖u‖ → 0 df(c; u) = A(c) u and necessarily A(c)ᵢⱼ = Dⱼfᵢ(c) real-valued case: dφ = Σⱼ (∂φ/∂xⱼ) dxⱼ = ∇φᵀ dx (the TOTAL DIFFERENTIAL)

The gradient ∇φ(c) is the column vector of partials — the transpose of the 1 × n derivative row Dφ(c). Keeping that distinction straight (derivative = row, gradient = column) prevents nearly every transpose bug in §11.

The total derivative along a curve is the chain rule in its most familiar dress: if each xⱼ is a function of t,

Total derivative along a path df/dt = Σⱼ (∂f/∂xⱼ)(dxⱼ/dt) = ∇fᵀ (dx/dt)

Directional derivatives

Directional derivative and the steepest-ascent property D_u φ(c) = lim_{t→0⁺} [ φ(c + t u) − φ(c) ] / t = ∇φ(c)ᵀ u (‖u‖ = 1) = ‖∇φ(c)‖ cos ϑ ⟹ max at ϑ = 0, min at ϑ = π, ZERO at ϑ = π/2

Three consequences, all visible in the viz below. (i) ∇φ points in the direction of steepest ascent and −∇φ steepest descent. (ii) ‖∇φ‖ is the steepest rate. (iii) The directions with D_uφ = 0 are exactly those orthogonal to ∇φ — the tangent to the level set. Hence the gradient is always perpendicular to contours. Caution: D_uφ = ∇φᵀu requires differentiability; a function can have every directional derivative at a point and still not be differentiable there.

The chain rule in several variables

Chain rule · scalar form and matrix form h = g ∘ f, b = f(c) Dⱼhᵢ(c) = Σ_{k=1}^{m} D_k gᵢ(b) · Dⱼf_k(c) (sum over every intermediate path) Dh(c) = Dg(b) · Df(c) — composition of functions is MULTIPLICATION of Jacobians

That second line is the whole of backpropagation compressed to five symbols; §12 unpacks it. Note the shape check does the proof for you: (p×m)(m×n) = (p×n).

Cauchy's rule of invariance is the practical corollary: dh(c; u) = dg(b; df(c; u)). In words — the first differential does not care whether its variables are independent or are themselves functions of something else. This is exactly the licence to write dy = ∂y/∂t · dt and then substitute dt = ∂t/∂x · dx without any bookkeeping, and it is what makes the differential-first method of §10 work. (Warning: the second differential does not have this invariance unless the inner function is affine — see §09.)

Implicit differentiation

If f(x₁, x₂) = 0 defines x₂ implicitly as a function of x₁, differentiate the identity totally and solve:

Implicit function differentiation ∂f/∂x₁ + (∂f/∂x₂)(dx₂/dx₁) = 0 ⟹ dx₂/dx₁ = − (∂f/∂x₁) / (∂f/∂x₂) (∂f/∂x₂ ≠ 0)

The implicit function theorem is the rigorous version: if f is C¹ and the relevant Jacobian block is non-singular at a point, then locally a unique differentiable solution exists. It is why the derivative of an inverse is 1/f′, why eigenvalues and eigenvectors are differentiable functions of a matrix (when the eigenvalue is simple), and — in modern practice — how implicit layers and deep-equilibrium models get gradients without unrolling.

09 The Jacobian, the Hessian, and the local quadratic model

First derivatives assemble into a Jacobian; second derivatives into a Hessian. Together they give the degree-2 Taylor model that every second-order method optimizes and every curvature argument reasons about.

The Jacobian

Jacobian matrix and Jacobian determinant Df(c) = [ ∂fᵢ/∂xⱼ ] ∈ ℝ^{m×n} row i = ∇fᵢᵀ ∇f(c) = (Df(c))ᵀ ∈ ℝ^{n×m} (the gradient is the transposed derivative) m = n: det Df is the JACOBIAN — the local volume-scaling factor
  • Caution: the Jacobian matrix may exist (all partials exist) at a point where f is not differentiable. The formula df(c;u) = Df(c)u is only valid under differentiability.
  • Change of variables. ∫_{g(S)} f(y) dy = ∫_S f(g(x)) |det Dg(x)| dx. For densities this is p_Y(y) = p_X(x) |det Dg(x)|⁻¹ — the exact identity that normalizing flows are built on, and why flow architectures go to such lengths to make det Dg cheap (triangular Jacobians, coupling layers).
  • Shapes to memorise: a network layer ℝⁿ → ℝᵐ has an m × n Jacobian. A loss is ℝⁿ → ℝ: Jacobian 1 × n, gradient n × 1. Reverse-mode AD (§13) exists precisely because the second shape is so lopsided.

The Hessian and the symmetry of mixed partials

Hessian of a real-valued φ: ℝⁿ → ℝ Hφ(c) = ∇²φ(c) = [ ∂²φ / ∂xᵢ∂xⱼ ] ∈ ℝ^{n×n} = D(∇φ) — the Jacobian of the gradient d²φ(c; u) = uᵀ Hφ(c) u — the second differential is a QUADRATIC FORM in u

Symmetry is a theorem, not a definition. If φ is twice differentiable at c (or, more weakly, if one mixed partial exists and is continuous near c), then ∂²φ/∂xᵢ∂xⱼ = ∂²φ/∂xⱼ∂xᵢ. Without such a hypothesis it can fail: for φ(x,y) = xy(x² − y²)/(x² + y²) (and φ(0,0) = 0) the two mixed partials at the origin are +1 and −1, giving a non-symmetric Hessian. Symmetry matters practically because it is what lets you recover H from the second differential at all — uᵀAu = uᵀBu for all u only forces A + Aᵀ = B + Bᵀ, so the symmetric part is all you can ever identify (§10).

Second-order Taylor — the local quadratic model

Taylor to second order in ℝⁿ φ(c + u) = φ(c) + ∇φ(c)ᵀu + ½ uᵀ Hφ(c) u + r(u), r(u)/‖u‖² → 0 exact (Lagrange) form: φ(c + u) = φ(c) + ∇φ(c)ᵀu + ½ uᵀ Hφ(c + θu) u, θ ∈ (0,1)

Everything about the geometry near a critical point (∇φ = 0) is then decided by the definiteness of H, because the quadratic term is all that is left:

Worked example. φ(x,y) = x³ − 3xy + y³. Then ∇φ = (3x² − 3y, −3x + 3y²)ᵀ, which vanishes at (0,0) and (1,1). The Hessian is H = [[6x, −3], [−3, 6y]]. At (0,0), H = [[0,−3],[−3,0]] with eigenvalues ±3 — indefinite, a saddle. At (1,1), H = [[6,−3],[−3,6]] with eigenvalues 3 and 9 — positive definite, a local minimum.   • The Hessian is the gradient's Jacobian, so second-order information costs one more differentiation pass — O(n²) entries and O(n³) to invert. This is why deep learning uses Hessian-vector products (Hv = ∇(∇φᵀv), one extra backward pass, no matrix ever formed) rather than the Hessian itself.
  • Chain rule for Hessians. For h = g ∘ f the 1-D formula h″ = g″(f′)² + g′f″ generalises to Hh = (Df)ᵀ(Hg)(Df) + Σ_s (D_s g)(Hf_s). The first term is the Gauss–Newton part (always PSD when g is convex); dropping the second term is exactly the Gauss–Newton approximation.
  • Lagrange multipliers. To optimize φ subject to g(x) = 0, note that at a constrained optimum you cannot move along the constraint surface and improve — so ∇φ must have no component tangent to it, i.e. ∇φ = λ∇g. Equivalently, ∇ of the Lagrangian L = φ − λg vanishes. Sufficiency uses the bordered Hessian (definiteness of H_L restricted to the tangent space). This is the geometry behind SVM duality and behind ridge regression's constrained form; the algorithmic side is on Optimization.

10 Matrix differentials — the method that replaces index-chasing

This is the section that changes how you work. Instead of computing ∂f_{st}/∂x_{ij} element by element, you compute a single differential using ordinary algebra, then read off the derivative from its shape. It is faster, it is harder to get wrong, and it is what backprop is doing.

Why element-wise notation fails

The tempting definition — arrange ∂φ/∂x_{ij} into a matrix the same shape as X, and stack those blocks for matrix-valued F — has a fatal flaw. Apply it to the identity function F(X) = X for an n × q matrix: the resulting nq × nq array of partials has rank 1, whereas the true Jacobian of the identity is I_{nq}, of rank nq. The block layout therefore displays the right numbers in the wrong structure: its determinant means nothing, its rank means nothing, and — decisively — there is no chain rule for it. Any layout you would want to compose must be a genuine Jacobian.

The only layout with a chain rule: vec-of-output by vec-of-input DF(X) = ∂ vec F(X) / ∂ (vec X)ᵀ ∈ ℝ^{mp × nq} for φ: ℝⁿ → ℝ: Dφ(x) = ∂φ/∂xᵀ (1 × n row) ∇φ(x) = (Dφ(x))ᵀ (n × 1 column) the display form ∂φ(X)/∂X (shaped like X) is fine as a RESULT, never as a step.

vec stacks the columns of a matrix into one long vector. It turns every matrix function into a vector function, so all the theory of §08 applies verbatim — that is the whole trick.

The identification theorems

Differentiability says f(c + u) = f(c) + A(c)u + o(‖u‖). Two facts make this into an algorithm. First, uniqueness: if A(c)u = A*(c)u for every u, then A(c) = A*(c) (subtract, rescale u → tu, let t → 0). Second, the entries of A must be the partials. Together:

First identification theorem df(x) = A(x) dx for all dx ⟺ Df(x) = A(x) matrix version: d vec F(X) = A(X) d vec X ⟺ DF(X) = A(X)
Second identification theorem d²φ(x) = (dx)ᵀ B (dx) ⟹ Hφ(x) = ½ (B + Bᵀ) (the symmetrisation is forced: uᵀAu = 0 for all u only means A is skew-symmetric)

So the recipe is three mechanical steps: (i) compute dF by algebra; (ii) vectorise into the canonical form d vec F = A · d vec X; (iii) declare DF = A. No limits, no indices, no ambiguity.

The rules of the calculus of differentials

Everything you need to push differentials around dA = 0 (A constant) d(αU) = α dU d(U ± V) = dU ± dV d(UV) = (dU)V + U dV — order matters, matrices don't commute d(U ⊗ V) = (dU) ⊗ V + U ⊗ dV d(U ⊙ V) = (dU) ⊙ V + U ⊙ dV d(Uᵀ) = (dU)ᵀ d vec U = vec dU d tr U = tr dU d(AXB) = A (dX) B d(X⁻¹) = −X⁻¹ (dX) X⁻¹ d|X| = |X| tr(X⁻¹ dX)

Derivation of d(X⁻¹), because it is the pattern for all the others: differentiate the identity X⁻¹X = I. The right side is constant, so 0 = d(X⁻¹X) = (dX⁻¹)X + X⁻¹ dX. Post-multiply by X⁻¹: dX⁻¹ = −X⁻¹(dX)X⁻¹. Two lines, no indices. (Compare deriving the same result from cofactor expansions.)

Derivation of d|X|: expanding the determinant along column j gives |X| = Σᵢ cᵢⱼxᵢⱼ where the cofactors cᵢⱼ do not involve xᵢⱼ, so ∂|X|/∂xᵢⱼ = cᵢⱼ and d|X| = Σᵢⱼ cᵢⱼ dxᵢⱼ = tr(X# dX) with X# the adjugate. When X is non-singular X# = |X|X⁻¹, giving d|X| = |X| tr(X⁻¹dX), and immediately d log|X| = tr(X⁻¹dX).

Worked example A — maximum likelihood for a covariance matrix

With n centred observations and scatter S = Σᵢ xᵢxᵢᵀ, the Gaussian log-likelihood in Σ is ℓ(Σ) = −(n/2)log|Σ| − ½ tr(Σ⁻¹S). Differentiate term by term with identities 5 and 6:

The famous answer, with no index gymnastics and no differentiation of n² separate entries. (A caveat the differential method makes visible: this treats the entries of Σ as free. Worked example B — softmax and cross-entropy

Let p = softmax(z), so pᵢ = e^{zᵢ}/Σⱼe^{zⱼ}, and let L = −log p_y be the cross-entropy for true class y.

The Jacobian of softmax, and why the combined gradient is so clean ∂pᵢ/∂zⱼ = pᵢ(δᵢⱼ − pⱼ) ⟹ Dp(z) = diag(p) − p pᵀ (symmetric, PSD, singular: rows sum to 0) L = −z_y + log Σⱼ e^{zⱼ} ⟹ ∂L/∂zⱼ = −δ_{jy} + pⱼ ∇_z L = p − e_y — predicted distribution minus the one-hot target

This is why frameworks fuse the two operations: composing the two Jacobians explicitly would cost an n × n matrix product, but the composition collapses to a subtraction. It is also numerically better — see the log-sum-exp note in §14.

The habit to build. Never look up a matrix derivative. Write d(the expression), apply the product rule and d(X⁻¹)/d|X|, use cyclicity of the trace to move dX to the right, and read the answer off row 3 of the identification table. It takes about the same time as a web search and cannot give you someone else's transpose convention by mistake.

12 The chain rule is backpropagation

Backprop has a reputation as a deep-learning invention. It is the multivariable chain rule, evaluated right-to-left because the output is a scalar. That is the entire idea; the rest is engineering.

The composition

A feed-forward network is a composition L = ℓ ∘ f_T ∘ f_{T−1} ∘ … ∘ f_1. The chain rule says the Jacobian of the composition is the product of the Jacobians:

Backprop, stated once DL(x) = Dℓ · Df_T · Df_{T−1} · … · Df_1 shapes: (1×n_T)(n_T×n_{T−1})···(n_1×n_0) associativity is a CHOICE: left-to-right ( ( (Dℓ·Df_T) ·Df_{T−1}) ··· ) every partial product is a ROW VECTOR → reverse mode right-to-left ( ··· (Df_2·Df_1) ) every partial product is a full MATRIX → forward mode

Both orders give the same answer; they differ enormously in cost. With one scalar output and n inputs, grouping from the left keeps every intermediate a 1 × nₖ row — you never materialise an nₖ × nⱼ Jacobian at all. Backprop is nothing more than choosing the cheap parenthesisation.

Vector–Jacobian products: what a layer must implement

Concretely, a framework never asks a layer for its Jacobian. It hands the layer an adjoint ḡ = ∂L/∂(output) and asks for ḡᵀ · Df — a vector–Jacobian product (VJP). For a dense layer h = Wx + b, use the identification method:

Derivation of the dense-layer gradients h = Wx + b, ḡ = ∂L/∂h (column, size m) dL = ḡᵀ dh = ḡᵀ[ (dW)x + W dx + db ] term in dW: ḡᵀ(dW)x = tr( x ḡᵀ dW ) = tr( (ḡxᵀ)ᵀ dW ) ⟹ ∂L/∂W = ḡ xᵀ term in dx: ḡᵀW dx ⟹ ∂L/∂x = Wᵀ ḡ term in db: ḡᵀ db ⟹ ∂L/∂b = ḡ

Three results, each one line, each with the right shape guaranteed by construction: ḡxᵀ is m × n like W; Wᵀḡ is n × 1 like x. The weight gradient being an outer product of the incoming adjoint and the stored input is exactly why the forward activations must be cached for the backward pass — and therefore why activation memory, not parameter memory, dominates training footprints.

What the Jacobian product explains

  • Vanishing / exploding gradients. ‖DL‖ ≤ Π_k ‖Df_k‖. If each layer's Jacobian has spectral norm consistently below 1, the product decays geometrically; above 1, it explodes. Same geometric series as §06.
  • Why residual connections help. f(x) = x + g(x) has Jacobian I + Dg. The identity term keeps the product from collapsing — the gradient always has a clean path back. See Residual / Skip Connections.
  • Why normalisation helps. It keeps layer inputs in a range where σ′ is not saturated, so the diagonal Jacobians stay away from zero.
  • Gradient clipping is a blunt instrument against the exploding case: rescale ḡ when ‖ḡ‖ exceeds a threshold, preserving direction and bounding the step.
Second-order caution. The first differential is invariant under substitution (Cauchy's rule, §08), which is what lets you chain layers naively. The second differential is not: d²h = d²g(df) + dg(d²f), with an extra term unless the inner map is affine. Forgetting the second term is precisely the Gauss–Newton approximation — usually a good one, never an identity.

13 Numerical vs symbolic vs automatic differentiation

There are exactly three ways a computer can get a derivative, and they are not variations on a theme — they have different accuracy, different cost, and different failure modes. Automatic differentiation is neither of the other two, despite being routinely confused with both.

Numerical differentiation (finite differences)

Finite differences and their error budgets forward: [ f(x+h) − f(x) ] / h = f′(x) + (h/2)f″(x) + … truncation O(h) central: [ f(x+h) − f(x−h) ] / 2h = f′(x) + (h²/6)f‴(x) + … truncation O(h²) round-off: ≈ ε_mach·|f| / h — grows as h shrinks. The two errors fight.

Balancing (h/2)|f″| against ε|f|/h gives an optimal h ≈ 2√(ε|f|/|f″|) ~ √ε ≈ 1.5×10⁻⁸ in double precision, with best achievable accuracy only ~√ε. For central differences the optimum is h ~ ε^{1/3} ≈ 6×10⁻⁶ with accuracy ~ε^{2/3}. So you can never get more than roughly half (or two-thirds) of your digits back. Cost: n + 1 function evaluations for a full gradient (or 2n central) — hopeless for a million parameters. Verdict: a testing tool, not a training tool (§14).

The complex-step trick. If f is analytic and you can evaluate it in complex arithmetic, f′(x) ≈ Im[f(x + ih)]/h has O(h²) truncation error and no subtractive cancellation at all — there is no difference of nearly equal numbers. You can take h = 10⁻²⁰ and get essentially machine-precision derivatives. A beautiful workaround, limited to analytic functions of one variable at a time.

Symbolic differentiation

Apply the rules of §03 to an expression tree and return a new expression tree. Exact, and it gives you a closed form you can inspect and simplify. The failure mode is expression swell: differentiating a product of k factors produces k terms, and nesting causes exponential blow-up, with common sub-expressions recomputed everywhere. Symbolic differentiation of a 50-layer network's loss is not a thing anyone does.

Automatic differentiation

AD sits between the two: it works on the program, not on a formula, and applies the chain rule numerically at each elementary operation. Results are exact to machine precision (no truncation error), and cost is a small constant times the cost of the original program. Read the count. Forward mode needs one sweep per input — two here, a billion in a real network. Reverse mode needs one sweep per output — always one for a scalar loss. That asymmetry, and nothing else, is why every deep-learning framework is built around a reverse-mode tape.

  • The memory price. Reverse mode must keep every intermediate value from the forward pass. Gradient checkpointing trades it back: store only a few checkpoints and recompute the rest during the backward pass — roughly O(√T) memory for O(1) extra forward passes.
  • Mixing modes. Hessian-vector products are best computed as forward-over-reverse: Hv = ∂/∂ε [ ∇φ(x + εv) ]|_{ε=0}, i.e. push a forward-mode tangent through the reverse-mode gradient. Cost: one extra backward pass, no n × n matrix.
  • Control flow is fine. AD differentiates the trace of operations that actually executed, so loops and branches are handled — but the derivative is that of the taken branch, which is why a piecewise definition can silently give you a one-sided derivative.
  • Where AD lies. At non-differentiable points (ReLU at 0, abs, max, sorting/ranking, round) AD returns a convention. And for iterative solvers it is often far better to use the implicit function theorem (§08) than to differentiate through every iteration.

Gradient checking — the one numerical-differentiation use that matters

When you hand-write a backward pass (a custom layer, a custom loss), verify it against central differences. The relative-error check below is the standard recipe.

Gradient check g_num[i] = [ L(θ + h eᵢ) − L(θ − h eᵢ) ] / (2h), h ≈ 10⁻⁵ … 10⁻⁶ rel_err = ‖g_num − g_analytic‖ / max(‖g_num‖ + ‖g_analytic‖, 10⁻⁸) < 10⁻⁷ excellent · < 10⁻⁵ usually fine · > 10⁻³ you have a bug
  • Use double precision for the check; float32 round-off alone will fail it.
  • Turn off dropout and any other stochasticity, and use a fixed batch — you must differentiate the same function twice.
  • Check only a random subset of coordinates; 2n evaluations is otherwise prohibitive.
  • Avoid kinks: a check near z = 0 for a ReLU will legitimately fail. Perturb away from the non-differentiable set.

Conventions that cause real bugs

  • Numerator vs denominator layout. Is ∂y/∂x for vector y, x an m×n or an n×m matrix? Both conventions are in the wild. Pick one — the numerator (Jacobian) layout ∂y/∂xᵀ ∈ ℝ^{m×n} is used throughout this page — and state it. Nearly every stray transpose is a layout clash.
  • Gradient (column) vs derivative (row). ∇φ = (Dφ)ᵀ. Keeping the two words distinct catches shape errors before the code does.
  • Symmetric or constrained parameters. Differentiating tr(Σ⁻¹S) as if all n² entries of Σ were free gives a different off-diagonal result than treating Σ as symmetric (a factor of 2). The stationary point is the same; a gradient-check is not.
  • Mean vs sum reductions. A 1/m in the loss rescales every gradient. Changing batch size without changing the reduction silently changes the effective learning rate.
