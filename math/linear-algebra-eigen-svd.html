The two great factorizations. 09 Complex numbers

A short but necessary detour: real matrices can have complex eigenvalues (any rotation does), so we need the machinery — plus the small set of rules that change when matrix entries leave ℝ.

Why they show up at all

  • The fundamental theorem of algebra says a degree-n polynomial has exactly n roots — if you allow complex ones. Eigenvalues are roots of a polynomial built from a matrix, so a perfectly real-valued matrix can hand you complex eigenvalues (§15).
  • The archetype: R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]] rotates the plane, so no real vector keeps its direction — there can be no real eigenvector. Its eigenvalues are cos θ ± i·sin θ = e^(±iθ). Rotation is complex multiplication in disguise.
  • Elsewhere in applied math the same machinery runs the Fourier transform and the FFT, where a signal is decomposed into complex exponentials carrying both amplitude and phase.

The complex plane

  • The reals form a line; the complex numbers ℂ form a plane. Horizontal = real axis (Re), vertical = imaginary axis (Im), and i = √(−1), so i² = −1.
  • Write z = a + ib (real part first, always). Variations you'll see: a + bi, [a bi], (a, bi). z is the default letter, then w. Engineers write j for i; Python agrees — the literal is 1j, and 3+4j is a complex scalar.
  • Vocabulary worth keeping straight: a complex number has both parts; an imaginary number has no real part (ib); the imaginary operator is the bare symbol i; the imaginary component of a + ib is the real number b, not ib.
  • Because a complex number is a point in a plane it carries four readings at once: real part, imaginary part, magnitude |z| = √(a² + b²) (distance from the origin), and angle from the positive real axis. Hence the polar form z = r·e^(iθ), in which multiplication is beautifully simple: magnitudes multiply, angles add.
  • Complex matrices are ordinary matrices whose entries are drawn from ℂ. Beware of miscounting: [[6 − i2], [3 + i4]] is a 2×1 column vector, not a 2×2 matrix. If you see an i, slow down and count entries.
i² = −1 z = a + ib |z| = √(a² + b²) z = r·e^(iθ), r = |z|

The complex conjugate

  • z̄ (or z*) flips the sign of the imaginary part — it does not make it negative. The conjugate of a − ib is a + ib. In polar form r·e^(iθ) → r·e^(−iθ).
  • Geometrically it is a reflection across the real axis. A real number is its own conjugate — which is precisely why real diagonals show up in Hermitian matrices below.
  • The key identity: z̄z = (a − ib)(a + ib) = a² + b² = |z|² — real and non-negative. This one line is the reason the complex dot product is defined the way it is.
  • Conjugate pairs travel together. A real-coefficient polynomial with a complex root has them in pairs: x² + 9 = 0 gives ±3i. Same story from the quadratic formula whenever b² < 4ac. Consequently, complex eigenvalues of a real matrix always come in conjugate pairs.

Arithmetic

  • Add / subtract component-wise: (a + ib) ± (c + id) = (a ± c) + i(b ± d).
  • Multiply by expanding, then use i² = −1: (a + ib)(c + id) = (ac − bd) + i(ad + bc). There is no "multiply the parts separately" shortcut — the cross terms matter. Example: (3 + 6i)(−2 − 5i) = 24 − 27i.
  • Divide by multiplying top and bottom by the conjugate of the denominator, which makes the denominator real: z/w = zw̄ / (ww̄) = zw̄ / |w|². Example: (3 + 6i)/(−2 − 5i) = (−36 + 3i)/29.
  • Conjugation distributes over everything: conj(z + w) = z̄ + w̄ and conj(zw) = z̄·w̄.
arithmetic(a + ib)(c + id) = (ac − bd) + i(ad + bc) z̄z = |z|² z/w = zw̄ / |w|²

The Hermitian transpose and the complex dot product

  • The Hermitian transpose vᴴ is conjugate + transpose. For real matrices conjugation does nothing, so ᴴ = ᵀ — every real result you know is the special case of a complex one.
  • The dot product is mechanically unchanged (multiply element-wise, sum), but in practice you always use the Hermitian dot product zᴴw rather than zᵀw.
  • Why: length must stay positive. For v = [0, i]ᵀ, which clearly has length 1, the naive vᵀv = 0 + i² = −1 — a negative squared length. Conjugating one side gives vᴴv = 0 + (−i)(i) = 1. In general vᴴv = ∑|vₖ|² is real and non-negative, so ‖v‖ = √(vᴴv) still makes sense.
  • It doesn't matter mathematically which vector you conjugate; vᴴw is convention. Note that swapping the arguments conjugates the result: wᴴv = conj(vᴴw), so the complex inner product is not symmetric but conjugate-symmetric.
  • In code this is a real trap: numpy's np.dot does not conjugate, np.vdot conjugates the first argument, and .conj().T spells out the Hermitian explicitly.
vᴴ = v̄ᵀ vᴴv = ∑ₖ |vₖ|² ≥ 0 wᴴv = conj(vᴴw) real A ⟹ Aᴴ = Aᵀ

Special complex matrices

  • Hermitian A = Aᴴ — the complex analogue of symmetric. Mirror entries have equal magnitude and opposite-sign imaginary parts, e.g. [[2, 3−2i, 2+2i], [3+2i, 5, 8], [2−2i, 8, 9]]. The diagonal must be real, since only real numbers equal their own conjugate. Hermitian matrices have real eigenvalues and orthogonal eigenvectors — exactly the properties that make symmetric matrices so pleasant.
  • Unitary UᴴU = I — the complex analogue of orthogonal (QᵀQ = I): columns are mutually orthogonal and unit length, so U preserves lengths and angles. Canonical example: U = ½·[[1+i, 1−i], [1−i, 1+i]], for which UᴴU = I but UᵀU ≠ I — proof that the conjugate is doing real work.
  • Skew-Hermitian A = −Aᴴ — the analogue of skew-symmetric. Its diagonal is purely imaginary and its eigenvalues are purely imaginary.
  • The symmetry-manufacturing tricks of §06 carry over with the same substitution: A + Aᴴ and AᴴA are Hermitian, not symmetric. Use the ordinary transpose by mistake and you get neither.

The one rule to internalize: everywhere a transpose appears in real linear algebra, the complex version wants a Hermitian transpose. Do that and lengths stay positive, symmetry becomes Hermitian-ness, orthogonal becomes unitary, and every theorem survives the crossing into ℂ.

15 Eigendecomposition

A matrix's special directions — the vectors it only stretches, never rotates. Find them and the matrix stops being a transformation and becomes a list of numbers.

Eigen-whatnow?

  • Defined only for square matrices. They may be singular or invertible, symmetric or triangular — but not rectangular. (The SVD, §16, lifts that restriction.)
  • An M×M matrix hides M eigenvalues and M paired eigenvectors. Eigenvalues are scalars (λ), eigenvectors are vectors (v).
  • Geometry: a matrix is an input-output transformer. For almost every vector w, Aw points somewhere else — the matrix rotates it. For a select few directions the output is parallel to the input: the matrix acted like a single number. That is the whole idea.
  • The relation belongs to the pair, not to the matrix or the vector alone. Change one element of A and v is generally no longer an eigenvector.
  • Eigenvalues can be zero, negative, or complex. λ < 0 means the direction is preserved but flipped; λ = 0 means the direction is annihilated (it's in the null space).
  • Eigenvectors are defined only up to scale — an eigenvector is really a basis vector for a 1D subspace. If v works, so does αv for any α ≠ 0. Convention (and every numerical library) picks ‖v‖ = 1; the sign is still arbitrary, so two runs of the same routine may return v or −v.
  • Where this shows up: plot two correlated measurements and the "natural axis" through the cloud is an eigenvector of the covariance matrix — the first principal component. PCA (§19) is nothing but an eigendecomposition of a covariance matrix.
the fundamental eigenvalue equationAv = λv v ≠ 0 "the matrix acts on v exactly as the scalar λ does"

Finding the eigenvalues

  • Move everything to one side and factor out v — inserting I to keep the shapes legal. The result says: the shifted matrix A − λI sends v to zero, so v lives in its null space.
  • We refuse the trivial v = 0, so A − λI must have a non-trivial null space ⟹ it is reduced-rank ⟹ its determinant is 0. That single condition is the machine that produces eigenvalues.
  • Expanding det(A − λI) = 0 gives the characteristic polynomial, degree M in λ. By the fundamental theorem of algebra it has exactly M roots (counting multiplicity, allowing complex ones) — hence M eigenvalues for an M×M matrix.
derivationAv − λv = 0 ⟹ Av − λIv = 0 ⟹ (A − λI)v = 0 characteristic equationdet(A − λI) = 0 2×2 shortcut (only 2×2!)λ² − tr(A)·λ + det(A) = 0 ⟹ λ = ( tr(A) ± √(tr(A)² − 4·det(A)) ) / 2
  • Worked 2×2: for [[1, 2], [2, 1]], det([[1−λ, 2], [2, 1−λ]]) = (1−λ)² − 4 = λ² − 2λ − 3 = (λ−3)(λ+1) ⟹ λ = 3, −1. Always try to factor before reaching for the quadratic formula — for [[1, 2], [2, 3]] you can't, and you get λ = 2 ± √5.
  • Free eigenvalues: for a triangular or diagonal matrix the eigenvalues are the diagonal entries — the determinant of a triangular matrix is the product of its diagonal, so the characteristic polynomial arrives pre-factored. E.g. [[9, 0, −8], [0, 3, −15], [0, 0, 1]] has λ = 9, 3, 1.
  • Two free sanity checks that work for any size: the eigenvalues sum to the trace and multiply to the determinant. Use them to find a missing eigenvalue, or to catch an arithmetic slip.
  • Eigenvalues are intrinsically unsorted. Software sorts them (by value or magnitude) for convenience — if you re-sort Λ, you must re-sort the columns of V identically or the pairing breaks.
sanity checksΣᵢ λᵢ = tr(A) Πᵢ λᵢ = det(A)

Finding the eigenvectors

  • Each eigenvalue is the key that unlocks its eigenvector: shift the matrix by that λ and find a vector in the null space of what's left.
  • For [[1, 2], [2, 1]]: λ₁ = 3 ⟹ A − 3I = [[−2, 2], [2, −2]], whose null space is spanned by [1, 1]ᵀ. λ₂ = −1 ⟹ A + I = [[2, 2], [2, 2]], null space spanned by [−1, 1]ᵀ.
  • Any scalar multiple works — [2, 2]ᵀ, [−13, −13]ᵀ, [π, π]ᵀ are the same eigenvector. Normalised, the pair is [1, 1]ᵀ/√2 and [−1, 1]ᵀ/√2. By hand, keep integers; in code, expect unit vectors.
finding eigenvectorsvᵢ ∈ N(A − λᵢI) (A − λᵢI)vᵢ = 0 convention: ‖vᵢ‖ = 1

Diagonalization

  • M separate equations Avᵢ = λᵢvᵢ collapse into one matrix equation by stacking the eigenvectors as columns of V and the eigenvalues on the diagonal of Λ.
  • It must be VΛ, not ΛV. Post-multiplying by a diagonal matrix scales each column (one λ per eigenvector); pre-multiplying would scale each row, hitting every eigenvector's i-th element with the same λ. Also, AV = ΛV would let you cancel V and conclude A = Λ, which is nonsense.
  • Right-multiply by V⁻¹ and you get the punchline: A is a diagonal matrix when written in the basis of its own eigenvectors. Diagonalization = finding the coordinate system in which the transformation is pure per-axis scaling.
  • Read A = VΛV⁻¹ right-to-left as a three-step process: V⁻¹ rewrites the input in eigen-coordinates, Λ stretches each eigen-axis independently, V translates back to the original coordinates.
diagonalizationAV = VΛ ⟹ A = VΛV⁻¹ ⟺ V⁻¹AV = Λ

When diagonalization fails

  • The step A = VΛV⁻¹ assumes V is invertible, i.e. the matrix has M linearly independent eigenvectors. A matrix that doesn't is called defective.
  • Good news for applied work: every symmetric matrix is diagonalizable, and most matrices arising in statistics, ML and simulation are diagonalizable.
  • Bad news: [[1, 1], [−1, −1]] is rank-1 yet has λ = {0, 0}. With Λ = 0 there is no way to rebuild the matrix. It is nilpotent: A² = 0. Every triangular matrix with a zero diagonal is nilpotent, has all-zero eigenvalues, and cannot be diagonalized — e.g. [[0, 1], [0, 0]].
  • Nilpotence explains the zero eigenvalues directly: if Aᵏ = 0 then 0 = Aᵏv = λᵏv, and since v ≠ 0, λ = 0.
  • The escape hatch is the SVD, which exists for every matrix. Those two defective matrices have perfectly ordinary singular values, {2, 0} and {1, 0}.

Distinct vs. repeated eigenvalues

  • Distinct eigenvalues always give linearly independent eigenvectors — so a matrix with M distinct λs is guaranteed diagonalizable.
  • Proof by contradiction: assume β₁v₁ + β₂v₂ = 0 with both β ≠ 0. Multiply through by A to get β₁λ₁v₁ + β₂λ₂v₂ = 0; multiply the original by λ₁ and subtract. The v₁ terms cancel, leaving (λ₁ − λ₂)β₂v₂ = 0. Three factors multiplying to zero: λ₁ ≠ λ₂ by assumption and v₂ ≠ 0 by definition, so β₂ = 0 — contradiction. Feed that back and β₁ = 0 too, so the only combination giving zero is the trivial one: independence.
  • Repeated eigenvalues are ambiguous — the same proof stalls, because (λ₁ − λ₂) = 0 already satisfies the equation and tells you nothing. Both outcomes are possible, and which one occurs depends on the matrix entries.
  • Case A — defective. [[6, −4], [1, 2]] has (λ − 4)² = 0, so λ = 4 twice, and A − 4I = [[2, −4], [1, −2]] has a 1D null space: only one eigenvector, [2, 1]ᵀ. Nothing is wrong with the matrix (rank 2, non-zero determinant) — it just doesn't have enough eigenvectors.
  • Case B — a full eigenspace. 4I = [[4, 0], [0, 4]] also has λ = 4 twice, but A − 4I = 0, so every vector is an eigenvector. Software returns the standard basis (orthogonal, unit length), but any full-rank V would do.
  • Geometrically: a distinct eigenvalue owns a 1D eigenline. A repeated eigenvalue either collapses onto a single line (defective — the eigenvectors fail to span ℝᴹ) or owns a whole eigenplane, in which case any two independent vectors in that plane serve as eigenvectors; convention picks an orthogonal pair.
  • Not just a curiosity: real datasets produce eigenvalues that are exactly repeated or statistically indistinguishable often enough to be worth watching for.

Complex eigenvalues and eigenvectors

  • If the discriminant of the characteristic polynomial goes negative, the eigenvalues are complex — and complex eigenvalues force complex eigenvectors. A real matrix can absolutely do this; nothing is broken.
  • The archetype is a rotation: [[0, −1], [1, 0]] turns every real vector by 90°, so no real direction survives. Its eigenvalues are ±i, with eigenvectors [1, ∓i]ᵀ. Any rotation-like block behaves the same way.
  • For a real matrix, complex solutions always arrive in conjugate pairs: λ and λ̄, with eigenvectors v and v̄. Take the conjugate of Av = λv; since Ā = A for real A, you get Av̄ = λ̄v̄ for free. For 2×2 it's visible in the quadratic formula — only the ±√(negative) differs between the two roots.
  • Complex eigen-solutions are awkward when your data are real, but they carry real information: the modulus of λ is the scaling and its argument is the rotation angle per application of A.

Symmetric matrices: the best case

  • Real eigenvalues. Take the Hermitian transpose of Av = λv: since Aᴴ = Aᵀ = A for a real symmetric matrix, vᴴA = λ̄vᴴ. Right-multiply by v: λvᴴv = λ̄vᴴv, and vᴴv = ‖v‖² ≠ 0 divides out, leaving λ = λ̄ — a number equal to its own conjugate is real.
  • Orthogonal eigenvectors (for distinct λ). Chase the equalities λ₁v₁ᵀv₂ = (Av₁)ᵀv₂ = v₁ᵀAᵀv₂ = v₁ᵀAv₂ = λ₂v₁ᵀv₂. Subtract and factor: (λ₁ − λ₂)v₁ᵀv₂ = 0. The eigenvalues differ, so the dot product must vanish — v₁ ⟂ v₂. The proof needs Aᵀ = A at the middle step and collapses without it.
  • Unit-normalise those orthogonal eigenvectors and V becomes an orthogonal matrix: VᵀV = I, so V⁻¹ = Vᵀ. The inverse in the decomposition becomes a free transpose — this is the spectral theorem.
  • Repeated eigenvalues don't spoil it: symmetric matrices are never defective, and the eigenvectors within a repeated eigenspace can be chosen orthogonal (that's what software returns).
  • Some texts write the same thing as A = PDP⁻¹ or A = UDU⁻¹; the letters change, the content doesn't.

Eigenvalues of singular matrices

  • Every singular matrix has at least one λ = 0; every full-rank matrix has none. Quick argument: det(A) = Πλᵢ, and a singular matrix has determinant 0, so some λ must be 0.
  • The insightful argument runs through (A − λI)v = 0. Set λ = 0 and it reads Av = 0 with v ≠ 0 — that is the definition of a non-trivial null space. So the eigenvectors for λ = 0 are exactly a basis for N(A).
  • Example: [[1, 2], [1, 2]] gives λ² − 3λ = 0 ⟹ λ = 0, 3, with eigenvectors [−2, 1]ᵀ (the null space) and [1, 1]ᵀ. Nothing exotic about the zero-eigenvalue eigenvector — it's an ordinary vector.
  • It isn't a fluke of hand-picked numbers: for the general rank-1 matrix [[a, σa], [b, σb]] the constant term of the characteristic polynomial cancels for any a, b, σ, so λ(λ − (a + σb)) = 0 and λ = 0 is always a root. The same cancellation happens for a rank-deficient 3×3.
  • Gotcha: "rank = number of non-zero eigenvalues" holds for diagonalizable matrices only. [[0, 1], [0, 0]] is rank 1 with both eigenvalues zero. The clean statement belongs to singular values, not eigenvalues (§16).

Eigenlayers: a matrix as a stack of rank-1 sheets

  • The outer product vᵢvᵢᵀ of a unit eigenvector with itself is an M×M rank-1 matrix. Summing all M of them gives nothing useful — eigenvectors carry direction but no magnitude. Weight each by its eigenvalue and the sum exactly reconstructs the matrix.
  • This is just A = VΛVᵀ written out layer by layer, so it is valid for symmetric matrices (where V⁻¹ = Vᵀ) with unit-normalised eigenvectors.
  • For a non-symmetric diagonalizable matrix the layer form still works, but the right-hand vector must be the i-th row of V⁻¹ instead of vᵢᵀ. That version needs no normalisation, because VV⁻¹ = I regardless of eigenvector magnitudes, whereas VVᵀ = I only for unit vectors.
  • Worked example: [[2, 3], [3, 2]] has λ₁ = −1, v₁ = [−1, 1]ᵀ/√2 and λ₂ = 5, v₂ = [1, 1]ᵀ/√2. Layers: A₁ = [[−0.5, 0.5], [0.5, −0.5]] and A₂ = [[2.5, 2.5], [2.5, 2.5]]. Each is rank 1; their sum is rank 2 and equals A.
  • Why anyone cares: you don't have to add all the layers. Keep the k largest-λ layers and you get a low-rank approximation; drop the layers you believe are noise and you get a denoised matrix. This is the seed of PCA and of the low-rank machinery in §16.

Powers, inverses, and shifts

  • Powers are free. In (VΛV⁻¹)ⁿ every interior V⁻¹V collapses to I, leaving VΛⁿV⁻¹ — and a diagonal matrix to the n-th power is just its entries to the n-th power. Repeated matrix multiplication becomes M scalar exponentiations.
  • Equivalently, per eigenvector: A²v = A(λv) = λ(Av) = λ²v, and by induction Aⁿv = λⁿv. Powers change the eigenvalues, never the eigenvectors. This is why |λ| < 1 directions die out and |λ| > 1 directions dominate in iterated dynamics — the basis of the power method and of Markov-chain steady states.
  • Inverses are just as easy: A⁻¹ = VΛ⁻¹V⁻¹, inverting only the diagonal. Impossible if any λ = 0 — which is exactly the singular case.
  • Is that a real shortcut, given that V still needs inverting? Yes, twice over: for symmetric A, V⁻¹ = Vᵀ for free; and because the eigenvectors are normalised, V has a low condition number (§16), so inverting it is numerically safer than inverting A directly.
  • Shifting A + sI adds s to every eigenvalue and leaves the eigenvectors untouched: (A + sI)v = Av + sv = (λ + s)v. That one line is why ridge regularization works — shifting nudges the smallest eigenvalue away from zero and makes a near-singular matrix invertible.
operations that keep the eigenvectorsAⁿ = VΛⁿV⁻¹ Aⁿv = λⁿv A⁻¹ = VΛ⁻¹V⁻¹ A⁻¹v = (1/λ)v (A + sI)v = (λ + s)v

Generalized eigendecomposition

  • Note that Av = λv and Av = λIv say the same thing. Replace I with another matrix B and you get the generalized eigenvalue problem, a.k.a. simultaneous diagonalization of two matrices.
  • When B is invertible it is equivalent to the ordinary eigendecomposition of B⁻¹A. Think of B⁻¹A as a matrix-valued ratio of A to B — "which directions maximise A relative to B?"
  • Gotcha: even if A and B are both symmetric, B⁻¹A generally is not, so the symmetric guarantees (real eigenvalues, orthogonal eigenvectors) do not carry over.
  • In practice, never form B⁻¹: inverting a large or ill-conditioned matrix injects numerical error. Solvers handle the pair directly (scipy.linalg.eig(A, B); numpy's eig takes only one matrix).
  • Where it earns its keep: maximise between-class over within-class scatter and you have linear discriminant analysis; maximise signal covariance over noise covariance and you have spatial filters for source separation. Both are one generalized eigendecomposition.

Eigenvectors are the matrix's natural axes: rewrite the world in those coordinates and a complicated transform becomes plain stretching. Everything downstream — matrix powers, PCA, ridge regularization, LDA, the SVD itself — is that one sentence applied somewhere new.

16 The SVD

The master decomposition: every matrix, any shape, any rank, factors into rotate → stretch → rotate. Eigendecomposition is the special case where the matrix is square and well-behaved; the SVD never fails.

What the SVD is

  • Its job is to hand you an orthonormal basis for each of the four subspaces (§9) plus a set of scalars — the singular values — that rank those basis vectors by importance.
  • A is M×N, any rank. U is M×M orthogonal and spans ℝᴹ (column space + left-null space). V is N×N orthogonal and spans ℝᴺ (row space + null space). Σ is M×N, diagonal, with real, non-negative entries sorted descending.
  • Because the decomposition uses Vᵀ, the right singular vectors are the columns of V but appear as the rows of Vᵀ — a constant source of confusion, and of transposed code.
  • Geometry: Vᵀ rotates the input into the "natural" input axes, Σ stretches axis i by σᵢ (and pads or truncates dimensions), U rotates into the output frame. The unit sphere in ℝᴺ is therefore mapped to an ellipsoid in ℝᴹ whose semi-axis lengths are the σᵢ and whose axis directions are the uᵢ.
  • Single-vector form Avᵢ = σᵢuᵢ is the SVD's answer to Av = λv: unlike eigenvectors, the input and output directions are allowed to be different vectors, which is why rectangular matrices are no obstacle.
  • Economy (thin) SVD: for a tall M×N matrix, columns N+1…M of U get multiplied by zero rows of Σ and contribute nothing to A. Dropping them gives U of size M×N and Σ of size N×N — same product, far less storage (numpy.linalg.svd(A, full_matrices=False)). You lose the explicit basis for the left-null space.
singular value decompositionA = U Σ Vᵀ UᵀU = Iₘ VᵀV = Iₙ σ₁ ≥ σ₂ ≥ … ≥ σ_min(M,N) ≥ 0 one singular triplet at a timeAvᵢ = σᵢuᵢ uᵢᵀA = σᵢvᵢᵀ

Computing the SVD

  • A may not be square, but AᵀA and AAᵀ always are — and always symmetric, so they are always diagonalizable with real eigenvalues and orthogonal eigenvectors (§15). Substitute the SVD into each and the orthogonal factors annihilate each other in the middle.
  • So: V = eigenvectors of AᵀA, U = eigenvectors of AAᵀ, and the singular values are the square roots of the shared non-zero eigenvalues. Non-negativity is immediate — they're square roots of eigenvalues of a symmetric PSD matrix; realness comes from the symmetric-matrix proof in §15.
  • You only need one of the two eigendecompositions: get V and Σ, then read off U column by column as uᵢ = Avᵢ/σᵢ. By hand, decompose whichever of AᵀA (N×N) or AAᵀ (M×M) is smaller.
  • Sizes gotcha: ΣᵀΣ is square even when A isn't. The real Σ is M×N; take the diagonal of the square version and trim the excess rows or columns. That's why a 2×3 matrix has three eigenvalues in AᵀA but only two singular values.
  • Normalisation and sign are not optional here. In VΛV⁻¹ any stray magnitude in V is cancelled by V⁻¹, so eigenvectors are magnitude- and sign-invariant. In UΣVᵀ the two outer matrices are not inverses of each other — they may not even be the same size — so nothing cancels. Singular vectors must be unit-length, and since all σ ≥ 0, the signs of uᵢ and vᵢ must be consistent (flip one, flip the other) or UΣVᵀ ≠ A.
  • In practice, never form AᵀA. It squares the condition number and throws away precision. Real algorithms (Golub–Kahan bidiagonalization + QR iteration) work on A directly: numpy.linalg.svd returns U, a vector of singular values, and Vᵀ.

  • Worked check: A = [[1, 1, 0], [0, 1, 1]] ⟹ σ = √3, 1 and Σ = [[√3, 0, 0], [0, 1, 0]]. Build the singular vectors as integers first if you like, but you must normalise every one of them before UΣVᵀ reproduces A.

Square A with complex λσ are always real and non-negative, guaranteed — they come from a matrix times its own transpose, which is always symmetric.
  • Why the apparent contradiction (identical for AᵀA, unrelated for a general A)? Because both decompositions are exact, all of the matrix's "energy" must live inside the three factors. In the SVD, U and V are orthogonal — norm 1, they can store no energy — so all of it sits in Σ. In an eigendecomposition of a non-symmetric matrix, V is not orthogonal, so energy is shared between V and Λ. Symmetry is what makes the two coincide.
  • Scale-dependence: multiply the matrix by c and every singular value multiplies by |c|. The orthogonal factors can't absorb a scalar, so Σ must. Raw singular values are therefore not comparable across matrices — normalise them first (below).

SVD of a symmetric matrix

  • Write the SVD of A and of Aᵀ: A = UΣVᵀ and Aᵀ = VΣUᵀ. If A = Aᵀ these must agree, forcing the left and right singular vectors to coincide up to sign.
  • Precisely: with the eigendecomposition A = QΛQᵀ, the SVD is U = Q, Σ = |Λ|, V = Q·sign(Λ). If A is positive semi-definite all signs are + and U = V = Q exactly: A = UΣUᵀ. Negative eigenvalues flip the corresponding column of V.
  • This is why covariance matrices, Gram matrices XᵀX, and kernel matrices behave so nicely: PSD and symmetric, so eigen and singular decompositions are literally the same object.

The SVD and the four subspaces

  • Split U and V at column r = rank(A) and all four subspaces fall out with orthonormal bases — the single most useful thing the SVD does.
  • The logic is Avᵢ = σᵢuᵢ: if σᵢ ≠ 0 the right-hand side is a non-zero vector reachable from the columns of A, so uᵢ ∈ C(A). If σᵢ = 0 the right-hand side is the zeros vector, so uᵢ ∈ N(Aᵀ). Run the same argument on uᵢᵀA = σᵢvᵢᵀ for the row space and null space.
  • Orthogonality between the pairs is automatic: any subset of columns of an orthogonal matrix is orthogonal to any non-overlapping subset. U spans all of ℝᴹ and V all of ℝᴺ, even when A is rank-deficient — unlike eigenvectors, which can fail to span anything (defective matrices, §15).
  • The ordering is not automatic: computed by hand, singular values emerge in no particular order. Software sorts Σ descending and permutes the columns of U and V to match.
reading the subspaces off the SVD (r = rank)C(A) = span{u₁ … u_r} N(Aᵀ) = span{u_(r+1) … u_M} C(Aᵀ) = span{v₁ … v_r} N(A) = span{v_(r+1) … v_N}

Rank — and "effective" rank

  • rank(A) = the number of non-zero singular values. Unlike the eigenvalue version of this claim (§15), this one is always true. It is literally how software computes rank.
  • Two arguments. (1) From the subspace reading above: a non-zero σ contributes a basis vector to the column space, a zero σ contributes one to the left-null space. (2) From rank rules: rank(ABC) ≤ min of the ranks, U and V are full-rank by construction, so the rank of the product is pinned to rank(Σ) — which for a diagonal matrix is its count of non-zero entries.
  • Effective rank: a computer can't tell "small but non-zero" from "zero plus rounding error". The recipe is rank = count(σ > tol) with a tolerance scaled to the matrix: roughly max(M, N) × eps(σ_max), where eps is the spacing between representable floats near that value. Too small a tolerance over-estimates rank; too large under-estimates it.
  • A tiny-but-non-zero σ means near rank-deficiency — technically invertible, practically not. That is the same phenomenon as multicollinearity in least-squares (§14).

Spectral theory: a matrix as a stack of ranked layers

  • Every "spectral theory" says the same thing: a complicated object is a sum of simple ones, the way white light is a sum of colours. Here, every matrix is a sum of rank-1 matrices, and the SVD supplies the best possible set of them.
  • Rewrite UΣVᵀ as a sum of outer products: layer i is uᵢσᵢvᵢᵀ, an M×N rank-1 matrix. Layers past r are multiplied by zero and can be dropped.
  • Contrast with plain layer-wise matrix multiplication (§6), where each layer is defined by the accident of a column's position. Rows and columns of a data matrix can usually be shuffled without changing the information; the SVD instead ranks layers by how much of the matrix they actually explain.
  • Each uᵢvᵢᵀ is a pure direction — both vectors are unit length, so the outer product has norm 1. The singular value is the magnitude attached to that direction. The signpost points; the number on it tells you how far.
  • Layer 1 typically captures the most prominent structure in the matrix, layer 2 the next, and so on — with the tail layers contributing changes you can barely see.
SVD spectral decompositionA = Σ_(i=1..r) σᵢ uᵢ vᵢᵀ each layer is rank 1, sorted by importance

Low-rank approximation

  • Truncate the sum at k < r and you get Ã, a rank-k stand-in for A. A rank-30 smoothed data matrix can be visually indistinguishable from its rank-4 approximation.
  • Eckart–Young: this truncation is not merely a good rank-k approximation, it is the best one — no rank-k matrix is closer to A in either the Frobenius norm or the spectral (2-)norm. The errors are exactly the discarded singular values.
  • Choosing k, method 1 — the scree plot. Plot the singular values descending and look for the "elbow" where they flatten out. Quick, visual, and genuinely ambiguous: two people can reasonably disagree by a component or two.
  • Method 2 — a variance threshold. Normalise the singular values (next block) and keep every layer contributing at least, say, 1% (or 0.1% to retain more detail). Still a judgement call, but reproducible.
  • Why bother: (1) Denoising — if signal lives in the large singular values and noise in the small ones, truncation "projects out" the noise. (2) Feature extraction for ML — train on the top-k singular vectors instead of raw columns: faster, often more accurate, and the core of PCA (§19). (3) Compression — a 10,000 × 100,000 float matrix is ~8 GB; if it is rank 100, storing 100 columns of U, 100 of V and 100 scalars costs under 0.1 GB. Image compression is the same trick on a pixel matrix.

Normalizing singular values

  • Is a largest singular value of 8 big? Unanswerable — σ scales with the numbers in the matrix. 10A has singular values 10σ. So convert to a share of the total.
  • The sum of all singular values is the nuclear norm (Schatten 1-norm) and can be read as the total "energy" or variance in the matrix. Dividing each σᵢ by that sum gives a percentage that is comparable across matrices of different scales.
  • For variance-explained in the PCA sense, use the squared singular values, σᵢ²/Σσⱼ² — because σ² are the eigenvalues of the covariance-like matrix AᵀA. (The Schatten-2 norm, √Σσᵢ², is just the Frobenius norm.)
  • Interpretation: a normalised top singular value of 82% says one component explains nearly everything — a simple matrix, maybe one pattern plus noise. A top value of 35% says the information is spread across several directions — a genuinely complicated matrix.
normalised singular values‖A‖_p = ( Σ_(i=1..r) σᵢᵖ )^(1/p) (Schatten p-norm; p=1 nuclear, p=2 Frobenius) σ̃ᵢ = 100·σᵢ / Σⱼ σⱼ variance explained: σᵢ² / Σⱼ σⱼ²

Condition number

  • The condition number κ measures the "spread" of a matrix — how differently it stretches its most- and least-favoured directions. In the circle→ellipse picture it is simply the ellipse's aspect ratio.
  • κ(I) = 1. In fact every orthogonal matrix has κ = 1, because QᵀQ = I means all its singular values are 1 — a rotation stretches nothing.
  • κ = ∞ (or undefined) for a singular matrix, since σ_min = 0. There's no universal cutoff for "ill-conditioned"; κ > 10⁴ is a common rule of thumb but it is application-specific.
  • What it predicts: sensitivity to perturbation. A high κ means small changes in the input (noise, rounding) produce large changes in anything that involves an inverse — regression coefficients, solutions of linear systems. Roughly, you lose log₁₀ κ digits of accuracy.
  • Don't over-read it. A matrix can carry enormous information and still be singular (κ undefined), or be near-singular and still be exactly the matrix you want. κ is a stability warning, not a quality score.
condition numberκ = σ_max / σ_min κ(Q) = 1 for orthogonal Q κ = ∞ for singular A

The inverse and the Moore–Penrose pseudoinverse

  • For a square full-rank matrix, inverting the SVD is nearly free: reverse the order, transpose the orthogonal factors (their inverses are their transposes), and reciprocate the diagonal.
  • This is where instability comes from. If some σ ≈ 10⁻¹⁵, then 1/σ ≈ 10¹⁵ and that one layer swamps everything. The explicit inverse of an ill-conditioned matrix amplifies noise by exactly κ — a formula-level explanation of why numerical people say "never invert a matrix".
  • It also proves that the inverse of a symmetric matrix is symmetric: A = VΣVᵀ ⟹ A⁻¹ = VΣ⁻¹Vᵀ, same singular vectors, still a diagonal core.
  • The pseudoinverse (§12, part 1) is the same procedure with one change: invert only the non-zero singular values, leave the zeros as zeros, and transpose the result to fix the shape. This works for any matrix — square or rectangular, full-rank or singular.
  • When A is square and full-rank, A⁺ = A⁻¹ exactly. When A is tall with full column rank, A⁺ equals the left inverse (AᵀA)⁻¹Aᵀ — substitute the SVD and everything collapses to VΣ⁻¹Uᵀ. Same story for the right inverse of a wide matrix. So the one-sided inverses need no explicit (AᵀA)⁻¹.
  • Least-squares, finished: β = A⁺y always minimises ‖Aβ − y‖, and when there are infinitely many minimisers it returns the one with the smallest norm. This is the clean answer to the rank-deficient case that broke §14's normal equations.
  • In code: numpy.linalg.pinv implements exactly this, thresholding singular values below rcond × σ_max to zero so that near-zero values don't explode. numpy.linalg.lstsq uses the same machinery for regression.

The SVD is the Swiss-army knife of linear algebra — rank, norms, the four subspaces, conditioning, inverses, least-squares, compression, and PCA all read straight off the same three matrices. When a decomposition is available and you don't know which one to reach for, reach for this one.
