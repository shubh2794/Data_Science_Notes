07 Rank

Rank is the single most informative number about a matrix: how many independent directions it actually spans. Nearly every "is this allowed / will this be stable" question is a rank question in disguise.

Six things about rank

  • Rank is one non-negative integer per matrix — never negative, never fractional. Only the zeros matrix has rank 0.
  • It is bounded: 0 ≤ rank(A) ≤ min(m, n).
  • It is a property of the whole matrix, not of its rows, columns, or subspaces — "the rank of the null space" is meaningless.
  • Full rank means r = min(m, n): full column rank if tall (r = n), full row rank if wide (r = m). Otherwise it's rank-deficient — reduced-rank, degenerate, low-rank, or (if square) singular.
  • Rank counts dimensions of information, not rows or columns: [[1,3,4],[3,9,12]] has 3 columns and 2 rows but rank 1 — every column is a multiple of the others, as is every row.
  • The definition to hold onto: the largest number of columns forming a linearly independent set, which always equals the largest number of independent rows.
rank(A) = dim C(A) = dim C(Aᵀ) = # non-zero singular values 0 ≤ r ≤ min(m, n)

Interpretations, and how to compute it

  • Algebraic: the size of the largest independent subset of columns (or rows). Independence is a property of a set, so "number of independent columns" is shorthand for this.
  • Geometric: the dimensionality of the subspace spanned — emphatically not the ambient dimensionality. [4, 0, 1]ᵀ lives in ℝ³ but spans a line, so rank 1 (every non-zero vector has rank 1).
  • The two views can look totally different and still agree. [[1,1,−4],[2,−1,2]] is three vectors spanning all of ℝ² column-wise, and two vectors spanning a plane inside ℝ³ row-wise: different subspaces, same dimensionality.
  • Three ways to compute: count the largest independent set by inspection (small integer matrices only); count pivots in echelon form (§10); count non-zero singular values from the SVD (§16) — the numerically robust route. np.linalg.matrix_rank does the last one, counting singular values above a tolerance.

  • These are ceilings, not values: knowing both ranks never pins down rank(A + B) or rank(AB). They also stack with the size bound — two rank-3 matrices of size 3×4 sum to rank at most 3, not 6. Subtraction obeys the same rule, since A − B = A + (−1)B.
  • Useful consequence: a random m×r times a random r×n gives a random m×n matrix of exactly rank r — the standard recipe for test matrices of prescribed rank.
  • Why rank(AᵀA) = rank(A): they share a null space. Forward, Ay = 0 ⟹ AᵀAy = 0; backward, AᵀAy = 0 ⟹ yᵀAᵀAy = 0 ⟹ ‖Ay‖ = 0 ⟹ Ay = 0. Same nullity ⟹ same rank (§08). Via the SVD: AᵀA = VΣUᵀUΣVᵀ = VΣ²Vᵀ, and Σ² has as many non-zeros as Σ. This is why least squares can work with the small square XᵀX instead of the tall X.

Sharper rank bounds, and two factorisations that expose the rank

  • The table above gives ceilings. Three more results give floors and exact values, and they are the ones that settle arguments.
  • Sylvester's law of nullity (a lower bound on a product). If A is n×n and B has n rows, then rank(AB) ≥ rank(A) + rank(B) − n. Together with the ceiling: rank(A) + rank(B) − n ≤ rank(AB) ≤ min(rank A, rank B). The practical reading is that a product can only lose as much rank as the shared dimension allows — multiply two full-rank square matrices and you cannot lose any at all.
  • Sums are two-sided too: |rank(A) − rank(B)| ≤ rank(A + B) ≤ rank(A) + rank(B). The lower bound follows from the upper one applied to A = (A + B) + (−B). So adding a low-rank matrix to a high-rank one cannot collapse it far — the basis of "low-rank plus sparse" decompositions such as robust PCA.
  • Rank is invariant to multiplication by non-singular matrices: rank(PAQ) = rank(A) for non-singular P, Q. That is the rank statement of matrix equivalence (linear maps) — row and column operations cannot create or destroy information, only re-describe it. Corollary: Gaussian elimination is a legitimate way to compute rank.
  • Blocks. Every block of a partitioned matrix has rank at most the whole: rank(Aᵢⱼ) ≤ rank(A); and rank(A) ≤ rank([A₁₁ | A₁₂]) + rank([A₂₁ | A₂₂]), with equality when the two block-rows span orthogonal row spaces. Also rank(A ⊗ B) = rank(A)·rank(B) and rank(A ⊕ B) = rank(A) + rank(B) — Kronecker multiplies rank, direct sum adds it.
  • Full-rank factorisation. Any m×n matrix of rank r > 0 factors as A = L·R with L of size m×r and full column rank, R of size r×n and full row rank. Constructively: let L hold r independent columns of A, and let R hold the coefficients that rebuild every column from them.
  • This is the honest definition of "low rank": a rank-r matrix is exactly one that factors through an r-dimensional bottleneck. It has r(m + n − r) free parameters instead of mn — the compression claim behind matrix factorisation for recommenders, embedding layers, and LoRA-style adapters. Equivalently, expanding the product column-by-row, a rank-r matrix is a sum of exactly r outer products (the layer perspective, §06).
  • Equivalent canonical form. Push the idea further and you may choose non-singular P, Q with PAQ = [[I_r, 0], [0, 0]]. Every matrix of a given size and rank reduces to this one shape; conversely, matrices reduce to the same shape exactly when their ranks agree. Rank is therefore a complete invariant under row-and-column operations — the tidiest theorem about rank there is.
  • The factorisation is not unique (any invertible M gives A = (LM)(M⁻¹R)), and it is not numerically stable. The stable, canonical choice of the same idea is the SVD, which picks L and R orthonormal and the bottleneck diagonal (§16).

Random matrices, and boosting rank by shifting

  • Fill a matrix with floating-point random numbers and it is full rank with probability 1 — an exact dependency among continuous values is a measure-zero event. The exception is a restricted range: random 0/1 entries very much can be dependent (a 4×4 binary matrix of rank 2 is easy to hit).
  • Shifting adds a multiple of the identity: Ã = A + λI, moving the diagonal and leaving everything else alone. Any λ outside the (finite) set of eigenvalues of −A makes Ã full rank, so an arbitrarily tiny λ almost always works: [[1,3,−19],[5,−7,59],[−5,2,−24]] has rank 2, and adding 0.01·I makes it rank 3 while changing the diagonal by under 1%.
  • The trade-off is the whole story: λ → 0 keeps Ã ≈ A (faithful but near-singular); large λ pushes Ã → λI (well-conditioned but informationless). The degenerate extreme: shifting the zeros matrix by λ = 1 raises the rank from 0 to 3 and destroys everything.
  • In statistics and ML this is regularization (matrix smoothing / ridge): (XᵀX + λI)⁻¹Xᵀy is ridge regression, and the same shift stabilizes PCA and generalized eigendecomposition. Choosing λ is application-specific and open; shrinkage methods (§19) are one principled answer.
shift / ridgeÃ = A + λI λ → 0 ⟹ Ã → A λ large ⟹ Ã → λI

Rank is hard in practice

  • Floating point can't distinguish a genuinely tiny singular value from a rounded-off zero. Is 3 × 10⁻¹⁵ signal or noise? Software picks a tolerance, and rounding error can land on either side of it.
  • Geometrically: three sensor readings that should lie in a plane will, with a whisker of noise, poke slightly off it — the computer reports rank 3 where the physics says 2. What you want is the numerical rank: how many singular values are large relative to the noise floor. Prefer asking "how fast do the singular values decay?" over "what is the rank?".

Rank and span — the augment-rank test

  • Is v in the span of a set of vectors? Put them in a matrix S, compute r₁ = rank(S) and r₂ = rank([S | v]). Equal ⟹ v is in the span (it added no new direction); one higher ⟹ it is not; smaller ⟹ you made an arithmetic error.
  • This is the same test as "is b reachable by Ax?" — the solvability condition for Ax = b (§08, §10). It answers whether, not with what weights; for those, run Gaussian elimination.
v ∈ span(S) ⟺ rank([S | v]) = rank(S)
Geometric meaning: a rank-deficient transform collapses space — a plane onto a line (or a point). Its determinant is 0 and it has no inverse. Set the determinant to ≈0 in the transform above to see it happen. This is the thread that leads to the inverse, least-squares, and PCA.
Why the fuss: some operations (above all the inverse) exist only at full rank, others merely behave far better there, and numerical algorithms are more reliable on full-rank inputs — which is exactly why regularization exists.

08 The four fundamental subspaces

Every matrix carves its input and output spaces into four subspaces. Rank is the hinge that fixes all of their sizes — this is the "big picture" of linear algebra. The entire chapter is really two questions: Ax = b (can I reach b?) and Ay = 0 (what gets destroyed?).

Column space C(A)

  • The subspace spanned by the columns — every linear combination β₁a₁ + … + βₙaₙ. Also called the range or image.
  • For A ∈ ℝ^(m×n), C(A) ⊂ ℝᵐ — not ℝⁿ. Each of the n columns has m entries, so the ambient space is set by the number of rows. Its dimension is r: if r = m the columns fill all of ℝᵐ; if r < m they span an r-dimensional slice of it.
  • Span vs basis: the columns always span the column space, but they form a basis only when they are linearly independent — i.e. when r equals the number of columns. A matrix and the same matrix with a duplicated column have identical column spaces but different basis status.
  • The solvability statement: Ax = b has an exact solution iff b ∈ C(A), and then x holds the weights on the columns that build b.
  • An easy basis for C(A) is the first r independent columns — easy, not good. The SVD (§16) produces an orthogonal basis for the same space, which is what you actually want numerically.
column spaceC(A) = span(a₁, …, aₙ) = {β₁a₁ + … + βₙaₙ : β ∈ ℝⁿ} C(A) ⊂ ℝᵐ, dim = r

A and AAᵀ share a column space

  • Sizes first: AAᵀ is m×m, so its column space also lives in ℝᵐ. (Note AᵀA could not possibly share it — it lives in ℝⁿ.)
  • By the column perspective of multiplication, every column of AAᵀ is a weighted combination of A's columns, so C(AAᵀ) ⊆ C(A). Both have the same rank (§07), hence the same dimension — and a subspace of equal dimension inside another is the other.
  • Same argument transposed: A and AᵀA have the same row space. This is a form of dimensionality reduction: AᵀA may be far smaller than A yet carries the same row space — the reason covariance matrices are such useful stand-ins for raw data.
  • Same space, different spanning vectors: the columns of A and of AAᵀ are generally different bases for the one subspace.

Is a given vector in the column space?

  • Take A = [[2,1],[4,4],[0,0]] — two independent columns, so C(A) is a plane inside ℝ³. Is v = [4, 12, 0] on it? Yes: 1·[2,4,0] + 2·[1,4,0] = [4,12,0], i.e. Ax = v with x = [1, 2]. Is w = [4, 1, 1]? No — no combination of columns whose third entry is 0 can produce a non-zero third entry, so Ax ≠ w for every x ∈ ℝⁿ.
  • Mechanically, the augment-rank algorithm: build B = [A | v] and compare ranks. Equal ⟹ v ∈ C(A); one higher ⟹ v ∉ C(A).
  • Geometrically: a vector already inside the subspace contributes no new direction, so the dimension can't grow. A vector poking outside adds exactly one new direction. Algebraically: if v is a combination of A's columns, augmenting creates a dependent set, so the rank cannot increase.
  • Corollary: if A is square and full rank, every v ∈ ℝᵐ is in the column space — there is no room for an (m+1)-dimensional subspace in ℝᵐ.
  • The test answers whether, not how. To recover the weights, run Gaussian elimination (§10).

Row space C(Aᵀ)

  • The span of the rows, written R(A) or C(Aᵀ) — the column space of the transpose. It lives in ℝⁿ and also has dimension r.
  • The question changes side: membership is xᵀA = vᵀ, a weighted combination of rows with the weight vector on the left. The augment-rank test still works — append v as an extra row.
  • The two spaces can look nothing alike. For [1, 2, 0, −3] the row space is a line in ℝ⁴ while the column space is all of ℝ¹ — completely different objects, identical dimension (1). For a square full-rank matrix they coincide: C(A) = R(A) = ℝⁿ.

Null space N(A)

  • Every y with Ay = 0 — the combinations of columns that cancel exactly. Also called the kernel. Vectors here are squashed to the origin and can never come back: no matrix B exists with BAy ≠ 0.
  • y = 0 always works; that is the trivial solution and we ignore it. The interesting question is whether a non-trivial y exists.
  • Example: [[1,2],[4,8]]·[−2, 1]ᵀ = [0, 0]ᵀ. And every scalar multiple works too — N([[1,2],[4,8]]) = {σ·[−2, 1]ᵀ}. A null space is a subspace (a line here), not a single vector, so we describe it by a basis.
  • Contrast [[1,2],[4,7]]: no non-trivial y exists. People say it "has no null space"; strictly, the null space is empty (just the origin), dimension 0.
  • The pattern is not a coincidence: [[1,2],[4,8]] is rank 1 and [[1,2],[4,7]] is rank 2. Full column rank ⟹ trivial null space; rank-deficient columns ⟹ non-trivial null space.
  • Sizes: the null vector weights the n columns, so N(A) ⊂ ℝⁿ — the same ambient space as the row space. Null spaces are not just for square matrices: [[1,2],[1,2],[1,2],[1,2]]·[−2,1]ᵀ = 0 works fine for a 4×2 matrix.
null spaceN(A) = {y : Ay = 0}, excluding the trivial y = 0 N(A) ⊂ ℝⁿ, dim = n − r

Left null space, and the geometry of collapse

  • The mirror image, with the vector on the left: yᵀA = 0ᵀ. Transposing gives Aᵀy = 0 — so the left null space is just the ordinary null space of Aᵀ, exactly as the row space is the column space of Aᵀ.
  • It weights the m rows, so N(Aᵀ) ⊂ ℝᵐ. And when A = Aᵀ the two null spaces coincide.
  • Geometry: take M = [[1,2],[2,4]] (singular). The vector y = [−2, 1] is in its null space and My is a single dot at the origin, while u = [−1, 1] maps to an ordinary non-zero vector. The matrix has a one-dimensional direction of total collapse.
  • Nothing is special about M or about y individually — what is special is the pairing. Note also that MAy ≠ AMy for a generic A: sneak a matrix in first and the vector is no longer aligned with M's null direction, so nothing collapses.

Orthogonal subspaces and orthogonal complements

  • Two subspaces are orthogonal when every vector in one is orthogonal to every vector in the other. It suffices to check basis vectors: if v₁ ⟂ w and v₂ ⟂ w then (α₁v₁ + α₂v₂) ⟂ βw, since scaling and summing zeros still gives zero.
  • They must share an ambient space — orthogonality is defined by dot products, which need matching dimensionality.
  • Trap: two perpendicular-looking planes in ℝ³ are not orthogonal subspaces. They intersect in a line, and a vector on that line would have to be orthogonal to itself. Two 2D objects can never be orthogonal subspaces inside 3D. A plane and a line normal to it can.
  • Orthogonal complements: subspaces V and W that are orthogonal and together span the whole ambient space, meeting only at the origin. Every vector in ℝᴺ is then in exactly one of them.

The four subspaces pair up

  • "y is orthogonal to C(A)" means y is orthogonal to every column, i.e. every entry of Aᵀy is zero — which is the definition of the left null space. Starting from orthogonality, we rediscover N(Aᵀ).
  • Likewise "y orthogonal to every row" collects into Ay = 0 — the null space. So the pairings are forced, not designed.
  • Because each pair is an orthogonal complement, the two halves fill the ambient space: every vector in ℝᵐ is either in the column space or the left null space, and every vector in ℝⁿ is either in the row space or the null space (only the zeros vector is in both).
  • Quick check: B = [[1,1],[2,2]] has C(B) = span{[1,2]} and N(Bᵀ) = span{[−2,1]} — dot product 0, visibly perpendicular lines. D = [[1,1],[2,3]] is full rank, so C(D) = ℝ² and its left null space is empty (just the origin): there is nothing left over to be orthogonal to.

Dimensionalities (rank-nullity)

  • Dimension ≠ rank. Rank is one number for the whole matrix; the four subspaces have four dimensions, and they are determined by the rank plus the shape.
  • Example: A = [[1,0,3],[0,4,5],[2,0,6]] is 3×3 with row 3 a multiple of row 1, so r = 2, dim C(A) = dim C(Aᵀ) = 2, and dim N(A) = 1 — a basis for it is [−12, −5, 4]. Column space (2) + left null space (1) = 3 = the ambient dimension.
  • Edge cases sanity-check the rule. [[1,1],[2,3]]: the column space is already all of ℝ², so nothing can be orthogonal to it and the left null space must be empty. The 2×2 zeros matrix: the column space is a point (dimension 0), so its complement must be all of ℝ² — the left null space is 2-dimensional, and any independent pair is a basis for it.
  • Full column rank ⟹ empty null space. Full row rank ⟹ empty left null space.
  • These four dimensions belong to the transformation, not to the grid. Re-describe A in any other pair of bases and every entry changes, yet r, n − r and m − r do not — the column space is the map's range space and the null space is its kernel, both defined without reference to coordinates (linear maps & change of basis). Rank–nullity is a theorem about maps that happens to be checkable on matrices.

Back to Ax = b and Ay = 0

  • Does Ax = b have a solution? Exactly when b ∈ C(A). In statistics the same equation is written Xβ = y — design matrix, regression coefficients, observed data — and nearly every linear model in ML is this equation wearing different letters.
  • If not? Solve Ax = b̂ instead, where b̂ is the point of C(A) closest to b. That is the least-squares solution (§14), the backbone of model fitting.
  • How many solutions? The general solution is x = x_particular + (anything in N(A)), because A(x_p + y) = b + 0 = b. So the solution is unique iff the null space is trivial; otherwise there are infinitely many, one for each null-space vector.
  • Why anyone wants a null space: almost nobody studies Ay = 0 for its own sake — they study the shifted version (A − λI)y = 0. Its non-trivial solutions are eigenvectors and λ the eigenvalues (§15). That single equation reappears as PCA, generalized eigendecomposition, the SVD, Fisher's linear discriminant, and the Rayleigh quotient.
general solutionAx = b ⟹ x = x_p + y, y ∈ N(A) unique ⟺ N(A) trivial ⟺ full column rank
Why it matters: Ax = b is solvable iff b lies in the column space; the null space tells you how many solutions (if any) — a non-trivial null space means infinitely many. Everything downstream (inverse, least-squares, PCA) is a statement about these four spaces.
One picture to keep: A splits ℝⁿ into a row space it maps faithfully onto the column space, and a null space it annihilates; and it splits ℝᵐ into the column space it can reach and a left null space it cannot. Rank r is the width of the channel between them.
