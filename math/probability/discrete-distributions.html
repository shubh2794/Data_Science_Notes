Random Variables & Discrete Distributions

A random variable turns an outcome into a number: the sum of two dice, the number of defective parts in a lot, the label of an image, the next token a language model emits. Once outcomes are numbers, a whole experiment can be summarised by its distribution, a list of values and their probabilities, together with two numbers that label it, the mean and the variance. This page builds that machinery and then the discrete families that come up again and again: Bernoulli, binomial, geometric, negative binomial, hypergeometric, Poisson, categorical and multinomial. Each one is the answer to a specific question about repeated trials, and recognising the question is most of the work.

01 What a random variable is

An outcome can be anything: a pair of dice faces, a string of coin tosses, an email, an image, a day of server logs. The questions we ask are almost always about a number computed from the outcome: the total shown, the count of heads, whether the email is spam, how many requests failed. A random variable is that computation, written down as a function. The randomness lives in which outcome occurs; the rule that turns the outcome into a number is fixed.

Turning outcomes into numbers

  • A random variable on a sample space Ω is a function X : Ω → ℝ that assigns a real number X(ω) to every outcome ω. Before the experiment is run, X has no value; once the outcome is known, so is X(ω).
  • Worked: two dice. Roll two fair dice and record the ordered pair, so Ω is the 36 equally likely pairs (ω₁, ω₂). Several random variables live on this one sample space:
    • the sum S(ω₁, ω₂) = ω₁ + ω₂, with values 2, …, 12;
    • the maximum M(ω₁, ω₂) = max(ω₁, ω₂), with values 1, …, 6;
    • the number of sixes Z(ω₁, ω₂) = 1{ω₁ = 6} + 1{ω₂ = 6}, with values 0, 1, 2;
    • the indicator of a double D(ω₁, ω₂) = 1{ω₁ = ω₂}, with values 0 and 1.
    The outcome (2, 6) gives S = 8, M = 6, Z = 1, D = 0. One outcome, four numbers. Each random variable is a different question asked of the same experiment.
  • Events from random variables. The statement "X = x" is shorthand for the event {X = x} = {ω ∈ Ω : X(ω) = x}, the set of outcomes that the function sends to x (its preimage). Likewise {X ≤ x}, {a < X ≤ b} and {X ∈ A} are events, so everything in Probability Foundations applies to them directly. P(X = x) means P({ω : X(ω) = x}).
  • Notation. Capital X is the random variable (the function); lower-case x is a particular value it can take. "P(X = x)" reads "the probability that the random variable X takes the value x". Writing X ~ Bin(10, ¼) means "X has the binomial distribution with those parameters"; the tilde here is not "approximately".
  • A random variable is neither random nor a variable. It is a deterministic function. All the randomness comes from the outcome fed into it. This matters when two random variables are defined on the same Ω: S and M above are computed from the same pair of faces, so learning one tells you something about the other. Handling several random variables at once is the subject of Joint Distributions & Dependence.
  • Functions of random variables are random variables. If X is a random variable and g is any function, then Y = g(X), meaning Y(ω) = g(X(ω)), is another one: S − 7, M², 1{S ≥ 10}, the loss on a random example, the logarithm of a count. §02 shows how to get the distribution of Y from that of X.

Indicators: the simplest random variables

  • For any event A, the indicator 1_A is the random variable that equals 1 if A occurs and 0 if it does not. It is the smallest possible step from events to numbers, and it loses nothing: A can be recovered as {1_A = 1}. Its distribution is P(1_A = 1) = P(A), P(1_A = 0) = 1 − P(A).
  • Indicators turn set algebra into arithmetic: 1_(A∩B) = 1_A · 1_B, 1_(Aᶜ) = 1 − 1_A, 1_(A∪B) = 1_A + 1_B − 1_A·1_B. (These were the bookkeeping device behind inclusion–exclusion in Probability Foundations.)
  • Counting with indicators. The number of events among A₁, …, Aₙ that occur is the random variable N = 1_(A₁) + 1_(A₂) + … + 1_(Aₙ). This one idea writes down a large share of the random variables that matter:
    • the number of heads in n tosses is Σ 1{toss i is heads};
    • the number of sixes Z above is 1{ω₁ = 6} + 1{ω₂ = 6};
    • the number of people who get their own hat back is Σ 1{person i gets hat i};
    • the number of floors an elevator stops at is Σ 1{someone chose floor i};
    • the number of test examples a classifier gets right is Σ 1{ŷᵢ = yᵢ}, and accuracy is that count divided by n.
  • Why this decomposition is so useful. The average value of a sum of indicators is the sum of their probabilities, E N = P(A₁) + … + P(Aₙ), whether or not the events are independent. That is linearity of expectation, stated in §03 and proved in Expectation, Variance & Inequalities. It gives answers that are very hard to get any other way. The expected number of people who get their own hat back is n · (1/n) = 1, for any n, even though the events "person i gets hat i" are dependent. §05 uses the same move to get the binomial mean in one line.

Discrete, continuous and mixed

  • A random variable is discrete if its possible values can be listed: finitely many, or a sequence x₁, x₂, …. Counts, labels, ranks and dice totals are discrete. Discrete values need not be integers: the proportion of defective parts in a lot of 100 takes the 101 values 0, 0.01, …, 1. This page is about discrete random variables.
  • A random variable is continuous if it ranges over an interval and every single value has probability zero, as with a latency, a weight or a voltage. Probabilities then come from integrating a density over intervals, which is the subject of Continuous Distributions. Rounding a continuous variable (latency to the nearest millisecond, age in whole years) makes it discrete.
  • A random variable can be mixed: a point mass at some values and continuous elsewhere. The latency of a request that is served from cache in exactly 0 ms with probability 0.3 and otherwise takes a continuous amount of time is mixed. So is an insurance claim (exactly 0 for most policies), and so is the output of a ReLU unit applied to a noisy input: max(0, Z) is exactly 0 whenever Z ≤ 0, which happens with positive probability, and is continuous above 0. The CDF of §02 describes all three types in one language.

Why machine learning is full of random variables

  • Labels are random variables: a binary label is an indicator, a class label is a categorical variable (§11), a rating is a discrete variable on 1 to 5.
  • Counts are random variables: clicks per session, events per hour, occurrences of a word in a document, defects per batch. Their distributions (binomial, Poisson, negative binomial) are the subject of most of this page.
  • Tokens are random variables: a language model's output at each step is a categorical distribution over a vocabulary, and generating text means drawing from it.
  • Every metric you report is a realised value of a random variable. Accuracy on a randomly drawn test set is an average of indicators, so it has a distribution, and its spread is what an error bar measures (§05). The loss on a random training example and the gradient of a random minibatch are random variables, which is why training curves are noisy.

02 The PMF and the CDF

A discrete random variable is completely described by listing its possible values and their probabilities: the probability mass function. The cumulative distribution function records the same information as running totals. The PMF is easier to read; the CDF is what you use to answer "at most", "more than" and "between" questions, and it is the description that also works for continuous and mixed variables.

The probability mass function

  • The probability mass function (pmf) of a discrete random variable X is p(x) = P(X = x), defined for every real x. When several variables are around it is written p_X(x).
  • The support of X is the set of values with p(x) > 0. Off the support, p(x) = 0. For M the support is {1, …, 6}; for the number of tosses until the first head it is {1, 2, 3, …}.
  • Two properties, and they are all you need. (1) p(x) ≥ 0. (2) Σ p(x) = 1, summed over the support. The events {X = x} for different x are disjoint (each outcome produces exactly one value) and together cover Ω, so the sum is P(Ω) = 1 by additivity. Conversely, any list of non-negative weights on a countable set of values that sums to 1 is the pmf of some random variable.
  • Probabilities of any set of values follow by adding: P(X ∈ A) = Σ_(x ∈ A) p(x). That is the whole computational content of the pmf.
  • Finding a normalising constant. If you know a pmf up to a constant, the constant is fixed by the sum. p(k) = c·k on k = 1, 2, 3, 4 needs c · 10 = 1, so c = 1/10. p(k) = c/k² on all positive integers needs c · Σ 1/k² = c · π²/6 = 1, so c = 6/π² ≈ 0.608, and then P(X = 1) = 0.608: more than half the mass sits on the first value even though the support is infinite.

The cumulative distribution function

  • The cumulative distribution function (cdf) is F(x) = P(X ≤ x), defined for every real x, not only values in the support. For a discrete variable it is the running total of the pmf: F(x) = Σ_(xᵢ ≤ x) p(xᵢ).
  • For the maximum of two dice, F(a) = (number of pairs with both faces ≤ a)/36 = ⌊a⌋²/36 for 0 ≤ a ≤ 6: both faces must be at most a, which happens in ⌊a⌋ · ⌊a⌋ pairs. So F(3) = 9/36, F(3.7) = 9/36 as well, and F(4) = 16/36.
  • Three properties characterise a cdf.
    1. Non-decreasing: if a ≤ b then {X ≤ a} ⊂ {X ≤ b}, so F(a) ≤ F(b) by monotonicity of probability.
    2. Limits 0 and 1: F(x) → 0 as x → −∞ and F(x) → 1 as x → +∞.
    3. Right-continuous: F(x + h) → F(x) as h ↓ 0. The events {X ≤ x + 1/n} shrink to {X ≤ x}, and countable additivity makes probability continuous along shrinking sequences (the axioms).
    Any function with these three properties is the cdf of some random variable, and two random variables with the same cdf have the same distribution: every probability statement about one is true of the other.
  • The discrete picture. F is a staircase: flat between support points, jumping up by p(xᵢ) at each xᵢ. At a jump the function takes the upper value (that is right-continuity), which is drawn as a filled dot on the top step and an open dot on the bottom one.

Reading one from the other

  • pmf → cdf: add up. cdf → pmf: read off the jumps. The jump at x is F(x) − F(x⁻) = P(X = x); where F is flat, p is zero.
  • Worked. Suppose F(a) = 0 for a < 0, 1/3 for 0 ≤ a < ½, ½ for ½ ≤ a < ¾, and 1 for a ≥ ¾. The jumps are at 0, ½ and ¾, of sizes ⅓, ⅙ and ½. So p(0) = 1/3, p(½) = 1/6, p(¾) = 1/2, and these sum to 1 ✓. The support does not have to be integers.
  • Two fair coins, X = number of heads. F(x) = 0, ¼, ¾, 1 on x < 0, [0, 1), [1, 2), [2, ∞). In particular F(1.4) = ¾: "at most 1.4 heads" is "at most 1 head". Forgetting that the cdf is defined between support points is the commonest cdf mistake.

Quantiles: the cdf read backwards

  • The quantile function answers "below what value does a fraction q of the probability lie?". Because a discrete cdf jumps over most levels, it is defined as the smallest value that reaches the level: F⁻¹(q) = min{x : F(x) ≥ q}. The median is F⁻¹(½), and the quartiles are F⁻¹(¼) and F⁻¹(¾).
  • Worked. For M, F(4) = 16/36 = 0.444 < ½ and F(5) = 25/36 = 0.694 ≥ ½, so the median is 5. For Bin(10, ¼) (§05), F(1) = 0.244 and F(2) = 0.526, so the median is 2.
  • The quantile function is also how a computer draws from a distribution: feed it a uniform random number U on (0, 1) and F⁻¹(U) has cdf F. That inverse-transform method, and why it works, is in Simulation & Stochastic Processes. Every figure on this page that simulates uses it.

The distribution of a function of X

  • If Y = g(X), then {Y = y} is the event that X lands on some x with g(x) = y. So p_Y(y) = Σ_(x : g(x) = y) p_X(x): collect the mass of every x that g sends to y. If g is one-to-one, the masses just move; if not, several values pile onto one.
  • Worked. Let X take values −1, 0, 1, 2 with probabilities ¼, ⅛, ⅛, ½, and let Y = X². Then Y = 0 only from X = 0; Y = 1 from X = −1 or X = 1; Y = 4 from X = 2. So p_Y(0) = ⅛, p_Y(1) = ¼ + ⅛ = ⅜, p_Y(4) = ½.
  • Same distribution is not the same variable. Let X = ±1 with probability ½ each and Y = −X. X and Y have identical pmfs, so every probability statement about one alone is true of the other, yet P(X = Y) = 0: they never agree. Two classifiers can have exactly the same distribution of scores and disagree on every example. A distribution describes a variable's behaviour, not its identity.

03 Expected value and variance, operationally

A pmf can have dozens or infinitely many entries. Two numbers summarise it well enough to compare families and plan experiments: the expected value, where the distribution balances, and the variance, how far from that point the mass typically sits. This section defines both and shows how to compute them, which is all the families below need. The full theory (expectations of functions, why linearity always holds, moment generating functions and the inequalities that turn a variance into a probability bound) is the subject of Expectation, Variance & Inequalities.

Expected value: the balance point

  • The expected value (expectation, mean) of a discrete random variable is the probability-weighted average of its values: E X = Σ x · p(x). It is often written μ or μ_X.
  • Physical reading. Put a mass p(x) at each point x on a weightless rod. E X is the point where the rod balances, its centre of mass. A long tail on one side pulls the balance point toward it.
  • Frequency reading. Repeat the experiment many times independently and average the observed values. The average settles toward E X, because the value x turns up in a fraction close to p(x) of the runs. That is the law of large numbers, made precise in Limit Theorems & Convergence.
  • The expected value need not be a possible value. A fair die has E X = (1 + 2 + … + 6)/6 = 3.5. Nobody ever rolls 3.5; it is the long-run average per roll.
  • Expectation of an indicator is a probability. E 1_A = 1 · P(A) + 0 · (1 − P(A)) = P(A). This tiny identity is what makes indicator decompositions (§01) so powerful: averages of counts become sums of probabilities.
  • Worked. The maximum of two dice: E M = Σ k (2k − 1)/36 = (1 + 6 + 15 + 28 + 45 + 66)/36 = 161/36 ≈ 4.47, above the middle value 3.5 because large values are more likely. The sum of two dice: E S = 7, by symmetry of the pmf about 7.

When the expected value does not exist

  • For an infinite support the sum Σ x p(x) may diverge. The expectation is defined only when Σ |x| p(x) < ∞; otherwise we say X has no (finite) mean. A random variable can be finite with probability 1 and still have an infinite expectation.
  • Worked: the doubling strategy. Stake 100 units on a game you win with probability p (winning pays the stake); after each loss double the stake; stop at the first win. You always finish exactly 100 ahead. The number of rounds X is geometric (§06), and the final stake is 100 · 2^(X − 1). Its expectation is Σₖ 100 · 2ᵏ⁻¹ (1 − p)ᵏ⁻¹ p = 100p Σₖ (2(1 − p))ᵏ⁻¹, a geometric series with ratio 2(1 − p). For p > ½ the ratio is below 1 and the sum is 100p/(2p − 1) (300 at p = 0.6). For a fair game, p = ½, every term equals 50 and the sum is infinite. You win 100 with certainty, but only by having, on average, an infinitely deep pocket. Table limits exist to stop exactly this.
  • Heavy-tailed counts in real data (followers per account, downloads per package, words by frequency rank) can behave like this: the sample mean keeps drifting upward as more data arrive instead of settling. When that happens, the median is the reliable summary.

Variance and standard deviation: the typical distance from the mean

  • The variance is the expected squared distance from the mean: Var X = E(X − μ)² = Σ (x − μ)² p(x). Squaring makes every deviation count positively and penalises large deviations most.
  • The standard deviation σ = √Var X is in the same units as X, so it is the number to quote: "the mean is 4.47 and values are typically about 1.4 away".
  • The shortcut. Expanding the square, Σ (x − μ)² p(x) = Σ x² p(x) − 2μ Σ x p(x) + μ² Σ p(x) = E X² − 2μ² + μ² = E X² − μ². So Var X = E X² − (E X)²: the mean of the squares minus the square of the mean. It is usually the faster route by hand. (In floating point, with values far from zero, the first form is the more accurate one.)
  • Scaling and shifting. Adding a constant moves the distribution without changing its spread, and multiplying by a multiplies every deviation by a. So E(aX + b) = a E X + b and Var(aX + b) = a² Var X, σ_(aX+b) = |a| σ_X. Changing units from metres to centimetres multiplies the variance by 10,000.
  • Variance of an indicator. 1_A² = 1_A, so E 1_A² = P(A) and Var 1_A = P(A) − P(A)² = P(A)(1 − P(A)). It is largest, ¼, when P(A) = ½: a coin flip is the most uncertain yes/no question.

What linearity buys, stated now and proved later

  • Expectation is additive, always. For any random variables on the same sample space, E(X + Y) = E X + E Y, with no independence assumption. This is the step that turns indicator decompositions into one-line means (§01, §05, §08).
  • Variance is additive only without correlation. Var(X + Y) = Var X + Var Y holds when X and Y are independent (more generally, uncorrelated). The correction term in general is twice the covariance, introduced in Joint Distributions & Dependence. Every variance formula on this page that adds variances is quietly using independence; the hypergeometric (§08) and multinomial (§11) are the cases where it fails and the answer is different.
  • The mean is not the typical value. For a skewed distribution the mean, median and mode can be far apart. The waiting time for a 1-in-100 event (§06) has mean 100, median 69 and mode 1. Quote the summary that answers the question being asked.
Why two numbers. The mean says where to centre a prediction; the variance says how wrong a prediction centred there will typically be. For each family below the page gives both in closed form. Together they are enough to tell families apart (§12), to size an experiment, and, through the inequalities and limit theorems that come later, to put a probability on "far from the mean".

04 Bernoulli trials: the atom of the discrete families

The simplest non-constant random variable takes two values, 1 and 0, "success" and "failure". A sequence of independent repetitions of such a yes/no experiment, each with the same success probability, is a sequence of Bernoulli trials. Nearly every discrete family on this page is a different question asked about that one sequence.

The Bernoulli distribution

  • X ~ Bernoulli(p) if P(X = 1) = p and P(X = 0) = 1 − p, for some 0 ≤ p ≤ 1. Compactly, p(x) = pˣ (1 − p)¹⁻ˣ for x ∈ {0, 1}: the exponent switches on the right factor.
  • "Success" and "failure" are just names for 1 and 0. A success can be a defective part, a failed request, a spam email or a patient with the disease. Choose the coding so that the count you care about is the count of 1s.
  • Every indicator is Bernoulli, with p = P(A), and every Bernoulli variable is the indicator of the event {X = 1}. So §01's indicators and this family are the same object.
  • Mean and variance, from the definitions of §03: E X = 0 · (1 − p) + 1 · p = p, and since X² = X, E X² = p and Var X = p − p² = p(1 − p). The variance is 0 at p = 0 or 1 (no randomness at all) and largest, ¼, at p = ½.

What "Bernoulli trials" assumes

  • A sequence X₁, X₂, … is a sequence of Bernoulli trials when three conditions hold: (1) each trial has exactly two outcomes; (2) the success probability p is the same on every trial; (3) the trials are independent, so the probability of any particular string of successes and failures is a product, as in the product spaces of Probability Foundations.
  • Each condition fails in practice, and each failure has a recognisable symptom and a recognisable fix:
    • More than two outcomes (a rating, a class among ten): the trial is categorical, and counts are multinomial (§11).
    • Changing p (users with different click rates, a machine that drifts, a model whose error rate varies by subgroup): counts are more spread out than the binomial predicts. That overdispersion is what the negative binomial models (§07).
    • Dependence (errors that come in bursts, a contagious illness, sampling without replacement): counts can be more or less spread out. Sampling without replacement is the clean case, and it gives the hypergeometric (§08).

Two boundary cases worth naming

  • Point mass. P(X = a) = 1: a constant viewed as a random variable. Its cdf is a single step at a, its mean is a, and its variance is 0. Bernoulli(0) and Bernoulli(1) are point masses. It is the limit of any family as its variance goes to zero.

05 The binomial distribution

Run n Bernoulli trials and count the successes. That count is binomial. It is the distribution of the number of heads, of defective parts in a sample, of correct answers on a guessed test, of users who click, and of test examples a classifier gets right. Its formula has two parts, a probability per arrangement and a count of arrangements, and both come straight from Probability Foundations.

Deriving the pmf

  • Let X = X₁ + … + Xₙ where the Xᵢ are Bernoulli(p) trials. X = k means exactly k of the n trials succeeded.
  • One arrangement. Any specific sequence with k successes and n − k failures, such as 1 1 0 1 0 0 …, has probability pᵏ (1 − p)ⁿ⁻ᵏ by independence: multiply p for each success and 1 − p for each failure. Every such sequence has the same probability, whatever the order.
  • How many arrangements. A sequence with k successes is determined by which k of the n positions hold them: C(n, k) = n!/(k!(n − k)!) choices (counting).
  • Add them up. The arrangements are disjoint events, so P(X = k) = C(n, k) pᵏ (1 − p)ⁿ⁻ᵏ for k = 0, 1, …, n. The probabilities sum to 1 by the binomial theorem, Σ C(n, k) pᵏ (1 − p)ⁿ⁻ᵏ = (p + (1 − p))ⁿ = 1, which is where the family gets its name.
  • Worked: guessing a test. A test has 10 questions, each with four options, and you need 6 correct to pass. Guessing independently, each answer is right with probability ¼, so the number right is Bin(10, ¼). P(X = 0) = (¾)¹⁰ = 0.0563, and P(pass) = P(X ≥ 6) = Σ_(k=6..10) C(10, k)(¼)ᵏ(¾)¹⁰⁻ᵏ = 0.0197, about one chance in fifty.

The shape: where the peak is and how it moves

  • The ratio of neighbours. Dividing consecutive probabilities, almost everything cancels: p(k + 1)/p(k) = [(n − k)/(k + 1)] · [p/(1 − p)]. This ratio is the cleanest way to compute a binomial pmf numerically (start at p(0) = (1 − p)ⁿ and multiply along) and it pins down the shape.
  • The mode. The pmf increases from k to k + 1 exactly when the ratio exceeds 1, that is when (n − k)p > (k + 1)(1 − p), which simplifies to k < (n + 1)p − 1. So the pmf rises, peaks, then falls (it is unimodal), and, for 0 < p < 1, the peak is at ⌊(n + 1)p⌋. When (n + 1)p is a whole number there are two equal peaks, at (n + 1)p − 1 and (n + 1)p.
  • Worked. Bin(10, ¼): (n + 1)p = 2.75, mode 2 ✓. Bin(20, 0.3): 6.3, mode 6, with p(5), p(6), p(7) = 0.1789, 0.1916, 0.1643. Bin(9, ½): exactly 5, so p(4) = p(5) = 0.2461, two modes.
  • Symmetry and skew. Counting failures instead of successes gives n − X ~ Bin(n, 1 − p). At p = ½ the pmf is symmetric about n/2; for p < ½ it has a longer right tail, and for p > ½ a longer left tail. The skew fades as n grows.
  • Spreading out, slowly. The standard deviation √(np(1 − p)) grows like √n, while the range 0…n grows like n. So in absolute terms the count gets more variable, but as a proportion X/n it concentrates, with standard deviation √(p(1 − p)/n). Meanwhile the peak height shrinks like 1/√(2πnp(1 − p)): P(5 heads in 10) = 0.2461, P(50 in 100) = 0.0796, P(500 in 1,000) = 0.0252. The single most likely count becomes unlikely, even though counts near it remain likely.

Mean and variance: two derivations

  • By indicators (the short way). X = X₁ + … + Xₙ, so by linearity E X = E X₁ + … + E Xₙ = np. The trials are independent, so their variances add: Var X = n · p(1 − p). The mean needed nothing; the variance needed independence.
  • By direct summation (the honest check). Using k · C(n, k) = n · C(n − 1, k − 1), E X = Σₖ k C(n, k) pᵏ qⁿ⁻ᵏ = np Σⱼ C(n − 1, j) pʲ qⁿ⁻¹⁻ʲ = np · 1, where q = 1 − p and j = k − 1. The same trick twice, with k(k − 1) C(n, k) = n(n − 1) C(n − 2, k − 2), gives E X(X − 1) = n(n − 1)p². Then Var X = E X(X − 1) + E X − (E X)² = n(n − 1)p² + np − n²p² = np(1 − p). Both routes agree, and the second uses no theorem about sums.
  • Independence matters for the distribution, not for the mean. The elevator of §01 counts Σ 1{floor i chosen}, a sum of 21 Bernoulli indicators with the same p = 1 − (20/21)ᵐ. It is not binomial, because the indicators are dependent: with m people there can be at most m stops. For m = 3 the exact distribution is 1, 2, 3 stops with probabilities 1/441, 60/441, 380/441, while Bin(21, p) would put mass on 4 or more stops. Yet the mean, (1 + 120 + 1140)/441 = 1261/441 ≈ 2.859, is exactly 21p, because linearity does not care.
  • Sums of binomials. If X ~ Bin(n₁, p) and Y ~ Bin(n₂, p) are independent, then X + Y ~ Bin(n₁ + n₂, p): concatenate the two runs of trials. This needs the same p. With different success probabilities the sum is a "Poisson-binomial" variable, which has mean Σpᵢ and variance Σpᵢ(1 − pᵢ) but no simple pmf.

Where the binomial shows up in machine learning

  • Error bars on accuracy.   • A/B tests compare two binomial proportions (conversions out of visitors), and the Bernoulli/binomial likelihood is the starting point of every such test.

06 The geometric distribution: waiting for the first success

Instead of fixing the number of trials and counting successes, keep trying until the first success and count the trials. That waiting time is geometric. It describes retries until a request succeeds, interviews until a hire, draws until a rejection sampler accepts, and days until a rare event. It is also the only memoryless distribution on {1, 2, 3, …}, which is the formal reason "it is due" is never a valid argument.

The pmf, the tail, and the cdf

  • Let X be the number of the trial on which the first success occurs. X = k means k − 1 failures followed by a success, so P(X = k) = (1 − p)ᵏ⁻¹ p for k = 1, 2, 3, …. There is only one such sequence, so no counting factor appears. This was the infinite sample space of Probability Foundations, now as a random variable.
  • It is a pmf. Σₖ (1 − p)ᵏ⁻¹ p = p · 1/(1 − (1 − p)) = 1, a geometric series, which is where the name comes from. The support is unbounded: there is no guarantee of a success within any fixed number of trials.
  • The tail, by thinking instead of summing. "More than k trials are needed" is exactly "the first k trials all fail", so P(X > k) = (1 − p)ᵏ. The cdf is then F(k) = 1 − (1 − p)ᵏ. (Summing the pmf from k + 1 to infinity gives the same answer, with more work.)
  • Worked: triples in a daily lottery. Three digits are drawn each day; "triples" (all three equal) has probability 10/1000 = 0.01. The wait for the first triple is Geo(0.01). P(wait > 100 days) = 0.99¹⁰⁰ = 0.366: more than a third of the time it takes longer than "the average".

The mean, two ways

  • The tail-sum formula. For a random variable with values in {0, 1, 2, …}, E X = Σ_(k ≥ 0) P(X > k). Proof: P(X > k) = Σ_(j > k) p(j), and when you add these over k = 0, 1, 2, … the term p(j) appears once for each k = 0, …, j − 1, that is j times. So the double sum is Σⱼ j p(j) = E X. For the geometric, E X = Σ_(k ≥ 0) (1 − p)ᵏ = 1/p.
  • First-step conditioning. Condition on the first trial (the law of total probability, applied to an average). With probability p it succeeds and X = 1. With probability 1 − p it fails, one trial is used up, and the process starts afresh, so the remaining wait has the same distribution as X. Hence E X = p · 1 + (1 − p)(1 + E X), which solves to E X = 1/p. The same move on X² gives E X² = p + (1 − p) E(1 + X)² , so E X² = (2 − p)/p² and Var X = (2 − p)/p² − 1/p² = (1 − p)/p².
  • Mean, median and mode are far apart. The pmf is largest at k = 1 (mode 1) and decreases geometrically. The median is the first k with 1 − (1 − p)ᵏ ≥ ½, which is ⌈ln ½ / ln(1 − p)⌉. For the lottery: mode 1, median 69, mean 100, standard deviation 99.5. A typical wait is well below the average wait, because a few very long waits pull the mean up.

Memorylessness, with proof

  • The property. For every k, t ≥ 0, P(X > k + t | X > k) = P(X > t). Having already waited k trials without success, the remaining wait has exactly the distribution of a fresh wait.
  • Proof. The event {X > k + t} is contained in {X > k}, so their intersection is the smaller event and P(X > k + t | X > k) = P(X > k + t)/P(X > k) = (1 − p)ᵏ⁺ᵗ/(1 − p)ᵏ = (1 − p)ᵗ = P(X > t). The same holds for the pmf: P(X = k + t | X > k) = (1 − p)ᵏ⁺ᵗ⁻¹p/(1 − p)ᵏ = P(X = t).
  • The lottery player. After 120 days without triples, the expected further wait is still 100 days, and the chance of waiting another 100 is still 0.366. Nothing is "due". This is the gambler's fallacy of Probability Foundations, now as a theorem about a distribution: independent trials leave no trace for the future to compensate.
  • The geometric is the only memoryless distribution on {1, 2, …}. Let G(k) = P(X > k). Memorylessness with t = 1 says G(k + 1) = G(k)G(1) for every k. With G(0) = 1, induction gives G(k) = G(1)ᵏ. Write 1 − p for G(1): that is the geometric tail. So memorylessness is not a curiosity of one family; it characterises it.
  • The continuous analogue. In continuous time the same property, P(T > s + t | T > s) = P(T > t), characterises the exponential distribution, the waiting time between events of a Poisson process. Shrinking the trial length to zero while keeping the success rate per unit time fixed turns the geometric into the exponential. That limit and the exponential itself are developed in Continuous Distributions.

Two conventions: count the trials, or count the failures

  • Some texts and software define the geometric as the number of failures before the first success, Y = X − 1, with support {0, 1, 2, …}, pmf (1 − p)ʸ p, mean (1 − p)/p and the same variance (1 − p)/p². Both are correct; they answer slightly different questions. Before using a library function, check whether its support starts at 0 or at 1. An off-by-one here changes every mean by exactly 1.

07 The negative binomial: waiting for the r-th success, and counts that vary too much

Keep going past the first success and wait for the r-th. The number of trials is negative binomial. The same family, with its parameter allowed to be any positive number, is also the standard model for counts that are more variable than Poisson, which in real data is most counts.

The pmf, by the "last trial" argument

  • Let X be the trial on which the r-th success occurs. X = x happens exactly when two things are true: trial x is a success, and the first x − 1 trials contain exactly r − 1 successes. The second event is binomial, C(x − 1, r − 1) pʳ⁻¹ (1 − p)ˣ⁻ʳ, and it is independent of trial x. Multiply by p: P(X = x) = C(x − 1, r − 1) pʳ (1 − p)ˣ⁻ʳ for x = r, r + 1, …
  • Why not C(x, r)? The last trial is forced to be a success; only the earlier r − 1 successes are free to move. Counting C(x, r) arrangements would include sequences whose r-th success came earlier.
  • Worked. A player makes each free throw with probability 0.4. The probability that the third make comes on the fifth attempt is C(4, 2)(0.4)³(0.6)² = 6 × 0.064 × 0.36 = 0.1382.
  • With r = 1 the formula is the geometric pmf: the geometric is the negative binomial with one success.

A sum of geometric waits

  • Split the wait at each success. Trials up to the first success form a Geo(p) wait G₁; trials after that up to the second success form another, G₂, which by independence of the trials (and memorylessness) is independent of G₁ and has the same distribution; and so on. So X = G₁ + G₂ + … + Gᵣ, a sum of r independent geometric variables.
  • Linearity gives the mean and independence gives the variance: E X = r/p, Var X = r(1 − p)/p². The same decomposition says that a sum of independent NB(r₁, p) and NB(r₂, p) waits is NB(r₁ + r₂, p).

The binomial duality: never sum a negative-binomial tail

  • "The r-th success needs more than n trials" is the same event as "fewer than r successes in the first n trials". So P(X > n) = P(Bin(n, p) ≤ r − 1) and P(X ≤ n) = P(Bin(n, p) ≥ r). Any negative-binomial cdf is a binomial cdf in disguise, and the infinite tail sum is never needed.
  • Worked: sequential testing. 5% of components are defective, and 12 good ones are needed. Components are tested until 12 good ones are found. Here a success is a good component, so p = 0.95 and r = 12. The probability that more than 15 must be tested is P(Bin(15, 0.95) ≤ 11) = 0.0055. On average 12/0.95 = 12.63 are tested, with standard deviation 0.82.
  • Getting the roles of success and failure the right way round is the whole difficulty in problems like this. If the 5% defect rate is plugged in as p, the same formula answers a different question, "wait for 12 defective parts", and gives nonsense for this one.

The failure-count form, and where "negative" comes from

  • Counting only the failures before the r-th success, Y = X − r, gives P(Y = y) = C(y + r − 1, y) pʳ (1 − p)ʸ for y = 0, 1, 2, …, with mean r(1 − p)/p and the same variance r(1 − p)/p². This is the form most statistical software uses.
  • The name. C(y + r − 1, y) = (−1)ʸ C(−r, y), a binomial coefficient with a negative top argument, defined by the usual product (−r)(−r − 1)⋯(−r − y + 1)/y!. The pmf therefore sums to one by the binomial series with a negative exponent: Σ_y C(y + r − 1, y) qʸ = (1 − q)⁻ʳ, so Σ_y P(Y = y) = pʳ (1 − (1 − p))⁻ʳ = 1.
  • r need not be a whole number. Written with gamma functions, C(y + r − 1, y) = Γ(y + r)/(Γ(r) y!), the failure-count pmf makes sense for any real r > 0. The "waiting for the r-th success" story is lost, but a different story takes its place, and it is the one that matters most in practice.

Overdispersion: counts that vary more than Poisson allows

  • Reparametrise by the mean. With μ = r(1 − p)/p, the variance r(1 − p)/p² becomes μ/p = μ(1 + μ/r) = μ + μ²/r. The Poisson distribution (§09) forces variance = mean; the negative binomial has variance greater than its mean by μ²/r. Small r means strong overdispersion; as r → ∞ with μ fixed, the excess vanishes and the negative binomial converges to the Poisson.
  • Where the extra variance comes from: a mixture. Suppose each unit (a user, a gene, a document, a road segment) has its own Poisson rate Λ, and the rates vary across units following a gamma distribution with shape r. Then the count of a randomly chosen unit is negative binomial. Total variance = average within-unit variance (E Λ = μ) plus the variance of the unit means (Var Λ = μ²/r). The gamma density and the one-line integral behind this are in Continuous Distributions; the variance split is the law of total variance from Expectation, Variance & Inequalities.
  • Worked. A count has mean 4 and variance 12. A Poisson model cannot fit both. Solving 4 + 16/r = 12 gives r = 2 (and p = r/(r + μ) = ⅓). The difference is dramatic in the tails: P(0) is (⅓)² = 0.111 under the negative binomial against e⁻⁴ = 0.018 under Poisson, six times as many zeros; P(X ≥ 10) is 0.075 against 0.008, nine times as many large counts. A Poisson model fitted to such data underestimates both ends and reports standard errors that are far too small.
  • The diagnostic. Compare the sample variance to the sample mean. A ratio near 1 is consistent with Poisson, a ratio well above 1 is overdispersion (heterogeneity, clustering, contagion), and a ratio below 1 is underdispersion (counts more regular than chance, such as scheduled arrivals).

  • In ML and data work. Negative-binomial regression is the default for overdispersed counts: clicks or purchases per user, reads per gene in sequencing data, accidents per road segment, defects per batch. A model that also has an excess of exact zeros (non-users who can never click) may need a separate zero-inflation component on top.

08 The hypergeometric distribution: sampling without replacement

Draw n items without replacement from a finite batch of N, of which K are "marked", and count the marked items in the sample. The draws are not independent (each draw changes what is left), so the count is not binomial. It is hypergeometric, and its pmf is a ratio of the counts from Probability Foundations, held together by Vandermonde's identity.

The pmf, by counting

  • Every subset of n items from the N is equally likely, so there are C(N, n) equally likely samples. A sample with exactly k marked items is built by choosing k of the K marked items and n − k of the N − K unmarked ones: C(K, k) · C(N − K, n − k) ways (multiplication principle). So P(X = k) = C(K, k) C(N − K, n − k) / C(N, n).
  • The support is max(0, n − (N − K)) ≤ k ≤ min(n, K): you cannot draw more marked items than exist, nor fewer than the sample forces once the unmarked ones run out. Draw 8 from a batch of 10 with 7 marked and at least 5 must be marked.
  • The probabilities sum to one because of Vandermonde's identity. Summing the numerator over k gives Σₖ C(K, k) C(N − K, n − k), which counts all n-subsets of the N items, split by how many marked ones they contain. That is C(N, n): Vandermonde's identity from counting, written in this page's symbols as Σₖ C(K, k) · C(N − K, n − k) = C(N, n). The identity is not a computation here; it is the statement that the cases "k marked" partition the sample space.
  • Worked: a 6-from-49 lottery. The six winning numbers are the "marked" items, and your ticket is a sample of 6 from 49. The number of your numbers that are drawn is hypergeometric with N = 49, K = 6, n = 6. Exactly 3 matches: C(6, 3) C(43, 3)/C(49, 6) = 20 × 12,341 / 13,983,816 = 0.0177, as in Probability Foundations. The full distribution is below; it is very skewed toward 0 and 1.
  • Worked: testing programs. 5 of 12 programs need an upgrade, and 4 are chosen at random for testing. P(at least 2 need it) = 1 − [C(7, 4) + C(5, 1)C(7, 3)]/C(12, 4) = 1 − (35 + 175)/495 = 285/495 = 0.576.

The mean, by symmetry and indicators

  • Write X = I₁ + … + Iₙ, where Iⱼ = 1 if the j-th draw is marked. Before anything is observed, every draw position is equally likely to hold any of the N items, so P(Iⱼ = 1) = K/N for every j, not only the first. (This is the urn of conditional probability, where the second ball drawn was red with probability 3/5, exactly like the first.) Linearity then gives E X = nK/N, the same as the binomial with p = K/N.
  • The indicators are dependent: if the first draw is marked, fewer marked items remain, so the second is less likely to be. The pmf therefore differs from the binomial, but the mean, which ignores dependence, does not.

The variance, and the finite-population correction

  • Var X = n p (1 − p) · (N − n)/(N − 1), with p = K/N. It is the binomial variance multiplied by the finite-population correction (N − n)/(N − 1), which is at most 1. Sampling without replacement is less variable than with replacement, because you never re-draw an item you have already seen: the sample is forced to be more representative.
  • Checks at the ends. With n = 1 the factor is 1 and the variance is p(1 − p), a single Bernoulli draw, correctly. With n = N the factor is 0 and the variance is 0, correctly, because drawing the whole batch always yields exactly K marked items.
  • Where the correction comes from. The variance of a sum of dependent indicators is the sum of their variances plus twice the sum of their covariances, and here every pair of draws has covariance −p(1 − p)/(N − 1): a marked first draw makes a marked second draw slightly less likely. That calculation needs covariance, which is introduced in Joint Distributions & Dependence. The n = N check above is enough to pin the covariance down: setting the variance to zero there forces exactly this value.
  • The same factor reappears as the finite-population correction to the standard error of a survey that samples without replacement; see sampling designs.

When the batch is large, it is binomial

  • Write the pmf with falling factorials, [a]ⱼ = a(a − 1)⋯(a − j + 1): P(X = k) = C(n, k) · [K]ₖ [N − K]ₙ₋ₖ / [N]ₙ. Pair the factors up: [K]ₖ[N − K]ₙ₋ₖ/[N]ₙ = Π_(i<k) (K − i)/(N − i) · Π_(i<n−k) (N − K − i)/(N − k − i). Now let N → ∞ with K/N → p and n, k fixed. Each of the first k ratios tends to p and each of the other n − k tends to 1 − p. So P(X = k) → C(n, k) pᵏ (1 − p)ⁿ⁻ᵏ: removing a handful of items from a huge batch barely changes the proportions, and the draws become effectively independent.
  • How large is large? What matters is the sampling fraction n/N, not N alone. With n = 10 and p = 0.3, the total-variation distance between the hypergeometric and the binomial (the largest difference in probability the two assign to any event, defined in §10) is 0.159 at N = 20, 0.054 at N = 50, 0.026 at N = 100 and 0.0024 at N = 1,000. A common rule treats the binomial as adequate when n/N ≤ 5%.
  • Worked: acceptance sampling. A lot of 100 parts contains 5 defectives, and 10 are inspected. P(no defective found) = C(95, 10)/C(100, 10) = 0.584; the binomial with p = 0.05 gives 0.95¹⁰ = 0.599. Capture–recapture: estimating an unknown N

  • To estimate the number of fish in a lake, catch K of them, mark them and release them. Later catch n fish and count the marked ones, k. If the population is closed and every fish is equally catchable, the number of marked fish in the second catch is hypergeometric with unknown N, and the natural estimate equates the sample proportion with the population one: k/n ≈ K/N, so N̂ = Kn/k.
  • Worked. Mark K = 50, recapture n = 40, find k = 8 marked. N̂ = 50 × 40/8 = 250. This is also the maximum-likelihood estimate: the ratio of the hypergeometric probability of the observed k at N to that at N − 1 is (N − K)(N − n)/(N(N − K − n + k)), which is at least 1 exactly when N ≤ Kn/k. So the likelihood rises up to Kn/k and falls after it, So the maximum-likelihood estimate is ⌊Kn/k⌋ when Kn/k is not a whole number; when it is, Kn/k − 1 and Kn/k tie, as here: N = 249 and N = 250 both give probability 0.1701. If k = 0 (no marked fish recaptured) the ratio exceeds 1 for every N, the likelihood increases for ever, and there is no finite estimate.
  • How precise is it? If the true N were 150, seeing 8 or fewer marked fish would have probability 0.027; if it were 400, seeing 8 or more would have probability 0.108. So the data make 150 implausible and are still quite compatible with 400: one recapture of 40 fish pins the population down only roughly. Turning this into a proper interval is estimation. (A slightly less biased variant, (K + 1)(n + 1)/(k + 1) − 1 = 231, is often preferred for small k; unlike Kn/k, it stays finite at k = 0.)
  • The same idea elsewhere. Two reviewers independently inspect a codebase. One finds 50 bugs, the other 40, and 8 bugs are found by both. Treating the first reviewer's finds as "marked", the estimated total is again about 250 bugs, so roughly 168 were missed by both. It also estimates the number of duplicate records from two overlapping samples, or the size of a hidden population from two independent lists. The assumptions (independent "catches", equal catchability) are where real applications go wrong: easy bugs are found by everyone, which makes k too large and N̂ too small.
  • The hypergeometric is also the exact null distribution behind Fisher's exact test for a 2×2 table: with both margins fixed, the count in one cell is hypergeometric.

09 The Poisson distribution: counting rare events

Many opportunities, each with a tiny chance: the number of typos on a page, server errors in an hour, customers arriving in a minute, mutations in a stretch of DNA. Each is a binomial count with enormous n and minute p, and in the limit all such counts follow one distribution, governed by a single number, the expected count μ. That limit is the Poisson distribution, and this section derives it rather than asserting it.

The law of rare events, derived

  • Take X ~ Bin(n, p) with p = μ/n, so that the expected count np = μ stays fixed while the number of opportunities grows and the chance of each shrinks. Fix a value k and split the pmf into four factors:
    C(n, k) (μ/n)ᵏ (1 − μ/n)ⁿ⁻ᵏ = [n(n − 1)⋯(n − k + 1)/nᵏ] · (μᵏ/k!) · (1 − μ/n)ⁿ · (1 − μ/n)⁻ᵏ
  • First factor → 1. It is a product of k terms, (1)(1 − 1/n)(1 − 2/n)⋯(1 − (k − 1)/n). With k fixed, each term tends to 1 and there are only k of them.
  • Second factor does not depend on n.
  • Third factor → e^(−μ). Take logarithms: n ln(1 − μ/n). Using ln(1 − x) = −x − x²/2 − x³/3 − … for |x| < 1, this is n(−μ/n − μ²/(2n²) − …) = −μ − μ²/(2n) − …, which tends to −μ. Exponentiate: (1 − μ/n)ⁿ → e^(−μ). This is the familiar limit (1 + x/n)ⁿ → eˣ with x = −μ.
  • Fourth factor → 1, since 1 − μ/n → 1 and the exponent −k is fixed.
  • Conclusion. P(X = k) → e^(−μ) μᵏ/k! for every fixed k = 0, 1, 2, … The argument only needs npₙ → μ, not exactly p = μ/n. The limit is a genuine pmf: Σₖ e^(−μ)μᵏ/k! = e^(−μ) · e^μ = 1, by the power series of the exponential.
  • What the limit means. No individual trial is modelled any more. The Poisson distribution says that if events are individually rare, roughly independent, and not able to happen two at once, then their count depends only on how many are expected, μ, and not on how many opportunities there were. That is why the same pmf fits radioactive decays, typos and request errors.

Mean, variance and shape

  • Mean. The k = 0 term vanishes, and k/k! = 1/(k − 1)!: E X = Σ_(k≥1) e^(−μ) μᵏ/(k − 1)! = μ Σ_(j≥0) e^(−μ) μʲ/j! = μ.
  • Variance, through the factorial moment. The same shift twice gives E X(X − 1) = μ², so E X² = μ² + μ and Var X = μ² + μ − μ² = μ. Both also follow from the binomial: np → μ and np(1 − p) → μ.
  • Mean equals variance. This is the Poisson's fingerprint and its most testable prediction. The standard deviation is √μ, so relative fluctuations shrink like 1/√μ: a count expected to be 100 typically lands within about 10 of it, a count expected to be 10,000 within about 100.
  • Shape. p(k)/p(k − 1) = μ/k, so the pmf rises while k < μ and falls after: the mode is ⌊μ⌋, with a tie between μ − 1 and μ when μ is a whole number (at μ = 3, p(2) = p(3) = 0.2240). For μ < 1 the mode is 0. The pmf is skewed right, with skewness 1/√μ, and looks increasingly normal as μ grows (§10).

Rates, windows and sums

  • Events usually come with a rate λ per unit of time, length or area, and the count in a window of size t is Poisson with mean μ = λt. Double the window, double the mean, not the count.
  • Independent Poisson counts add. If X ~ Poisson(μ₁) and Y ~ Poisson(μ₂) are independent, then X + Y ~ Poisson(μ₁ + μ₂). In the binomial picture this is just concatenating two runs of rare trials. (A direct proof is a one-line application of the binomial theorem to the convolution sum, done in Joint Distributions & Dependence.)
  • Worked: new accounts. Customers open accounts at 10 per day. Today's count is Poisson(10), and P(more than 8 today) = 1 − F(8) = 1 − 0.333 = 0.667. Over two days the count is Poisson(20), not twice a Poisson(10) count (which could only be even), and P(more than 16 in two days) = 1 − 0.221 = 0.779.
  • Worked: typos. A manuscript averages one typo per two pages, so a page's count is Poisson(0.5). P(clean page) = e^(−0.5) = 0.607, so about 303 of 500 pages are clean; P(two or more typos) = 1 − e^(−0.5)(1 + 0.5) = 0.090.
  • Worked: a classic fit. A nineteenth-century record of deaths from horse kicks in cavalry units covers 200 unit-years with 122 deaths, so μ̂ = 0.61. Poisson predicts 200 · P(k) = 108.7, 66.3, 20.2, 4.1, 0.6 unit-years with 0, 1, 2, 3, 4 deaths. The record shows 109, 65, 22, 3, 1. The sample variance is 0.611, essentially equal to the mean, exactly as the Poisson model requires.
  • Worked: birthdays again. Among 23 people there are 253 pairs, each matching with probability 1/365. The number of matching pairs is approximately Poisson with μ = 253/365 = 0.693, so P(at least one match) ≈ 1 − e^(−0.693) = 0.500, against the exact 0.507. The pairs are not quite independent, which is why the Poisson answer is close rather than exact.

When Poisson fails

  • The derivation assumed three things: many opportunities with small, equal probabilities; independence between them; and no simultaneous events. Each failure leaves a signature in the data.
  • Overdispersion (variance > mean). The rate varies between units or over time (some users are heavy users, some hours are busy), or events cluster (one failure triggers others, one infection causes more). This is the most common failure by far, and the negative binomial is the standard replacement.
  • Underdispersion (variance < mean). Events are more regular than chance: scheduled buses, a machine that produces exactly one part per cycle, counts with a hard cap. A binomial with a moderate p often fits better.
  • Excess zeros. Some units can never produce an event (non-users never click), so zeros exceed e^(−μ) even when the non-zero counts look Poisson.
  • A changing rate. If the rate drifts across the observation window, the count over the whole window is a mixture and is overdispersed. Model the rate as a function of time instead.
  • Quick check. Compare Var/mean on the data with 1. For the horse-kick data it is 1.00; for the overdispersed example of §07 it is 3.
Where the Poisson shows up in machine learning. Count features and count targets (Poisson regression uses a log link, log E[y | x] = wᵀx, and its loss is the negative Poisson log-likelihood); request and event rates for capacity planning; anomaly detection on counts, where an observed count is flagged if its Poisson tail probability P(X ≥ x) is tiny; and the arrival process behind queues and streaming systems, the Poisson process, whose inter-arrival times are exponential. The process itself is developed in Simulation & Stochastic Processes.

10 The Poisson approximation in practice

The limit in §09 says the binomial becomes Poisson eventually. In practice you have one particular n and p and want to know whether the Poisson answer is good enough. That needs a way to measure the distance between two distributions and a bound on it. The answer turns out to depend almost entirely on p, not on n.

Measuring the gap: total-variation distance

  • The total-variation distance between two distributions on the same values is d_TV(P, Q) = ½ Σₖ |p(k) − q(k)|. It has a direct meaning: it is the largest difference in probability that the two can assign to any event, d_TV = max_A |P(A) − Q(A)|. If d_TV = 0.01, then every probability you compute with the approximation, for any event whatever, is within 0.01 of the truth.
  • Why the two definitions agree. Let B = {k : p(k) > q(k)}. For any event A, dropping the values outside B can only increase P(A) − Q(A), and adding the values of B not yet in A also increases it. So P(A) − Q(A) ≤ P(B) − Q(B). Because both pmfs sum to 1, P(B) − Q(B) = Q(Bᶜ) − P(Bᶜ), and adding these two equal quantities gives Σ |p(k) − q(k)|. So the maximum is half the sum, attained at A = B.

A bound that depends on p

  • For a sum of independent Bernoulli trials with success probabilities p₁, …, pₙ and mean μ = Σpᵢ, the distance to Poisson(μ) satisfies d_TV ≤ ((1 − e^(−μ))/μ) · Σ pᵢ². For the binomial, with all pᵢ = p, this is d_TV ≤ (1 − e^(−μ)) · p ≤ p. A simpler and older bound, d_TV ≤ Σpᵢ² = np², is weaker by a factor μ/(1 − e^(−μ)): about 1.6 at μ = 1 (0.100 against 0.063 in the table below), approaching μ once μ is a few units.
  • Three consequences. (1) The quality of the approximation is controlled by the size of the individual probabilities, not by n: at fixed μ, halving p halves the error. (2) The trials do not need equal probabilities. Typos on pages with different lengths, errors on requests of different sizes and failures of components with different reliabilities all give Poisson counts as long as every pᵢ is small. That is what makes the "law of rare events" a law. (3) The bound is honest in its order of magnitude: the true distance is never smaller than about Σpᵢ²/32 times min(1, 1/μ). When μ is of order 1 or less, that factor is 1, and a few trials with a large p ruin the approximation. At large μ the factor 1/μ makes the lower bound tiny: one Bernoulli(0.9) trial among trials totalling μ ≈ 100 still leaves the count close to Poisson(100), with a lower bound of about 0.00025.
  • In the table below the actual distance is about a quarter to a third of p in every row, under the bound each time. A practical rule: the Poisson approximation is good to within about 1.5 percentage points when p ≤ 0.05 (the usual textbook rule is n ≥ 20 and p ≤ 0.05), and very good when p ≤ 0.01, whatever n is.

Worked approximations

  • A batch of lamps. 1,000 lamps, each defective with probability 0.001. Exactly: P(0) = 0.999¹⁰⁰⁰ = 0.3677, P(more than 2) = 0.0802. Poisson(1): e⁻¹ = 0.3679 and 0.0803. The distance is 0.00028, smaller than the rounding in any practical answer.
  • When p is close to 1, flip it. 97% of messages arrive without error; what is the chance that at least 195 of 200 do? The successes are not rare, but the failures are: Y = 200 − X ~ Bin(200, 0.03) with μ = 6. P(X ≥ 195) = P(Y ≤ 5), which is 0.4457 under Poisson(6) and 0.4432 exactly.
  • When neither is rare. At n = 10, p = 0.5, the distance is 0.17, and no Poisson answer should be trusted. Moderate p with large n is the territory of the normal approximation instead.

Both roads lead to the normal curve

  • As μ grows, the Poisson pmf becomes symmetric and bell-shaped around μ with standard deviation √μ; as n grows with p fixed, the binomial does the same around np with standard deviation √(np(1 − p)). Both are instances of the central limit theorem, because both are sums of many small independent pieces: Bernoulli trials for the binomial, and unit-sized Poisson windows for the Poisson.
  • Worked. X ~ Poisson(100): exactly, P(X ≤ 110) = 0.8529. The normal approximation N(100, 10²) with continuity correction gives Φ(1.05) = 0.8531; without it, Φ(1.0) = 0.8413.
  • Which approximation when. Small p (or 1 − p) and moderate np: Poisson. np(1 − p) above roughly 10: normal with continuity correction. Otherwise, or whenever in doubt: compute the exact sum, which any computer does instantly.
  • The theorem itself, with a proof sketch and the rate at which the normal curve takes over, is in Limit Theorems & Convergence. The applied side, standard errors for proportions and counts, is in Sampling Distributions & the CLT.

11 Categorical and multinomial: more than two outcomes

A Bernoulli trial has two outcomes. A die has six, a classifier chooses among ten classes, and a language model chooses among tens of thousands of tokens. One such trial is categorical; the counts from n independent trials are multinomial. If machine learning has a native distribution, this is it: every softmax output is a categorical distribution, and every cross-entropy loss is its negative log-likelihood.

The categorical distribution: one roll of a k-sided die

  • A categorical random variable takes one of k values, labelled 1, …, k, with probabilities p₁, …, pₖ that are non-negative and sum to 1. Its pmf is just the list: P(X = j) = pⱼ. The labels are names, not quantities: "the mean class label" is meaningless when classes are cat, dog and car.
  • The one-hot form. Encode the outcome as a vector x = (x₁, …, xₖ) with a single 1 in position j. Then the pmf can be written p(x) = p₁^(x₁) p₂^(x₂) ⋯ pₖ^(xₖ): the exponents pick out the right factor, exactly as in the Bernoulli formula pˣ(1 − p)¹⁻ˣ, which is the case k = 2.
  • Mean and variance, coordinate by coordinate. Each coordinate of the one-hot vector is an indicator, xⱼ = 1{X = j}, so E xⱼ = pⱼ and Var xⱼ = pⱼ(1 − pⱼ). The mean of the one-hot vector is the probability vector itself, which is why a model's predicted probabilities can be read as its expected one-hot label.
  • Uncertainty. The spread of a categorical distribution is measured by its entropy, H = −Σ pⱼ log pⱼ: 0 when one outcome is certain, and log k, the maximum, when all k outcomes are equally likely (ln 6 = 1.792 nats for a fair die).

The multinomial distribution: counts from n rolls

  • Roll the k-sided die n times independently and let Nⱼ be the number of times face j appears, so N₁ + … + Nₖ = n. The vector (N₁, …, Nₖ) is multinomial(n; p₁, …, pₖ).
  • Deriving the pmf exactly as for the binomial. Any particular sequence of rolls with counts n₁, …, nₖ has probability p₁^(n₁) ⋯ pₖ^(nₖ) by independence. The number of such sequences is the number of ways to split n positions into labelled groups of sizes n₁, …, nₖ, the multinomial coefficient n!/(n₁! ⋯ nₖ!) of counting. Multiply. The probabilities sum to 1 by the multinomial theorem, (p₁ + … + pₖ)ⁿ = 1.
  • Each count on its own is binomial. Face j versus "anything else" is a Bernoulli trial with success probability pⱼ, so Nⱼ ~ Bin(n, pⱼ), with E Nⱼ = npⱼ and Var Nⱼ = npⱼ(1 − pⱼ). Merging categories keeps the multinomial form: the counts of "faces 1–2", "faces 3–4" and "faces 5–6" are multinomial with the summed probabilities.
  • The counts are negatively related. They must add to n, so if one count is high the others must, on balance, be lower. The covariance of two different counts is −n pᵢ pⱼ; it is derived in Joint Distributions & Dependence. This is the reason the multinomial is a joint distribution of a vector rather than k separate binomials.

The distribution machine learning runs on

  • Class labels. A multiclass classifier models y | x as categorical. Its last layer produces a vector of real-valued scores z (logits), and the softmax turns them into a valid probability vector: pⱼ = e^(zⱼ) / Σᵢ e^(zᵢ). Every entry is positive and they sum to 1, whatever the scores are. Adding the same constant to every logit changes nothing, which is why implementations subtract the largest logit before exponentiating. See multiclass logistic regression.
  • Cross-entropy is the negative categorical log-likelihood. In one-hot form, log p(y) = Σⱼ yⱼ log pⱼ = log p_(true class). Training with cross-entropy maximises the probability the model assigns to the observed labels, exactly as binary cross-entropy did for the Bernoulli (§04).
  • Temperature. Dividing the logits by T before the softmax sharpens (T < 1) or flattens (T > 1) the distribution without changing the ranking. As T → 0 all mass goes to the largest logit (greedy choice); as T → ∞ the distribution becomes uniform. For logits (2, 1, 0.5, 0, −0.5, −1) the top probability is 0.825 at T = 0.5, 0.538 at T = 1 and 0.338 at T = 2, and the entropy rises from 0.64 to 1.33 to 1.67 nats.
  • Next-token prediction. A language model's output at each step is a categorical distribution over its vocabulary, and generating text means drawing a token from it, often after reshaping it with a temperature or by truncating to the most likely tokens; see decoding. A model that knew nothing would put 1/V on each of V tokens; with V = 50,000 its cross-entropy would be ln 50,000 = 10.8 nats per token, which is the baseline a trained model's loss is measured against.
  • Bag-of-words. Treating a document of n words as n independent draws from a topic-specific word distribution makes its word counts multinomial. That model, with Bayes' rule on top, is multinomial naive Bayes; scoring each vocabulary word as present or absent instead gives Bernoulli naive Bayes. See naive Bayes variants and the classical text-classification pipeline. Testing whether observed counts fit a multinomial is the chi-square goodness-of-fit test of categorical data analysis.

The families are not a list to memorise; each is the answer to a question about how the data were generated. Questions that pick the family

  1. Is the number of trials fixed in advance? Yes: binomial, hypergeometric or multinomial. No, you stop at a success: geometric or negative binomial. There are no identifiable trials, just a rate: Poisson.
  2. Does drawing change what is left? From a finite batch, without replacement: hypergeometric. With replacement, or from a population much larger than the sample (n/N under about 5%): binomial.
  3. Two outcomes or more? More than two: categorical for one draw, multinomial for counts.
  4. Is p small and n large or unknown? Poisson with μ = np, accurate to within about p/3 in total variation (§10).
  5. Is the success probability the same for every trial? If it varies between units or over time, counts will be overdispersed, and a negative binomial (or an explicit model of how p varies) is needed.

The mean–variance fingerprint

  • For count data, the ratio Var/E separates the families before any formal fitting. Binomial: 1 − p < 1. Hypergeometric: smaller still for n ≥ 2 (equal at n = 1), (1 − p)(N − n)/(N − 1). Poisson: exactly 1. Negative binomial (failure form): 1 + μ/r > 1. A sample variance well above the sample mean rules out Poisson and binomial before anything else is checked.

13 Where this feeds machine learning

Discrete distributions are the vocabulary in which models of labels, counts and tokens are written. A loss function is usually the negative log of one of the pmfs on this page, a data-sampling decision is a choice between binomial and hypergeometric draws, and many surprises in training (empty minibatches, unstable rare-class metrics, overconfident count models) are these distributions behaving exactly as they should.

Class imbalance is a binomial (or hypergeometric) problem

  • If 1% of training examples are positive and minibatches of 32 are drawn at random, the number of positives in a batch is approximately Bin(32, 0.01). P(no positives) = 0.99³² = 0.725: almost three batches in four contain no positive example at all, and the gradient for the positive class comes from the rare remainder. With batches of 256, the expected number of positives is 2.56 and the chance of none falls to 0.076, but the count still fluctuates between batches (P(5 or more) = 0.116).
  • When batches are drawn without replacement within an epoch, the count is hypergeometric, with slightly less variance (§08), and stratified or class-balanced batching removes the variation altogether. Reweighting, resampling and threshold choice for rare classes are in data sampling and class imbalance.
  • Metrics on rare classes are noisy. A test set with 50 positives estimates recall from a Bin(50, recall) count: at a true recall of 0.8 the standard deviation is √(0.8 × 0.2/50) = 0.057, so two models whose recall differs by 5 points are statistically indistinguishable on that test set.

Model families built from these distributions

  • Naive Bayes is Bayes' rule with a discrete class-conditional model. Bernoulli naive Bayes treats each vocabulary word as an independent Bernoulli presence/absence feature; multinomial naive Bayes treats a document's word counts as a multinomial draw. Both are covered in naive Bayes variants; the conditional-independence assumption behind them is in Probability Foundations.
  • Generalised linear models pair a linear score with a distribution from this page: logistic regression with the Bernoulli, softmax regression with the categorical, Poisson regression with the Poisson, negative-binomial regression with the negative binomial.
  • Language models are a chain of categorical distributions: the chain rule of conditional probability writes the probability of a sequence as a product of next-token categoricals, and each step's loss is a categorical cross-entropy.
  • Count features (number of visits, purchases, errors) are usually overdispersed. Treating them as Poisson in a generative model, or comparing them with a Poisson-based test, will flag far too many "anomalies". Check Var/mean first.
  • Randomness inside training: dropout masks are Bernoulli, bagging resamples with replacement (so each example's multiplicity in a bootstrap sample is approximately Poisson(1), and about e⁻¹ = 36.8% of examples are left out of each bag), and random minibatches without replacement are hypergeometric in their composition.
