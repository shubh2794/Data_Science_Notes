02 The PMF and the CDF

A discrete random variable is completely described by listing its possible values and their probabilities: the probability mass function. The cumulative distribution function records the same information as running totals. The PMF is easier to read; the CDF is what you use to answer "at most", "more than" and "between" questions, and it is the description that also works for continuous and mixed variables.

The probability mass function

  • The probability mass function (pmf) of a discrete random variable X is p(x) = P(X = x), defined for every real x. When several variables are around it is written p_X(x).
  • The support of X is the set of values with p(x) > 0. Off the support, p(x) = 0. For M the support is {1, …, 6}; for the number of tosses until the first head it is {1, 2, 3, …}.
  • Two properties, and they are all you need. (1) p(x) ≥ 0. (2) Σ p(x) = 1, summed over the support. The events {X = x} for different x are disjoint (each outcome produces exactly one value) and together cover Ω, so the sum is P(Ω) = 1 by additivity. Conversely, any list of non-negative weights on a countable set of values that sums to 1 is the pmf of some random variable.
  • Probabilities of any set of values follow by adding: P(X ∈ A) = Σ_(x ∈ A) p(x). That is the whole computational content of the pmf.
  • Finding a normalising constant. If you know a pmf up to a constant, the constant is fixed by the sum. p(k) = c·k on k = 1, 2, 3, 4 needs c · 10 = 1, so c = 1/10. p(k) = c/k² on all positive integers needs c · Σ 1/k² = c · π²/6 = 1, so c = 6/π² ≈ 0.608, and then P(X = 1) = 0.608: more than half the mass sits on the first value even though the support is infinite.

The cumulative distribution function

  • The cumulative distribution function (cdf) is F(x) = P(X ≤ x), defined for every real x, not only values in the support. For a discrete variable it is the running total of the pmf: F(x) = Σ_(xᵢ ≤ x) p(xᵢ).
  • For the maximum of two dice, F(a) = (number of pairs with both faces ≤ a)/36 = ⌊a⌋²/36 for 0 ≤ a ≤ 6: both faces must be at most a, which happens in ⌊a⌋ · ⌊a⌋ pairs. So F(3) = 9/36, F(3.7) = 9/36 as well, and F(4) = 16/36.
  • Three properties characterise a cdf.
    1. Non-decreasing: if a ≤ b then {X ≤ a} ⊂ {X ≤ b}, so F(a) ≤ F(b) by monotonicity of probability.
    2. Limits 0 and 1: F(x) → 0 as x → −∞ and F(x) → 1 as x → +∞.
    3. Right-continuous: F(x + h) → F(x) as h ↓ 0. The events {X ≤ x + 1/n} shrink to {X ≤ x}, and countable additivity makes probability continuous along shrinking sequences (the axioms).
    Any function with these three properties is the cdf of some random variable, and two random variables with the same cdf have the same distribution: every probability statement about one is true of the other.
  • The discrete picture. F is a staircase: flat between support points, jumping up by p(xᵢ) at each xᵢ. At a jump the function takes the upper value (that is right-continuity), which is drawn as a filled dot on the top step and an open dot on the bottom one.

Reading one from the other

  • pmf → cdf: add up. cdf → pmf: read off the jumps. The jump at x is F(x) − F(x⁻) = P(X = x); where F is flat, p is zero.
  • Worked. Suppose F(a) = 0 for a < 0, 1/3 for 0 ≤ a < ½, ½ for ½ ≤ a < ¾, and 1 for a ≥ ¾. The jumps are at 0, ½ and ¾, of sizes ⅓, ⅙ and ½. So p(0) = 1/3, p(½) = 1/6, p(¾) = 1/2, and these sum to 1 ✓. The support does not have to be integers.
  • Two fair coins, X = number of heads. F(x) = 0, ¼, ¾, 1 on x < 0, [0, 1), [1, 2), [2, ∞). In particular F(1.4) = ¾: "at most 1.4 heads" is "at most 1 head". Forgetting that the cdf is defined between support points is the commonest cdf mistake.

Quantiles: the cdf read backwards

  • The quantile function answers "below what value does a fraction q of the probability lie?". Because a discrete cdf jumps over most levels, it is defined as the smallest value that reaches the level: F⁻¹(q) = min{x : F(x) ≥ q}. The median is F⁻¹(½), and the quartiles are F⁻¹(¼) and F⁻¹(¾).
  • Worked. For M, F(4) = 16/36 = 0.444 < ½ and F(5) = 25/36 = 0.694 ≥ ½, so the median is 5. For Bin(10, ¼) (§05), F(1) = 0.244 and F(2) = 0.526, so the median is 2.
  • The quantile function is also how a computer draws from a distribution: feed it a uniform random number U on (0, 1) and F⁻¹(U) has cdf F. That inverse-transform method, and why it works, is in Simulation & Stochastic Processes. Every figure on this page that simulates uses it.

The distribution of a function of X

  • If Y = g(X), then {Y = y} is the event that X lands on some x with g(x) = y. So p_Y(y) = Σ_(x : g(x) = y) p_X(x): collect the mass of every x that g sends to y. If g is one-to-one, the masses just move; if not, several values pile onto one.
  • Worked. Let X take values −1, 0, 1, 2 with probabilities ¼, ⅛, ⅛, ½, and let Y = X². Then Y = 0 only from X = 0; Y = 1 from X = −1 or X = 1; Y = 4 from X = 2. So p_Y(0) = ⅛, p_Y(1) = ¼ + ⅛ = ⅜, p_Y(4) = ½.
  • Same distribution is not the same variable. Let X = ±1 with probability ½ each and Y = −X. X and Y have identical pmfs, so every probability statement about one alone is true of the other, yet P(X = Y) = 0: they never agree. Two classifiers can have exactly the same distribution of scores and disagree on every example. A distribution describes a variable's behaviour, not its identity.

03 Expected value and variance, operationally

A pmf can have dozens or infinitely many entries. Two numbers summarise it well enough to compare families and plan experiments: the expected value, where the distribution balances, and the variance, how far from that point the mass typically sits. This section defines both and shows how to compute them, which is all the families below need. The full theory (expectations of functions, why linearity always holds, moment generating functions and the inequalities that turn a variance into a probability bound) is the subject of Expectation, Variance & Inequalities.

Expected value: the balance point

  • The expected value (expectation, mean) of a discrete random variable is the probability-weighted average of its values: E X = Σ x · p(x). It is often written μ or μ_X.
  • Physical reading. Put a mass p(x) at each point x on a weightless rod. E X is the point where the rod balances, its centre of mass. A long tail on one side pulls the balance point toward it.
  • Frequency reading. Repeat the experiment many times independently and average the observed values. The average settles toward E X, because the value x turns up in a fraction close to p(x) of the runs. That is the law of large numbers, made precise in Limit Theorems & Convergence.
  • The expected value need not be a possible value. A fair die has E X = (1 + 2 + … + 6)/6 = 3.5. Nobody ever rolls 3.5; it is the long-run average per roll.
  • Expectation of an indicator is a probability. E 1_A = 1 · P(A) + 0 · (1 − P(A)) = P(A). This tiny identity is what makes indicator decompositions (§01) so powerful: averages of counts become sums of probabilities.
  • Worked. The maximum of two dice: E M = Σ k (2k − 1)/36 = (1 + 6 + 15 + 28 + 45 + 66)/36 = 161/36 ≈ 4.47, above the middle value 3.5 because large values are more likely. The sum of two dice: E S = 7, by symmetry of the pmf about 7.

When the expected value does not exist

  • For an infinite support the sum Σ x p(x) may diverge. The expectation is defined only when Σ |x| p(x) < ∞; otherwise we say X has no (finite) mean. A random variable can be finite with probability 1 and still have an infinite expectation.
  • Worked: the doubling strategy. Stake 100 units on a game you win with probability p (winning pays the stake); after each loss double the stake; stop at the first win. You always finish exactly 100 ahead. The number of rounds X is geometric (§06), and the final stake is 100 · 2^(X − 1). Its expectation is Σₖ 100 · 2ᵏ⁻¹ (1 − p)ᵏ⁻¹ p = 100p Σₖ (2(1 − p))ᵏ⁻¹, a geometric series with ratio 2(1 − p). For p > ½ the ratio is below 1 and the sum is 100p/(2p − 1) (300 at p = 0.6). For a fair game, p = ½, every term equals 50 and the sum is infinite. You win 100 with certainty, but only by having, on average, an infinitely deep pocket. Table limits exist to stop exactly this.
  • Heavy-tailed counts in real data (followers per account, downloads per package, words by frequency rank) can behave like this: the sample mean keeps drifting upward as more data arrive instead of settling. When that happens, the median is the reliable summary.

Variance and standard deviation: the typical distance from the mean

  • The variance is the expected squared distance from the mean: Var X = E(X − μ)² = Σ (x − μ)² p(x). Squaring makes every deviation count positively and penalises large deviations most.
  • The standard deviation σ = √Var X is in the same units as X, so it is the number to quote: "the mean is 4.47 and values are typically about 1.4 away".
  • The shortcut. Expanding the square, Σ (x − μ)² p(x) = Σ x² p(x) − 2μ Σ x p(x) + μ² Σ p(x) = E X² − 2μ² + μ² = E X² − μ². So Var X = E X² − (E X)²: the mean of the squares minus the square of the mean. It is usually the faster route by hand. (In floating point, with values far from zero, the first form is the more accurate one.)
  • Scaling and shifting. Adding a constant moves the distribution without changing its spread, and multiplying by a multiplies every deviation by a. So E(aX + b) = a E X + b and Var(aX + b) = a² Var X, σ_(aX+b) = |a| σ_X. Changing units from metres to centimetres multiplies the variance by 10,000.
  • Variance of an indicator. 1_A² = 1_A, so E 1_A² = P(A) and Var 1_A = P(A) − P(A)² = P(A)(1 − P(A)). It is largest, ¼, when P(A) = ½: a coin flip is the most uncertain yes/no question.

What linearity buys, stated now and proved later

  • Expectation is additive, always. For any random variables on the same sample space, E(X + Y) = E X + E Y, with no independence assumption. This is the step that turns indicator decompositions into one-line means (§01, §05, §08).
  • Variance is additive only without correlation. Var(X + Y) = Var X + Var Y holds when X and Y are independent (more generally, uncorrelated). The correction term in general is twice the covariance, introduced in Joint Distributions & Dependence. Every variance formula on this page that adds variances is quietly using independence; the hypergeometric (§08) and multinomial (§11) are the cases where it fails and the answer is different.
  • The mean is not the typical value. For a skewed distribution the mean, median and mode can be far apart. The waiting time for a 1-in-100 event (§06) has mean 100, median 69 and mode 1. Quote the summary that answers the question being asked.
Why two numbers. The mean says where to centre a prediction; the variance says how wrong a prediction centred there will typically be. For each family below the page gives both in closed form. Together they are enough to tell families apart (§12), to size an experiment, and, through the inequalities and limit theorems that come later, to put a probability on "far from the mean".
