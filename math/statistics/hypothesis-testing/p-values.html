02 The two hypotheses: choosing them, and where the burden of proof sits

A test needs two statements about the parameter that between them cover every possibility. Which one you call the null is not a technical detail — it decides which mistake the machinery protects you against, and therefore what the result means. Get this backwards and every number afterwards is answering a question you did not ask.

The formal setup

partition the parameter space into two disjoint piecesΘ = Θ₀ ∪ Θ₁, Θ₀ ∩ Θ₁ = ∅ H₀: θ ∈ Θ₀ versus H₁: θ ∈ Θ₁ simple vs composite — a hypothesis that pins the distribution down completely is SIMPLEsimple: H₀: θ = θ₀ one distribution, so P(anything | H₀) is a number composite: H₀: θ ≤ θ₀ a family, so error rates are taken as a supremum over it the test itself is a REJECTION REGION: a set of data outcomesR ⊂ 𝒳, reject H₀ ⟺ observed data ∈ R, usually R = { x : T(x) > c }

Almost every test in practice has Θ₀ a single point (or a half-line whose boundary point is the worst case), and almost every rejection region is "the test statistic is too big". The generality above matters for one thing: it is what makes the error-rate definitions in §07 unambiguous when H₀ is not a single distribution.

Four rules for choosing the null

rule 1
The null is the boring explanation
No effect, no difference, no association, the coin is fair, the drug does nothing, the new model is no better. "Nothing extraordinary is going on."
rule 2
The null is the one you can compute with
"p = ½" gives a distribution; "p ≠ ½" does not. The null must be specific enough to generate a reference distribution — that is why it gets the equals sign.
rule 3
The null is the status quo you would keep
The default action if the evidence is inconclusive. Rejecting it is what triggers a change: ship the model, approve the drug, publish the claim.
rule 4
The alternative is what you hope to establish
The burden of proof is on it. Which means: if being wrong in favour of a claim is the expensive mistake, that claim belongs in H₁.
The asymmetry is a choice about which error you fear. A regulator testing a new drug puts "the drug is unsafe" nowhere near the null — the null is "no benefit", because falsely approving an ineffective drug is the error the system is built to prevent. Reverse the roles and you get a different, equally coherent procedure with a different guarantee. Nothing in the mathematics tells you which to pick; the cost of the two mistakes does.

One-sided or two-sided

two-sided (the default, and the honest default)H₀: θ = θ₀ H₁: θ ≠ θ₀ reject for large |T| p = P( |T| ≥ |t| | H₀ ) for a symmetric null distribution, = 2·P(T ≥ |t|) one-sidedH₀: θ ≤ θ₀ H₁: θ > θ₀ reject for large T only p = P( T ≥ t | θ = θ₀ ) the boundary point is the worst case, so the sup is attained there the exchange rate, for a symmetric null distributionp₍two-sided₎ = 2 × p₍one-sided₎ whenever t falls on the side H₁ points to the one-sided critical value is SMALLER: z₀.₀₅ = 1.64485 vs z₀.₀₂₅ = 1.95996
  • A one-sided test is more powerful against the alternative it names, and blind to the other direction. That is the trade, and it is a real one: at α = 0.05 the one-sided test needs only 1.645 standard errors instead of 1.960, which is roughly the power of an extra 12% of sample. But if the effect goes the other way — the new model is worse — a one-sided test cannot detect it at any sample size. It will simply return a large p-value forever.
  • Use one-sided only when the other direction would trigger the same action as no effect. The genuine case: you will keep the incumbent unless the challenger beats it, and "the challenger is worse" and "the challenger is the same" lead to the identical decision. Then the other tail carries no information you would act on.
  • Report which you used. A p-value with no side attached is ambiguous by a factor of two, which is exactly the factor that separates 0.03 from 0.06.

The dishonesty of picking the side afterwards

Suppose you run a two-sided test, get p = 0.08, notice the effect is positive, and rewrite the alternative as H₁: θ > θ₀ so that the p-value halves to 0.04. This is not a re-analysis; it is a different procedure, and its actual type I error is not 5%.

the procedure you actually ran, stated honestly"reject if the one-sided p-value in WHICHEVER direction the data went is below 0.05" its true type I error, for a symmetric continuous null distributionP(reject | H₀) = P(T > z₀.₀₅) + P(T < −z₀.₀₅) = 0.05 + 0.05 = 0.10 so the label is wrong by a factor of twoadvertised α = 0.05 actual α = 0.10

The two-sided test is the correct accounting for "I did not know which way it would go". Choosing the side after seeing the direction is the smallest possible instance of the p-hacking family in §13 — one binary decision made after looking — and it already doubles the error rate. Larger versions of the same move do far worse.

The test to apply to yourself. Before the data arrive, write down the alternative and the level. If you cannot state which direction you would have called significant before you saw the sign of the effect, you do not have a one-sided test — you have a two-sided test with a mislabelled p-value.

03 The test statistic, its null distribution, and the region that rejects

Everything computable in a test comes from one object: a number summarising the data, whose distribution you know exactly on the assumption that the null is true. Call it the test statistic; call that distribution the null distribution. Where the observed value falls in it is the entire evidence, and the two ways of reading that position — a fixed cut-off, or a tail area — are the critical value and the p-value.

The recipe, and the one form almost every statistic takes

a test statistic measures the distance from what H₀ predicts, in units of the noiseT = (observed − expected under H₀) / SE the two standard instancesz = (estimate − θ₀) / SE SE known or from a large sample → z ~ Normal(0,1) under H₀ t = (estimate − θ₀) / SÊ SE estimated from the data → t ~ t(ν) under H₀ why the division matters — it makes the statistic UNIT-FREE and its null distribution UNIVERSALa 3-gram difference and a 3-metre difference are the same evidence if both are 2 SE. this is the same object as part 4's pivot, with θ replaced by a specific θ₀pivot (x̄ − μ)/(s/√n) — μ unknown, used to build an interval statistic (x̄ − μ₀)/(s/√n) — μ₀ named by H₀, used to build a test

The last two lines are the whole of §09 in miniature. A pivot with the parameter left free rearranges into an interval; the same pivot with the parameter pinned to a hypothesised value becomes a test statistic. The interval and the test are two readings of one calculation, and part 4's §06 pivot construction is where the calculation was set up.

The five steps, once, in full

  1. State H₀ and H₁, and fix α. Before the data. All three.
  2. Choose T, and derive its distribution under H₀. This is the only step that needs mathematics; §11 says where the choice comes from.
  3. Fix the rejection region R = {T ≥ c} (or |T| ≥ c) by solving P(T ∈ R | H₀) = α for the critical value c.
  4. Compute t from the data.
  5. Report. Either "t ∈ R, reject at level α", or the p-value, or — best — the estimate with a confidence interval and the p-value beside it.

  • α is a property of the rule, chosen by you, and it is the only error rate the framework actually controls. It is not estimated from the data and it is not a conclusion. Its whole content is: if I run this rule on a stream of studies whose nulls are true, I will falsely reject about 100α% of the time.
  • 0.05 is a convention with no mathematical standing. It became standard because a single printed table had to stop somewhere. Genome-wide association studies use 5×10⁻⁸; particle physics uses roughly five standard deviations, about 3×10⁻⁷; some fields have moved to 0.005 (§13).   • When the null distribution is discrete, the size equation usually has no exact solution. Ten tosses of a fair coin: the two-sided region {0,1,9,10} has probability 0.02148 and the next one out, {0,1,2,8,9,10}, has 0.10938. Neither is 0.05, so the level-0.05 test is the conservative one at 0.0215. Discreteness costs you power, and there is no way around it short of randomising the decision, which nobody does.

A first test, computed to the end

A coin is tossed ten times and comes up tails seven times. Is it biased? The count of tails is a sum of ten 0/1 labels, so under H₀: P(tails) = ½ its mean is 5 and its standard deviation is √(10 × ½ × ½) = 1.58114.

the normal approximationz = (7 − 5)/1.58114 = 1.26491 two-sided p = 2(1 − Φ(1.26491)) = 0.2059 the EXACT answer, from the binomial itselfP(X ≥ 7) = (120 + 45 + 10 + 1)/1024 = 176/1024 = 0.171875 two-sided (by symmetry) = 2 × 0.171875 = 0.34375 the approximation was off by 40% — because n = 10 and the count is an INTEGERwith a continuity correction, z = (6.5 − 5)/1.58114 = 0.94868 two-sided p = 2(1 − Φ(0.94868)) = 0.34278 vs exact 0.34375 ✓

Either way the conclusion is the same — seven tails in ten is entirely unremarkable — but the discrepancy is worth keeping. The normal approximation to a discrete count is a continuous curve being asked about a step function, and at small n it systematically understates the tail unless you shift the boundary by half a unit. Part 3, §10 derives the approximation and its error; the rule of thumb there — np₀ ≥ 10 and n(1−p₀) ≥ 10 — is exactly the condition under which you may skip the correction. Here np₀ = 5, so you may not.

The general lesson, which will recur. The test statistic's null distribution is a model, and the p-value inherits every error in that model. A z statistic whose reference curve is wrong by 40% produces a p-value that is wrong by 40%, and nothing downstream can detect it. §10 lists, for each named test, the assumption whose failure does this.

04 The p-value, defined three ways and computed once

Three definitions, all standard, all equivalent, and each illuminating something the others hide. Learn all three: the tail-area one is how you compute it, the smallest-α one is what it means, and the uniform-distribution one is why the whole scheme controls the error rate at all.

Definition 1 — the tail area under the null

for a simple null and a statistic where large values argue against H₀p = P₍H₀₎( T ≥ t_obs ) t_obs = the value computed from YOUR data for a composite null, take the worst case over itp = sup₍θ ∈ Θ₀₎ Pθ( T ≥ t_obs ) two-sided, symmetric null distributionp = P₍H₀₎( |T| ≥ |t_obs| ) = 2·P₍H₀₎( T ≥ |t_obs| ) in words, and every clause is load-bearing"the probability, IF the null were true, of a result AT LEAST AS EXTREME as the one observed."
  • "If the null were true" — the probability is computed inside a hypothetical world. It is a conditional probability with the null in the condition, which is precisely why it is not a probability about the null (§05).
  • "At least as extreme" — not "equal to". For a continuous statistic, P(T = t) = 0 for every t, so the point probability is useless and a tail is the only thing available. This also means the p-value depends on results you did not get, which is a genuine philosophical oddity and the main Bayesian objection to the whole apparatus.
  • "Extreme" means "in the direction the alternative points", and that direction is set by H₁, not by the data. This is the formal statement of §02's warning.

Definition 2 — the smallest level at which you would have rejected

suppose you have a size-α test for every α, with rejection region Rαp = inf { α : t_obs ∈ Rα } because the regions are nested — a bigger α means a bigger regionα < α′ ⟹ Rα ⊂ Rα′ so there is a single crossing point, and p is it the decision rule, restated — this is the only thing a p-value is USED forreject at level α ⟺ p ≤ α

This is the definition to carry around. It says the p-value is a summary of the whole family of tests at once: instead of reporting a verdict at your level, you report the level at which the verdict would flip, and every reader can apply their own threshold. That is also the honest answer to "why report the p-value rather than reject/retain" — the older name for it, observed significance level, says exactly this.

Definition 3 — the transformation that makes the null distribution uniform

if T is continuous, then under H₀ the p-value is a Uniform(0,1) random variableP = 1 − F₀(T) with F₀ the null cdf of T ⟹ P ~ Uniform(0, 1) under H₀ the proof is one line — the probability integral transformP(P ≤ u) = P(1 − F₀(T) ≤ u) = P(F₀(T) ≥ 1 − u) = P(T ≥ F₀⁻¹(1−u)) = u and THIS is why the level is honouredP(reject | H₀) = P(P ≤ α) = α exactly, for every α under an alternative, the same P is squashed towards zeroP(P ≤ α | H₁) = power ≥ α, and → 1 as the effect or n grows
Read the uniformity result twice, because it explains almost everything downstream. If the null is true, p = 0.03 is exactly as likely as p = 0.53 — one time in a hundred you will see p < 0.01 from pure noise, by construction. It is also why a p-value carries no information about effect size: the transform destroyed the scale. And it is why running k tests under true nulls produces small p-values at a predictable rate — 1 − (1−α)ᵏ — which is the arithmetic behind §13 and part 9.

A worked p-value, with the exact answer beside the approximate one

Ten cups are filled at random with one of two colas; a taster names seven correctly. Can they tell them apart? The claim is directional — a taster who is guessing scores 5, one who can tell scores more — so H₀: p = ½ against H₁: p > ½, one-sided.

the normal approximation, as usually taughtz = (7 − 5)/1.58114 = 1.26491 p = 1 − Φ(1.26491) = 0.1029 the exact binomial p-valuep = P(X ≥ 7 | X ~ Binomial(10, ½)) = 176/1024 = 0.17188 with the continuity correctionz = (6.5 − 5)/1.58114 = 0.94868 p = 1 − Φ(0.94868) = 0.17139 ✓ the verdict is the same at any conventional level0.172 > 0.05 → do not reject. Seven out of ten is not evidence of a discriminating palate.

Note the size of the error in the uncorrected version: 0.103 against a true 0.172, an understatement by 40%. Had the taster scored eight, the exact one-sided p would be 56/1024 = 0.0547 and the uncorrected normal approximation would give 0.0289 — on opposite sides of 0.05. A test whose conclusion depends on which approximation you used is a test you should be computing exactly. With n = 10 you can, and should.

What to report

ReportSaysVerdict

"p < 0.05"a bound, usually because a table only had a few rowsAn artefact of pre-computer typography. Software gives the number; print the number.
"p = 0.031"the observed significance levelBetter. Still says nothing about how big the effect is.
"effect 2.4 (95% CI 0.2 to 4.6), p = 0.031"estimate, precision, and compatibility with the nullThis. The interval carries the effect size; the p-value adds the one number the interval does not display directly.

Two conventions worth adopting. Never write p = 0.000 — write p < 0.001, because the computed value is a tail area of a model you do not believe out to six decimal places. And never call a result "marginally significant", "approaching significance", or "trending towards significance": these are all descriptions of a p-value that failed to clear the bar you set, dressed up as a partial success. If the threshold was worth setting, it was worth respecting; if it was not, do not set one and report the interval instead.

05 Seven things a p-value is not, each with the arithmetic

This is the section the page exists for. Every misreading below appears in published work, in textbooks, and in the sentence most readers would have written before opening this page. Each one is answered here not with an assertion but with a calculation whose answer differs from the misreading's, usually by a large factor. The single most useful instrument is the base-rate calculation of §06 — but the others are worth having separately, because they fail for different reasons.

the one true statement, to hold beside all sevenp = P( data at least this extreme | H₀ true ) the conditional runs THIS way. Reversing it is the source of five of the seven errorsP(data | H₀) ≠ P(H₀ | data)
✗ 1. "p = 0.03, so there is a 3% probability that the null hypothesis is true."
This reverses the conditional. P(D | H₀) and P(H₀ | D) are related by Bayes' rule, and the relation involves a term the p-value does not contain: the prior probability that H₀ is true.
what the p-value isp = P(D | H₀) what the misreading claims it isP(H₀ | D) = P(D | H₀)·P(H₀) / [ P(D | H₀)·P(H₀) + P(D | H₁)·P(H₁) ] the two are equal only if the bracketed correction happens to be 1 — it never isP(H₀ | D) = p ⟺ P(H₀)·(1 − p) = P(D | H₁)·P(H₁) an accident, not an identity
The concrete failure. Screen 1 000 candidate genes of which 100 really matter. At α = 0.05 and 80% power you get 80 true and 45 false rejections. Take any one of those 125 "significant" genes: the probability its null is true is 45/125 = 36%, not 5% and not 3%. Change the prior to 1 in 100 and the same p-value carries a 86% chance that the null is true. The p-value did not move; the answer changed by a factor of 24. ✓ Say instead: "if there were no effect, data this extreme would arise 3% of the time."
✗ 2. "p = 0.03, so there is only a 3% chance the result is due to chance."
The same error in folk dress, and the more dangerous one because it sounds like plain English rather than statistics. "Due to chance" means "the null is true", so this is misreading 1 with the conditional hidden inside an idiom. Note also that the p-value was computed assuming chance is the whole story: it is a number produced inside the very hypothesis it is being used to assign a probability to. ✓ Say instead: "chance alone produces a result this extreme 3% of the time."
✗ 3. "p = 0.03, so there is a 97% probability the alternative is true" — or "the effect will replicate 97% of the time."
Two separate errors stacked. The first is 1 − p read as a posterior, which fails for the reason above. The second is a claim about replication, and it is checkable.
take the observed effect AS IF it were the truth, and rerun at the same nreplication power = Φ(|z| − z₍1−α/2₎) + Φ(−|z| − z₍1−α/2₎) at p = 0.05 exactly, so |z| = 1.95996= Φ(0) + Φ(−3.91993) = 0.5000 + 0.00004 = 0.5000 the general picture — and these are the OPTIMISTIC figures, since they assume the estimate is exactoriginal p = 0.05 → replication succeeds 50.0% of the time original p = 0.01 → 73.1% original p = 0.001 → 90.8%
A result that just clears 0.05 is, on the most generous possible assumption, a coin flip to replicate. And the assumption is not generous in practice, because the original estimate was selected for being large (§13, the winner's curse), so the true replication rate is lower still. ✓ Say instead: nothing about replication — the p-value contains no information about it.
✗ 4. "p = 0.001 means the effect is much bigger than one with p = 0.04."
The p-value confounds effect size with sample size and precision, and by construction it cannot be decomposed back into them. Two studies with identical p-values can have effect sizes differing by any factor you like; two studies with identical effect sizes can have p-values differing by any factor you like.
the identity that makes the confusion inevitablez = effect / SE = (effect/σ) × √n so p depends on n as much as on the effect two studies of the same drug, both with σ = 10 mmHg — same p-value, effect sizes 100× apartstudy A: effect 2.00 mmHg, n = 100 SE = 1.00 → z = 2.00, p = 0.0455 study B: effect 0.02 mmHg, n = 1 000 000 SE = 0.01 → z = 2.00, p = 0.0455 and the reverse — one fixed effect of 0.20 mmHg, p-values 10 000× apartn = 400 SE = 0.500 → z = 0.400, p = 0.689 n = 10 000 SE = 0.100 → z = 2.000, p = 0.0455 n = 40 000 SE = 0.050 → z = 4.000, p = 0.0000633
Study A found a 2 mmHg drop, which is worth a prescription; study B found 0.02 mmHg, which is invisible to any patient and to any instrument. Their p-values are the same to three decimals. ✓ Say instead: report the effect and its interval, and let the p-value do only the job it can do.
✗ 5. "Study A got p = 0.02 and study B got p = 0.20, so study A found a much stronger effect."
Not comparable across studies with different n, for exactly the reason above. Worse, this comparison is routinely used to declare that two studies disagree, and that inference is invalid even when the two estimates are nearly identical. The difference between "significant" and "not significant" is not itself significant.
two studies, both estimating the same effect, both with SE = 10study A: estimate 25, SE 10 → z = 2.50, p = 0.0124 "significant" study B: estimate 10, SE 10 → z = 1.00, p = 0.3173 "not significant" now test whether the two studies actually differdifference = 25 − 10 = 15 SE of difference = √(10² + 10²) = 14.142 z = 15/14.142 = 1.0607 p = 0.2888 NOT significant
The two studies are entirely compatible with each other. The headline "A replicated, B failed to replicate" describes an artefact of two arbitrary threshold crossings. ✓ Say instead: test the difference directly, or better, pool them.
✗ 6. "p = 0.35, so we can conclude there is no effect" — or "the two groups are equivalent".
§01's asymmetry, in the form it most often appears. A large p-value is consistent with a true null and equally consistent with a real effect that this study could not see. The distinguishing evidence is the width of the confidence interval, which the p-value discards.
two studies, both with p ≈ 0.35, telling completely different storiesstudy C: effect 0.400, SE 0.4300 95% CI (−0.443, 1.243) z = 0.930, p = 0.352 study D: effect 0.0040, SE 0.0043 95% CI (−0.00443, 0.01243) z = 0.930, p = 0.352 the same p-value; utterly different conclusionsC: "we learned essentially nothing; effects up to 1.24 remain perfectly live." D: "any effect is below 0.013, which for this application is zero."
Only study D supports the "no effect" claim, and it supports it because of its interval, not its p-value. ✓ Say instead: "we found no evidence of an effect; the data are compatible with anything from −0.44 to 1.24, so this study cannot settle the question." Or run a formal equivalence test (§01).
✗ 7. "p = 0.049 is a discovery and p = 0.051 is not."
The null distribution is continuous and the evidence changes continuously with it. Nothing whatsoever happens at 0.05; the threshold is a decision boundary you imposed, and it is doing all the work in that sentence.
the underlying statistics, on the natural scalep = 0.049 ⟺ |z| = 1.96862 p = 0.051 ⟺ |z| = 1.95149 a difference of 0.0171 standard errors. For a mean with σ = 1 and n = 100, so SE = 0.1the two data sets differ by 0.00171 in x̄ — under a fifth of one percent of a single SD. yet one gets published and the other goes in a drawerthis discontinuity in CONSEQUENCE, applied to a continuum of EVIDENCE, is what §13 is about.
✓ Say instead: report the number and the interval, and if you must dichotomise, do it because a decision genuinely has to be made — not because a journal expects it.

The professional consensus, compressed

In 2016 the American Statistical Association issued a formal statement on p-values — an unusual step for a professional body — because the misreadings above had become endemic. Its six principles are worth reproducing because they are, in effect, the summary of this section:

  1. p-values can indicate how incompatible the data are with a specified statistical model.
  2. p-values do not measure the probability that the studied hypothesis is true, or the probability that the data were produced by random chance alone.
  3. Scientific conclusions and business or policy decisions should not be based only on whether a p-value passes a specific threshold.
  4. Proper inference requires full reporting and transparency.
  5. A p-value, or statistical significance, does not measure the size of an effect or the importance of a result.
  6. By itself, a p-value does not provide a good measure of evidence regarding a model or hypothesis.
Principle 1 is quietly the sharpest. Note what it says the p-value is incompatible with: not "the null hypothesis" but "a specified statistical model". The model includes the null and independence, and the sampling scheme, and the absence of measurement bias, and the fact that you did not look at the data first. A small p-value indicts the whole package. Very often the weakest member of that package is not the null hypothesis at all.

06 The base-rate calculation: why most "significant" results can be false

Of everything in §05, this is the argument that changes how people read a p-value permanently, because it is arithmetic rather than admonition. A test's advertised error rate is P(significant | null true). What a reader wants is P(null true | significant). The two differ by the base rate of real effects in whatever population of hypotheses you are drawing from — and in most research settings that base rate is low enough to flip the answer.

The four-cell arithmetic

m hypotheses, a fraction π of them genuinely non-null, test at level α with power 1 − βtruly non-null: mπ of which mπ(1−β) are rejected → TRUE positives truly null: m(1−π) of which m(1−π)α are rejected → FALSE positives the quantity a reader actually cares about — positive predictive valuePPV = P(H₁ true | rejected) = π(1−β) ────────────────────── π(1−β) + (1−π)α and its complement, the false discovery proportion among the rejectionsFDR = 1 − PPV = (1−π)α / [ π(1−β) + (1−π)α ] note what PPV does NOT depend onm cancels. And α alone tells you nothing — the ratio (1−π)/π is half the answer.

An underpowered study is not merely a study that might miss something — it is a study whose positive findings are less trustworthy, because it produces fewer true positives against the same fixed number of false ones. This is the least intuitive consequence in the table and the most important.
  • The last row is the whole argument for a stricter threshold (§13). Dropping α from 0.05 to 0.005 takes PPV from 0.64 to 0.95 without touching power, and costs about 70% more sample to hold power constant: (z₀.₀₀₂₅ + z₀.₂₀)²/(z₀.₀₂₅ + z₀.₂₀)² = (3.6487/2.8016)² = 1.696.
  • π is not observable, which is the honest limitation of this argument. You cannot look up the fraction of your field's hypotheses that are true. But you can usually bound it by asking how surprising the finding would be — and the calculation is monotone, so a range for π gives a range for PPV. "If fewer than one in ten of these candidate genes is real, then over a third of my hits are noise" is a defensible sentence.

Three corollaries worth stating separately

corollary 1
The more you search, the worse your hits
Testing a million genomic markers with a handful of real ones is π ≈ 10⁻⁵. At α = 0.05 essentially every "discovery" is noise. This is why such fields use thresholds near 5×10⁻⁸ — that number is 0.05 divided by a million tests, which is Bonferroni (part 9).
corollary 2
Novelty is expensive
A surprising claim is by definition one with a low prior. The same p-value that would confirm a boring hypothesis barely dents a surprising one. "Extraordinary claims require extraordinary evidence" is this formula, and the required evidence scales like (1−π)/π.
corollary 3
Publication bias multiplies all of it
If only significant results are published, the literature is the "discoveries" column and nothing else. Every number in the table above then describes what a reader sees. Check the box in the visualization above to watch the other 875 hypotheses disappear.
The transfer to machine learning is exact. Substitute "hypothesis" for "candidate feature", "candidate architecture", "candidate hyperparameter setting", or "candidate prompt", and the arithmetic is unchanged. Evaluating 200 configurations on one validation set and keeping the best is a π-times-200 problem, and the winner's held-out advantage is the sum of a real effect and a selection artefact. That is precisely the reason a separate, untouched test set exists — see model evaluation, §validation — and §14 makes the correspondence explicit.
