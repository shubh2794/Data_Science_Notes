GPT

Generative Pre-trained Transformer — the decoder-only, autoregressive lineage that turned "predict the next token" into general-purpose AI. Where BERT reads bidirectionally to understand, GPT generates left-to-right to produce.

LLMs & Generative AI Decoder-only Generative

01 What GPT is

  • A decoder-only Transformer trained by generative pretraining — predict the next token on a huge unlabeled corpus.
  • It flipped the old recipe: instead of training on labeled task data, pretrain unsupervised at scale, then adapt with little or no fine-tuning (just prompts).
  • The lineage (GPT-1 → 4) is mostly the same idea scaled up, with new capabilities emerging along the way.
One sentence: GPT is a causal Transformer decoder that predicts the next token — scaled until prompting alone solves tasks.

02 Autoregressive generation

GPT generates one token at a time, each conditioned on everything before it. Step through it — note each token only sees the left.

Next-token generation (causal) Each generated token attends only to earlier tokens — the opposite of BERT
P(x₁…x_n) = Πᵢ P(xᵢ | x₁ … xᵢ₋₁) · causal mask: position i attends to ≤ i

04 The scaling breakthrough: in-context learning

  • At GPT-3 scale, the model learns a task from examples in the prompt — zero-shot (just a description) or few-shot (a handful of demonstrations) — with no weight updates.
  • This emergent ability is what made one model a general-purpose tool, eliminating per-task fine-tuning.
  • See Large Language Models and Context Engineering.

05 Decoder-only architecture

  • A stack of Transformer decoder blocks with causal self-attention (each token attends only leftward) + feed-forward layers — see Transformers.
  • No encoder, no cross-attention: the same stack both "reads" the prompt and writes the continuation.
  • Tokens are processed in parallel during training; generation is sequential (one token feeds the next).

06 From GPT-3 to ChatGPT

  • A raw pretrained GPT continues text but isn't a helpful assistant. InstructGPT/ChatGPT add post-training:
  • SFT on instruction→response demonstrations, then RLHF to align with human preferences — see Policy / Preference Optimization.
  • That alignment step is what turned a next-token predictor into a usable chat assistant.

08 Takeaways

  • GPT = decoder-only autoregressive Transformer — predict the next token, causally.
  • Scaling the same idea (GPT-1→4) produced emergent in-context learning, removing per-task fine-tuning.
  • Causal vs bidirectional is the core split from BERT: generate vs understand.
  • SFT + RLHF turn a base GPT into an aligned assistant.
  • The archetype behind every modern LLM.
