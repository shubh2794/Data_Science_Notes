Textual Entailment

Also called Natural Language Inference: given a premise, does a hypothesis follow from it, contradict it, or neither? A simple three-way decision that turns out to be a versatile building block — for zero-shot classification, fact-checking, and grounding.

NLP Inference Reasoning

01 The task

premise + hypothesis → { entailment, contradiction, neutral }
  • Entailment: the hypothesis must be true if the premise is.
  • Contradiction: the hypothesis can't be true if the premise is.
  • Neutral: the hypothesis might be true — the premise doesn't decide.

02 Three-way classification

Same premise, three hypotheses, three labels. Pick one to see the model's prediction.

Premise vs hypothesis → label A classifier outputs a probability over the three relations

03 Datasets

  • SNLI / MultiNLI: large human-labeled premise-hypothesis pairs across genres — the standard benchmarks.
  • Known to contain annotation artifacts (hypothesis-only cues), so models can cheat — a caution for evaluation.

04 Models

  • Cross-encoders (BERT-style) read premise and hypothesis together and classify — the accurate default.
  • Bi-encoders embed each separately for fast, scalable comparison.
  • LLMs do NLI zero-shot via prompting.

A cross-encoder concatenates premise and hypothesis, reads them jointly, and feeds the pooled [CLS] representation through a small linear head. A softmax turns the three logits into a probability over the labels; training minimizes cross-entropy against the gold one-hot label.

head P( label | premise, hypothesis ) = softmax( W · h[CLS] + b ) softmax softmax(z)k = ezk / ∑j ezj loss L = − ∑k yk · ln( pk ) (y = one-hot gold label)

05 Why NLI is everywhere

  • Zero-shot classification: phrase each candidate label as a hypothesis ("This text is about {sports}") and pick the most-entailed — classify with no task-specific training.
  • Faithfulness / fact-checking: does a generated answer follow from the evidence? See Hallucination & Factuality.
  • RAG verification: check whether a claim is entailed by retrieved context.

The trick: treat the input as the premise and each candidate class as a templated hypothesis. Score the entailment probability for every label and pick the argmax — a multi-class classifier built entirely out of an entailment model.

zero-shot label* = argmaxlabel P( entailment | text, "This text is about {label}" )

06 Takeaways

  • NLI = a 3-way decision — entailment, contradiction, neutral — between a premise and hypothesis.
  • Cross-encoders are accurate; LLMs do it zero-shot.
  • It's a reusable primitive: zero-shot classification, fact-checking, and grounding all reduce to entailment.
  • Watch for dataset artifacts.
  • Powers faithfulness checks and entailment-based evaluation.
