06 The discrete Fourier transform: a finite, exact, invertible matrix

Computers hold N numbers, not functions. Replace the integral by a sum over those N samples and the transform stops being analysis and becomes linear algebra: an N × N complex matrix, unitary up to a scale, with an exact inverse. Nothing is approximated. The DFT of a finite vector is not "the Fourier transform, discretised"; it is an exact statement about that vector.

the pair, in the convention used everywhere on this pageforward: F(k) = ∑ₙ f(n)·e^{−j2πkn/N} n, k = 0 … N−1 inverse: f(n) = (1/N)·∑ₖ F(k)·e^{+j2πkn/N} The 1/N sits on the INVERSE. Two other conventions put it on the forward sum, or split it as 1/√N on both to make the matrix exactly unitary. Nothing depends on the choice except constants; everything depends on being consistent, and a mismatched pair is the single most common bug in transform code. as a matrix — and it is worth seeing it as oneF = W·f W(k, n) = ωᴺ^{kn}, ωᴺ = e^{−j2π/N} ⎡ 1 1 1 … 1 ⎤ ⎢ 1 ω ω² … ω^{N−1} ⎥ W = ⎢ 1 ω² ω⁴ … ω^{2(N−1)}⎥ each ROW is one basis frequency ⎢ ⋮ ⋮ ⎥ each COLUMN is one sample position ⎣ 1 ω^{N−1} … ω^{(N−1)²}⎦ W* · W = N·I so W⁻¹ = W*/N, and W/√N is UNITARY.

What the bin index means, and where the negative frequencies went

Bin k corresponds to a frequency of k/N cycles per sample, or ω = 2πk/N radians per sample. But e^{−j2π(k+N)n/N} = e^{−j2πkn/N}·e^{−j2πn} = e^{−j2πkn/N} because n is an integer — so the transform is periodic in k with period N. Bin N−1 is bin −1. The honest picture of the frequency axis is therefore a circle, and the useful window on it is k ∈ [−N/2, N/2].

the bin map, which every display of a spectrum silently appliesstored order: k = 0 1 2 … N/2 … N−2 N−1 means: f = 0 +1/N +2/N … ½ … −2/N −1/N cycles per sample DC ────── positive ──────┤├── negative ────── The "fftshift" every plot applies is just rotating this array by N/2 so that DC lands in the middle and the axis reads −½ … 0 … +½. It is a DISPLAY operation and it changes no arithmetic — but doing it before a multiply, and forgetting to undo it, silently modulates the image by (−1)ⁿ. That is §09's checkerboard bug.

Dropping it, as truncating "the top half" naively does, leaves an error of exactly |F(4)|/N = 0.375 per sample on this signal, and that is precisely the RMSE measured when the reconstruction keeps DC and the three conjugate pairs: 0.3750.

07 Why this basis: convolution is diagonal in it

There is nothing sacred about sinusoids as such. They are forced on us by one requirement: we want a basis in which every shift-invariant filter is a diagonal matrix. There is exactly one such basis, and the complex exponentials are it. That claim is a theorem about circulant matrices and it is short.

a convolution under wrap-around, written as the matrix it iswith h = [1, 2, 1]/4 centred, and N = 8, the operator g = h ∗ f is g = C·f with ⎡ .50 .25 0 0 0 0 0 .25 ⎤ ⎢ .25 .50 .25 0 0 0 0 0 ⎥ ⎢ 0 .25 .50 .25 0 0 0 0 ⎥ C = ⎢ 0 0 .25 .50 .25 0 0 0 ⎥ every row is the row above, ⎢ 0 0 0 .25 .50 .25 0 0 ⎥ shifted one place right. ⎢ 0 0 0 0 .25 .50 .25 0 ⎥ That is a CIRCULANT matrix, ⎢ 0 0 0 0 0 .25 .50 .25 ⎥ and the corner .25 entries are ⎣ .25 0 0 0 0 0 .25 .50 ⎦ the wrap-around. now feed it a complex exponential v_m(n) = e^{j2πmn/N} and watch(C·v_m)(n) = ∑ₖ h(k)·v_m(n − k) = ∑ₖ h(k)·e^{j2πm(n−k)/N} = ( ∑ₖ h(k)·e^{−j2πmk/N} )·e^{j2πmn/N} = H(m) · v_m(n) ← the DEFINITION of an eigenvector So every v_m is an EIGENVECTOR of C, with eigenvalue H(m) = the DFT of the kernel. The DFT matrix is not one convenient basis among many. It is the eigenbasis of every circulant matrix at once — the same basis for every filter, which is why the change of coordinates can be done once and reused.
Verified numerically. For the circulant above, the eigenvalues computed by a general eigen-solver and the eigenvalues predicted as the DFT of the first column agree to 5.0 × 10⁻¹⁶, and the residual ‖C·v₃ − H(3)·v₃‖∞ is 3.0 × 10⁻¹⁶. The eigenvalues are [1, 0.853553, 0.5, 0.146447, 0, 0.146447, 0.5, 0.853553] — all real, because the kernel is symmetric, and the fourth is exactly 0, which is the statement that [1,2,1]/4 annihilates the Nyquist frequency. That single zero is Part 2 §12's condition H(π) = 0, appearing here as an eigenvalue.

What the linear algebra buys, stated plainly

diagonalisation
C = W⁻¹·diag(H)·W
Every circulant matrix has the same eigenvectors. So circulants commute with each other, they are closed under multiplication and (when no eigenvalue is zero) inversion, and composing two filters means multiplying two diagonals. That is why blur-then-blur is one blur, and why Part 2 §10's variances add.
inversion
Deconvolution is division
F = G/H, elementwise. And immediately the difficulty: wherever H(k) ≈ 0 the division explodes. A blur that killed a frequency cannot be undone, and dividing by the small number that remains amplifies noise without bound. §27's Wiener filter is the regularised version of exactly this quotient.
conditioning
The eigenvalues are the singular values
For a symmetric kernel the H(k) are real, so |H(k)| are the singular values of the blur operator and their ratio is its condition number. For [1,2,1]/4 at N = 8 that ratio is 1/0 = ∞: the operator is singular, it destroys one direction completely, and no algorithm recovers it. See the SVD for what a zero singular value means in general.
The connection worth making explicit. Eigendecomposition asks: given a matrix, find a basis in which it is diagonal. Usually the answer depends on the matrix. The remarkable thing here is that for the whole class of shift-invariant operators the answer does not: one fixed, known, image-independent basis diagonalises all of them simultaneously, and it can be applied in O(N log N). That combination — a universal eigenbasis with a fast transform — is why signal processing looks the way it does, and it has no analogue for general matrices.

08 The FFT: why the frequency domain is usable at all

The DFT is a dense matrix product, O(N²). At image sizes that is not slow, it is impossible — and the entire practical value of everything above rests on one recursive factorisation that makes it O(N log N). This section derives the factorisation and then puts numbers on what it saves, because the numbers are the argument.

The split, in four lines

separate the even-indexed and odd-indexed samplesF(k) = ∑ₙ f(n)·ω^{kn} ω = e^{−j2π/N} = ∑_{n even} f(n)·ω^{kn} + ∑_{n odd} f(n)·ω^{kn} = ∑_{m=0}^{N/2−1} f(2m)·ω^{2km} + ω^{k}·∑_{m=0}^{N/2−1} f(2m+1)·ω^{2km} and now the fact that makes it work: ωᴺ² = ω_{N/2}e^{−j2π·2/N} = e^{−j2π/(N/2)} the squared root of unity IS the half-size one so F(k) = E(k) + ω^{k}·O(k) for k = 0 … N/2 − 1 F(k + N/2) = E(k) − ω^{k}·O(k) because ω^{k+N/2} = −ω^{k} where E and O are DFTs of length N/2. TWO half-size transforms and N/2 multiplies buy the whole thing. The ± pair is the "butterfly", and it is the entire algorithm. the recurrence, and its solutionT(N) = 2·T(N/2) + N/2 complex multiplies T(1) = 0 T(N) = (N/2)·log₂N exactly, for N a power of two
Checked against a reference. The recursive split above, implemented literally, reproduces a library FFT on a random 256-vector to 2.0 × 10⁻¹⁴ — floating-point round-off and nothing else. This page's own JavaScript carries both the direct O(N²) sum and the recursion, and uses the direct sum whenever N is not a power of two, so that no figure quietly changes its answer with its length.

three different "cost of a 2-D DFT" numbers, for an N × N imageN⁴ the double sum evaluated literally for every output 1.1 × 10¹² at N = 1024 2N³ separably, but with a direct 1-D DFT each time 2.1 × 10⁹ N²·log₂N separably, with an FFT each time 1.0 × 10⁷ Separability alone is worth a factor of N/2. The FFT is worth a further 2N/log₂N. Quoting "the FFT is N log N" without the separability step understates the first saving and overstates the second.
When to filter in frequency, and when not to. A direct separable convolution with a K × K kernel costs 2K multiplies per pixel (Part 2 §11). Doing it by transform costs two FFTs, a multiply and an inverse — about 3·log₂N + 1 operations per pixel with real-transform savings, independent of K. At N = 1024 that is roughly 31 per pixel, so the crossover is near K ≈ 15: below it, convolve; above it, transform. But the crossover moves with implementation, cache behaviour and whether the kernel is separable at all — an unseparable K × K kernel costs K² and the crossover drops to K ≈ 6. Measure rather than assume, and remember §17's warning that the transform route computes a circular convolution unless you pad.

09 Two dimensions, and how to actually read the picture

The 2-D transform is the 1-D transform applied twice, once along each axis, and the algebra is unchanged. What is not obvious is how to look at the result: a spectrum image is one of the most frequently mis-read pictures in the subject, and four conventions have to be fixed before it means anything.

the 2-D pair, and the separability that makes it cheapF(k_x, k_y) = ∑_x ∑_y f(x, y)·e^{−j2π(k_x·x/M + k_y·y/N)} = ∑_x [ ∑_y f(x, y)·e^{−j2πk_y·y/N} ]·e^{−j2πk_x·x/M} └──── a 1-D DFT down each column ────┘ └──────── then a 1-D DFT along each row ────────┘ The exponential factors because the exponent is a SUM. That is the whole proof of separability, and it is why a 2-D FFT is 2N one-dimensional FFTs and not something new. Every property of §04 carries over with x, ω and x₀ read as vectors and the products read as inner products. what a frequency vector means, geometricallya coefficient at (k_x, k_y) is a plane-wave CORRUGATION with wavelength = N / √(k_x² + k_y²) pixels, crest to crest direction of variation = (k_x, k_y) / |k| the stripes themselves run PERPENDICULAR to that so vertical stripes in the image ⇒ energy on the HORIZONTAL axis of the spectrum.

Four conventions that must be fixed before the picture means anything

1 · origin
DC lands in the corner
The array as computed has k = 0 at index 0, so the four corners of the raw spectrum are the low frequencies and the centre is Nyquist. Every published spectrum has been rotated by half its width in each direction to put DC in the middle. That rotation is display only — but it is equivalent to multiplying the image by (−1)^{x+y}, so applying it before a filter multiply and forgetting to undo it modulates the result by a checkerboard.
2 · dynamic range
Nothing is visible on a linear scale
For the running house image, 79.41% of the energy sits in the coefficients with |k| ≤ 1 — nine of 4096. Displayed linearly, a spectrum is a black square with one white dot. Every spectrum you have seen is log(1 + |F|) or similar, and the choice of compression changes the picture's apparent content substantially.
3 · magnitude only
Half the information is not shown
The displayed image is |F|. The phase is never plotted because it looks like noise — and §11 shows that the thing that looks like noise is carrying the structure. A magnitude spectrum is genuinely informative about texture and orientation and almost silent about shape.
4 · the implicit tiling
The DFT thinks the image is periodic
A finite DFT is the transform of the image tiled infinitely. The left edge is a neighbour of the right edge, and if they differ there is a discontinuity — which is why almost every real spectrum has a bright cross along the axes. Part of that cross is the seam and part of it is genuine axis-aligned content, and §21 measures both and shows they cannot be told apart by eye.

10 Magnitude and phase, and which one is doing the work

A transform coefficient is one complex number, and it is universally split into a magnitude and a phase. The split is not symmetric in importance. The magnitude is what gets displayed, what gets described as "the spectrum", and what most people picture when they think of a Fourier transform — and it is the less informative half by a wide margin.

Measured on the running house image. Reconstructing from the phase alone, with every magnitude forced to 1, gives an image whose raw-intensity correlation with the original is only 0.269 — but every edge is in the right place, because that is what the phase encodes. Reconstructing from the magnitude alone, with every phase forced to 0, gives a correlation of −0.290: an unrecognisable blob of energy piled at the origin. Neither number is impressive; the point is that the first image is recognisable to a human and the second is not, which is exactly the discrepancy §11 makes unmistakable.

11 The phase swap

Take two images. Compute both transforms. Build a new transform from the magnitude of the first and the phase of the second, and invert it. The result looks like the second image. This is the single most persuasive demonstration in the subject and it takes four lines of code.

the constructionF_A = F{A}, F_B = F{B} S₁ = F⁻¹{ |F_A| · e^{j·arg F_B} } A's magnitude, B's phase S₂ = F⁻¹{ |F_B| · e^{j·arg F_A} } B's magnitude, A's phase measured on the running house (A) and face (B), correlations of the result with each source with A with B S₁ (|A|, arg B) −0.7065 +0.8372 ← follows the PHASE donor S₂ (|B|, arg A) +0.8372 −0.4478 ← follows the PHASE donor Both results follow the image whose PHASE they borrowed, and are ANTI-correlated with the image whose magnitude they borrowed. The magnitude contributed the energy; the phase contributed the picture. two exact identities that hold in the swap, and are worth checking1. ∑ S₁² = ∑ A² exactly. Measured difference: 2.3 × 10⁻¹³. Parseval again — the ENERGY comes entirely from the magnitude donor, since energy is a sum of |F|² and the phase does not enter it at all. The figure's own JavaScript, which uses a recursive FFT rather than a library one, reports 1.4 × 10⁻¹¹ for the same identity — both are accumulated round-off, not approximation. 2. mean(S₁) = mean(A) exactly: 0.3048828 = 0.3048828. The DC coefficient's magnitude is A's; B's phase at DC is 0 because a real non-negative image has a real positive DC. So the average brightness is inherited from the magnitude and everything else from the phase.
Why this happens, and it is not mysterious. An edge is a place where a great many frequencies happen to be aligned in phase — that alignment is what makes their sum add up to a step instead of cancelling into noise. Delete the magnitudes and the alignment survives, so the edges survive. Delete the phases and the alignment is destroyed, so nothing survives but a pile of energy at the origin. Structure in an image is a phase coherence phenomenon; the magnitude only says how loud each contributor is. This is also the principle behind phase congruency as a contrast-invariant edge measure, and behind why phase correlation aligns images robustly.
Said: "the Fourier transform of an image" and shown a magnitude spectrum, as if that were the transform.
Actually: that is half the transform, and the half that a human eye can least read. The other half is not usually plotted because a phase image looks like static — yet it is where the house and the face are. Any claim of the form "these two images have similar spectra, so they are similar images" is a claim about magnitude only, and §11 is the counter-example.
