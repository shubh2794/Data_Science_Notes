Vision Transformers (ViT)

Drop the convolutions: cut an image into fixed-size patches, treat each patch as a token, and feed the sequence to a plain Transformer encoder. At scale, "an image is worth 16×16 words" — ViT matches or beats CNNs and underpins CLIP, modern detectors, and vision-language models.

Deep Learning Computer vision Attention Patches

01 The core idea: an image as a sequence of patches

A Transformer already knows how to model a set of tokens with global attention. Make image patches the tokens and almost nothing else has to change.

CNNs bake in two strong priors — locality (a pixel relates to its neighbors) and translation equivariance (a cat is a cat anywhere). Those priors are what let CNNs learn from modest data. ViT throws most of them away and lets attention learn spatial relationships from data instead. With enough data, that flexibility wins; with too little, the missing priors hurt.

The pipeline in one breath

  1. Split the image into a grid of non-overlapping P×P patches.
  2. Flatten each patch and linearly project it to a D-dim embedding.
  3. Prepend a learnable [CLS] token; add positional embeddings.
  4. Run a standard Transformer encoder (multi-head self-attention + MLP, pre-norm).
  5. Read the final [CLS] representation through an MLP head for classification.
One sentence: ViT = patch embedding → [CLS] + position → vanilla Transformer encoder → linear head. The only vision-specific piece is how you turn pixels into tokens.

The Transformer encoder itself is exactly the one covered under Transformers & Self-Attention and Attention — ViT is best understood as a clever tokenizer bolted onto that machinery.

02 Patchify: how many tokens?

Patch size is the one knob that sets sequence length, compute, and how fine the model can see.

An H×W image with C channels, cut into square patches of side P, yields

N = (H · W) / P²

tokens, each a flattened vector of dimension P²·C. For the canonical setup — a 224×224 RGB image with P = 16 — that's N = (224·224)/16² = 196 patches, each of length 16²·3 = 768, plus one [CLS] token → a sequence of length 197.

Patch embedding = a strided convolution

Each patch is flattened and projected by a shared matrix E ∈ ℝ^{(P²·C)×D}:

z₀ = [ x_class ; x¹ₚ E ; x²ₚ E ; … ; xᴺₚ E ] + E_pos

where xⁱₚ is the flattened i-th patch and E_pos ∈ ℝ^{(N+1)×D} are positional embeddings. Implementation-wise this is identical to a single Conv2d with kernel P and stride P — the only convolution left in the whole model.

The quadratic catch

Self-attention costs O(N²·D). Halving P from 16 to 8 quadruples N and so multiplies attention cost by ~16×. Smaller patches = finer detail but far more compute; this is the central tension the slider below makes concrete.

03 The [CLS] token & positional embeddings

A spare token to aggregate the image, and learned vectors to tell attention where each patch lives.

The classification token

  • A single learnable vector x_class is prepended to the patch sequence. It carries no image content of its own — its job is to accumulate information from all patches via self-attention.
  • After the final encoder layer, only the [CLS] output z⁰_L is fed to the classification head. It's the borrowed-from-BERT trick: one designated slot becomes the whole-image summary.
  • Alternative: global average pooling over all patch tokens works about as well; the [CLS] token is a convention, not a necessity.

Positional embeddings

  • Attention is permutation-invariant — without position, shuffling the patches would give the same output. ViT adds a learnable 1-D position embedding to each token.
  • Standard 1-D learned embeddings beat or tie 2-D and relative schemes in the original study — surprisingly, the model recovers a 2-D grid structure on its own (nearby patches learn similar position vectors).
  • Resolution change: at fine-tuning on larger images, N grows, so the pretrained position embeddings are 2-D interpolated to the new grid — one of the few hand-built priors ViT keeps.

04 The encoder: a standard Transformer

From here it is the textbook encoder — pre-norm, multi-head attention, GELU MLP, residuals.

Each of the L layers applies, with LayerNorm before each sublayer (pre-norm):

z'ₗ = MSA( LN(zₗ₋₁) ) + zₗ₋₁ zₗ = MLP( LN(z'ₗ) ) + z'ₗ

where MSA is multi-head self-attention and the per-token MLP is two linear layers with a GELU in between (hidden width ≈ 4D). The final image / class representation is

y = LN( z⁰_L )
  • Self-attention is softmax(QKᵀ/√d_k)V over the full patch set — every patch can talk to every other patch in one layer, giving a global receptive field from the start (a CNN needs many layers to reach that).
  • Attention distance: empirically, early heads split into local (small attention distance, CNN-like) and global heads; deeper layers attend globally across the whole image.
  • GELU, pre-norm, and residual connections match modern language Transformers — see Residual / Skip Connections for why depth is trainable at all.

06 The data-hunger problem

ViT's weak inductive bias is a double-edged sword: it needs a lot of data to pay off.

  • On ImageNet-1k alone (~1.3M images), ViT underperforms a comparable ResNet — it lacks locality/translation priors and overfits.
  • Pretrained on ImageNet-21k (~14M) it catches up; pretrained on the in-house JFT-300M (~300M images) it beats the best CNNs while costing less to train.
  • The lesson: inductive bias and data are substitutes. CNNs encode priors so they learn from less; ViT learns priors from data, so it needs more — but scales further once you have it.
The original paper's title — "An Image Is Worth 16×16 Words" (Dosovitskiy et al., 2020) — is also its thesis: at sufficient scale, a generic sequence model on patches dethrones bespoke vision architectures.

07 Beating the data hunger: DeiT, hybrids, and friends

A wave of follow-ups made ViT trainable on ordinary datasets and pushed it past CNNs everywhere.

DeiTHeavy augmentation + a distillation token that learns from a CNN teacherTrains on ImageNet-1k only, no giant pretraining

  • DeiT's distillation token works like the [CLS] token but is supervised by a teacher's prediction — see Knowledge Distillation.
  • Swin restores a CNN-like pyramid, making windows the unit of attention so cost grows linearly, not quadratically, with resolution.
  • MAE turns ViT into a masked autoencoder — an image-domain analogue of masked language modeling.

09 Where ViT shows up downstream

The patch-token backbone became the default visual encoder across modern systems.

  • Vision-language & CLIP: a ViT image encoder paired with a text encoder, aligned by contrastive training, powers zero-shot recognition and feeds multimodal vision-language models.
  • Detection & segmentation: ViT/Swin backbones (DETR-style, ViTDet, SAM) replaced CNN feature extractors.
  • Document AI: patch-based vision encoders read page images directly without OCR.
  • Self-supervised features: MAE and DINO ViTs yield strong general-purpose representations transferable with little labeled data — see Fine-Tuning & Transfer Learning.

10 Takeaways

  • Tokens, not pixels. Split the image into P×P patches → N = (H·W)/P² tokens, linearly embed, and run a plain Transformer encoder.
  • Patch size is the master knob. Smaller P → more tokens → finer detail but O(N²) attention cost grows fast.
  • [CLS] + learned positions give a whole-image summary and a sense of where each patch sits; attention itself is order-blind.
  • Weak inductive bias ⇒ data hunger. ViT needs large-scale pretraining (ImageNet-21k / JFT-300M) to beat CNNs; below that, CNN priors win.
  • DeiT, Swin, MAE closed the data gap with distillation, hierarchical local attention, and masked self-supervision.
  • The default visual backbone now — feeding CLIP, detectors, segmenters, document AI, and vision-language models.
